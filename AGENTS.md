# 技術士（化学部門）一次試験 study guide — agent instructions

Load the workspace skill **gijutsushi-study-guide**
(`.codex/skills/gijutsushi-study-guide/SKILL.md`) before doing anything here. It
holds the pipeline, data contracts, repo state and gotchas. This file holds only
standing rules.

## Rules

- `source/` is read-only. Never modify or re-save the docx files.
- `extracted/` and `artifacts/` are generated by the skill scripts. Never
  hand-edit them; fix the script and re-run.
- Hand-edited sources of truth are `content/*.md` (the outline and chapters)
  and the `latex/` templates and figures.
- The objective is passing the exam. Follow the page budget and treatment
  levels in `content/outline.md`. Do not expand coverage beyond it without the
  user's agreement.
- Gap topics stay as headings and stub outlines. Do not fill them from general
  knowledge unless the user asks.
- Keep the 日本語 ↔ 中文 pairing for every chemical name, term and reaction
  name.
- Run Python with `-X utf8`. Do not write files with Windows PowerShell 5.1
  `Set-Content`/`Out-File` (BOM).

## Evolving the repo

When a workflow repeats, fold it into the workspace skill (scripts, references,
assets) following the global **skill-forge** skill. Update the skill's "State of
the repo" table, bump its version and add a CHANGELOG entry. Record decisions in
the skill references or `content/outline.md`, not only in chat.
