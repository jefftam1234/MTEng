### [★] S107　カルボン酸誘導体：反応性序列・相互変換・還元剤の適用範囲


すべて求核アシル置換（四面体中間体経由）。二つの規則で全問対応できる。

規則①：高活性→低活性は自発。低活性→高活性はSOCl₂等で活性化が必要。 　規則②：入ってきた求核剤が生成物を決める——H₂O→カルボン酸、R′OH→エステル、NH₃/RNH₂→アミド。

| 誘導体 | 脱離基 | 共鳴供与 | 反応性 |
|---|---|---|---|
| 酸塩化物 RCOCl | Cl⁻ | ほぼ無 | 最高（水と即反応、白煙HCl） |
| 酸無水物 (RCO)₂O | RCOO⁻ | 弱 | 高 |
| エステル RCOOR′ | RO⁻ | 中 | 中 |
| カルボン酸 RCOOH | OH⁻ | 中 | 中 |
| アミド RCONH₂ | NH₂⁻ | 強 | 低（加熱必須） |
| カルボキシラート RCOO⁻ | — | — | 最低 |

頻出の誤答肢：「酸塩化物 + 水 → エステル」。エステルのR′はアルコール由来でなければならないので、水しかなければ生成物はカルボン酸。原子の出所を追えば即断できる。エステル化には R–COCl + R′OH（HCl中和にショッテン・バウマン法）。

エステルの加水分解は酸性・塩基性の両方で進む。酸性＝可逆（エステル化の逆）、塩基性＝けん化・不可逆（生成カルボン酸が即脱プロトンされカルボキシラートになり再攻撃を受けない）。応用：油脂+NaOH → セッケン+グリセリン。

アミドの加水分解には「加熱」が必須。Nの孤立電子対が強く供与して部分C=N⁺性をもち最も不活性。この安定性がペプチド結合が生体内で保たれる基盤。

|---|---|---|---|
| アルデヒド／ケトン | ✔ | ✔ | ✔ |
| エステル | ✕ | ✔ → 第1級アルコール | ✔ → アルデヒドで停止 |
| カルボン酸 | ✕ | ✔ → 第1級アルコール | — |
| アミド | ✕ | ✔ → アミン（アルコールではない） | ✔ → アルデヒド |

カルボン酸・エステルの還元生成物が必ず第一級アルコールになるのは骨格から自明（COOHの炭素にHが2個ついてCH₂OH）。暗記不要。 　LiAlH₄によるアミド還元はC–Oが切れてC–Nが残るため生成物はアミン。ここを「アルコール」とする選択肢は定番の誤り。 　計量比は第23項A（H24）参照：LiAlH₄ : アルデヒド = 1:4（1:1ではない）。

カニッツァロの典型的な誤り作問：2 PhCHO → PhCOOH ＋ PhCH₂OH（ベンジルアルコール）が正しい。還元生成物をフェノール PhOH と書いた式は、C7 が C6 になっており炭素が脱落しているので誤り。アルデヒドの還元は –CHO → –CH₂OH であって炭素は失われない。機構は、OH⁻ が付加した四面体中間体から第二のアルデヒドへ H⁻（ヒドリド）が移動する。α-H がなくエノール化できないためこの経路しかない。

炭素が減るのが正常な場合＝脱炭酸（罠の裏返し）

マロン酸エステル型（同一炭素上に二つの COOH）は加熱で CO₂ を一つ失う。

PhCHO ＋ CH₂(CO₂Et)₂ →(NaOEt) PhCH=C(CO₂Et)₂ →(H₃O⁺) PhCH=C(COOH)₂ →(−CO₂) PhCH=CH–COOH（ケイ皮酸）

「加水分解 → 脱炭酸」で CO₂Et が一つ消えるのは正しい。これを誤りと判定させるのが定番の罠。同じ論理がマロン酸エステル合成・アセト酢酸エステル合成にも適用される。

重點** **反射動作：看 OsO₄→cis；看 Br₂→trans；看環氧開環→trans；看 O₃→斷環。

環氧開環的兩個細節（避免過度一般化「開環都** anti****」）：**

| 軸 | 基本規則 | 例外／注意 |
|---|---|---|
| 立體 | 親核性開環＝背面進攻(anti) → trans-diol | 酸性＋能穩定正電荷的碳(3°/苄基/烯丙基)會帶 SN1 性格，立體純度下降 |
| 區域 | 鹼/中性：打取代基少的碳（SN2） | 酸性：打取代基多的碳（正電荷密度高）— 兩者剛好相反 |

### [★] S138　アルケンへの付加：syn / anti の二分（中間体の形で決まる）


中間体が三員環なら背面攻撃しかできず anti、五員環または金属表面なら同一面に固定され syn。試薬名を丸暗記せず、中間体の形から導く。

| 反應 | 試薬 | 中間体 | 立体 | 環状基質の結果 |
|---|---|---|---|---|
| 接触水素化 | H₂ / Pt・Pd・Ni | 金属表面に吸着 | syn | cis |
| ヒドロホウ素化-酸化 | BH₃ → H₂O₂/NaOH | 四中心環状遷移状態 | syn（＋反マルコフニコフ） | — |
| ジヒドロキシ化 | OsO₄ → NaHSO₃（または冷希 KMnO₄） | 五員環オスミウム酸エステル | syn | cis-ジオール |
| ハロゲン付加 | Br₂・Cl₂ | 三員環ブロモニウムイオン | anti | trans-ジブロミド |
| ハロヒドリン生成 | Br₂ / H₂O | 三員環ブロモニウム | anti | trans |
| エポキシ化 → 加水分解 | mCPBA → H₃O⁺ | エポキシド（三員環） | anti | trans-ジオール |

cis-ジオールが欲しければ OsO₄、trans-ジオールが欲しければ mCPBA → 酸で開環。この対が最頻の出題点で、両者を入れ替えた誤答肢が必ず置かれる。

二段階反応の立体化学は最後の段階で決まる。エポキシ化そのものは syn だが、開環が anti なので最終産物は trans。エポキシ化の syn に引きずられると誤答する。

エポキシド開環は酸性・塩基性いずれも anti（背面攻撃）。違いは位置選択性のみ：酸性＝置換の多い炭素（正電荷が乗る側）、塩基性＝置換の少ない炭素（純 Sₙ2 で立体障害を見る）。

NaHSO₃（亜硫酸水素ナトリウム）は後処理の還元剤でオスミウム酸エステルを加水分解するだけ。立体化学を変えない。

出處：H30-Q3（關聯：H27-Q2＝ヒドロホウ素化 vs オキシ水銀化）

### [●] S139　アルキンの反応系統：末端アルキンの酸性が起点


pKa: HC≡CH (25) ≪ H₂C=CH₂ (44) <** CH₃CH₃ (50)。sp 炭素は s 性 50% で負電荷を安定化できる。NaNH₂（共役酸 NH₃ の pKa 36）で定量的にアセチリドが生成する。**

| 反應 | 試薬 | 產物 | 要點 |
|---|---|---|---|
| アルキル化 | NaNH₂ → R–X（1級のみ） | 内部アルキン（C–C 結合生成） | Sₙ2。炭素数が増える——ここで検算できる |
| ハロゲン付加 | Br₂ 2当量 | テトラハロアルカン | 4個のハロゲンは元の三重結合炭素2つに集中 |
| 水和（マルコフニコフ） | H₂O / HgSO₄・H₂SO₄ | エノール →互変異性→ ケトン | 末端アルキン → メチルケトン |
| 水和（反マルコフニコフ） | BH₃ → H₂O₂/NaOH | エノール → アルデヒド | 末端アルキンのみ意味を持つ |
| 部分水素化（cis） | Lindlar 触媒（Pd/CaCO₃＋Pb または キノリンで被毒） | cis（Z）-アルケン | 表面 syn 付加（第138項と同一原理） |

当量数の論理：脱 HBr × 2 ＋ 末端 H の引き抜き × 1 ＝ 3当量。内部アルキンを作る場合は酸性水素がないので 2当量で足りる。3当量目はアセチリドとして「鎖の末端に固定」し、強塩基下での内部アルキンへの異性化を防ぐ役目もある。

Lindlar = cis、Na/NH₃ = trans の対は毎年級の頻出。

### [★] S198　苯炔（ベンザイン）機構：生成位置與加成方向


條件：鹵苯＋NaNH₂（或 KNH₂）／液體アンモニア，無拉電子基的鹵苯不能走 S_NAr，改走脫離-付加機構。

### [?] S033　休克爾規則(Hückel’s Rule)：芳香性判斷總整理

### [●] S170　芳香族性：四条件は順番に確認する（[10]アヌレンが失格する理由）


4n+2 は最後の条件。環状・完全共役・平面の三つを満たして初めて Hückel 則を適用できる。

| 順 | 条件 | 崩れる例 |
|---|---|---|
| ① | 環状である | 鎖状ポリエン |
| ② | 環上の全原子が p 軌道を持つ（完全共役） | sp³ 炭素が一つでもあれば失格 |
| ③ | 平面である | [10]アヌレン、シクロオクタテトラエン |
| ④ | π 電子数が 4n+2 | シクロブタジエン（4π・平面 → 反芳香族） |

[10]アヌレン（シクロデカペンタエン）　π 電子は 10 個で 4n+2（n=2）を満たすが平面になれない。

全 cis 形：正十角形にすると内角 144°、sp² の 120° から外れ角ひずみが過大。

trans を含む形（ナフタレンから中央の結合を除いた形）：1 位と 6 位の H が二つとも環の内側を向き衝突する（立体反発）。

よって p 軌道が連続して重ならず非局在化できない。内側 H を CH₂ 架橋に置き換えた 1,6-メタノ[10]アヌレンはほぼ平面で芳香族性を示すことが傍証。ナフタレンは 1 位と 6 位を直接結合で繋いだ形にあたり、同じ問題が解消されている。

π 電子数の数え方

| 環上の原子 | 寄与 |
|---|---|
| C=C の C | 1 |
| C⁺（空の p 軌道） | 0（共役は途切れない）→ トロピリウムは 6π で芳香族 |
| C⁻（孤立電子対が p 軌道） | 2 → シクロペンタジエニルアニオンは 6π で芳香族 |
| ピロール型 N（N–H、孤立電子対が p 軌道） | 2（だから塩基性が弱い） |
| ピリジン型 N（C=N、孤立電子対が sp²） | 1（孤立電子対は環平面内なので塩基性が残る） |
| sp³ 炭素 | 共役が切れる → 即失格 |

ピロールとピリジンの塩基性の差は、窒素の孤立電子対が π 系に使われているかどうかで決まる。

出處：R1再-Q6（關聯：第33項＝Hückel 則の総整理）

### [●] S166　芳香族求電子置換：反応名は「攻撃する側」で決まる


求電子／求核は、攻撃してくる試薬の性質で命名する。基質の側から名付けるのではない。

| 反応 | 攻撃する側 | 名称 |
|---|---|---|
| ベンゼン ＋ Br₂/FeBr₃ | Brᵟ⁺（電子を求める） | 芳香族求電子置換 S_EAr |
| R–X ＋ OH⁻ | OH⁻（電子対を与える） | 求核置換 S_N1／S_N2 |
| アルケン ＋ HBr | H⁺ | 求電子付加 |
| ニトロ置換ハロベンゼン ＋ OH⁻ | OH⁻ | 芳香族求核置換 S_NAr |

S_EAr：環は電子豊富（π 電子を供給する側）。芳香族性のため安定で、アルケンより求電子試薬への反応性に乏しく触媒が要る。

S_NAr：環が電子不足（–NO₂ 等の強い求引基）＋脱離基（–Cl）が必須。条件がまったく違う。

Lewis 酸触媒の役割　FeBr₃、AlCl₃ は空軌道を持ち Br₂ や RCl の孤立電子対を受け取る（電子対受容＝Lewis 酸）。Br–Br⁺–FeBr₃⁻ となって Br–Br が分極し、末端 Br が強い Brᵟ⁺ になる。Lewis 塩基（電子対供与）では逆に電子を押し込むので機能しない。

二置換ベンゼンの配向性の合致点

| 置換基 | 環への効果 | 配向性 |
|---|---|---|
| –COOH、–CHO、–NO₂、–CN、–SO₃H | 不活性化（求引） | メタ |
| –CH₃、–OH、–OR、–NH₂ | 活性化（供与） | オルト・パラ |
| –F、–Cl、–Br、–I | 不活性化するが | オルト・パラ |

p-メチル安息香酸（COOH が C1、CH₃ が C4）の場合：

| 位置 | COOH から | CH₃ から | 判定 |
|---|---|---|---|

### [●] S105　アセタール／チオアセタール：保護基戦略と C=O → CH₂


アセタールが保護基になれる根拠は「酸に不安定・塩基に安定」という非対称性。この酸塩基を入れ替えた記述が定番の誤答肢。

| 項目 | アセタール（O） | チオアセタール（S） |
|---|---|---|
| 生成試薬 | アルコール／ジオール（酸触媒、脱水） | チオール／ジチオール |
| 中間体 | ヘミアセタール | ヘミチオアセタール |
| 酸に対して | 不安定（＝脱保護できる） | 安定 |
| 塩基に対して | 安定 | 安定 |
| 脱保護法 | 希酸水溶液 | HgCl₂/H₂O、酸化剤 |
| 特有用途 | カルボニル保護 | ラネーNiで脱硫 → CH₂ 化、極性転換(アンポール) |

機構的根拠：加水分解はオキソカルベニウム経由。アセタール酸素のプロトン化が起点で、ROH 脱離 → R₂C⁺–OR（共鳴安定化）→ 水付加 → ヘミアセタール → カルボニル。プロトンがなければ開始しない。塩基性では脱離基が RO⁻（極めて悪い脱離基）で進行しない。生成自体が酸触媒平衡なので逆反応も酸触媒——これが最短の推論経路。

保護基としての使い方：カルボニルをエチレングリコールで環状アセタール（1,3-ジオキソラン）化 → グリニャール試薬・LiAlH₄・NaBH₄・強塩基に不活性なまま他部位を反応 → 希酸で脱保護。

チオアセタールの真価＝ラネーNi 脱硫：R₂C=O →(RSH, 酸)→ R₂C(SR)₂ →(ラネーNi, H₂)→ R₂CH₂。C–S が水素化分解されて C–H×2 になる。

C=O → CH₂ の三法比較（頻出）

| 方法 | 試薬 | 条件 | 適用制限 |
|---|---|---|---|
| チオアセタール経由 | RSH → ラネーNi | 中性 | 酸にも塩基にも弱い基質に使える |
| クレメンゼン還元 | Zn(Hg) / 濃HCl | 強酸 | 酸に弱い基質は不可 |
| ウォルフ・キシュナー還元 | H₂NNH₂ / KOH, 加熱 | 強塩基 | 塩基に弱い基質は不可 |

ラネーニッケルの二用途：①水素を吸蔵した多孔質Ni触媒として通常の接触水素化（C=C、C≡N、ニトロ基）②C–S 結合の水素化分解（脱硫）。試薬名の馴染みの薄さで誤答肢と決めつけないこと。

第16項E との関係：H24 では「ヘミアセタール＝還元性あり／アセタール＝還元性なし（トレンス試薬）」を整理済。本項は安定性の酸塩基非対称という別軸。両方が出題実績あり。

出處：H29-Q5（関連：H24＝第16項E の還元性論点）

### [★] S108　R/S配置の判定手順：Hの位置による反転規則


回転方向を読む前に、まず最低優先度（通常H）がどこにあるかを確認する。これが本質。

| Hの位置 | 処理 |
|---|---|
| 破線（奥） | そのまま 1→2→3 を読む（時計回り=R、反時計回り=S） |
| 楔形（手前） | 読んだ結果を反転 |
| 平面（実線） | 破線上の基と1回入替→読んで反転 |

原理：任意の二基の入替1回＝配置反転1回。奇数回なら反転、偶数回なら不変。この一般則を使えば任意の描画に対応できる。

CIP順位則の要点

第一原子の原子番号が大きいほど優先。同点なら外側一層の原子集合を大きい順に並べて対決。 　二重結合・芳香環は複製原子で扱う：C=O は (O,O,C)、芳香環炭素は(C,C,C) と見なす。したがって フェニル基(C,C,C) >** メチル基(H,H,H)、エチル基(C,H,H) ****>**** メチル基(H,H,H)。 　–NH₂(N=7) ****>**** –CO₂H(C on O,O,O) ****>**** –CH₃ ****>**** –H、–OH(O=8) ****>**** –CO₂H ****>**** –CH₃ ****>**** –H** は頻出の順位。

検算に使える既知の配置

| 化合物 | 配置 |
|---|---|
| L-アラニン（天然アミノ酸） | S |
| L-乳酸（筋肉代謝） | S |
| L-システイン | R（SがOより原子番号大で順位が入れ替わる例外） |

紛らわしい概念の区別

| 対 | 相違 |
|---|---|
| R/S vs D/L | R/SはCIPによる絶対配置、D/LはFischer投影での左右。固定した対応関係はない |
| R/S vs (+)/(−) | R/Sは構造記述、(+)/(−)は旋光の実測方向。相互に推論不可 |
| 立体特異的 vs 立体選択的 | 特異的＝一つの立体異性体から一つの立体異性生成物（SN2）／選択的＝一方が優先的に生成 |

出題設計の典型：複数化合物を並べ、紙面上の回転方向を全て同一（例：全て時計回り）にしておき、Hの位置だけを変える。回転方向しか見ない者は全て同じ配置と判定して選択不能になる。

出處：H29-Q7、R1再-Q5

### [●] S169　CIP 順位則の実行手順（比較の作法）


直結する第一原子の原子番号。大きいほうが優先。

同点なら、その原子が持つ 3 原子を大きい順に並べ、最大のものから一つずつ比較。最初に差が出た時点で決着。

なお同点なら、最優先の枝を一段外へ辿って続行。

多重結合は相手原子を複製する（C=O → C は (O,O) を持つ、C≡C → C は (C,C,C) を持つ）。複製原子はそれ以上の原子を持たない（(0,0,0) として扱う）。

合計しない。遠くの重原子も見ない。決着したら即停止。

頻出の比較例

| 比較 | 第一層 | 結論 |
|---|---|---|
| -CO₂CH₃ vs -COCH₃ | (O,O,O) vs (O,O,C) | -CO₂CH₃ |
| -COCH₃ vs -CH₂OCH₃ | (O,O,C) vs (O,H,H) | -COCH₃（どちらも O を含むで止めない） |
| -CH₂Br vs -CN | (Br,H,H) vs (N,N,N) | -CH₂Br（N 三つを足しても無意味） |
| -CH₂Br vs -CH₂CH₂Br | (Br,H,H) vs (C,H,H) | -CH₂Br（相手の Br は第二層で見えない） |
| -SO₃H vs -SO₂CH₃ | S が (O,O,O,O,O) vs (O,O,O,O,C) | -SO₃H |
| -SCH₃ vs -SH | S が (C) vs (H) | -SCH₃ |
| -C₆H₅ vs -C≡CH | 第一層とも (C,C,C)、第二枝 (C,C,H) vs (0,0,0) | -C₆H₅ |
| -C≡CH vs -C(CH₃)₃ | 第二層の最大枝 (C,C,H) vs (H,H,H) | -C≡CH |
| -CH=CH₂ | (C,C,H) | 上記三つより下位 |

炭素系四つの序列（丸暗記可）　-C₆H₅ ＞ -C≡CH ＞ -C(CH₃)₃ ＞ -CH=CH₂ ＞ -CH₂CH₃ ＞ -CH₃

ハロゲンは原子番号順　-I ＞ -Br ＞ -Cl ＞ -F。設問が「左ほど優先順位が高い」と指定していたら、F から並んでいる肢は即誤り。

### [★] S068　酸鹼反應方向判定：pKa 差值決定可行性


酸鹼反應永遠往「生成較弱的酸」方向進行。把反應寫成「左酸+左鹼→右鹼+右酸」，比較兩側酸的pKa：pKa(左酸)<pKa(右酸)則反應可行；反之不可行。

| 判定式 | 內容 |
|---|---|
| 平衡常數估算 | K = 10^(pKa右酸 − pKa左酸) |
| 「十分に起こり得る」門檻 | ΔpKa ≥ +2(K≥10²)，考題通常給到 +10 以上 |
| 反應不可行 | ΔpKa 為負值，逆反應才自發 |
| 化合物 | pKa |
| CH₃COOH 酢酸 | 5 |
| HCN シアン化水素酸 | 9 |
| H₂O 水 / C₂H₅OH エタノール | 16 |
| CH₃COCH₃ アセトン(α-H) | 19 |
| NH₃ アンモニア | 36 |

陷阱：シアン化水素「酸」名字帶酸字，但比酢酸弱4個數量級，無法把酢酸從其鹽中趕出。不可被名稱誤導。

### [・] S070　形式電荷速算法：實際鍵數減正常鍵數


形式電荷** = (****價電子數****) − (****孤對電子數****×2) − (****鍵的數目****)****。等價速算：形式電荷**** = ****實際鍵數**** − ****該元素正常鍵數****(C=4****、****N=3****、****O=2****、鹵素****=1)****。****鍵越多越正，孤對越多越負。**

| 化合物 | 被問原子 | 實際鍵數 | 正常鍵數 | 形式電荷 |
|---|---|---|---|---|
| CO 一酸化炭素 :C≡O: | O | 3 | 2 | +1(碳為−1) |
| HNO₃ 硝酸 | N | 4 | 3 | +1 |
| O₃ オゾン(中心O) | 中心O | 3 | 2 | +1 |
| O₃ オゾン(單鍵端O) | 端O | 1 | 2 | −1 |
| O₃ オゾン(雙鍵端O) | 端O | 2 | 2 | 0 |

題幹若寫「8電子則は常に満たされている」，即禁止價層擴張，每個結構只剩唯一畫法：CO必為三鍵(雙鍵時碳僅6電子違反八隅體)；HNO₃的N不得有5鍵，必為O⁻—N⁺=O。

CO的著名特徵：電負度大的O帶正電、C帶負電，故CO以碳端配位金屬、以碳端與血紅素結合。

陷阱：O₃三個氧角色完全不同，題目指定「中心の酸素」時勿誤填端點氧的−1。中心氧被兩氧夾住必有3鍵→正電。

通則捷徑：中性N有4鍵必定+1(NH₄⁺、硝基−NO₂、胺鹽皆同)。

驗算：全分子形式電荷總和須等於分子總電荷(中性分子為0)。

### [・] S103　結合次数 → 結合長・結合エネルギー・s性の一括判定


一本の判定軸で排序題を片づける：結合次数が大きいほど結合は短く、強い。

| 化合物 | 混成 | s性 | 結合次数 | C–C 結合長 | 傾向 |
|---|---|---|---|---|---|
| エタン | sp³ | 25% | 1.0 | 154 pm | 長・弱 |
| ベンゼン | sp² | 33% | 1.5 | 139 pm | ↕ |
| エチレン | sp² | 33% | 2.0 | 134 pm | ↕ |
| アセチレン | sp | 50% | 3.0 | 120 pm | 短・強 |

ベンゼンが中間に来る理由：π電子6個が環全体に非局在化し、各 C–C は平均1.5重結合。単純平均 (154+134)/2 ≈ 144 pm よりさらに短い 139 pm なのは芳香族安定化の寄与。6本すべて等長であることが単/二重結合の交替が存在しない証拠。

同方向に動く性質（エタン→エチレン→アセチレン）：結合長は短く／結合エネルギーは大きく／s性は増え／C–H の酸性度は強くなる（sp炭素の H が最も酸性、pKa ≈ 25）。

排序題の頻出陥穽：①「結合の長さ」を分子中の C–C の総和や分子の大きさと取り違える（環状のベンゼンが最長になる誤答へ誘導）②不等号の方向（相対関係は正しくても短→長／長→短を逆に書く）。必ず数値を書き出してから問題文の記号に照合すること。

出處：H29-Q2

### [★] S035　NMR基礎：核自旋是偵測的必要條件

### [●] S171　NMR 補遺：信号数・磁気異方性・トピシティ


A　¹³C のシグナル数は「等価でない炭素の種類数」

炭素数をそのまま答えにしない。対称面を探して等価な炭素をまとめる。

p-ブロモアセトフェノン Br–C₆H₄–COCH₃：CH₃／C=O／環 C1／環 C2=C6／環 C3=C5／環 C4 → 8 炭素で 6 本。パラ二置換ベンゼンは C1–C4 を通る対称面を持つ。

B　磁気異方性：アルキニル水素は高磁場

| プロトン | δ（ppm） | 理由 |
|---|---|---|
| アルキニル –C≡C–H | 約 2〜3（高磁場） | 三重結合の円筒状 π 電子の誘起磁場が軸方向で外部磁場と逆 → 遮蔽 |
| ビニル型 =C–H | 約 4.5〜6.5 | 二重結合の平面上は反遮蔽領域 |
| 芳香族 | 約 7〜8 | 環電流による強い反遮蔽 |
| アルデヒド –CHO | 約 9〜10 | 反遮蔽＋電気陰性度 |

sp 炭素の電気陰性度だけで考えると逆に読み違える。磁気異方性の寄与のほうが大きい。

C　核スピンの有無

陽子数・中性子数がともに偶数のときのみ I = 0（¹²C、¹⁶O）。どちらかが奇数なら I ≠ 0。¹H、¹³C、¹⁹F、³¹P はすべて I = 1/2 で観測可能な代表核。「¹⁹F や ³¹P は核スピンを持たない」は誤り。

D　トピシティの判定（D 置換法）

一方の H を D に置き換えた二分子の関係を見る。

| 関係 | 分類 | NMR |
|---|---|---|
| 完全に同一 | ホモトピック | 同じ |
| 鏡像異性体 | エナンチオトピック | 同じ（キラル溶媒でのみ分裂） |
| ジアステレオマー | ジアステレオトピック | 異なる |

エタノールの CH₂ はエナンチオトピックで一組のシグナル。

E　関連する反応の識別（設問で組み合わされる）

メチレンシクロヘキサンのヒドロホウ素化−酸化は逆マルコフニコフでシクロヘキシルメタノール（–CH₂OH が δ 約 3.4、2H）。酸触媒水和はマルコフニコフで 1-メチルシクロヘキサノール（C–O は四級炭素なのでその位置に H がなく、CH₃ 一重線が δ 約 1.2 に出る）。

### [●] S197　紅外光譜（IR）：波數區域・吸收強度・氫鍵


波數由虎克定律決定：ν̃ = (1/2πc)√(k/μ)。鍵越強（k 大）、原子越輕（μ 小）→ 波數越高。

| 區域（cm⁻¹） | 歸屬 | 推理 |
|---|---|---|
| 4000〜2500 | X–H 伸縮（O–H、N–H、C–H） | H 最輕，μ 最小 |
| 2500〜2000 | 三鍵（C≡N、C≡C） | k 最大 |
| 2000〜1500 | 雙鍵（C=O 約 1700、C=C 約 1650） | k 次之 |
| 1500〜400 | 指紋區（指紋領域） | 分子固有圖形，用於比對鑑定 |

### [●] S004　UV-Vis λmax 判斷：共軛長度而非雙鍵總數


核心原則：λmax 由** HOMO-LUMO ****能隙決定；連續共軛的**** ****π**** ****系統越長，能隙越小，****λ****max ****越長（紅移）。**

孤立雙鍵（如 1,4-戊二烯，兩個 C=C 被 sp³ 碳隔開）＝不算共軛，λmax 短，勿被「雙鍵數量多」誤導。

非平面/扭轉結構（如環辛四烯 COT，盆狀）＝共軛因軌域無法有效重疊而中斷，λmax 不會因雙鍵多而特別長。

長鏈多烯（如視黃醇/維生素A，連續5個以上共軛C=C）＝共軛最長，λmax 最大，可達可見光範圍（顯色）。

排序邏輯：連續共軛雙鍵數 越多 → λmax 越大（紅移）。孤立雙烯 < 環狀非共軛/扭轉 < 共軛雙烯 < 長鏈多烯。

### [・] S104　テルペノイドの分類階梯とカロテノイド → 視覚


イソプレン則（ワラッハ則）：テルペンは C₅ のイソプレン（2-メチル-1,3-ブタジエン C₅H₈）単位が頭尾結合して生成。イソペンタン（飽和 C₅H₁₂）ではない——二重結合がなければ連結機構（IPP/DMAPP のカルボカチオン機構）が成立しない。

語尾規則（片假名化合物名の即断法）：-タン = 飽和(-ane)／-テン, -レン = 二重結合(-ene)／-チン, -イン = 三重結合(-yne)。

| 名称 | イソプレン単位数 | 炭素数 | 代表例 |
|---|---|---|---|
| モノテルペン | 2 | C₁₀ | ミルセン、リモネン、ピネン、メントール、樟脳 |
| セスキテルペン | 3 | C₁₅ | ファルネセン、ファルネソール |
| ジテルペン | 4 | C₂₀ | フィトール、レチノール、タキソール |
| トリテルペン | 6 | C₃₀ | スクアレン → ステロール |
| テトラテルペン | 8 | C₄₀ | β-カロテン、リコペン |
| ポリテルペン | 多数 | (C₅)ₙ | 天然ゴム（ポリイソプレン） |

命名の要注意：接頭辞は「イソプレン単位数」ではなく C₁₀ を1単位とする倍数。モノ=C₁₀、ジ=C₂₀、テトラ=C₄₀。「モノ＝イソプレン1個＝C₅」と読むのが最頻の誤り。

精油の主成分がモノテルペン(C₁₀)である理由：揮発性（沸点150〜180℃）。C₂₀ 以上は不揮発で精油成分になり得ない。なお「ミルセン」等は個別化合物名であり、「一群の化合物の名称」を問われたら分類名（総称）で答えること。

β-カロテンの発色：共役二重結合11個 → HOMO–LUMOギャップ小 → 約450 nm（青）を吸収 → 補色の黄橙色。全直鎖のリコペンが赤なのに β-カロテンが橙止まりなのは、両端の環上の二重結合が主鎖と同一平面に乗れず実効共役長が短いため。「緑黄色」は緑黄色野菜からの誘導肢（緑はクロロフィル）。

視覚サイクル：β-カロテン →(小腸で中央開裂)→ レチナール ⇄ レチノール(ビタミンA) → 11-cis-レチナール →(オプシンとシッフ塩基)→ ロドプシン →(光)→ all-trans-レチナール → 神経信号。C11=C12 の cis→trans 光異性化が視覚の分子的基盤。問題文に「11-cis-」が出た時点で答えは視覚。 欠乏症＝夜盲症。

出處：H29-Q4

### [・] S211　直鏈烷烴 vs 支鏈烷烴的物性（同碳數）


直鏈＝細長、接觸面大、易纏繞、易排列 → 沸點・熔點・黏度皆高於支鏈。支鏈不是「卡住流動」，而是使分子緊湊、分子間力變弱。

| 性質 | 比較 | 機制 |
|---|---|---|
| 沸點 | n > iso | 接觸面積大 → 分散力強 |
| 熔點 | n > iso（一般） | 易排列進晶格；例外：新戊烷等高對稱分子 |
| 黏度 | n > iso | 分子間力強＋鏈間纏繞 → 流動阻力大（與沸點同機制） |
| 低溫性 | n 差 | 直鏈析出蠟 → 流動點高（→ 冷凍機油用環烷系，第113項） |

- 比熱：石油類約 2 kJ/(kg·K)，受組成影響小，隨溫度上升而增大。

- 總發熱量（重量基準）：密度越大 → H/C 越低 → 越小；體積基準則相反（第75項）。
