### カルボン酸誘導体の反応性 {S107 S225}

反応性：**酸塩化物 ＞ 酸無水物 ＞ エステル ≈ カルボン酸 ＞ アミド ＞ カルボキシラート**。全部是求核アシル置換（四面体中間体）。決定因素＝**脱離基の良さ ＋ 共鳴供与の強さ**（只用誘起効果判斷 → R4-Q3 失分）。

規則①：高活性 → 低活性は自発；低 → 高は SOCl₂ 等で活性化。規則②：**入ってきた求核剤が生成物を決める**（H₂O → カルボン酸、R′OH → エステル、NH₃ → アミド）。

<!-- cols: X:1.3 c X:0.7 -->
| 敘述（題目語氣） | ◯✗ | 理由 |
|---|---|---|
| 酸塩化物は水と反応してエステルを与える | ✗ | カルボン酸（H29-Q6） |
| エステルの塩基性加水分解（けん化）は不可逆である | ◯ | カルボキシラートは再攻撃されない |
| エステルの酸性加水分解は可逆である | ◯ | エステル化の逆反応 |
| アミドは室温の水で容易に加水分解される | ✗ | N の共鳴供与で最も不活性・加熱必須 |
| LiAlH₄ でアミドを還元するとアルコールを与える | ✗ | アミン（C–N が残る） |

> クライゼン「縮合」（エステル → β-ケトエステル）≠ クライゼン「転位」（[3,3]）。ホフマン「転位」（アミド → アミン）≠ ホフマン「則」（嵩高い塩基 → 置換基の少ないアルケン）。ホフマン／クルチウス／ロッセンは共通中間体イソシアネート R–N=C=O、R 基は立体保持で移動。

> [!key] 「1」「2」の意味（R2-Q1 失分）
> 律速段階に関わる分子数＝速度式の次数。生成物の種類数ではない。E2 も Zaitsev／Hofmann の混合物を与えるので、「主・副生成物がある」では E1／E2 を区別できない。

### 判定マトリクス（基質級數 × 試薬） {S195}

<!-- cols: c X X X -->
| 基質 | 強求核・弱塩基（I⁻ CN⁻ N₃⁻ RS⁻） | 強塩基（OH⁻ RO⁻ RC≡C⁻） | 弱求核・プロトン性溶媒 |
|---|---|---|---|
| 1° | SN2 | SN2（嵩高い塩基は E2） | ほぼ反応せず |
| 2° | SN2 | ==E2== | SN1／E1 混合 |
| 3° | ✗（不可） | E2 | SN1（加熱で E1） |

- カルボニルの β 位に OH・OR ＋ 塩基 → **E1cB**（α-H を先に引抜き → エノラート → 脱離。アルドール縮合の脱水段階）。
- 非プロトン性溶媒（DMSO・DMF・アセトン）は陰イオンを溶媒和しない → 求核性↑ → SN2 有利。
- 溶媒で決まる：KOH／==エタノール== → 脱離（E2）、KOH／==水== → 置換（SN2）。

### アルコール → ハロゲン化アルキル・脱離の向き {S140}

- 塩化チオニル SOCl₂（副生 SO₂＋HCl は気体）、三臭化リン PBr₃（SN2）＝**転位しない**標準法。HX は 2°・3° で転位の危険。ルーカス試薬（HCl／ZnCl₂）で級数判別。
- ウィリアムソンエーテル合成：アルコキシドは嵩高くてよいが、ハロゲン化物は ==1級==。t-ブチルエチルエーテル ＝ t-BuONa ＋ ブロモエタン（逆は E2）。
- ザイツェフ則：置換基の多いアルケンが主（2-ブロモブタン ＋ NaOEt → 2-ブテン）。ホフマン則：嵩高い塩基（t-BuOK・LDA）・第4級アンモニウム → 末端アルケン（R7-Q4）。
- グリニャール試薬はアリールハライドからも作れる（SN1・SN2 はできないのに）。微量の水で R–H に分解 → 無水必須。

### 速度支配 vs 熱力学支配（R5-Q3 失分） {S237}

```chem
$\ce{CH2=CH-CH=CH2 ->[HBr]}\ \underset{\text{1,2-付加（0 ℃ 主）}}{\ce{CH3-CHBr-CH=CH2}}\ +\ \underset{\text{1,4-付加（40 ℃ 主）}}{\ce{CH3-CH=CH-CH2Br}}$
```

| 條件 | 可逆性 | 支配因子 | 主生成物 |
|---|---|---|---|
| 低温（0 ℃） | 不可逆 | 活性化エネルギー＝速度支配 | 1,2-付加体 |
| 高温（40 ℃） | 可逆・平衡 | 生成物の安定性＝熱力学支配 | 1,4-付加体（内部二置換アルケン） |

- 共通のアリルカチオン中間体 → 生成比は反応物の組成と無関係。題文に「平衡の支配」→ 熱力学支配。
- 反応名は**攻撃する試薬**で決まる：C=C・ベンゼン ＋ 求電子剤 → 求電子付加／置換；C–X・C=O ＋ 求核剤 → 求核置換／付加。

## 1.3 付加反応（アルケン・アルキン） {F03 S138 S258 T069 S240 S139 S034}

### syn／anti は中間体の形で決まる {S138 F03}

<!-- cols: X:0.95 X:1.1 X:0.95 c X:0.6 -->
| 反応 | 試薬 | 中間体 | 立体 | 環の結果 |
|---|---|---|---|---|
| 接触水素化 | H₂ / Pt・Pd・Ni | 金属表面 | syn | cis |
| ヒドロホウ素化-酸化 | BH₃ → H₂O₂ / NaOH | 四中心遷移状態 | syn | — |
| ジヒドロキシ化 | OsO₄ → NaHSO₃ | 五員環エステル | syn | cis-ジオール |
| ハロゲン付加 | Br₂・Cl₂ | 三員環ブロモニウム | anti | trans |
| エポキシ化 → 加水分解 | mCPBA → H₃O⁺ | エポキシド | anti | trans-ジオール |

> [!key] 反射動作
> 三員環中間体 → 背面攻撃しかできない → **anti**；五員環・金属表面 → **syn**。二段階反応は**最後の段階**で決まる（エポキシ化自体は syn だが開環が anti → trans）。cis-ジオールなら OsO₄、trans-ジオールなら mCPBA → 酸。エポキシド開環は酸性・塩基性とも anti；違うのは位置だけ（酸性＝置換の多い炭素、塩基性＝少ない炭素）。

## 1.4 芳香族 {S170 S033 S166 S260 S281 S207 S198 T073 S039 T072}

### 芳香族性：四条件を順番に {S170 S033}

① 環状 → ② 環上の全原子が p 軌道（完全共役；sp³ が一つでも失格）→ ③ 平面 → ④ π 電子数 4n＋2（4n で平面なら反芳香族）。

| 環上の原子 | π 電子の寄与 |
|---|---|
| C=C の炭素 | 1 |
| C⁺（空の p 軌道） | 0 → トロピリウムカチオン 6π：芳香族 |
| C⁻（孤立電子対） | 2 → シクロペンタジエニルアニオン 6π：芳香族 |
| ピロール型 N（N–H） | 2 → 孤立電子対は π 系に使用 → 塩基性ほぼなし |
| ピリジン型 N（C=N） | 1 → 孤立電子対は sp²・環外 → 塩基性あり |

- シクロブタジエン：4π → 反芳香族。シクロオクタテトラエン：桶形で非平面 → 非芳香族。
- [10]アヌレン：10π でも内側 H の衝突で平面になれず ✗（R1再-Q6）。ナフタレン・アズレンは 10π 芳香族。

### R／S の判定手順（R4-Q4 失分） {S108 S169}

| 最低順位（H）の位置 | 処理 |
|---|---|
| 破線（奥） | 1→2→3 をそのまま読む（時計回り＝R） |
| くさび（手前） | 読んだ結果を==反転== |
| 紙面上（実線） | 破線上の基と 1 回入れ替え → 読んで反転 |

## 1.7 酸・塩基・電子効果 {S068 S209 S239 S225 T071 S142 S070 S103}

### pKa で反応の向きを決める {S068}

酸塩基反応は**弱い酸ができる向き**に進む。左の酸の pKa ＜ 右の酸の pKa なら進行；$K = 10^{\Delta \mathrm{p}K_\mathrm{a}}$。

|---|---|---|---|
| CF₃COOH | 0.2 | 水 H₂O | 15.7 |
| 酢酸 CH₃COOH | 4.8 | エタノール | 16 |
| フェノール | 10.0 | アセトン（α-H） | 19 |
| シアン化水素 HCN | 9.2 | アセチレン | 25 |
| NH₄⁺ | 9.2 | NH₃ | 36 |

> [!trap] 名前に「酸」
> シアン化水素「酸」は酢酸より 4 桁弱い → 酢酸ナトリウムから酢酸を追い出せない。NaNH₂（36）はアセトン（19）を定量的にエノラートにする（ΔpKa ＝ +17）。

### 強弱の序列（R3-Q5・R5-Q5） {S209 S239 T071}

| 系列（左が強い） | 序列 | 判断軸 |
|---|---|---|
| フェノール類の酸性 | ピクリン酸 ＞ p-ニトロフェノール ＞ フェノール ＞ ==p-クレゾール== | NO₂ は求引、CH₃ は供与で酸性↓ |
| フッ素置換酢酸 | CF₃ ＞ F₂CH ＞ FCH₂ ＞ CH₃COOH | −I の数 |
| 窒素塩基 | グアニジン ＞ ジイソプロピルアミン ＞ ピリジン ＞ ==ピロール== | ピロールの孤立電子対は芳香族 6π に使用 |
| 陰イオンの塩基性 | CH₃⁻ ＞ NH₂⁻ ＞ OH⁻ ＞ NH₃ | 同周期の電気陰性度 |
| 水素化物の酸性 | HF（3.2）＞ H₂S（7.0）＞ H₂O ＞ NH₃ | HF と H₂S は数値で覚える |
| p-置換安息香酸 | NO₂（3.44）＞ CN ＞ CF₃ ＞ Cl（3.98）＞ F ＞ H（4.20）＞ CH₃ ＞ OCH₃ ＞ NH₂ | Hammett σₚ |

- F の σₚ ≈ 0（−I と +R が相殺）。m 位は共鳴が効かない → m-クロロ安息香酸は p- より酸性（H27-Q4）。
- 求引基が安定化するのは**陰イオン**（→ 酸性↑）；陽イオン（アミニウム）は供与基が安定化（→ 塩基性↑）。p-置換アニリンの塩基性：OCH₃ ＞ CH₃ ＞ H ＞ Cl ＞ NO₂（R2-Q5 失分：方向を逆にした）。

### 電子効果の三つの枠組み（R4-Q3） {S225 S142}

| 枠組み | 伝わる経路 | 規則 |
|---|---|---|
| 誘起効果 | σ 結合 | 電気陰性度が大きく数が多いほど強い；距離で急減 |
| 共鳴効果 | π 共役 | 誘起と逆向きなら共鳴が勝つ（ハロゲンは例外） |
| 脱離基 | 結合開裂で電子対を持ち去る | 共役酸が強い（pKa 小）ほど良い：TfO⁻ ＞ I⁻ ＞ Br⁻ ＞ TsO⁻ ≈ Cl⁻ ＞ H₂O ≫ F⁻ ＞ HO⁻・RO⁻ |

アミンの塩基性：脂肪族アミン（pKaH ≈ 10.7）＞ NH₃（9.3）≫ アニリン（4.6、孤立電子対が環と共役）≫ アミド（≈0）。「アニリンは活性化基」と「アニリンは弱塩基」は同じ理由 ― 片方 ◯ ならもう片方の「強塩基」は ✗。

### 形式電荷・結合次数 {S070 S103}

- 形式電荷 ＝ 実際の結合数 − 通常の結合数（C 4、N 3、O 2、ハロゲン 1）。CO の O ＝ +1（C は −1）、HNO₃ の N ＝ +1、O₃ の中心 O ＝ +1（H28-Q3 ＝ R4-Q7）。中性で 4 本結合の N は必ず +1。
- C–C 結合長：アセチレン 120 ＜ エチレン 134 ＜ ==ベンゼン 139== ＜ エタン 154 pm（結合次数 3 ＞ 2 ＞ 1.5 ＞ 1；H29-Q2 ＝ R2-Q4）。結合エネルギー・s 性・C–H 酸性度は逆順に大きい。不等号の向きを最後に照合。

## 1.8 構造解析（NMR・IR・UV・MS） {S035 S171 S069 S197 S004 S227 S256 S259 S020}

### NMR（R5-Q7 失分 ＝ R1再-Q7 の重複題） {S035 S171 S069}

- 核スピン：陽子数・中性子数がともに偶数のときだけ I ＝ 0（¹²C、¹⁶O は観測不可）。¹H・¹³C・¹⁹F・³¹P は I ＝ 1/2。「¹⁹F・³¹P は核スピンをもたない」✗。
- 化学シフト δ（ppm）＝ 周波数差（Hz）÷ 装置周波数（MHz）→ 磁場に依存しない。内部標準 TMS ＝ 0。**低磁場 ＝ δ 大**。
- n＋1 則：CH₃CH₂Br の CH₃ は三重線、CH₂ は四重線。
- ¹³C のシグナル数 ＝ 等価でない炭素の**種類**の数：p-ブロモアセトフェノン 8C → 6 本。
- トピシティ：エナンチオトピック（エタノールの CH₂）は同じシフト；ジアステレオトピックだけが分裂。

| プロトン | δ（ppm） | 理由 |
|---|---|---|
| アルデヒド –CHO | 9〜10 | 反遮蔽 ＋ 電気陰性度 |
| 芳香族 | 6.5〜8.5 | 環電流による反遮蔽 |
| ビニル =C–H | 4.5〜6.5 | |
| アルキニル ≡C–H | ==2〜3（高磁場）== | 三重結合の磁気異方性で遮蔽 |
| アルキル | 0.9〜2.5 | |

> [!trap] アズレン（H28-Q2・R3-Q6 で二回失分）
> 「炭化水素なのに有色（可視吸収）・双極子モーメント ≈ 1.0 D・全 H が δ 6.5〜8.5」＝ **アズレン**（青色、五員環 ＋ 七員環、10π）。ナフタレン・フェナントレンは無色。フェニルアセチレン（≡C–H δ 3.1）やスチレン（ビニル H）は δ 範囲外で失格。

### IR・UV・MS {S197 S004 S227 S259}

| 波数（cm⁻¹） | 帰属 |
|---|---|
| 4000〜2500 | X–H 伸縮（O–H・N–H・C–H） |
| 2500〜2000 | 三重結合（C≡N・C≡C） |
| 2000〜1500 | 二重結合（C=O ≈ 1700、C=C ≈ 1650） |
| 1500〜400 | 指紋領域 |

- 波数：結合が強く原子が軽いほど高い。**吸収強度 ∝ 双極子モーメント変化**（「双極子が大きいほど弱い」✗）；対称伸縮・N₂・O₂ は IR 不活性 → ラマン。
- 水素結合 → 低波数シフト ＋ 幅広。1級アミンの N–H は 2 本（非対称 ≈ 3450 ＞ 対称 ≈ 3350）、2級は 1 本。
- UV-Vis：**連続した共役**が長いほど λmax が長い（赤方移動）。孤立ジエン（1,4-ペンタジエン）・アレン（π 結合が直交）・非平面 COT は共役にならない（R4-Q5 失分）。
- MS：マクラファティ転位は C=O から γ 位の H が六員環で移動；MALDI-TOF はソフトイオン化でタンパク質・高分子の分子量。
- 電磁波 → 対象：X 線＝内殻電子（XPS・XRF）／紫外可視＝価電子／赤外＝分子振動／マイクロ波＝回転／ラジオ波（磁場中）＝核スピン（NMR）。

## 1.9 天然物・物性 {S073 S104 S001 S002 S211}

| タンパク質の構造 | 維持する力 |
|---|---|
| 一次構造（アミノ酸配列） | ペプチド（アミド）結合 |
| 二次構造（α ヘリックス・β シート） | 主鎖 C=O···H–N の==水素結合== |
| 三次・四次構造 | 疎水性相互作用・イオン結合・ジスルフィド結合 S–S |

「立体構造」＝二次以上 → 答えは水素結合（アミド結合ではない）。S–S は三次構造（二次ではない）。変性で一次構造は壊れない。天然アミノ酸は L 型（グリシンは不斉炭素なし）。

- テルペン：イソプレン（C₅H₈）の頭尾結合。モノテルペン ＝ ==C₁₀==（イソプレン 2 個）、セスキ C₁₅、ジ C₂₀、トリ C₃₀（スクアレン）、テトラ C₄₀（β-カロテン：黄橙色 → レチナール → 視覚、11-cis）。「モノ ＝ C₅」✗。
- 糖：炭水化物 ＝ ポリヒドロキシカルボニル化合物。アルドース／ケトース、ヘミアセタール（還元性あり）／アセタール（なし）、アノマー（変旋光で平衡）／エナンチオマー。用語の入れ替えが陷阱。
- 溶媒の二層：クロロホルム（1.49）は**下層**、ジエチルエーテル・トルエンは上層、アセトン・エタノール・THF・DMSO は水と混和。
- 融点は対称性（ベンゼン 5.5 ℃ ＞ トルエン −95 ℃）、沸点は分子間力（トルエン 111 ℃ ＞ ベンゼン 80 ℃）。同炭素数なら直鎖 ＞ 分枝（沸点・粘度）。
