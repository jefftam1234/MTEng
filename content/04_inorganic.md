## 4.1 元素・化合物 {S180 S054 S090 S017 F13 T092 S123 S055 S053 S022 T088}

### 酸化物の酸塩基性（R1再-Q21・R7-Q23） {S180 S054}

| 元素 | 酸化物 | 例 |
|---|---|---|
| 金属性が強い（左下） | 塩基性 | Na₂O、K₂O、CaO、MgO、BaO |
| 境界の対角帯 | ==両性== | Al₂O₃、ZnO、SnO₂、PbO、BeO、Cr₂O₃ |
| 非金属（右上） | 酸性 | CO₂、SO₃、P₄O₁₀、SiO₂、B₂O₃、SeO₃ |

- 両性金属は「ああ、すんなり」＝ **Al・Zn（亜鉛）・Sn・Pb**（＋Be、Cr(III)）。強塩基で錯イオン：\ce{Al2O3 + 2NaOH + 3H2O -> 2Na[Al(OH)4]}。
- 同一元素では**酸化数が高いほど酸性**：CrO（塩基）→ Cr₂O₃（両性）→ CrO₃（酸性）；MnO → Mn₂O₇（酸性）。
- 「金属酸化物」と書いてあっても Se・S・P・C などの非金属が混ぜてある → 無条件に酸性。SiO₂ は酸性（塩基とケイ酸塩）。
- ガラス：網目形成体（SiO₂・B₂O₃・P₂O₅）＝酸性、中間体 Al₂O₃ ＝両性、修飾体（Na₂O・CaO）＝塩基性。スラグ塩基度 ＝ CaO/SiO₂。

## 4.2 無機工業・金属製錬 {S231 S120 S125 S092 S182 T094 S056}

### 金属製錬は活性度で決まる（R4-Q21 失分） {S231 S120}

| 活性度 | 金属 | 方法 |
|---|---|---|
| 最も活性（==K Ca Na Mg Al==） | | ==溶融塩電解==（水溶液では H₂ が先に出る） |
| 中程度 | Zn・Fe・Sn・Pb | 硫化物を焙焼 → 酸化物 → C・CO 還原；Zn・Ni は水溶液電解も可（水素過電圧が大きい） |
| 酸化物が極めて安定 | V・Cr・Mn・Ti | より活性な金属で還元：テルミット法（Al）、クロール法（TiCl₄＋Mg） |
| あまり活性でない | Cu・Hg・Ag | 硫化物を空気中で加熱 → 金属（HgS、Ag₂S）；Cu は電解精製 |
| 貴金属 | Pt・Au | 比重選鉱（自然金属） |

| 金属 | 溶融塩電解 |
|---|---|
| Al | ==ホール・エルー法==：Al₂O₃ を氷晶石 Na₃AlF₆ に溶かし ≈960 ℃ |
| Na | ダウンズ法：NaCl＋CaCl₂（融点降下）≈600 ℃ |
| Mg | MgCl₂ ≈700 ℃（現在は熱還原のピジョン法も） |

方法が弱すぎても ✗、貴金属に炭素還元のような余計な方法も ✗。「H より卑だから H₂ しか出ない」は Zn で破れる（過電圧）。

### ソーダ工業・バイヤー法（H29-Q25） {S125 S092 S182 T094 S056}

| 製品 | 製法 | 要點 |
|---|---|---|
| NaOH・Cl₂・H₂ | 食塩電解（現行は==イオン交換膜法==） | 陽極 2Cl⁻ → Cl₂、陰極 2H₂O → H₂＋2OH⁻（Na は出ない、O₂ も出ない）；NaOH と Cl₂ が一定比で出る「バランス産業」 |
| Na₂CO₃（ソーダ灰） | ソルベー法（アンモニアソーダ法） | NaCl＋NH₃＋CO₂＋H₂O → NaHCO₃↓＋NH₄Cl；加熱 → Na₂CO₃；NH₃・CO₂ は循環、副生物は CaCl₂ |
| アルミナ | ==バイヤー法== | ボーキサイトを **NaOH** で溶解（両性を利用）→ Fe₂O₃（赤泥）を分離 → Al(OH)₃ 析出 → 焼成 |
| NH₃ | ハーバー・ボッシュ法 | Fe 系触媒、高圧・中温 |
| H₂SO₄／HNO₃ | 接触法（V₂O₅）／オストワルト法（Pt–Rh） | — |
| HCl | H₂＋Cl₂ の直接合成 | 「NaOCl の還元」✗ |
| 高純度 Si | 帯域融解（偏析 k ＜1）、単結晶は CZ・FZ | — |

- 食塩電解の三法：水銀法（水俣病で全廃）、隔膜法（石綿、NaOH 純度低）、イオン交換膜法（Na⁺ のみ透過、日本が先導）。「水銀法で炭酸ソーダ」✗（電解槽に炭素源がない）。毒性では判定しない。
- バイヤー法で硫酸 ✗：Fe₂O₃ も溶けて分離できない。ホール・エルー法（アルミナ → 金属 Al）と混同しない。
- ソーダ灰 Na₂CO₃ ／苛性ソーダ NaOH ／重曹 NaHCO₃（ソルベー法の中間体）。
- 含塩素オキソ酸：過塩素酸 +7 ＞ 塩素酸 +5 ＞ 亜塩素酸 +3 ＞ 次亜塩素酸 +1。

### X 線・単結晶 {S185 S252 S251}

- X 線の透過：**波長が短いほど、原子番号が小さいほど、薄いほど**よく透過（質量吸収係数 ∝ Z³〜Z⁴；Pb は遮蔽材）。「原子番号が大きいほど透過」✗。

## 4.4 セラミックスの製造・熱伝導 {S218 S156 S157 S216 S274 S277 S276 S278}

### 焼結（R7-Q28・H30-Q22） {S218 S156}

| 焼結法 | 加圧 | 特徴 |
|---|---|---|
| 常圧焼結 | なし | 量産・複雑形状、助剤が必要（粒界にガラス相） |
| ホットプレス | 一軸（黒鉛型） | ==低温で緻密化 → 粒成長抑制==・高純度・配向が生じる；形状制限・量産性低 |
| HIP | 等方ガス圧 | 閉気孔をつぶす（開気孔があると不可 → 先に常圧で閉気孔化） |
| SPS | 一軸＋パルス通電 | 数分で緻密化 |

- 「ホットプレスは低温で緻密化できるが粒成長は抑制できない」✗（低温なら粒成長も自動的に抑えられる）。
- 物質移動：表面拡散・蒸発凝縮は**ネック成長のみ（収縮しない）**；体積拡散・粒界拡散・溶解析出・粘性流動は収縮（緻密化）。三段階：初期（相対密度 50〜60%）→ 中期（連続気孔・粒成長）→ 終期（孤立気孔、95% 以上）。異常粒成長は終期。
- 前処理：酸化物粉は極性溶媒（水）に分散；分散は静電反発（ゼータ電位）＋立体障害；乾式プレスでもバインダー（PVA）は必要；脱脂不足は高温でも緻密化しない（R3-Q23）。
- 成形：鋳込み（吸水性の石膏型）／射出（金型・熱可塑性バインダー・脱脂必須）／押出（ハニカム）／ドクターブレード（グリーンシート）。
- 原料調製：噴霧乾燥（球状顆粒）、凍結乾燥（昇華・毛管力なし）、ゾル-ゲル、共沈、火炎加水分解（SiCl₄ → ヒュームドシリカ・光ファイバ母材）。
- 機械的性質：弾性率 ＝ 応力/ひずみ（逆は ✗）；ビッカース（四角錐、荷重/表面積）、ヌープ（菱形、投影面積）、モース（ひっかき 1〜10）；ワイブル係数 m 大 ＝ ばらつき小。細孔：ミクロ ＜2 nm ≤ メソ ≤ 50 nm ＜ マクロ；BET（N₂、77 K）で比表面積、水銀圧入でマクロ孔。

### 絶縁性セラミックスの熱伝導（R3-Q21 失分） {S216 S274}

絶縁体はフォノンで熱を運ぶ：κ ≈ (1/3)·C·v·**l**（l ＝平均自由行程）。

| 要因 | κ |
|---|---|
| 高温（フォノン散乱、κ ∝ 1/T） | ↓ |
| 多孔質（空気＋界面散乱） | ↓（断熱れんが） |
| 不純物・固溶（AlN 中の酸素） | ↓ |
| 非晶質（ガラス：石英結晶 ≈10 vs 石英ガラス 1.4 W/(m·K)） | ↓ |
| 高純度・緻密・軽元素の強い結合 | ↑（ダイヤモンド・AlN・SiC・BeO） |

回路基板：==AlN（150〜200 W/(m·K)）≫ Al₂O₃（20〜30）==（逆にした肢 ✗；H24-Q24）。

### 薄膜：PVD と CVD（R3-Q24） {S157 F13}

| 手法 | 粒子エネルギー | 機構 | 密着性 |
|---|---|---|---|
| 真空蒸着（抵抗・電子ビーム加熱） | 0.1〜1 eV | 加熱蒸発 | 低 |
| スパッタリング | 1〜10 eV | Ar⁺ がターゲットを叩き出す（運動量交換；組成ずれ少） | 中〜高 |
| イオンプレーティング | 10〜1000 eV | 蒸発 → イオン化 → **負バイアスで加速**して打ち込み | 最高 |
| MBE | ≈0.1 eV（熱） | 超高真空の分子線、原子層制御のエピタキシー | — |

PVD は物理（反応なし・低温・段差被覆性が劣る）；CVD は気体原料の**化学反応**（高温・段差被覆性良）。「反応を利用」＝CVD。「MBE は高エネルギー粒子」✗。

| 黒鉛 | 散乱断面積大・吸収小 | 原子炉の減速材（制御棒は吸収大の Cd・B） |
| 二水石膏 CaSO₄·2H₂O | C₃A の瞬結を遅らせる | セメントの凝結調整（無水石膏 ✗） |

- **NTC**（温度↑ → 抵抗↓：Mn・Co・Ni 酸化物）＝温度センサ；**PTC**（↑ → ↑）だけがヒーターになれる（負帰還）。「PTC の T は湿度」✗。
- 包含関係：圧電体 ⊃ 焦電体 ⊃ 強誘電体（水晶は圧電だが焦電でない）。焦電センサは温度**変化**にしか反応しない。
- 効果 ↔ 応用：マイスナー＝磁気浮上・MRI（超音波探傷 ✗）、ゼーベック＝熱 → 電気、ペルティエ＝電子冷却、本多・藤嶋＝光触媒。
- サイアロン：β ＝ 置換型固溶、α ＝ さらに侵入型固溶。hBN は層状で潤滑・易切削、cBN は超高圧合成で鉄系の切削。

### TiO₂（H25-Q22・R7-Q25） {S019 S183}

- 光触媒（本多・藤嶋効果）：紫外線（< 388 nm）で電子・正孔 → •OH → 有機物分解・抗菌；超親水性（防曇・セルフクリーニング）。**アナターゼ**（3.2 eV）が高活性、**ルチル**（3.0 eV）は白色顔料。金属 Ti は光触媒にならない。
- 白い理由：λ ＝ 1240/Eg ＝ 388〜413 nm で可視光を吸収しない＋屈折率 ≈2.7（最高）→ 隠ぺい力最大。製法：硫酸法（イルメナイト）・塩素法（TiCl₄）。
- 顔料の色：ZnO（亜鉛華）白、PbO 黄、Pb₃O₄ 赤、鉛白 白、黒色顔料＝カーボンブラック・Fe₃O₄。ルビー＝Al₂O₃＋Cr³⁺（赤）、サファイア＝Al₂O₃＋Fe²⁺/Ti⁴⁺（青）。

### 半導体（R4-Q24・R7-Q22） {S093 S232}

| | 金属 | 半導体 |
|---|---|---|
| キャリア数 | 多く一定 | 熱励起で指数的に増加 n ∝ exp(−Eg/2kT) |
| 温度↑の電気伝導率 | ==低下==（格子散乱） | ==上昇== |

- Si（14 族）に 15 族（P・As・Sb）→ ドナー → **n 型**；13 族（B・Al・Ga）→ アクセプター → **p 型**（「リンは P だから p 型」✗）。真性半導体は電子数＝正孔数。導電率は温度に依存し湿度には依存しない。
- Eg：Ge 0.66 ＜ Si 1.12 ＜ GaAs 1.42 ＜ GaN 3.4 ＜ ダイヤモンド 5.5 eV。構造：Si・Ge ダイヤモンド型、GaAs 閃亜鉛鉱型、GaN ウルツ鉱型。

### レーザー（H29-Q26） {S126}

- 誘導放出の光子は入射光子と**波長・位相・方向・偏光がすべて同一**（1 → 2、増幅）。波長は λ ＝ hc/ΔE で**媒質の準位差だけ**で決まる（「入射光のエネルギーで変わる」✗）。
- 増幅には**反転分布**（熱平衡では不可能 → ポンピング）。二準位系では不可能、三準位（ルビー）は効率低、四準位（Nd:YAG）が主流。
- 例：ルビー 694 nm（初のレーザー、1960）、He-Ne 633 nm、Nd:YAG 1064 nm、CO₂ 10.6 μm、エキシマ KrF 248／ArF 193 nm（リソグラフィ）。

## 4.6 電気化学・コロイド {F12 S087 S120 S088 S089 S016 T093 F21 S058}

### 電極の鉄則 {S016 T093}

**アノード ＝ 酸化、カソード ＝ 還元**（電池でも電解でも不変）。＋／−が逆転するだけ：電解ではアノード＝＋極、電池ではアノード＝−極。

- 電解槽電圧 ＝ 理論分解電圧（熱力学、ΔG ＝ −nFE）＋ 過電圧（速度論）＋ IR 損（溶液抵抗）。水の理論分解電圧 1.23 V、実際は 1.8〜2.0 V。標準水素電極電位や整流器内部抵抗は槽電圧の構成要素ではない。
- 電流効率 ＝ 実際の生成量 / 理論生成量（物質量の比）；電圧効率 ＝ 理論電圧 / 印加電圧。

### ファラデーの電気分解の法則（計算・H28-Q20） {F12 S087}

| 段階 | 式 | 例（1000 A・1 h・効率 80%・MgCl₂） |
|---|---|---|
| ① 電気量 | Q ＝ I·t（秒）× 効率 | 3.6×10⁶ × 0.80 ＝ 2.88×10⁶ C |
| ② 電子の mol | Q / F（F ＝ 96 485 C/mol） | 29.8 mol |
| ③ 物質の mol | ÷ ==価数 z== | Mg：29.8/2 ＝ 14.9 mol |
| ④ 質量 | × モル質量 | Mg ≈360 g、Cl₂（==71==）≈1060 g |

③の価数割り（Mg²⁺ は 2、Al³⁺ は 3）と Cl₂ の分子量 71 が二大脱落点（Mg を 1 価で 720 g が誤答肢）。検算：Mg 1 mol に Cl₂ 1 mol。

### 電池 {S088 S058 F21}

- 一次電池（使い切り）／二次電池（充電可：鉛蓄電池・Ni-MH・Li イオン）／燃料電池（外部から燃料を供給し続ける開放系 → 「充電」しない）。
- リチウムイオン電池：負極＝==黒鉛==（LiC₆、インターカレーション；白金 ✗）、正極 LiCoO₂・LiMn₂O₄（スピネル）・LiFePO₄（オリビン）、電解液＝**有機溶媒**＋LiPF₆（3.7 V は水の電位窓 1.23 V を超える）。金属 Li 負極はデンドライトで短絡するので使わない。Li の E° ＝ −3.04 V（最も卑）、理論容量 3860 mAh/g。
- 鉛蓄電池の電解液は希硫酸（塩酸 ✗）；マンガン乾電池の正極活物質は MnO₂（炭素棒は集電体）。
- 酸素センサ＝濃淡電池：YSZ 電解質＋Pt 電極、ネルンスト式 E ＝ (RT/4F) ln(p₁/p₂)（分圧の**比**であって差ではない）。Nafion は H⁺ 伝導膜（PEFC）。

### コロイド（H28-Q22） {S089}

| 分散媒＼分散相 | 気体 | 液体 | 固体 |
|---|---|---|---|
| 気体 | — | エアロゾル（霧） | エアロゾル（煙） |
| 液体 | フォーム（泡） | ==エマルション==（牛乳・マヨネーズ） | サスペンション（泥水・墨汁） |
| 固体 | 固体フォーム（発泡スチロール） | ゲル（寒天） | 色ガラス・合金 |

- エマルション＝**液体/液体**（牛乳の白は油滴の光散乱）。O/W（牛乳・マヨネーズ、水で薄まる）／W/O（バター）。乳化剤で安定化。
- 疎水コロイドは少量の電解質で**凝析**、親水コロイドは多量の電解質で**塩析**（天然ゴムラテックスは蛋白質に覆われた保護コロイド → 塩析）。
- 浸透圧（逆浸透の海水淡水化）：水は化学ポテンシャルの低い海水側へ；海水 π ≈ 0.6 mol/L × 2 × RT ≈ 3 MPa（解離後の粒子数、T は K）。
