# 高分子 | 問15〜問21 ・ 過去失分率 70% ・ 最弱項

> [!key] 本章用法
> 高分子題幾乎都是「語句組合せ」或「最も不適切」。五格填空**不必全會**：先填最有把握的兩格就能鎖定選項（H28-Q6、H28-Q15 的解法）。但 R5-Q15 教訓：**名稱字面常就是答案**（エラストマー＝elastic → 「弾性」）。

## 2.1 重合形式の分類 {F07 S082 S271 S148 S249 S204 S116 S011 S086 S046}

### 連鎖重合 vs 逐次重合 {S082 F07}

<!-- cols: X:0.8 X:1.1 X:1.1 -->
| 比較軸 | 連鎖重合（付加重合・開環重合） | 逐次重合（重縮合・重付加） |
|---|---|---|
| つながる仕組み | C=C の開裂・環の開裂 | 両末端の官能基どうし |
| 重合開始剤 | 必要（ラジカル・カチオン・アニオン） | 不要 |
| 活性種 | 鎖末端に存在 | なし |
| 分子量 vs 反応率 | ==反応率が低くても高分子量== | 反応率が極めて高くなって初めて高分子量 |
| 系内 | 完成した長鎖＋未反応モノマー | 二量体・三量体…が一緒に成長、モノマーは早期に消失 |
| 例 | PE・PS・PVC・PMMA；ナイロン6（開環） | ナイロン66・PET・PC・ポリウレタン・フェノール樹脂 |

> [!trap] 名前が似ている四つ
> **付加重合**（連鎖側）≠ **重付加**（逐次側）。重付加 vs 重縮合の唯一の判定基準＝**小分子が脱離するか**（名前に「エステル」「アミド」があるかではない）。ポリウレタン＝重付加（脱離なし）；ナイロン66・PET・PC＝重縮合。開環重合は脱離なしでも機構で**連鎖重合**に分類。

### 重合形式と代表例 {S271 S086 S046}

| 形式 | 機構 | 副生物 | 例 |
|---|---|---|---|
| 重縮合 | 官能基の反応で小分子が脱離 | H₂O・HCl・CH₃OH | ナイロン66、PET、PC（ビスフェノールA＋ホスゲン → HCl） |
| 重付加 | X–H が不飽和結合に付加（H 移動） | なし | ポリウレタン（ジイソシアネート＋ジオール）、ポリウレア |
| 付加縮合 | HCHO が先に付加（–CH₂OH）→ 縮合 | H₂O | フェノール・ユリア・メラミン樹脂 |
| 開環重合 | 環ひずみ解放で連鎖的に成長 | なし | ナイロン6、PEG、PLA、POM |

\ce{R^1-N=C=O + HO-R^2 -> R^1-NH-CO-O-R^2}（ウレタン結合：全原子が残る＝重付加）。ナイロン XY：X＝ジアミンの炭素数、Y＝ジカルボン酸の炭素数（ナイロン66＝ヘキサメチレンジアミン＋アジピン酸）。ナイロン6 は ε-カプロラクタム（ベックマン転位で製造）の開環重合で数字は一つ。

### 連結基は官能基ペアで一意に決まる {S148}

<!-- cols: X:0.9 X:1.0 X:0.7 X:1.4 -->
| 単量体 A | 単量体 B | 連結基 | 高分子 |
|---|---|---|---|
| ジオール | ジカルボン酸・酸クロリド | エステル –O–CO– | ポリエステル（PET） |
| ビスフェノール | ホスゲン COCl₂ | カーボネート –O–CO–O– | ポリカーボネート（ポリエステルの一種 ◯） |
| ジアミン | ジ酸クロリド | アミド –NH–CO– | ポリアミド（アラミド） |
| ジオール | ジイソシアネート | ==ウレタン== –O–CO–NH– | ポリウレタン |
| ジアミン | ジイソシアネート | ==ウレア== –NH–CO–NH– | ポリウレア |
| ジアミン | 酸二無水物 | イミド環 | ポリイミド（ポリアミド酸で成形 → 閉環；R4-Q17） |
| ビスフェノール | 活性ジフルオロ芳香族 | エーテル –O– | PEEK（SNAr、F が最良の脱離基） |

- 検算三手順：① 官能基ペアから連結基を先に決める ② 原子を数える（原料に無い原子が生成物にあれば ✗；ウレタンには OH が必須）③ 繰り返し単位を**二つつないでから**炭素を数える。
- アラミド：**p**-フェニレンジアミン＋テレフタル酸クロリド＝ケブラー（高強度）；**m**-体＋イソフタル酸クロリド＝ノーメックス（耐熱・難燃）。

### 付加縮合と熱硬化性樹脂（R2-Q17・R5-Q20 失分） {S204 S249}

| 原料 | 樹脂 |
|---|---|
| フェノール ＋ ホルムアルデヒド | フェノール樹脂（ベークライト） |
| 尿素（＝ユリア＝ウレア）＋ HCHO | ユリア樹脂 |
| メラミン（トリアジン環＋3NH₂）＋ HCHO | メラミン樹脂（耐熱・耐水・食器） |
| ビスフェノールA ＋ ==エピクロロヒドリン== | エポキシ樹脂（アミンで開環硬化） |

- 名前は**ホルムアルデヒドの相手**で決まる。ビスフェノールA は OH をもつがフェノール樹脂ではない（三員環エポキシを見たらエポキシ樹脂）。
- 網目になる理由＝官能度：フェノール 3（o,o,p）、尿素 4、メラミン 6、HCHO は 2 個をつなぐ橋。官能度 ≥3 → 三次元網目 → 熱硬化性。
- ノボラック（酸触媒・フェノール過剰・熱可塑）は**ヘキサメチレンテトラミン**を加えて硬化；レゾール（塩基触媒・HCHO 過剰）は加熱だけで硬化。

### 開環重合：環の中の結合＝主鎖の結合（R2-Q19・R4-Q19・R7-Q21） {S116}

| 環状モノマー | 環内の結合 | 生成高分子 |
|---|---|---|
| ε-カプロ==ラクタム==（7員） | アミド | ナイロン6 |
| ε-カプロ==ラクトン==（7員） | エステル | ポリカプロラクトン（生分解性） |
| ラクチド（6員、2エステル） | エステル | ポリ乳酸 PLA |
| エチレンオキシド・エピクロロヒドリン（3員） | エーテル | ポリエーテル（PEG）；–CH₂Cl は側鎖 |
| トリオキサン（6員） | アセタール –O–CH₂–O– | POM（ポリアセタール） |
| N-カルボキシ無水物（NCA） | — | ポリペプチド（CO₂ 放出は正常） |

- ラクタム → アミド、ラクトン → エステル（対調は最頻出の ✗）。開環重合では原子が一つも抜けない → 環とくり返し単位の C・O・N を一つずつ数える。
- 駆動力＝環ひずみ：3員 ≫ 7員 ＞ 6員 ＞ 5員（γ-ブチロラクトンはほぼ重合しない）。
- PLA をラクチド経由にするのは、乳酸の直接重縮合が平衡で高分子量にならないため。

## 2.2 連鎖重合：開始剤と単量体 {S150 S230 S177 S268 T082}

### 開始剤の三分類（R2-Q18・R4-Q18 失分） {S150 S230}

| 分類 | 見分け方 | 代表例 |
|---|---|---|
| ラジカル | ==–N=N–==（アゾ）、==–O–O–==（過酸化物） | AIBN、過酸化ベンゾイル、K₂S₂O₈（活性種は SO₄•⁻） |
| カチオン | プロトン酸・ルイス酸 | H₂SO₄、BF₃・OEt₂、AlCl₃ |
| アニオン | 求核剤・強塩基 | n-BuLi、ナトリウムナフタレン、t-BuOK、Grignard、H₂O（シアノアクリレートのみ） |

| 置換基 | 適する重合 | 単量体 |
|---|---|---|
| 電子供与基（–OR、アルキル） | カチオン | イソブチレン、ビニルエーテル |
| 電子求引基（–CN、–COOR） | アニオン | アクリロニトリル、MMA、シアノアクリレート |
| 共役系 | すべて | スチレン、ブタジエン |
| なし・ハロゲン・OAc | ==ラジカルのみ== | エチレン（高圧）、塩化ビニル、酢酸ビニル |

- 方向：活性種と**逆の電荷**を安定化する置換基が要る（カチオン＝供与基、アニオン＝求引基）。
- アニオン開始剤は**成長末端より強い塩基**であること：スチレン（ベンジルアニオン pKa ≈ 41）には n-BuLi（≈50）が必要；MMA なら Grignard・t-BuOK でも可；シアノアクリレートは水でも開始（瞬間接着剤）。
- アニオン重合＝**リビング重合**：停止なし、Mw/Mn ≈ 1.0〜1.1、第二単量体でブロック共重合体（SBS）。水・O₂・CO₂ で失活 → 完全無水。
- ナトリウムナフタレンはラジカルアニオンだが**アニオン重合**を開始する（R2-Q18）。

### ラジカル重合の素反応 {S177}

開始・成長・停止・連鎖移動の四つ。

| 停止 | 機構 | 鎖長 | 分散度 |
|---|---|---|---|
| 再結合 | 2 本 → 1 本 | ==2n== | ≈1.5 |
| 不均化 | β-H を引抜き、2 本が別々に終わる | n | ≈2.0 |

「再結合の分子量 ＝ 不均化の 2 倍」（逆は ✗）。スチレンはほぼ再結合、MMA は不均化が主。LDPE の分岐＝連鎖移動：分子内（バックバイティング、5 番目の炭素の H）→ 短鎖分岐、分子間 → 長鎖分岐。

### イオン重合と溶媒（R6-Q17 失分） {S268 T082}

- ブチルゴム＝イソブチレン＋少量イソプレン、AlCl₃・約 −100 ℃ のカチオン重合（イソプレンは加硫用の二重結合）。気体透過性が極めて低い → インナーチューブ。
- イソプレン＋BuLi：==非極性溶媒==（ヘプタン）→ Li⁺ が末端に接触イオン対で配位 → cis-1,4 ＞ 90%；極性溶媒（THF）→ 3,4-・1,2-付加が増える。「イオン重合には極性溶媒が必要」✗。
- イオン末端どうしは同符号で反発 → 再結合停止は起こらない（再結合はラジカル専用）。

### カロザースの式 {S117 S012 T086}

分子数 N ＝ N₀(1 − p)（直線で減少）、**数平均重合度 X̄ₙ ＝ 1/(1 − p)**（H29-Q17：実線＝分子量、破線＝分子数。対調させた選択肢に注意）。

<!-- cols: l c c c c c -->
| p | 0.50 | 0.90 | 0.95 | 0.99 | 0.999 |
|---|---|---|---|---|---|
| X̄ₙ | 2 | 10 | 20 | ==100== | 1000 |

- 化学量論比 r ＜ 1 だと p ＝ 1 でも X̄ₙ ＝ (1＋r)/(1−r)：r ＝ 0.99 → 199。高分子量の三条件＝反応率 ＞ 99%・等モル（ナイロン塩）・高純度。
- 最も確からしい分布（==フローリー分布==、正規分布ではない）：n 量体の個数分率 Nₙ ＝ N₀ pⁿ⁻¹(1−p)²、重量分率 wₙ ＝ n pⁿ⁻¹(1−p)²（(1−p) は**二乗**）。Mw/Mn ＝ 1＋p → 2。
- 分散度 Đ：リビング → 1.0、ラジカル再結合 1.5、不均化 2.0、逐次 → 2。

## 2.5 平均分子量と測定法 {S129 T081 S154 S270 S081 S179 T083 S050}

$M_n=\dfrac{\sum N_iM_i}{\sum N_i}=\dfrac{\sum w_i}{\sum w_i/M_i}$、$M_w=\dfrac{\sum N_iM_i^2}{\sum N_iM_i}=\dfrac{\sum w_iM_i}{\sum w_i}$、$M_z=\dfrac{\sum N_iM_i^3}{\sum N_iM_i^2}$

> [!key] 計算は四列の表で（H24-Q30・H29-Q29）
> M・w（g）・w/M（mol）・w×M を並べる。例：10,000／50,000／100,000 が 10／40／50 g → Mn ＝ 100/0.0023 ＝ 43,500、Mw ＝ 7.1×10⁶/100 ＝ 71,000。単純平均 53,333 は罠。**Mn ≤ Mw は常に成立**（逆なら式の取り違え）。同重量混合の Mw ＝ 同モル混合の Mn（どちらも算術平均）。

<!-- cols: X:1.3 c c X:0.7 -->
| 測定法 | 平均 | 絶対／相対 | 原理 |
|---|---|---|---|
| 浸透圧・凝固点降下・沸点上昇・蒸気圧浸透圧 | Mn | 絶対 | 束一的性質＝粒子の個数 |
| 末端基定量（NMR・滴定） | Mn | 絶対 | 末端の数＝分子の数 |
| 光散乱（ジム・プロット） | Mw | 絶対 | 散乱強度 ∝ M² |
| 超遠心・沈降平衡 | ==Mz== | 絶対 | さらに高次の重み |
| 粘度法 [η] ＝ KMᵃ | Mv | 相対 | a ≈ 0.5〜0.8 ＜ 1 なので Mn ＜ Mv ＜ Mw |
| GPC（SEC） | 分布全体 | 相対（PS 標準） | 流体力学的体積 |

- 序列 Mn ≤ Mv ≤ Mw ≤ Mz。判定基準「標準試料が要るか」：要らない＝絶対法。NMR は相対**強度**だが絶対法（R6-Q19 失分）。
- 粘度法は Mz ではない（a ＜ 1）― 最も引っかかる誤答肢。
- 浸透圧：**ファントホッフ** π ＝ RTC/M（PV ＝ nRT と同形）。ファンデルワールス（実在気体 (P＋a/V²)(V−b) ＝ RT）と取り違えない。π/(RTC) ＝ 1/M ＋ A₂C ＋ …：C に掛かる係数が**第2ビリアル係数** A₂（第1は定数項 1/M）。
- A₂ ＞ 0 良溶媒（鎖が広がる）、A₂ ＝ 0 ==θ 溶媒==（理想鎖）、A₂ ＜ 0 貧溶媒。
- ジム・プロット：濃度 → 0 外挿の傾き＝回転半径、角度 → 0 外挿の傾き＝A₂、共通切片＝1/Mw。ブリルアン散乱は弾性率（分子量とは無関係）。
- NMR 末端基法：シグナル強度比を**プロトン数で割ってから**重合度を出す（H26-Q18）。

## 2.6 熱的・力学的性質 {S084 T085 F18 S152 S083 S115 S247 S045 S118 F10 S096 S151 S203 S178 S015 S176 F11}

### Tg と結晶性（H29-Q18・R4-Q16） {S084 S118 S178}

- **Tg（ガラス転移温度）**＝ミクロブラウン運動（数十単位のセグメントの協同運動）が凍結／開始する温度。Tg 以下＝ガラス状態（振動のみ）、Tg 以上＝ゴム状態。低温＝硬いガラス、高温＝柔らかいゴム ― この向きは装置によらず**絶対に逆にならない**。
- ガラス転移は熱力学的相転移**ではない**（潜熱なし・昇温速度で Tg が変わる・非平衡の緩和現象）。比熱・熱膨張率が不連続（擬二次転移）；体積 V は連続、α（V の傾き）が折れる。
- 主鎖が剛直（芳香環）→ Tg 上昇：PE ≈ −120 ℃、PC ≈ 150 ℃。剛直 ≠ まっすぐ。

| | 非晶性高分子 | 結晶性高分子 |
|---|---|---|
| 構造 | 全部無秩序 | 結晶部＋非晶部（結晶化度 30〜80%、==100% にならない==） |
| 転移 | Tg のみ | Tg（非晶部）と Tm（結晶部） |
| 外観 | 透明 | 不透明・白濁 |
| 例 | PS、PMMA、PC、PVC | PE、PP、PET、ナイロン、POM |

固体構造の階層：分子鎖の折りたたみ → **ラメラ晶**（厚さ ≈10 nm の板状）→ 放射状集合 → **球晶**（μm）。非晶部の鎖の形＝ランダムコイル（ミセルは会合体なので ✗；R1再-Q19＝R5-Q19）。

### 粘弾性（R5-Q17 で推測） {S083 S096 S151}

| 現象 | 固定するもの | 変化 | 力学模型 |
|---|---|---|---|
| 応力緩和 | ひずみ一定 | 応力が減る | マクスウェル（ばね＋ダッシュポット直列） |
| クリープ | 応力一定 | ひずみが増える | フォークト（並列） |

名前で覚える：「応力」緩和 → 応力が減る → 固定はひずみ。緩和時間 τ ＝ η/E。時間-温度換算（WLF）：高温短時間 ≡ 低温長時間。架橋（加硫）するとクリープが消える。

| 流動 | 粘度の変化 | 例 |
|---|---|---|
| ニュートン | 一定（応力-ずり速度が原点を通る直線） | 水 |
| 擬塑性（shear thinning） | ずり速度↑で==低下== | 高分子溶液、塗料 |
| ダイラタンシー | ずり速度↑で増大 | 片栗粉＋水、濡れた砂 |
| ビンガム塑性 | 降伏応力を超えて流動（縦軸を切る直線） | マヨネーズ、歯磨き粉 |
| チキソトロピー | 時間とともに低下（静置で回復） | ペンキ、ヨーグルト |

- **ワイセンベルグ効果**：回転棒を液が這い上がる（法線応力；水は逆に中央が凹む）。**バラス効果**（ダイスウェル）：押出物がダイ径より太る（弾性回復）。
- 応力-ひずみ曲線：初期の傾き＝==弾性率==（急なほど硬い；日常語の「弾性がある」＝弾性率が**小さい**、R2-Q16 失分）、破断点の縦軸＝破断応力、横軸＝破断ひずみ、曲線下の面積＝靭性。

### ゴム（R4-Q20・R7-Q17 失分） {S153 S015 S115 S176 F11}

<!-- cols: X:1.0 X:1.0 X:1.0 -->
| 項目 | ゴム | プラスチック・繊維 |
|---|---|---|
| Tg | 室温より==低い==（NR −70 ℃） | 室温より高い |
| 結晶性 | 非晶 | 中〜高（繊維は高配向） |
| 分子間力（凝集エネルギー） | 小 | 大（繊維は水素結合） |
| 弾性率 | 1〜10 MPa（小） | 10³〜10⁴ MPa |
| エントロピー | 大 | — |
| 架橋 | 必須（加硫） | なし |

- ゴム弾性＝**エントロピー弾性**：伸ばすとエントロピー減少 → 戻ろうとする。荷重下で加熱すると**縮む**（グー・ジュール効果）、急に伸ばすと発熱。ポアソン比 ≈ 0.5。
- cis-1,4-ポリイソプレン（天然ゴム）：二重結合で主鎖が折れる → 不規則 → 結晶化しない → ゴム。trans-1,4（グタペルカ）：まっすぐ → 結晶化 → 硬い樹脂。判定は主鎖の二つの CH₂ が同じ側か（CH₃ と H を見ない）。1,2-／3,4-付加は二重結合が側鎖 → ゴムにならない。
- 製造：ラテックス →（酸で**塩析**；蛋白質に覆われた親水コロイド）→ 生ゴム →**素練り**（配合剤なし、分子鎖切断）→ 混練り →**加硫**（硫黄 5〜8%、アリル位に –Sₓ– 架橋；30〜40% でエボナイト）。
- ゴムの構造は側鎖で読む：ベンゼン環 → SBR、–CN → NBR、–C(CH₃)₂– → ブチル、–COOEt → アクリルゴム、–OH → EVOH（ゴムではない）。
- **熱可塑性エラストマー**（R5-Q15 失分）：ブロック共重合体（SBS）→ 非相溶だが共有結合でつながる → ==ミクロ相分離== → 硬いセグメント（PS）が物理架橋点、柔らかいセグメント（PB）がゴム弾性。高温で TΔS が勝ち均一相 → 溶融・再成形可。ランダム共重合体では不可。

### エンプラの判定（R3-Q19・R5-Q16 失分） {S119 S248 S051}

判定基準＝**主鎖の芳香環**または**高度な結晶性（水素結合）**→ 耐熱。

- 五大汎用エンプラ：==PA（ナイロン）・POM・PC・変性 PPE・PBT==。スーパーエンプラ：PPS・PEEK・PI・LCP。四大汎用プラ：PE・PP・PVC・PS。
- POM は脂肪族ポリエーテルだが高結晶（Tm ≈ 175 ℃）でエンプラ；PEO・PEG（Tm ≈ 60 ℃、水溶性）は非エンプラ（H29-Q19）。「構造が単純 ＝ 汎用」✗。
- PBT は PET より結晶化が速く成形性が良い（ジオールが C4 で柔軟）。

### 高分子反応・分解・その他（R7-Q16・R7-Q19 失分） {S289 S288 S215 S052 F19}

- イオン交換樹脂：–SO₃⁻（固定基が負）＝**陽**イオン交換；クロロメチル化 PS＋アミン → –N⁺R₃ ＝ 陰イオン交換。
- ビニロン：酢酸ビニル → 重合 → けん化（PVA）→ HCHO でアセタール化。
- ポリケイ皮酸ビニル：光で [2+2] 二量化 → 架橋 → 露光部が不溶＝**ネガ型**。
- セルロース：水素結合で難溶；NaOH＋CS₂（ビスコース）、シュバイツァー試薬 [Cu(NH₃)₄]²⁺（銅アンモニア）で溶解。
- リサイクル：逐次重合系（PET・PU）はアルコリシス・加水分解で単量体へ（ケミカル）；PMMA は熱分解で 90% 以上単量体（ジッパー型解重合）；PVC は 250〜300 ℃ で先に HCl 脱離 → ポリエン → 炭化。マテリアル＝溶融再成形、サーマル＝焼却で熱回収。
- 生分解性：**主鎖**に加水分解できる結合（エステル・アミド）→ 分解（PLA・PGA・PCL・PHB・PBS）；PMMA は主鎖 C–C（エステルは側鎖）→ 分解しない。R/S 表示は無関係。
- 導電性高分子：主鎖全体が π 共役＋ドーピング（I₂ → p 型、Na → n 型）；ポリアセチレン（白川英樹）。1,4-ポリブタジエンは sp³ CH₂ で共役が切れ絶縁体。
- 高分子電解質 → 高分子イオン（巨大）＋**対イオン**（小さい・反対電荷）；ポリアニオン（–COO⁻・–SO₃⁻）／ポリカチオン（–NR₃⁺）。高吸水性ポリアクリル酸ナトリウム：解離 → 静電反発・浸透圧（「水で分解」✗）。
- 炭素繊維の原料＝PAN（–C≡N の環化 → 耐炎化 200〜300 ℃ → 炭化）またはピッチ。PP は不可。
