## 6.3 易混淆用語（題目最愛對調）

| 一方 | 另一方 | 區別 |
|---|---|---|
| 付加重合 | 重付加 | 連鎖 vs 逐次（小分子脱離なし） |
| 立体配置 configuration | 立体配座 conformation | 結合を切る vs 単結合の回転 |
| 応力緩和 | クリープ | ひずみ一定で応力↓ vs 応力一定でひずみ↑ |
| 弾性率（大＝硬い） | 「弾性がある」 | ゴムは弾性率が小さい |
| 曇り点 | 流動点 | 白濁する温度 ＞ 流動する最低温度 |
| 引火点 | 発火点 | 軽質油ほど低い vs 重質油ほど低い |
| 原料炭 | 一般炭 | 粘結性あり・コークス用 vs 燃料用 |
| 絶対粘度 μ | 動粘度 ν ＝ μ/ρ | 日本語「動」＝ kinematic |
| ファントホッフ式 | ファンデルワールス式 | 浸透圧（溶液） vs 実在気体 |
| ショットキー欠陥 | フレンケル欠陥 | 空孔対 vs 空孔＋格子間 |
| 凝析 | 塩析 | 疎水コロイド・少量電解質 vs 親水コロイド・多量 |
| 精密ろ過 MF | 限外ろ過 UF | MF のほうが孔が大きい |
| 蛍光 | りん光 | S₁ → S₀（速い） vs T₁ → S₀（遅い） |
| アノード | カソード | 常に酸化 vs 常に還元 |
| 熱力学支配 | 速度論支配 | 高温・平衡・安定生成物 vs 低温・速い生成物 |
| 求電子 | 求核 | 名前は攻撃する試薬で決まる |
| 水酸化アルミニウム | 水素化アルミニウムリチウム | 還元力なし vs 強還元剤 |
| 酸化亜鉛 ZnO | 酸化鉛 PbO | 白（亜鉛華） vs 黄 |
