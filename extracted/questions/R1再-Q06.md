# R1再-Q06　芳香族性を持たない化合物

<!-- era: new; copies in source: 1 -->

主題：芳香族性を持たない化合物　正解：②（[10]アヌレン）

4n+2 は最後の条件であって最初の条件ではない

| 条件 | ②の状況 |
|---|---|
| ① 環状 | ✓ |
| ② 環上の全原子が p 軌道を持つ（完全共役） | ✓ |
| ③ 平面 | ✗ |
| ④ π 電子数 4n+2 | ✓（10π、n=2） |

②は [10]アヌレン（シクロデカペンタエン）。π 電子は確かに 10 個で 4n+2 を満たすが、平面になれない。

全 cis 形：正十角形に広げると内角 144° となり sp² の 120° から大きくずれ、角ひずみが過大。

設問の形（ナフタレンから中央の結合を取った形、trans 二重結合を含む）：1 位と 6 位の H が二つとも環の内側を向き、平面上で衝突する（立体反発）。

このため分子はねじれ、p 軌道が連続的に重ならず π 電子が環全体に非局在化できない。平面性で失格。

傍証：内側の二つの H を CH₂ 架橋に置き換えた 1,6-メタノ[10]アヌレンはほぼ平面で芳香族性を示す。ナフタレン（①）は 1 位と 6 位を直接結合で繋いだ形にあたり、内側 H の問題が同時に解消されている。

π 電子数の数え方フレーム

| 環上の原子 | π 電子の寄与 |
|---|---|
| C=C の C | 1 |
| C⁺（空の p 軌道） | 0（ただし共役は途切れない） |
| C⁻（孤立電子対が p 軌道） | 2 |
| ピロール型 N（N–H、孤立電子対が p 軌道） | 2 |
| ピリジン型 N（C=N、孤立電子対が sp²） | 1 |
| sp³ 炭素（CH₂） | 共役が切れる → 即失格 |

他の肢　①ナフタレン：平面・10π ✓。③ピロール：C 4個×1 ＋ N の孤立電子対 2 ＝ 6π ✓（孤立電子対を芳香族性に使うため塩基性が弱い）。④ピリジン：C5＋N1 で 6π ✓（N の孤立電子対は環平面内の sp² にあり π 系に不参加、だから塩基性が残る）。⑤トロピリウムイオン：C⁺ が空 p 軌道で共役を繋ぎ、二重結合三つ分の 6π ✓。

対照　シクロオクタテトラエン 8π（4n）はタブ形にねじれて反芳香族性を回避＝非芳香族。シクロブタジエン 4π は平面なので反芳香族性。

一句速記　環状 → 平面 → 完全共役 → 4n+2 の順に確認。[10]アヌレンは 10π でも内側 H の衝突で平面になれず失格。
