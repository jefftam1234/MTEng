# R1再-Q14　重付加／重縮合と生成高分子

<!-- era: new; copies in source: 1 -->

主題：重付加／重縮合と生成高分子　正解：②（A と C）

|  | 試薬の組合せ | 生成する結合 | 高分子 | 反応形式 |
|---|---|---|---|---|
| A | ジオール ＋ ジイソシアネート（MDI） | –O–CO–NH– ウレタン | ポリウレタン | 重付加 |
| B | ジアミン ＋ ジイソシアネート | –NH–CO–NH– 尿素 | ポリ尿素 | 重付加 |
| C | エチレングリコール ＋ テレフタル酸 | –O–CO– エステル | ポリエステル（PET） | 重縮合（脱 H₂O） |
| D | p-フェニレンジアミン ＋ ピロメリット酸二無水物 | イミド | ポリイミド | 重付加 → 脱水環化 |
| E | ジアミノジヒドロキシベンゼン ＋ テレフタル酸 | ベンゾオキサゾール環 | PBO（ザイロン） | 重縮合 |

A がポリウレタンである理由　R–OH ＋ O=C=N–R′ → R–O–CO–NH–R′。アルコールの O がイソシアネートの中心炭素（電子不足）を求核攻撃し、O–H の水素が N へ移動する。小分子が脱離しないので重縮合ではなく重付加。

判定法：–N=C=O（イソシアネート）を見たらまずポリウレタン。相手が OH ならウレタン、NH₂ ならウレア。A と B の違いは求核剤が OH か NH₂ かだけ。よって B はポリウレタンではなく①③は排除。

D の判定　酸無水物 ＋ アミン → ポリイミド。アミンが無水物を開環攻撃してポリアミド酸（前駆体）を与え、加熱脱水閉環でイミドになる。D はポリエステルでもポリウレタンでもないので④⑤は排除。

ウレタン結合には実質的に OH ＋ NCO が必要　ウレタン結合 –O–CO–NH– は O と N を同時に供給せねばならず、小分子を脱離せずにそれを一段でこなせる官能基は NCO だけ。クロロ蟻酸エステル ＋ アミンの経路は実験室的には可能だが HCl が出るため工業的には使わない。なお「ポリオール」は小分子ジオールに限らず、末端 OH のポリエーテル／ポリエステルオリゴマーも指す。
