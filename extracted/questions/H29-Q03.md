H29-Q3　クメン法の生成物

考點　工業製法名と生成物の対応。純背誦題だが炭素数保存で救済可能。

片假名の分解　イソプロピルベンゼン＝クメン（cumene, C₆H₅–CH(CH₃)₂）。問題文の括弧が同義語注であることに気づけば、原料構造は与えられている。

正答①　フェノール（＋アセトン）

クメン法（ホック法）三段階

第一段：ベンゼン + プロペン →(H₃PO₄ または AlCl₃, フリーデル・クラフツ アルキル化)→ クメン。プロペンのプロトン化で 2°カルボカチオン（マルコフニコフ則）が生じるため、n-プロピルではなくイソプロピルが付く。

第二段：クメン + O₂（空気酸化）→ クメンヒドロペルオキシド C₆H₅–C(CH₃)₂–OOH。酸化位置が特定される理由：そこが 3級かつベンジル位の C–H で、生じるラジカルが超共役と芳香環との共鳴の両方で安定化される＝分子中で最も弱い C–H。

第三段：H₂SO₄ による ホック転位（1,2-アリール転位）。O–O 開裂で電子不足酸素が生じ、フェニル基が炭素から酸素へ移動、続く加水分解で C–C が切断されて フェノール + アセトン。

工業的意義　生成比 フェノール : アセトン ≈ 1:1（モル比）で両者とも大宗基礎原料。原料（ベンゼン・プロペン・空気）が安価。世界のフェノール生産の9割以上がこの法。下流：フェノール + アセトン → ビスフェノールA → ポリカーボネート／エポキシ樹脂。

②　アニリン：ニトロベンゼンの還元（H₂/Ni、または Sn+HCl）で製造。窒素源が必要だがクメン法の全工程に含窒素試薬は存在しない → 最速の排除法。

③　安息香酸：トルエンの空気酸化（Co/Mn触媒）。側鎖が1炭素でなければ COOH で止まらない。

④　ベンズアルデヒド：トルエンの塩素化 → 加水分解（C₆H₅CH₃ → C₆H₅CHCl₂ → C₆H₅CHO）。いずれもトルエン起点でクメンではない。

⑤　トルエン：石油の接触改質、またはベンゼンのメチル化で得る原料側の物質。3炭素側鎖を1炭素に削る工程に工業的意義はない。

救済法（製法名を忘れた場合）　炭素数保存で解ける。クメンは C₉。生成物の合計も C₉ でなければならない。フェノール C₆ + アセトン C₃ = C₉ ✓。この一手で②③④⑤を現場で排除できる。

側鎖炭素数による工業製法の判別

| 側鎖炭素数 | 原料 | 主な目的物 |
|---|---|---|
| 1C | トルエン | ベンズアルデヒド、安息香酸 |
| 2C | エチルベンゼン | スチレン（脱水素） |
| 3C | クメン | フェノール + アセトン |

関連製法一括　スチレン＝エチルベンゼン脱水素／無水フタル酸＝o-キシレンまたはナフタレン酸化／テレフタル酸＝p-キシレン酸化（Amoco法）。

過去問との関係　速查表 第73項D に H27-Q6 でクメン法を整理済み。H29 は同じ製法を「生成物は何か」という最も直截な形で再出題。

一句話速記　クメン法：ベンゼン + プロペン → クメン →(O₂) ヒドロペルオキシド →(H⁺, ホック転位) フェノール + アセトン。一石二鳥かつ炭素数保存 C₉ = C₆ + C₃。
