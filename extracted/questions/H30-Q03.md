# H30-Q03　シクロアルケンの反応（最も適切なもの）

<!-- era: new; copies in source: 1 -->

主題：シクロアルケンの反応（最も適切なもの）　正解：① 1,2-ジメチルシクロヘキセン + H₂/Pt → cis-1,2-ジメチルシクロヘキサン

本題の正体は syn / anti 付加の一点のみ

五肢すべてが同じ判定軸で解ける。中間体が三員環なら背面攻撃で anti、五員環または金属表面なら同一面に固定されて syn（第138項）。

① 正　H₂/Pt は金属表面への吸着を経るため syn 付加。2個の H が C1・C2 の同一面に入る → 元からある 2 個のメチル基はともに反対面へ押し出される → メチル同士が同じ側 = cis。

② 誤（誤答した肢）　二段階反応の立体化学は最後の段階で決まる

シクロヘキセン →(mCPBA)→ エポキシド →(酸性水溶液)→ ジオール。

第一段のエポキシ化は確かに syn（酸素が片面から入る）——ここまでは正しい

第二段の酸性開環が anti：エポキシド酸素がプロトン化 → C–O が良い脱離基に → H₂O が背面から Sₙ2 型攻撃 → 2個の OH が異面に

したがって産物は trans-1,2-シクロヘキサンジオール。題目の cis は誤り。エポキシ化の syn に引きずられて最終産物まで cis と判断するのが典型的な誤りの分岐点。

補足：エポキシド開環は酸性・塩基性いずれも antiで、違いは位置選択性のみ（酸性＝置換の多い炭素、塩基性＝置換の少ない炭素）。

③ 誤　OsO₄ は五員環オスミウム酸エステル中間体を経るため syn ジヒドロキシ化で cis-ジオール。NaHSO₃（亜硫酸水素ナトリウム）は還元的後処理でエステルを加水分解し有毒な Os(VIII) を還元するだけで、立体化学を変えない。題目の trans は誤り。

②と③は cis / trans がちょうど入れ替えて置かれている。trans-ジオールを作る正規ルートが②（mCPBA → 酸）、cis-ジオールを作る正規ルートが③（OsO₄）。

④ 誤　Br₂ は三員環ブロモニウムイオンを経て Br⁻ が背面開環 → anti → trans-1,2-ジブロモシクロペンタン。題目の cis は誤り。

⑤ 誤　ここだけ立体ではなく位置選択性

1-メチルシクロヘキセン + HBr：マルコフニコフ則により H⁺ は水素の多い C2 に付き、3級カルボカチオンが C1 に生成（最も安定）→ Br⁻ が C1 を攻撃 → 1-ブロモ-1-メチルシクロヘキサン。題目の「1-ブロモ-2-メチル」は反マルコフニコフ生成物で、これは HBr + 過酸化物（ラジカル機構）でのみ得られる。過酸化物の記載がないので誤り。

なお C1 は4級炭素なので立体異性の問題は生じない——本肢だけ判定軸が違うことに注意。

一句話速記：三員環中間体（ブロモニウム、エポキシド）は片面を塞ぐので anti → trans；五員環（OsO₄）や金属表面（H₂/Pt）は同一面に固定するので syn → cis。二段階反応は最後の段階で決まる。
