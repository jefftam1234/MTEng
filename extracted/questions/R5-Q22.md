# R5-Q22　セラミックスの応用製品と材料（不適切な組合せ）

<!-- era: new; copies in source: 1 -->

主題：セラミックスの応用製品と材料（不適切な組合せ）　正解：② A、E　用戶答錯（選① A、B）

A 錯　高溫超導＝銅氧化物（YBa₂Cu₃O₇，Tc 約 92 K ＞ 液氮 77 K；Bi 系）。BaTiO₃ 不含 Cu。BaTiO₃＝強介電體 → 只配積層電容器・PTC サーミスタ。

E 錯　SiO₂ 為絕緣體，不能焦耳發熱；發熱體＝SiC、MoSi₂、LaCrO₃（導電＋耐高溫氧化）。二酸化ケイ素 vs 炭化ケイ素字面陷阱。

B 正（用戶誤判）　PLZT＝PZT 添加 La → 透明＋電氣光學效應 → 光快門。未添加 La 的 PZT 不透明，用於壓電元件。

C・D 正　水酸アパタイト Ca₁₀(PO₄)₆(OH)₂＝骨成分 → 人工骨；ZnO（＋Bi₂O₃）晶界能障 → 壓敏電阻（非線性 V-I）。

|---|---|---|
| 鈦酸鋇 | チタン酸バリウム | barium titanate |
| 高溫超導體 | 高温超電導体 | high-Tc superconductor |
| 摻鑭鋯鈦酸鉛 | ランタン添加チタン酸ジルコン酸鉛 | PLZT |
| 羥基磷灰石 | 水酸アパタイト | hydroxyapatite |

| 碳化矽 | 炭化ケイ素 | silicon carbide |

一句速記　BaTiO₃ 只配電容器・PTC；高溫超導必含 Cu；發熱體須導電 → SiC 不是 SiO₂；PLZT 透明 → 光快門。（速查第155・250項；關聯 H26-Q25、H29-Q22、H30-Q21、R2-Q22）
