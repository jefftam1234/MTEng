# R1再-Q09　炭化水素の常圧沸点の高低

<!-- era: new; copies in source: 1 -->

主題：炭化水素の常圧沸点の高低　正解：⑤（最も不適切）

同炭素数（C7）なので差はすべて分散力＝分子どうしがどれだけ密着できるか

| 因子 | 効果 | 理由 |
|---|---|---|
| 直鎖 vs 分枝 | 直鎖 ＞ 分枝 | 分枝で球形に近づき表面積が減る |
| 環状 vs 鎖状 | 環状 ＞ 鎖状 | 剛直で形が揃い密着しやすい |
| 芳香族 vs 脂肪族 | 芳香族が最高 | 平面剛直＋π 電子の分極率が大きい |

| 化合物 | 沸点 |
|---|---|
| トルエン | 約 111 ℃ |
| メチルシクロヘキサン | 約 101 ℃ |
| ヘプタン | 約 98 ℃ |
| 2-メチル-2-ヘキセン | 約 95 ℃ |
| 2-メチルヘキサン | 約 90 ℃ |

⑤が誤り　ヘプタンと 2-メチルヘキサンは同じ C₇H₁₆ の構造異性体。直鎖のヘプタン（98 ℃）＞ 分枝の 2-メチルヘキサン（90 ℃）。設問は不等号が逆。「＜」の左が低沸点・右が高沸点であることを読み違えないこと。

①②③④は正しい　①ヘプタン（直鎖）＜ トルエン（芳香族）。②メチルシクロヘキサン（環状）＜ トルエン（芳香族）。③2-メチル-2-ヘキセン（分枝鎖状）＜ メチルシクロヘキサン（環状）。④2-メチルヘキサン（飽和）＜ 2-メチル-2-ヘキセン（二重結合部が平面・剛直で分極率もやや大）。

分子間力の用語階層（補足）　ファンデルワールス力 ＝ 配向力（Keesom、永久双極子どうし）＋ 誘起力（Debye、永久双極子と誘起双極子）＋ 分散力（London、瞬間双極子と誘起双極子）の総称。本題の炭化水素はいずれも双極子モーメントがほぼゼロなので、三成分のうち分散力しか働かない。だから「ファンデルワールス力」でも誤りではないが「分散力」と言うほうが正確で、形状・表面積が効く理由も直結する。O–H、N–H、H–F を含む化合物の沸点比較ではまず水素結合を考える。

一句速記　同炭素数の沸点は 芳香族 ＞ 環状 ＞ 直鎖 ＞ 分枝。分枝が増えるほど球形に近く接触面が減って沸点が下がる。
