# R1再-Q27　無機結晶物質の欠陥

<!-- era: new; copies in source: 1 -->

主題：無機結晶物質の欠陥　正解：④（最も不適切）

④が誤り——正しくは「陰イオン空孔と陽イオン空孔の対」

設問は「陰イオン空孔と陽イオンの対」となっており、二つ目の「空孔」が欠けている。「陰イオン空孔＋陽イオン」という組合せはどの欠陥の定義でもない。キーワードが二文字だけ違う型の作問（Q24 の「酸化亜鉛／酸化鉛」と同種）。

設問の構造を読む　①②③は次元分類（教科書一行の定義）で要素が一つしかなく、改変すると露骨。④⑤は「A と B の対」という二つの要素の組合せなので、片方を差し替えれば自然な誤りになる。「A と B の対は〜である」という文型を見たら A と B を別々に確認する。

二つの点欠陥（電荷中性と組成変化で推理できる）

|  | ショットキー欠陥 | フレンケル欠陥 |
|---|---|---|
| 内容 | 陽イオン空孔 ＋ 陰イオン空孔（対） | 格子間イオン ＋ 同種イオンの空孔（対） |
| イオンの行き先 | 結晶表面へ出る | 格子間へ移る（結晶内に留まる） |
| 密度 | 下がる | ほぼ不変 |
| 体積 | 増える | ほぼ不変 |
| 起きやすい系 | 陰陽イオンの半径が近い（NaCl、KCl、MgO） | 陰陽イオンの半径差が大きい（AgCl、AgBr、CaF₂、ZrO₂） |

推理の筋道　① 電荷は中性でなければならない。ショットキーは空孔しか作らないので、陽イオン空孔（実効負電荷）と陰イオン空孔（実効正電荷）が価数に応じた比で対になる（NaCl は 1:1、MgCl₂ は Mg²⁺ 空孔 1 個に Cl⁻ 空孔 2 個）。② フレンケルは「引っ越し」であって「退去」ではないので、格子間イオンと空孔は同一種のイオンであり電荷は自動的に釣り合い組成も変わらない。③ 半径差が大きいと小さい陽イオンが隙間に入れる（AgCl の Ag⁺ は約 115 pm、Cl⁻ は 181 pm）。NaCl は両者が近く隙間に入れないので結晶外へ出るしかない。

①②③は正しい——次元による分類

| 次元 | 名称 | 実例 |
|---|---|---|
| 0 次元 | 点欠陥 | 空孔、格子間原子、置換型不純物、ショットキー、フレンケル |
| 1 次元 | 線欠陥 | 転位（刃状転位、らせん転位） |
| 2 次元 | 面欠陥 | 結晶粒界、双晶界面、積層欠陥、表面 |
| 3 次元 | 体欠陥 | ボイド、析出物、介在物 |

数え方は「欠陥が伸びている方向の数」。工学的意味：転位は金属の塑性変形の担い手（加工硬化は転位どうしの絡み合い）。結晶粒界は Hall-Petch 関係（粒が細かいほど粒界が多く転位の移動を妨げて硬い）。点欠陥はイオン伝導の担い手。

補足：非化学量論組成（不定比）　FeO（Fe₁₋ₓO）は Fe²⁺ 空孔と一部 Fe³⁺ で電荷を補う。ZrO₂ に Y₂O₃ を固溶させた YSZ では Y³⁺ が Zr⁴⁺ を置換し、電荷中性を保つため酸素空孔が生じる——これが酸化物イオン伝導の起源で、固体酸化物燃料電池と酸素センサに使われる。

一句速記　ショットキーは空孔どうしの対（イオンが結晶外へ出るので密度が下がる）、フレンケルは格子間イオンと同種イオンの空孔の対（引っ越しなので組成不変）。空孔 0 次元・転位 1 次元・粒界 2 次元。
