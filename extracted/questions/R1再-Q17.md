# R1再-Q17　良好なゴム弾性を示すポリイソプレン

<!-- era: new; copies in source: 1 -->

主題：良好なゴム弾性を示すポリイソプレン　正解：①　cis-1,4-ポリイソプレン（天然ゴム）

第一段階：二重結合が主鎖にあるか側鎖にあるか

| 肢 | 付加様式 | 主鎖 |
|---|---|---|
| ①④ | 1,4-付加 | 二重結合が主鎖にある |
| ② | 1,2-付加 | –CH₂–C(CH₃)< 、側鎖に –C(H)=CH₂ |
| ③⑤ | 3,4-付加 | –CH–CH₂– 、側鎖に –C(CH₃)=CH₂ |

②③⑤は主鎖が C–C のみになり、かつ嵩高い側基の立体障害で鎖の柔軟性が落ち Tg が上がる。ゴムにならない。候補は①④に絞られる。

第二段階：cis か trans か——見るのは主鎖の CH₂ 二つ

|  | 二つの主鎖 CH₂ の位置 | 幾何 | 物性 |
|---|---|---|---|
| ① | 同じ側 | cis | 天然ゴム。良好なゴム弾性 |
| ④ | 反対側 | trans | グタペルカ。硬い樹脂状 |

判定時に見るのは主鎖が繋がる原子（CH₂）であって、CH₃ と H ではない。ここが見誤りやすい。

因果の鎖：cis → 鎖が折れ曲がる → 不規則 → 結晶化しない → 鎖が動ける → エントロピー弾性

cis（①）：各二重結合で主鎖が約 120° 強制的に折れ曲がり、鎖全体が不規則に湾曲する。鎖どうしが揃わないので非晶のまま。Tg 約 −70 ℃ で室温よりはるかに低く、常温で鎖が自由に運動できる。

trans（④）：二重結合部でも主鎖がまっすぐ伸び、鎖の形が規則的なのでファスナーのように平行に積層できる。結晶化度 50〜60 %、融点約 60 ℃。鎖が格子に固定され、硬くて強靭な樹脂になる（かつてゴルフボール外皮・歯科材料）。

両者は化学式が同一の幾何異性体でありながら物性が正反対。工業的には Ziegler-Natta 系やリチウム系触媒で立体規則性を制御し、cis 含有率 98 % 以上の IR（合成天然ゴム）を作る。

ゴム弾性の三条件　① 長鎖で柔軟（Tg が使用温度よりはるかに低い）② 非晶（結晶は鎖の運動を凍結する）③ 適度な架橋（加硫。無架橋だと塑性流動＝永久変形、過度だとエボナイト）。なお天然ゴムは 400 % 以上に伸ばすと伸長結晶化を起こし、これは逆に強度を高める天然ゴム固有の利点。

一句速記　cis-1,4 だけがゴム。二重結合部で折れ曲がる → 不規則 → 非晶 → 鎖が動く。trans-1,4 はまっすぐで規則的なので結晶化し硬いグタペルカ。
