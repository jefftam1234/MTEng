H29-Q17　逐次聚合的分子量・分子數與反應率

考點　圖表選擇題。カロザースの式是否掌握。

正答②　實線（分子量）末端急遽發散、虛線（分子數）單調遞減

兩條曲線的定量根據

逐次聚合的本質是「兩個分子合併成一個」，每形成一個鍵，分子總數減少 1：

分子數　N = N₀(1 − p)　→ 直線遞減

分子量（數量平均聚合度）　X̄ₙ = N₀/N = 1/(1 − p)　→ 雙曲線，p→1 處垂直發散

（N₀＝初期分子數、p＝反應率）

| 反應率 p | 聚合度 X̄ₙ |
|---|---|
| 0.50 | 2（只是二聚體） |
| 0.90 | 10 |
| 0.95 | 20 |
| 0.99 | 100 |
| 0.995 | 200 |
| 0.999 | 1000 |
| 1.00 | ∞ |

關鍵特徵：p 接近 1 之前分子量幾乎不上升，到 p >** 0.99 才急速飆升。**這正是縮聚製程必須高真空脫水、長時間反應的理由。

逐一排除

①　實線直線上升＝分子量與反應率成正比。若成立則 p=0.5 應有一半分子量，實際只得二聚體。且虛線水平（分子數不變）也不可能。 ③　實線形狀正確，但虛線水平。逐次聚合就是分子彼此合併，分子數不可能守恆。 ④　兩條完全對調——分子量不變、分子數增加皆不可能。這是典型的「對的語互相對調」設計，不細看座標指的是哪條線就會誤選。 ⑤　兩條都是增加且初期急升後飽和——這是連鎖聚合的行為，不是逐次聚合。

逐次重合 vs 連鎖重合（本題真正的考點）

| 項目 | 逐次重合（縮聚・重付加） | 連鎖重合（付加重合） |
|---|---|---|
| 分子量 vs 反應率 | 反應率 >99% 才得高分子量 | 初期就生成高分子量 |
| 系中成分 | 單體幾乎立刻消失，全是低聚物 | 單體與完成的高分子共存 |
| 反應種 | 所有末端皆可反應 | 只有活性末端 |
| 停止反應 | 無 | 有（再結合、不均化） |
| 例 | ナイロン、PET、ポリウレタン | PE、PS、PVC、PMMA |

延伸公式：化學計量比不平衡時

若兩單體莫耳數不等，即使 p=1 也得不到無限大分子量：

X̄ₙ = (1 + r) / (1 + r − 2rp)　　r = N_A/N_B ≤ 1

p = 1 時簡化為　X̄ₙ = (1 + r)/(1 − r)

| r | p=1 時的 X̄ₙ |
|---|---|
| 1.00 | ∞ |
| 0.99 | 199 |
| 0.98 | 99 |
| 0.95 | 39 |

計量比只差 1%，聚合度就從無限大掉到 199。這是逐次聚合實務上最嚴苛的要求（單官能雜質同樣會封端）。

分子量分布（最確率／Flory 分布）

X̄ₙ = 1/(1−p)、X̄_w = (1+p)/(1−p) → 分散度 X̄_w/X̄ₙ = 1 + p → p→1 時趨近 2

| 聚合方式 | 分散度 Đ |
|---|---|
| 逐次重合 | → 2 |
| ラジカル重合（再結合停止） | 1.5 |
| ラジカル重合（不均化停止） | 2.0 |
| リビング重合 | → 1.0 |

注意：題目敘述中「実践が分子量」應為「実線」的誤植。圖表題務必先確認實線／破線各代表什麼——④ 就是專抓混淆此點的人。

一句話速記　逐次聚合：分子數 N = N₀(1−p) 遞減，分子量 X̄ₙ = 1/(1−p) 在 p→1 才發散。p=0.99 才聚合度 100——這就是縮聚必須追求 99% 以上反應率與嚴格 1:1 計量比的理由。
