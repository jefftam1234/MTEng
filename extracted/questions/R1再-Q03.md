# R1再-Q03　人名反応の反応式

<!-- era: new; copies in source: 1 -->

主題：人名反応の反応式　正解：③（誤っているもの）

③ カニッツァロ反応が誤り——炭素数で即断できる

α水素を持たないアルデヒドを濃塩基中で反応させると不均化し、一方が酸化、他方が還元される。

2 PhCHO + OH⁻ → PhCOO⁻（→ PhCOOH）＋ PhCH₂OH（ベンジルアルコール）

図の還元生成物はフェノール PhOH になっており、CH₂ が一つ足りない。PhCHO は C7 なので生成物も両方 C7。安息香酸は C7 ✓、フェノールは C6 ✗。アルデヒドの還元は –CHO → –CH₂OH であり炭素は脱落しない。反応名を知らなくても炭素数保存で判定できる論理推理題。

機構：OH⁻ がカルボニルに付加した四面体中間体が、第二のアルデヒドへ H⁻（ヒドリド）を移動する。α-H がなくエノール化できないためこの経路しかない。

①　クライゼン縮合　酢酸エチル2分子、NaOEt。α-カルバニオンが他分子のエステルカルボニルを攻撃し EtO⁻ が脱離、アセト酢酸エチル + EtOH。炭素数検算 4+4 = 6+2 ✓。

②　マイケル付加　アセト酢酸エチルの活性メチレン（二つのカルボニルに挟まれ最も酸性）のカルバニオンが、メチルビニルケトンの β炭素へ 1,4-共役付加 ✓。

④　クネーフェナーゲル縮合 → 加水分解 → 脱炭酸（受験者が誤って選びやすい肢。正しい）

PhCHO + CH₂(CO₂Et)₂ / NaOEt → 付加・脱水 → PhCH=C(CO₂Et)₂

H₃O⁺ で二つのエステルが加水分解 → PhCH=C(COOH)₂

同一炭素上に二つの COOH（マロン酸型）は加熱で脱炭酸し CO₂ を一つ失う → PhCH=CH–COOH（ケイ皮酸）✓

マロン酸エステル合成と同じ「加水分解 → 脱炭酸」。生成物で CO₂Et が一つ減っているのを見て誤りと判断するのが典型的な罠。

⑤　マンニッヒ反応　CH₃CHO + ジメチルアミン → イミニウムイオン CH₃CH=N⁺(CH₃)₂。シクロヘキサノンのエノールがこれを攻撃し 2-(1-ジメチルアミノエチル)シクロヘキサノン ✓。最も典型的なアルデヒドは HCHO だが他のアルデヒドでも成立する。

一句速記　カニッツァロは「カルボン酸＋第一級アルコール」で炭素数不変。生成物の炭素が減っていたら誤り。マロン酸エステルの H₃O⁺ 処理は加水分解＋脱炭酸で CO₂ が一つ減るのが正常。
