# R2-Q08　日本一次能源供給構成（2017 年度統計）

<!-- era: new; copies in source: 1 -->

主題：日本一次能源供給構成（2017 年度統計）　正解：②（石炭 30% 以上＝錯誤）　純背誦題

| 能源 | 2017 年度占比 | 選項 | 判定 |
|---|---|---|---|
| 石油 | 約 39% | ① 40% 以下 | ✓ |
| 石炭 | 約 25% | ② 30% 以上 | ✗ |
| 天然氣 | 約 23% | ③ 20% 以上 | ✓ |
| 再生能源（含水力） | 約 11%（水力約 3.5％＋其他約 7.6％） | ④ 10% 以上 | ✓ |
| 核能 | 約 1.4% | ⑤ 5% 以下 | ✓ |

用戶失誤（選④）　漏看括號「含む水力」。不含水力約 7.6%，含水力約 11%。括號內的計算範圍必須確認。

加總檢驗　石油≈40＋石炭≥30＋天然氣≥20＋再生≥10 已約 100%，五個門檻不可能同時成立 → 必有一個數字被誇大。

事實邏輯　福島後核電幾乎全停 → 由 LNG 與石炭火力補位；石炭 2010 年代維持約 25%，未超過 30%。石油 1973 年約 75% → 2010 年代約 40%。

一句速記　2017 年度：石油約 39%、石炭約 25%、天然氣約 23%、再生能源含水力約 11%、核能約 1.4%；石炭不到 30%。（速查第199項）
