# R5-Q29　固有粘度（計算）

<!-- era: new; copies in source: 1 -->

主題：固有粘度（計算）　正解：② 200 cm³/g　用戶答對

計算　t₀＝140.00 s（純溶劑）。η_sp/c＝(t/t₀ − 1)/c：c＝1.00×10⁻³ → (169.12/140 − 1)/0.001＝208；2.00×10⁻³ → 216；3.00×10⁻³ → 224。每格 +8 → 外插 c＝0：208 − 8＝200 cm³/g。Huggins：η_sp/c＝[η]＋k_H[η]²c，斜率 8000 → k_H＝8000/200²＝0.20。

快速排除　η_sp/c 隨 c 遞增 → [η] 必 ＜ 208 → 只剩 ①100、②200；100 與每格 8 的規律不符 → ②。（只看「2xx」不夠：③230、④270 也是 2xx）

一句速記　η_sp＝t/t₀ − 1，η_sp/c 對 c 直線外插到 c＝0 的截距＝[η]（Huggins）。（公式集追加；關聯 H24-Q17）
