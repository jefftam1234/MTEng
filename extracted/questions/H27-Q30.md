# H27-Q30　水加熱器の総括伝熱係数 U（計算）

<!-- era: new; copies in source: 1 -->

主題：水加熱器の総括伝熱係数 U（計算）　正解：② 8.1×10² W·m⁻²·K⁻¹

核心：Q＝ṁcΔT 求傳熱量、Δt 用対数平均温度差(LMTD)、U＝Q/(A·LMTD)。給 ln2 就是 LMTD 的信號。

步驟 1. Q（水側）＝ṁ·c·ΔT＝2.8×(4.18×10³)×(80−30)＝5.85×10⁵ W 2. 驗證（蒸汽側，凝縮潜熱）：0.28×(2.09×10⁶)＝5.85×10⁵ W ✓（兩側相等＝無熱損；蒸汽數據是驗證組） 3. 溫差（蒸汽130°C凝縮恆溫）：Δt₁=130−30=100、Δt₂=130−80=50 → LMTD＝(100−50)/ln(100/50)＝50/ln2＝50/0.69＝72.5 K 4. U＝Q/(A·LMTD)＝5.85×10⁵/(10×72.5)＝807.6≈8.1×10²

易錯（既知弱點：不會用多給的數字）　數字全部有用：面積→A；水流量/比熱/溫升→Q；蒸汽凝縮水/凝縮熱→驗證Q；ln2→LMTD分母。Δt 不可用算術平均(75)，須LMTD(72.5，指數衰減故≤算術平均)。蒸汽側用凝縮潜熱非比熱(130°C恆溫靠相變)。

識別信號　題目出現 ln 數值→幾乎必用 LMTD。熱交換器四步：Q=ṁcΔT → 畫兩端溫差 → LMTD → U=Q/(A·LMTD)。

一句話：Q＝ṁcΔT(水側2.8×4180×50=5.85×10⁵，蒸汽側0.28×2.09×10⁶驗證)；LMTD＝(100−50)/ln2＝72.5K(見ln就用LMTD，蒸汽凝縮恆溫)；U＝Q/(A·LMTD)＝8.1×10²。
