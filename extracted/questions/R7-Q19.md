# R7-Q19　高分子反応（正しい組合せ）

<!-- era: new; copies in source: 1 -->

主題：高分子反応（正しい組合せ）　正解：⑤ A と D　用戶選①（B と C）

(A)（正）　纖維素氫鍵強難溶；NaOH＋CS₂（黃原酸鹽 → 黏膠嫘縈）或 [Cu(NH₃)₄]²⁺（銅氨嫘縈）可溶（純背誦）。

(B)（誤）　氯甲基化 PS＋胺 → 四級銨（固定基帶正電）→ 交換陰離子＝陰離子交換樹脂。陽離子交換樹脂是 –SO₃⁻。

(C)（誤）　乙烯醇不存在（互變異構為乙醛）；PVA 由聚乙酸乙烯酯皂化。後半 PVA＋HCHO → 維尼綸正確。

(D)（正）　聚肉桂酸乙烯酯照光 [2+2] 光二聚交聯 → 曝光部不溶留下＝負型光阻（與 R7-Q7 的 4n+2 規則相關）。

|---|---|---|
| 陰離子交換樹脂 | 陰イオン交換樹脂 | anion exchange resin |

| 乙烯醇／互變異構 | ビニルアルコール／互変異性 | vinyl alcohol / tautomerism |
| 皂化 | けん化 | saponification |
| 維尼綸 | ビニロン | vinylon |
| 負型光阻 | ネガ型フォトレジスト | negative photoresist |
| 黏膠／銅氨嫘縈 | ビスコース／キュプラ | viscose / cupro |

一句速記　固定基帶正電 → 陰離子交換；乙烯醇不存在；肉桂酸酯光交聯 → 負型。（速查第289項）
