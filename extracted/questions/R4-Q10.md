# R4-Q10　潤滑油基油

<!-- era: new; copies in source: 1 -->

主題：潤滑油基油　正解：③（最も不適切）　用戶答對（憑感覺判斷③自相矛盾）

③為何錯　粘度指數高＝溫度造成的黏度變化小（パラフィン系基準油＝100、ナフテン系＝0）。邏輯：①稱高 VI 基油需水素化分解精製 → 高 VI 是好性質 → 潤滑油要的是黏度不隨溫度變。

①②④（正確）　水素化分解（含異性化）除 S・芳香族、開環 → 高 VI 基油（API Group III）；礦物油系成本低為主流；パラフィン系 VI 高、氧化安定性好。

⑤（正確，框架）　直鏈パラフィン低溫析出ワックス → 流動點高；ナフテン環狀不易結晶 → 低溫性能好 → 電氣絕緣油、冷凍機油。

| 中文 | 日本語 | English |
|---|---|---|
| 黏度指數 | 粘度指数 | viscosity index |
| 加氫裂解／異構化 | 水素化分解／水素化異性化 | hydrocracking / hydroisomerization |
| 傾點 | 流動点 | pour point |
| 電氣絕緣油 | 電気絶縁油 | electrical insulating oil |

一句速記　VI 高＝黏度不隨溫度變；パラフィン VI 高但有ワックス，ナフテン低溫好。（速查第113項）
