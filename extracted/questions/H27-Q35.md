# H27-Q35　非理想溶液の気液平衡・気相メタノール濃度（計算）

<!-- era: new; copies in source: 1 -->

主題：非理想溶液の気液平衡・気相メタノール濃度（計算）　正解：④ 42%

核心：非理想溶液 → 拉午耳定律加活量係數 γ** 修正：Pᵢ=****γ****ᵢxᵢPᵢ^sat，yᵢ=Pᵢ/****Σ****P。**

步驟　液相甲醇x=0.10 → 水x=0.90。P甲醇=γ·x·P^sat=1.786×0.10×236.7=42.3kPa；P水=1.009×0.90×64.24=58.3kPa；P總=100.6kPa → y甲醇=42.3/100.6=0.42=42%。

用戶困惑　不認得活量係數怎麼用。破解：看到「活量係数」→ 公式前乘 γ（Pᵢ=γᵢxᵢPᵢ^sat），求氣相 y=分壓/總壓。給了 γ 就是明示非理想、要用。

陷阱③24%＝忘乘活量係數（只用理想拉午耳）的偏小值。呼應 H27-Q28：易揮発成分（甲醇蒸氣壓高×γ大）在氣相富集 → y(42%)>x(10%)，落對角線上方，此為其定量版。

一句話：非理想溶液 Pᵢ=γᵢxᵢPᵢ^sat、y=Pᵢ/ΣP；P甲醇=1.786×0.1×236.7=42.3、P水=1.009×0.9×64.24=58.3、P總100.6 → y甲醇=42%；忘乘γ掉入③24%。

【H27-Q29~Q35 計算題七連 通用心法】 1. 給的特殊常數是路標：ln→LMTD；e→exp次方；2^(1/3)→開三次方；活量係数→非理想修正。 2. 比值題消不變量：同設備/同反應→常數與單位全消，不算絕對值（Q32/33/34）。 3. 守恆優先：PV守恆(Q32)、質量/莫耳守恆(Q29/31)。 4. 單位雙查：°C→K(+273)、kJ→J、分母是溶劑or溶液。 5. 數量級檢查：除法後看商合理性(Q32的0.01 vs 0.95)。
