# R2-Q20　液晶性高分子

<!-- era: new; copies in source: 1 -->

主題：液晶性高分子　正解：②（誤り：B はサーモトロピック）

用戶失誤（選⑤）　不熟悉液晶聚合物分類。⑤ 為正確敘述。

② 為何錯　B＝アラミド（Kevlar）：全對位剛直＋醯胺氫鍵 → 熔點 ＞ 分解溫度 → 不能熔融 → 不可能是熱致型。實為リオトロピック（濃硫酸溶液中呈液晶 → 紡絲 → 高強度・高彈性率纖維，即③）。

⑤ 為何正確　A＝全芳香族ポリエステル（HBA/HNA 共聚）。均聚物熔點 ＞ 500℃；共聚 2,6-萘單元（曲柄軸型、非直線性）打亂規則性 → 熔點約 280℃ → 熔融加工（熱致型）。

①　メソゲン在主鏈 → 主鎖型。④　聚甲基丙烯酸酯主鏈＋(CH₂)₂ 間隔基＋苯甲酸苯酯型メソゲン → 側鎖型。

| 中文 | 日本語 | English |
|---|---|---|
| 液晶高分子 | 液晶ポリマー（LCP） | liquid crystalline polymer |
| 液晶原 | メソゲン | mesogen |
| 主鏈型／側鏈型 | 主鎖型／側鎖型 | main-chain / side-chain |
| 熱致型／溶致型 | サーモトロピック／リオトロピック | thermotropic / lyotropic |
| 間隔基 | スペーサー | spacer |
| 芳綸 | アラミド | aramid |

一句速記　兩條軸：液晶原在主鏈或側鏈；液晶相靠加熱（熱致）或溶劑（溶致）；芳綸不能熔融只能溶致，全芳香族聚酯以萘共聚降熔點成熱致型。（速查第205項）
