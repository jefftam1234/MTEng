# R1再-Q28　二成分系溶液の蒸気圧

<!-- era: new; copies in source: 1 -->

主題：二成分系溶液の蒸気圧　正解：④（最も不適切）

④の破綻点は「常に」

「常に」「必ず」「すべて」といった絶対量詞は、反例が一つあれば倒れる。まず疑うべき語。

活量係数 γ は理想溶液からのずれの向きを表し、1 より大きくも小さくもなる。

| γ | 呼称 | 分子間力 | 例 |
|---|---|---|---|
| γ ＞ 1 | 正の偏差 | 異種間の引力 ＜ 同種間 → 分子が逃げたがる → 蒸気圧が理想より高い | エタノール–水、ベンゼン–メタノール |
| γ ＝ 1 | 理想溶液 | 異種＝同種 | ベンゼン–トルエン |
| γ ＜ 1 | 負の偏差 | 異種間の引力 ＞ 同種間 → 引き留められる → 蒸気圧が理想より低い | クロロホルム–アセトン（水素結合）、HCl–水、アセトン–水 |

負の偏差の典型機構：クロロホルムの C–H とアセトンの C=O が水素結合を作り、同種どうしより強く引き合うので双方とも蒸発しにくい。

向きの覚え方：異種分子が「仲が良い」→ 液相に留まる → 蒸気圧が下がる → γ＜1。「仲が悪い」→ 逃げたがる → γ＞1。正の偏差が極端だと最低沸点共沸（エタノール–水 95.6 %）、負の偏差が極端だと最高沸点共沸（HCl–水 20.2 %）。

②③は対で理解する——ラウールとヘンリーは同じ図の両端の極限則

|  | 対象 | 濃度条件 | 式 |
|---|---|---|---|
| ラウールの法則 | 溶媒（多数成分） | x → 1（濃度が大きい） | p_A ＝ x_A · p_A°（純成分蒸気圧） |
| ヘンリーの法則 | 溶質（少数成分） | x → 0（希薄） | p_B ＝ x_B · k_H（ヘンリー定数） |

違いは比例定数だけ。物理像：溶媒の濃度が 1 に近いと、溶媒分子の周囲はほぼ同種なので環境が純物質と同じ → 純物質の蒸気圧に比例（ラウール）。溶質の濃度が 0 に近いと、溶質分子の周囲は全て溶媒なので環境は均一だが純溶質の環境ではない → 濃度に比例はするが比例定数が p° ではなく k_H（ヘンリー）。②③の「大きく」「小さく」を入れ替えると誤り肢になる——この型の改造は頻出。

①が正しい　アントワン式 log₁₀P ＝ A − B/(T ＋ C)。A、B、C は物質固有の定数で、クラウジウス・クラペイロン式に C 項を加えて曲線を補正した実用式。算出するのは「純成分」の蒸気圧であり、これがラウール式の p° にあたる。①と②は論理的に繋がっている。

⑤が正しい——浸透圧の蒸気圧による解釈

① 溶質を加える → 溶媒のモル分率が下がる → 蒸気圧降下（ラウール）② 蒸気圧降下 ⇔ 溶媒の化学ポテンシャルの低下（μ ＝ μ° ＋ RT ln p）③ 半透膜の両側で化学ポテンシャルが不等（純水側が高い）→ 水が溶液側へ流れる ④ 流れを止めるには溶液側の化学ポテンシャルを純水の水準まで上げる必要がある ⑤ 凝縮相の化学ポテンシャルは加圧で上げられる（dμ ＝ V_m dP）⑥ そのために必要な圧力が浸透圧 π

πV_m ＝ RT ln(p°/p)。希薄極限で展開すればファントホッフ式 π ＝ RTC/M（R1再-Q20）に戻る。

蒸気圧降下・沸点上昇・凝固点降下・浸透圧の四つの束一的性質は、すべて「溶媒の化学ポテンシャルが希釈で下がる」という一つの原因から出る。

一句速記　活量係数は 1 より大きくも小さくもなる（水素結合で引き合えば γ＜1 の負の偏差）。ラウールは溶媒・x→1・p° を使い、ヘンリーは溶質・x→0・k_H を使う。 R1再-Q29

主題：管型反応器と槽型反応器　正解：①（最も不適切）

①が誤り——槽型（CSTR）は同じ反応率を得るのにより大きな容積を要する

作問が巧妙なのは、「槽内の濃度を均一にできる」という前半が事実である点。しかしその事実が導く結論は設問と逆になる。

設計式（A → B、一次反応 −r_A ＝ kC_A）

槽型（CSTR、完全混合）：槽内の濃度はどこでも出口濃度に等しいので、速度式には出口条件を代入する。

V(CSTR) ＝ F_A0·X/(−r_A)出口 ＝ v₀C_A0X/[kC_A0(1−X)] ＝ (v₀/k)·X/(1−X)

管型（PFR、押出し流れ）：濃度が軸方向に連続変化するので積分する。

V(PFR) ＝ F_A0∫dX/(−r_A) ＝ (v₀/k)·ln[1/(1−X)]

| 反応率 X | V(CSTR) | V(PFR) | 倍率 |
|---|---|---|---|
| 0.5 | 1.00 | 0.693 | 1.44 |
| 0.9 | 9.00 | 2.303 | 3.91 |
| 0.99 | 99.0 | 4.605 | 21.5 |

CSTR の方が常に大きく、反応率が高いほど差が開く。

物理的理由（公式を覚えなくても出る）　CSTR の「均一」こそが弱点。原料は槽に入った瞬間に出口濃度まで希釈されるので、反応器全体が最も遅い速度で運転される。PFR には濃度勾配があり、入口側は高濃度・高速度で働くので、大部分の容積が CSTR より速い条件で働く。

通則：正の反応次数（n ＞ 0）なら PFR ＜ CSTR が常に成り立つ。（次数が負、または自触媒的な反応では逆転しうる。）

図解（Levenspiel プロット）　1/(−r_A) を X に対して描くと、PFR ＝ 曲線下の面積、CSTR ＝ 出口点の高さの長方形。1/(−r_A) が単調増加なら長方形が必ず大きい。公式より図の方が覚えやすい。

②は正しい　PFR は流れながら反応が進むので、成分 A の濃度は入口から出口へ単調に減少する（軸方向に勾配、径方向は均一、軸方向混合なし）。

③は正しい　入口で C_A が最大 → 反応速度 kC_A が最大 → 単位容積あたりの発熱が最大。よって均一温度を保つには入口付近の除熱を大きくする必要がある。

（失敗の型）機構は正しく推論できたのに、結論を選択肢と逆に当てはめた。「出口付近は反応速度が低いから温度上昇が小さい」という推論はそのまま③が正しい理由になる。推論し終えたら、結論と選択肢の文面を一語ずつ突き合わせてから判定する。

二つの反応器の対照

|  | 管型（PFR） | 槽型（CSTR） |
|---|---|---|
| 濃度分布 | 軸方向に勾配 | 均一＝出口濃度 |
| 同反応率での容積 | 小 | 大 |
| 発熱の分布 | 入口に集中 | 全槽均一 |
| 除熱・温度制御 | 入口で強化が必要、均温が難しい | 容易 |
| 滞留時間分布 | 狭い | 広い（短絡成分あり） |
| 適する場面 | 大量生産、高反応率 | 温度制御が重要、多品種少量、高粘度 |

一句速記　CSTR は入った瞬間に出口濃度まで薄まり全槽が最も遅い速度で動くので、同じ反応率なら PFR より容積が大きい（X＝0.9 で約 4 倍）。PFR は入口が高濃度なので発熱が集中し除熱が要る。
