# H27-Q16　高分子溶液の浸透圧 語句組合せ（最も適切）

<!-- era: new; copies in source: 1 -->

主題：高分子溶液の浸透圧 語句組合せ（最も適切）　正解：⑤ 半透膜/浸透圧/数平均分子量/ファントホッフの式/第2ビリアル係数

逐格判定　【ア】只通溶劑不通高分子＝半透膜（「透過膜」非標準術語，砍③④）。【イ】＝浸透圧（「透過圧」非標準，砍③④）。【ウ】浸透壓是依数性（只數粒子個數）→ 測得数平均分子量 Mₙ（砍②③重量平均）。【エ】π=RTC/M=cRT，與理想氣體 P=cRT 同形 → ファントホッフの式（砍①②③寫成ファンデルワールス）。【オ】π/RTC=1/M+A₂C+…，「近似的に C に比例」取一次項 → 比例定数＝第2ビリアル係数（第1是常數項1/M，砍①寫第1、②③寫第3）。

エ 的陷阱（你不會的一格）　ファントホッフ（van ’t Hoff，浸透壓 π=cRT）vs ファンデルワールス（van der Waals，實氣體 (P+a/V²)(V−b)=RT）——兩者皆荷蘭人、名字皆「ファン」開頭。判別：題目式無 a/b 修正項＝理想式 → 必為ファントホッフ。此一格即可砍①②③，剩④⑤，再看ア半透膜 vs 透過膜 → ⑤。兩步定案。

オ（你不會的一格）　ビリアル展開常數項 1/M 算「第1」，第一個含濃度的修正項才是「第2」→ 與 C 成正比的比例定数＝第2ビリアル係数。物理意義：A₂>0良溶劑、=0θ溶劑、<0貧溶劑。

跨題連結　與 H27-Q14（平均分子量定義、x↔数/w↔重量）直接相連：浸透壓法測 Mₙ。測定法：π/C 對 C 作圖外插 C→0，截距求 Mₙ、斜率求 A₂。

一句話：浸透圧 π=cRT＝ファントホッフ式（非ファンデルワールス，後者有 a/b 項）；依数性測 Mₙ；π/RTC 一次項比例定数＝第2ビリアル係数。
