H29-Q27　気体の性質と蒸発潜熱

考點　找最適切者。正解：①（原選⑤）

正答①為何對　「気体の粘度は、温度の上昇とともに増大する」——正確。気体と液体の最も根本的な差異。

気体には分子間引力がほとんど効かず、粘性の正体は「分子が層を越えて飛び移ることによる運動量輸送」。温度上昇 → 分子の熱運動が速くなる → 層間を飛び移る頻度が増える → 運動量輸送が活発化 → 粘度が増大。 　気体分子運動論　μ = (1/3)ρ v̄ λ ∝ √T 　気体の粘度は圧力にほぼ依存しない（低〜中圧域）。圧力上昇で密度 ρ は増えるが平均自由行程 λ が減り、両者が相殺するため。

|  | 気体 | 液体 |
|---|---|---|
| 粘性の起源 | 分子の運動量輸送 | 分子間引力（凝集力） |
| 温度上昇時 | 粘度↑ | 粘度↓ |
| 温度依存 | μ ∝ √T | μ ∝ exp(E/RT)（Andrade式） |

日常経験（機油・蜂蜜を温めると薄くなる）は液体の話。気体は逆。実例：空気の粘度は 0℃ で 1.71×10⁻⁵ Pa·s、100℃ で 2.17×10⁻⁵ Pa·s（約 27% 増）。

②　蒸発潜熱は圧力上昇とともに増大——誤。逆に減少する。圧力上昇 → 沸点上昇 → 液相と気相の密度差が縮まる → 相変化に要するエネルギーが減る → 臨界点で潜熱ゼロ。

| 圧力 | 飽和温度 | 蒸発潜熱 |
|---|---|---|
| 0.1 MPa | 100℃ | 2257 kJ/kg |
| 1 MPa | 180℃ | 2015 |
| 10 MPa | 311℃ | 1317 |
| 22.06 MPa（臨界点） | 374℃ | 0 |

Watson 式　ΔHv/ΔHv,0 = ((1−Tr)/(1−Tr,0))^0.38、Tr = T/Tc。高圧蒸気は単位質量あたりの熱輸送能力が低い——蒸気配管設計の要点。

③　気体の熱伝導率は温度上昇とともに減少——誤。粘度と同じ機構（分子の熱運動によるエネルギー輸送）なので λ = (1/3)ρ c_v v̄ ℓ ∝ √T で増大する。粘度・熱伝導率・拡散係数は三つとも分子運動論由来で同方向。

| 状態 | 温度上昇時の熱伝導率 | 機構 |
|---|---|---|
| 気体 | 増大 | 分子運動 |
| 液体 | 減少（水は約130℃まで例外的に上昇） | 分子間相互作用 |
| 金属 | 減少 | 自由電子の散乱増加 |
| 絶縁体・セラミックス | 減少 | フォノン散乱増加 |

④　気体のエンタルピーは圧力上昇とともに増大——誤。理想気体では H = H(T) のみで圧力に依存しない（(∂H/∂P)_T = 0）。実在気体では (∂H/∂P)_T = −C_P·μ_JT、常温の大部分の気体は μ_JT ****>**** 0 なのでわずかに減少。理想でも実在でも「増大」は誤り。**** ****　④と⑤は同じ偏微分の二つの切り方：④は等温での H の P 依存性、⑤は等エンタルピーでの T の P 依存性。両方とも μ_JT の符号で決まる。出題者が並べているのはこの関連を問うため。

⑤　25℃の高圧水素を減圧すると温度は低下する——誤。水素は昇温する。

ジュール・トムソン係数 μ_JT = (∂T/∂P)_H。減圧時 dP****<****0 なので、μ_JT > 0 なら降温、μ_JT < 0 なら昇温。

| 気体 | 最高逆転温度 | 25℃(298K) での挙動 |
|---|---|---|
| H₂ | 約 202 K（−71℃） | 298 >** 202 → 昇温** |
| He | 約 45 K | 昇温 |
| Ne | 約 250 K | 昇温 |
| N₂ | 約 621 K | 降温 |
| 空気 | 約 603 K | 降温 |
| CO₂ | 約 1500 K | 降温 |
| CH₄ | 約 968 K | 降温 |

T >** T逆転 → 膨張で昇温／T ****<**** T逆転 → 膨張で降温。常温で昇温するのは H₂・He・Ne の三つだけ。** 　機構：JT 効果は分子間引力（膨張時に引力に逆らって仕事 → 降温）と分子自身の体積による斥力（膨張時に斥力エネルギー解放 → 昇温）の競合。水素とヘリウムは分子間引力が異常に小さい（沸点 20 K、4 K）ため斥力効果が勝つ。 　実務上の安全課題：70 MPa の高圧水素タンクから漏洩しても冷えず、むしろ昇温して発火リスクがある——水素ステーション設計で必ず考慮される。対照的に LNG（CH₄ 主体）は漏洩時に急冷して白霧を生じる。液体水素の製造が難しいのも、JT 液化に先立って液体窒素で 202 K 以下に予冷する必要があるため（空気の液化＝リンデ法が直接 JT で可能なのは逆転温度 603 K だから）。

誤判分析　「スプレー缶を使うと缶が冷たくなる」という日常観察から「気体は減圧すると冷える」と推論した。観察自体は正しいが機構が違う。

| 機構 | 内容 | 必ず冷えるか |
|---|---|---|
| 蒸発潜熱 | 液体が気化して吸熱 | 必ず冷える（スプレー缶・冷房・汗） |
| 断熱膨張（外部仕事） | 気体がピストンを押して仕事 | 必ず冷える |
| ジュール・トムソン効果 | 絞り膨張、外部仕事なし | 気体と温度による |

スプレー缶の中身は液化ガス（LPG、DME）であり、冷却の主因は蒸発潜熱。JT 効果ではない。 　対策：「膨張・減圧 → 温度」の設問では三つを順に確認する。①相変化はあるか（あれば潜熱で必ず降温）②外部に仕事をするか（すれば必ず降温）③どちらもなければ JT → 逆転温度を確認（H₂・He・Ne が例外）。

一句話速記　気体の粘度と熱伝導率は温度上昇で増大（∝√T、分子運動論）、液体は逆。蒸発潜熱は圧力上昇で減少し臨界点でゼロ。理想気体のエンタルピーは温度のみの関数。H₂・He・Ne は逆転温度が常温以下なので減圧すると昇温する。
