# H28-Q19　重縮合及び重付加により得られる高分子のうち不適切なものの組合せ

<!-- era: new; copies in source: 1 -->

主題：重縮合及び重付加により得られる高分子のうち不適切なものの組合せ　正解：⑤ D、E

D ✗（不適切）

ポリウレタンは重付加であって重縮合ではない。R–N=C=O + HO–R′ → R–NH–CO–O–R′ で、イソシアネートのN=C=Oが開きアルコールのHが窒素へ移るだけで、小分子の脱離が一切ない。重縮合と重付加の唯一の区別は小分子脱離の有無。題幹自体が「重縮合及び重付加により得られる高分子」と両者を並列しているため、どれかが両者を入れ替えていると予期すべき。

E ✗（不適切）

方向が完全に逆。アラミドはアミド結合間が芳香環であるため、一般のポリアミド(ナイロン)より耐熱性も引張強度も遥かに高い(引張強度は同重量比で鋼の約5倍、400℃以上でも溶融せず炭化)。機構:①脂肪族−(CH₂)ₙ−は自由回転できるが芳香環は回転不可→鎖が剛直棒状→繊維軸方向へ高度配向。②剛直平面構造ゆえ鎖間のN–H···O=C水素結合がシート状に整列→分子間力が極めて強い。用途は防弾チョッキ、消防服、光ファイバ補強、タイヤコード。

B ✓（誤選者注意）

エチレングリコール+テレフタル酸→PET、全て正しい。PET=Poly(Ethylene Terephthalate) で原料名が製品名に入っている。エステル結合生成で脱水→重縮合。用途も合成繊維・飲料容器で正しい。工業ルートはDMT法(脱メタノール)とTPA直接エステル化法(脱水、現主流)の二つあるが両方とも重縮合なので記述に問題なし。

A ✓ と C ✓

A:ヘキサメチレンジアミン(C6ジアミン)+アジピン酸(C6二酸)→ナイロン66(二つの6は各単量体の炭素数)、デュポン命名、カロザーズ発明(H28-Q18と直結)。C:ビスフェノールA+ホスゲン→ポリカーボネート、脱HCl→重縮合。「ポリエステルの一種」は正しい——カーボネート結合−O−CO−O−は炭酸のエステルであるため。直感的に別カテゴリと感じて誤判しやすい最大の難所。熱可塑性で加工性良、Tg約145℃で耐熱性良、非晶性ゆえ透明→CD、レンズ。

錯誤模式：正しい第一直感の放棄

Dに「ポリウレタンは重付加では」という技術的な疑いを持ちながら、確信が持てずBへ乗り換えた形。組合せ型は誤りが二つ許容されるため、選択肢間で「どちらがより誤りか」を比較する必要はない。各項を独立に○×判定し、全項判定してから選択肢を見ること。項目間で取捨した時点で失点の可能性が生じる。

一句話：ポリウレタンは重付加(小分子脱離なし)で重縮合ではない;アラミドは芳香環により剛直配向し耐熱性・引張強度とも一般ポリアミドを大きく上回る;ポリカーボネートは炭酸のエステルゆえポリエステルの一種。
