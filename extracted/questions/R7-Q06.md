# R7-Q06　鏻鹽 → 磷葉立德 → Wittig 反應

<!-- era: new; copies in source: 1 -->

主題：鏻鹽 → 磷葉立德 → Wittig 反應　正解：④ 求核置換反応、リンイリド、酸塩基反応、Wittig反応　用戶答對

第1步　Ph₃P: 孤對電子攻擊 C、X⁻ 離開 → [Ph₃P⁺–CHR₂]X⁻（SN2，親核取代）→ 排除②③⑤。

第2步　鹼（n-BuLi、NaH）拔 P⁺ 相鄰的酸性 C–H → Ph₃P⁺–C⁻R₂；只有質子轉移，屬酸鹼反應（非氧化還原）。葉立德的定義：相鄰原子分帶 +／−、整體中性——用結構判斷，不要只看名稱。①④的區分點在產物一般名：亞胺（C=N）vs 葉立德（P⁺–C⁻）。

Wittig　葉立德 + 醛／酮 → [2+2] → 氧磷雜環丁烷 → 烯烴 + Ph₃P=O；驅動力＝強 P=O 鍵。穩定化葉立德 → E 型；非穩定化 → Z 型。

排除用　Mannich（胺＋甲醛＋可烯醇化羰基 → β-胺基羰基）、Gabriel（鄰苯二甲醯亞胺 → 一級胺）、Stork（烯胺 α-烷基化）皆為 N 系，不涉 P。

一句速記　PPh₃ SN2 生成鏻鹽 → 鹼拔 H 成葉立德（P⁺–C⁻）→ Wittig 把 C=O 換成 C=C，驅動力 P=O。（速查第196項）
