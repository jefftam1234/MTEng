# R3-Q23　常壓燒結（不適切な組合せ）

<!-- era: new; copies in source: 1 -->

主題：常壓燒結（不適切な組合せ）　正解：④ C、D　用戶答錯（選 ⑤ C、E）

C 為何錯　乾式壓製仍用黏結劑（漿料噴霧乾燥造粒），否則生坯無強度。

D 為何錯　脫脂不完全 → 分解氣體被封在閉氣孔、殘碳阻礙擴散；高溫只使氣體膨脹。

E（正確）　高蒸氣壓 → 蒸發-凝結主導 → 只粗大化不收縮 → 難緻密化（SnO₂）。

A・B（正確）　氧化物極性表面難分散於低介電常數非極性溶劑（電雙層不形成）；分散劑（立體障礙）與表面電位（靜電排斥）防止凝集。

用戶失點　以為「物質容易移動＝容易緻密」。需看物質是否從晶界移走。「〜すれば〜する」萬能句型多為錯誤選項。

| 中文 | 日本語 | English |
|---|---|---|
| 緻密化 | 緻密化 | densification |
| 蒸發-凝結 | 蒸発-凝縮 | evaporation–condensation |
| 黏結劑 | バインダー | binder |
| 脫脂 | 脱脂 | debinding |
| 電雙層 | 電気二重層 | electric double layer |

一句速記　物質從晶界移走才緻密化；高蒸氣壓只粗大化；脫脂不足留下閉氣孔；乾式壓製也要黏結劑。（速查第218・156項）
