# H27-Q05　有機反應的分類（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：有機反應的分類（最も不適切）　正解：⑤ ベンゼンのニトロ化は求核置換反応

為何⑤錯　ニトロ化的活性種是 NO₂⁺（求電子剤），由 HNO₃ + 2H₂SO₄ → NO₂⁺ + H₃O⁺ + 2HSO₄⁻ 生成。苯環 π 電子（電子豐富）主動攻擊 NO₂⁺ → アレニウムイオン → 脫 H⁺ 回復芳香性。故為求電子芳香族置換（SEAr），非求核置換。分類（置換）對，但進攻者身分完全反了。普通苯環電子密度高，求核劑靠近只會互相排斥；除非掛強 EWG 才走 SₙAr。

各選項（皆正確）　① アセチレン + H₂O/HgSO₄/H₂SO₄ → エノール →（ケト–エノール互変異性）→ アセトアルデヒド：分子變大、π 鍵消失 = 付加。② ブロモシクロヘキサン + KOH/エタノール溶液中 → E2 = 脱離（若為水溶液則走 Sₙ2 得シクロヘキサノール）。③ (CH₃)₃COH + HBr → Sₙ1（OH 質子化成 −OH₂⁺ 離去 → 3° カルボカチオン → Br⁻ 攻擊）= 置換。④ 醛/酮 + HCN/少量鹽基 → CN⁻ 攻擊 δ+ 羰基碳 → アルコキシド → 奪 H⁺ 得シアノヒドリン = 求核付加（正確敘述）。

易錯點（兩層）　(1) 漏看方向詞「最も不適切」而選了正確的④。(2) 前一題框架污染：把 H27-Q3 的「NO₃⁻ 是弱求核劑」延伸到本題的ニトロ化。但 NO₃⁻（負、求核）與 NO₂⁺（正、求電子）電荷相反，H₂SO₄ 的作用正是把 HNO₃ 轉成 NO₂⁺。套用上一題框架前，先確認物種電荷是否相同。

一句話：苯環電子豐富只會被求電子劑攻擊 → ニトロ化是 SEAr，活性種為 NO₂⁺ 而非 NO₃⁻。
