# H30-Q06　ハロゲン化アルキルに関する記述（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：ハロゲン化アルキルに関する記述（最も不適切）　正解：⑤

⑤ が誤りの理由：3級ハロゲン化物 + アルコキシド は Sₙ2 不可能、E2 が走る

2-ブロモ-2-メチルプロパン（t-ブチルブロミド、3級）＋ ナトリウムエトキシド（強塩基性の求核剤）／エタノール中。

Sₙ2 は不可能：3級炭素は背面が3つのメチル基で完全に塞がれており、求核剤が到達できない

エトキシドは強塩基（共役酸 EtOH の pKa 16）なので、β水素を引き抜く E2 が支配的

生成物は 2-メチルプロペン（イソブチレン）

したがって「2-エトキシ-2-メチルプロパン（t-ブチルエチルエーテル）が主生成物」は誤り。

ウィリアムソンエーテル合成の鉄則：アルコキシドは級数の高い側、ハロゲン化物は1級を使う。t-ブチルエチルエーテルを作りたければ役割を逆にして、ナトリウム** *****t*****-ブトキシド ＋ ブロモエタンとする。3級ハロゲン化物でエーテルを作ろうとする肢は定番の誤答。**

なお 3級でも弱い求核剤・弱塩基（EtOH のみ、加熱）なら Sₙ1 でエーテルが少量得られるが、エトキシドイオン（強塩基）が存在する条件では E2 が圧倒的。

② 正（誤答した肢）

2-ブタノール + PBr₃（三臭化リン） → 2-ブロモブタン。正しい。

PBr₃ はアルコールの OH をリン系の良い脱離基に変換し、Br⁻ が背面から Sₙ2 攻撃する。カルボカチオンを経ないため骨格転位が起こらないのが利点で、2級アルコールでも安全に使える。これが「OH → Br の標準法」と呼ばれる理由。

① 正　1-プロパノール + SOCl₂（塩化チオニル） → 塩化プロピル。副生物が SO₂ と HCl（ともに気体）で系から抜けるため後処理が容易。これが「OH → Cl の標準法」。SOCl₂・PBr₃ が HX より好まれる理由は共通で、転位を回避できること。

③ 正　無水エーテル中でブロモベンゼン + Mg → Grignard 試薬（フェニルマグネシウムブロミド）。

注目点：アリールハライドは Sₙ1 も Sₙ2 も起こさない（sp² 炭素で背面攻撃不可、フェニルカチオンは極めて不安定）が、Grignard 化はできる。この非対称性が出題される。微量の水でも R–H に分解するため「無水」が必須。

④ 正　エタノール中で 2-ブロモブタン + ナトリウムエトキシド → E2 で 2-ブテンが主生成物。ザイツェフ則（より置換の多い＝安定なアルケンが主）に従う。1-ブテンは副生成物。

例外＝ホフマン則：嵩高い塩基（t-BuOK、LDA）または嵩高い脱離基（第4級アンモニウム塩＝ホフマン脱離）なら、末端アルケン（1-ブテン）が主になる。塩基の嵩高さが向きを決める。

本題の構造　①②＝OH → X 変換試薬、③＝Grignard、④⑤＝E2 と Sₙ2 の競合。④が正しく⑤が誤りという配置は、「同じエトキシド／エタノール条件でも基質の級数で結論が変わる」ことを問うている。④と⑤を並べて読み、違いが基質の級数だけであることに気づけば即断できる。

一句話速記：SOCl₂ / PBr₃ は転位しない OH → X 標準法；3級ハロゲン化物 + アルコキシドは Sₙ2 不可能で E2（ザイツェフ則）。ウィリアムソン合成はハロゲン化物側を1級にする。
