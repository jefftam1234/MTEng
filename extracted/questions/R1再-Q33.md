# R1再-Q33　液液平衡（抽出）

<!-- era: new; copies in source: 1 -->

主題：液液平衡（抽出）　正解：⑤（4.5 mol）

第一手：分配係数が定数かを確認する

表の二本のタイラインで A の比を取る。

トルエン相/水相 ＝ 2.6/7.8 ＝ 1/3、　5.0/15.0 ＝ 1/3

両方とも 1/3 なので、この濃度範囲では分配係数が一定とみなせる。これが分かれば関係式が一本立つ。この確認が本題の核心。

立式　上層はトルエン相（トルエンの密度 0.87 ＜ 水 1.0）。トルエン相中の A を x mol とする。

| 相 | 溶剤 | A | 総量 | A のモル% |
|---|---|---|---|---|
| 水相（下層） | 水 100 | 20 − x | 120 − x | 100(20−x)/(120−x) |
| トルエン相（上層） | トルエン 100 | x | 100 ＋ x | 100x/(100+x) |

各相の総量は「溶剤 ＋ その相の溶質」で、両方とも足し算。相互溶解度をゼロとするので溶剤は相を移動しない。

平衡関係：x/(100+x) ＝ (1/3)·(20−x)/(120−x)

交差して：3x(120 − x) ＝ (20 − x)(100 + x)

左辺 360x − 3x²、右辺 2000 − 80x − x²

整理：2x² − 440x ＋ 2000 ＝ 0 → x² − 220x ＋ 1000 ＝ 0

解く　判別式 220² − 4×1000 ＝ 48400 − 4000 ＝ 44400

手計算の平方根は完全平方因数を先に括り出す。√44400 ＝ √(400×111) ＝ 20√111。√111 は 10.5²＝110.25、10.6²＝112.36 より約 10.54。よって 20 × 10.54 ＝ 210.7

x ＝ (220 ± 210.7)/2 → x₁ ＝ 4.65、x₂ ＝ 215.4（A の全量 20 mol を超えるので捨てる）

答え x ≒ 4.65 → 最も近いのは ⑤ 4.5 mol

実戦的には選択肢代入法が速い　「最も近い値」で選択肢が五つしかないので、二次方程式を解かずに代入して比が 1/3 に最も近いものを選ぶ。

| x | 水相 A % | トルエン相 A % | 比 | 1/3 との差 |
|---|---|---|---|---|
| 4.5 | 15.5/115.5 ＝ 13.42 | 4.5/104.5 ＝ 4.31 | 0.321 | 0.012 |
| 6.5 | 13.5/113.5 ＝ 11.89 | 6.5/106.5 ＝ 6.10 | 0.513 | 0.180 |
| 8 | 12/112 ＝ 10.71 | 8/108 ＝ 7.41 | 0.691 | 0.358 |

三回の代入の方が二次方程式より速く、符号ミスも起きない。方程式が二次以上になる、または選択肢の間隔が明らかに広い場合は代入法を優先する。

分母を近似して一次方程式にする手もある　A の量（≦20）は溶剤（100）に比べ小さいので分母を固定して：x/105 ≒ (1/3)(20−x)/115 → x ≒ 0.3043(20−x) → x ≒ 4.67。二次方程式を完全に回避できる。

本題のチェックリスト

| 項目 | 本題の値 |
|---|---|
| 分母は「溶剤 ＋ 溶質」か | 120−x、100+x（どちらも足し算） |
| 移項時に定数項も符号が変わったか | ＋1000 |
| 二次公式の分母は 2a（＝2）であって 2b ではない | 2 |
| 平方根は完全平方を先に括り出したか | √44400 ＝ 20√111 |
| 物理的に不適な根を捨てたか | x ＝ 215 ＞ 20 を捨てる |
| 答えが妥当な範囲か | 0 ＜ 4.65 ＜ 20 ✓ |

一句速記　液液平衡は複数のタイラインで分配係数が一定かを先に確認。各相の総量は溶剤＋溶質で両方足し算。選択肢の間隔が広ければ代入法が二次方程式より速く確実。
