H29-Q32　ベンゼン-トルエン系の泡点組成

考點　計算題。正解：② 0.40

ラウール則の正しい使い方

題目の式 Py_i = p_i x_i は成分ごとの関係。全圧を求めるには全成分を足す（ドルトンの分圧則）。気相は 2 成分のみなので y₁+y₂=1：

P=p1x1+p21−x1

計算（x = ベンゼンの液相モル分率）

0.1569x+0.06361−x=0.1013

0.0933x=0.0377 ⇒ x=0.404

汎用式（泡点組成）

x1=P−p2p1−p2=0.1013−0.06360.1569−0.0636=0.404

物理的意味：全圧は必ず両純成分の蒸気圧の間にあり（p₂ < P < p₁）、x₁ はその区間内での相対位置。0.0636 < 0.1013 < 0.1569 ✔。区間外なら題意に矛盾がある。

五つの選択肢はすべて異なる誤処理に対応している

| 選項 | 値 | 誤処理 |
|---|---|---|
| ① | 0.25 | (P−p₂)/p₁ ＝ 分母からトルエンを引き忘れ |
| ② | 0.40 | 正解 |
| ③ | 0.60 | 1−0.404 ＝ トルエンの分率（成分の取り違え） |
| ④ | 0.63 | y = p₁x₁/P ＝ 気相の分率（相の取り違え） |
| ⑤ | 0.68 | (P−p₂)/(p₁−P) ＝ 分母を p₁−P と誤る |

③④は「計算は正しいが答える対象を間違えた」型。「ベンゼンの液相中のモル分率」——成分と相の二語を必ず丸で囲む。H29-Q9（重量当たり）、Q11（煙点）と同型の陥穽。

誤答分析　最初に立てた式は (0.1569x)/(0.0636y) = 0.1013 という除算の形。二つの誤り：①分圧は加算して全圧になるのであって除算ではない ②2 成分系では x_トルエン = 1 − x_ベンゼン であり、y（気相）を同一式に混ぜてはならない。 　判断規則：「全圧」「合計」なら加算、「比」「相対」なら除算。相対揮発度 α = p₁/p₂ と気液平衡比 K = y/x だけが除算の形をとる。

本問の完全な平衡組成（検算用）

| 量 | 値 |
|---|---|
| x_ベンゼン（液相） | 0.404 |
| y_ベンゼン（気相） | 0.626 |
| 相対揮発度 α = p₁/p₂ | 2.47 |
| K_ベンゼン = p₁/P | 1.55（>1 → 気相に濃縮） |
| K_トルエン = p₂/P | 0.628（<1 → 液相に濃縮） |

y >** x は易揮発成分が気相に濃縮されることを示し、蒸留が成立する物理的根拠。α = K₁/K₂ = 2.47 で検算一致。α = 1 は普通の蒸留では分離不能**（共沸・沸点近接）を意味する。 　y-x 関係式　y₁ = αx₁/(1+(α−1)x₁) = 2.47×0.404/(1+1.47×0.404) = 0.626 ✔

泡点 vs 露点

|  | 泡点（液が沸き始める） | 露点（蒸気が凝縮し始める） |
|---|---|---|
| 既知 | 液相組成 x | 気相組成 y |
| 条件式 | Σp_i x_i = P | Σ(y_i/K_i) = 1 |

H29-Q30 と同一の枠組み：あちらは溶質が非揮発性で y_水 = 1 となり K = 1/x に簡略化された特殊形。

一句話速記　泡点組成 x₁ = (P−p₂)/(p₁−p₂)。ラウール則は分圧の加算であって除算ではない。0.60 はトルエン、0.63 は気相——「どの成分・どの相」を必ず確認。
