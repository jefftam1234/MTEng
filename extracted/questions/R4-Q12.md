# R4-Q12　水素エネルギー技術（下線部）

<!-- era: new; copies in source: 1 -->

主題：水素エネルギー技術（下線部）　正解：①（最も不適切）　用戶選④

①為何錯　水蒸氣改質 CH₄＋H₂O → CO＋3H₂；シフト反応 CO＋H₂O → CO₂＋H₂；總和 CH₄＋2H₂O → CO₂＋4H₂。碳必以 CO₂ 排出（グレー水素）。

④（正確）用戶選錯的理由　有機ハイドライド法：製造地加氫（トルエン → MCH），常溫液體運輸，需要地脫氫，トルエン送回。H₂ 從製造地出發必須先「裝進」載體，方向正確。

②③⑤（正確）　壓縮氫 19.6 MPa 鋼瓶束成カードル；液化氫 −253 °C 以下；FCV 需加氫站。
