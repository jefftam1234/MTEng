# R3-Q29　三成分液液平衡的直角三角圖（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：三成分液液平衡的直角三角圖（最も不適切）　正解：⑤　用戶答對（排除法）

讀點　x_C：R＝0.1、M＝0.3、E＝0.4。

⑤ 為何錯　C 收支：0.4m_E ＋ 0.1m_R＝0.3(m_E＋m_R) → 0.1m_E＝0.2m_R → m_E/m_R＝2 → E：R＝2：1，題目寫 1：2（方向對調）。刻度為質量分率，故得質量比。

①〜④（正確）　M 的 C＝0.3；F 加 C 沿 CF 線移動；CF 線上 A：B 比恆定（M：0.4：0.3＝4：3 → F 的 A≈0.57）；F 在 AB 邊上 C＝0。

用戶疑問　「為何是質量」→ 槓桿法則只是物質收支，刻度用什麼分率，得到的就是什麼單位的比。
