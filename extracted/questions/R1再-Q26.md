# R1再-Q26　X 線の透過・蛍光・回折

<!-- era: new; copies in source: 1 -->

主題：X 線の透過・蛍光・回折　正解：③（B、D が不適切）

(A) 正しい　X 線は光電吸収が主で、波長が短い＝光子エネルギーが高いほど吸収されにくく透過力が大きい（硬X線）。長波長は軟X線で吸収されやすい。

注意：「波長が長いほどよく透る」は可視光・赤外の散乱主導の経験則であり、X 線には当てはまらない。

(B) 誤り　質量吸収係数は概ね Z³〜Z⁴（Z＝原子番号）に比例するので、原子番号が大きいほど吸収が強く透過しない。

| 元素 | Z | 用途 |
|---|---|---|
| H、C、O（軟組織） | 1、6、8 | ほぼ透過（X 線写真で黒） |
| Ca（骨） | 20 | 吸収され白く写る |
| Ba（造影剤） | 56 | 強吸収 |
| Pb（防護） | 82 | ほぼ全吸収。防護衣・遮蔽壁 |

鉛が遮蔽に使われることが直接の反証。なお B は「物体が薄いほどよく透過する」（正しい）と「原子番号が大きいほど透過する」（誤り）の二つの主張を含む。一つの下線部に複数の主張があるときは分けて検証し、一つでも誤れば全体が不適切。

(C) 正しい　入射 X 線が内殻（K 殻）電子を叩き出し、外殻（L、M 殻）電子が落ちて空孔を埋める際にエネルギー差を X 線として放出する。これが特性X線（蛍光X線、二次X線）で、波長は元素に固有。X 線管球のスペクトルは連続X線（制動放射、白色X線）と特性X線の重ね合わせ。特性X線の波長と原子番号の関係はモーズリーの法則 √ν ∝ (Z − σ)。

(D) 誤り——正しくは蛍光X線分析法（XRF）

命名の論理：X 線を当てて X 線を測るのだから、方法名に X 線が残る。

| 方法 | 入射 | 測定対象 | 論理 |
|---|---|---|---|
| 蛍光X線分析（XRF） | X 線 | 特性X線（発光） | X 線 → X 線 |
| 発光分光分析（AES/OES） | 熱（火炎、ICP、アーク） | 紫外・可視光（発光） | 熱 → 光 |
| 原子吸光分析（AAS） | その元素固有波長の光 | 光の減衰 | 光 → 吸収 |
| X 線透過法 | X 線 | 透過X線の強度 | 内部構造を見る（元素分析ではない） |
| X 線回折法（XRD） | X 線 | 回折線の角度 | 結晶構造を見る |

AAS の光源は中空陰極（ホロカソード）ランプで、陰極が目的元素そのものなのでその元素の固有波長が出る。一元素一ランプが特徴であり制約。「全波長を掃引して吸収ピークを探す」のは分子吸光光度法（UV-Vis）であって AAS ではない。XRF と XRD はどちらも X 線を使うが、XRF は「何の元素か」、XRD は「原子がどう並んでいるか」を見る。

(E) 正しい　各原子が散乱した X 線の位相がそろって強めあう（強めあう干渉）と回折線が現れる。条件はブラッグの条件 2d sinθ ＝ nλ。回折角 θ から面間隔 d が逆算でき、単位格子の大きさが分かる。

一句速記　X 線は波長が短いほど透過し、原子番号が大きいほど吸収される（だから鉛で遮蔽）。X 線を当てて X 線を測るのが蛍光X線分析、熱で励起して可視光を測るのが発光分光分析、固有波長の吸収を測るのが原子吸光分析。
