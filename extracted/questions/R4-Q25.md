# R4-Q25　二成分系状態図

<!-- era: new; copies in source: 1 -->

主題：二成分系状態図　正解：③（B、C）　提示後作答（C 判錯＋A 正確 → 排除法；B 的理由未獨立掌握）

B為何錯　てこの法則：w_s·S＋w_L·O＝M、w_s＋w_L＝1 → w_s＝MO/SO、w_L＝SM/SO → 固相：液相＝MO：SM，題目寫 SM：MO 反。極端驗算：M 靠近 S → 固相多 → 固相對應遠端 MO。

C為何錯　IV 是 A₂B 基單相；III（II＋IV）、V（L＋IV）是二相區，二相區不能當「相」。

A・D・E（正確）　II＝A 基固溶體；r 共晶點、T_r 共晶溫度（L → IV＋VIII）；VI＝IV＋VIII。T_p 包晶：L＋II → IV（A₂B 分解熔融）。

| 區域 | 類型 | 組成相 |
|---|---|---|
| I | 二相 | L＋II |
| II | 單相 | A 基固溶體 |
| III | 二相 | II＋IV |
| IV | 單相 | A₂B 基中間相 |
| V | 二相 | L＋IV |
| VI | 二相 | IV＋VIII |
| VII | 二相 | L＋VIII |
| VIII | 單相 | B 基固溶體 |

一句速記　某相的量＝對面那一段；窄條・貼縱軸＝單相，夾中間＝二相；V 字底＋水平線＝共晶。（速查第184項）
