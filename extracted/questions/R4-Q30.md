# R4-Q30　標準反応エンタルピー（計算）

<!-- era: new; copies in source: 1 -->

主題：標準反応エンタルピー（計算）　正解：①（發熱）　用戶答對（但稱「正為發熱」反）

修正　ΔH 負＝發熱；舊式反應熱 Q 正＝發熱（符號相反）。題目為 ΔH。

| 反應 | ΔH（kJ/mol） |
|---|---|
| ① CO＋H₂ → C＋H₂O(l) | −175（發熱） |
| ② CO＋H₂O(l) → H₂＋CO₂ | ＋3（液態水；氣態約 −41） |
| ③ CO₂ → CO＋½O₂ | ＋283 |
| ④ C＋CO₂ → 2CO（Boudouard） | ＋172 |
| ⑤ C＋2H₂O(l) → 2H₂＋CO₂ | ＋178 |

一句速記　ΔH＝生成物−反應物，單質 0；負＝發熱；注意水的相態。（速查第190項）
