# R3-Q33　Freundlich 吸附平衡下的平衡濃度

<!-- era: new; copies in source: 1 -->

主題：Freundlich 吸附平衡下的平衡濃度　正解：⑤ 0.0084　用戶答對（經提示）

設定　吸附量 m（kg），總量 0.10×10＝1.0 kg，C＝(1−m)/10，q＝m/20 → m/20＝0.5√((1−m)/10) → m²＋10m−10＝0 → m＝(−10＋√140)/2＝0.916 → C＝0.084/10＝0.0084。

用戶失點　判別式寫成 100−40（b²−4ac 中 c＝−10 的正負號），得兩負根。變數 c 與二次式係數 c 撞名是誘因。

更快解法　1 − 10C＝10√C，把選項代回：⑤ 0.916 vs 0.917 ✓。配方法 (m＋5)²＝35；牛頓法 √35≈6−1/12＝5.917。
