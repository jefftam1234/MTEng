# R5-Q13　石炭（不適切なもの）

<!-- era: new; copies in source: 1 -->

主題：石炭（不適切なもの）　正解：②　用戶答對（純背誦）

② 錯　無煙炭為石炭化度最高（C ＞ 90%、揮發分最少、難著火、燃燒少煙）；最低為褐炭（含泥炭則泥炭）。

① 正　古代植物經生物化學作用・地熱地壓變質；褐炭 → 亜瀝青炭 → 瀝青炭 → 無煙炭。

③ 正　乾留＝隔絕空氣加熱（熱分解）→ コークス（高溫約 1000°C）／チャー（低溫約 500〜700°C）、ガス、タール。

④ 正　石炭ガス主成分 H₂（約 50%）＋CH₄（約 30%）。

⑤ 正　タール蒸餾 → 苯・甲苯・萘・蒽・酚類等芳香族化學品。

| 中文 | 日本語 | English |
|---|---|---|
| 煤化程度 | 石炭化度 | coal rank |
| 褐煤／亞煙煤／煙煤／無煙煤 | 褐炭／亜瀝青炭／瀝青炭／無煙炭 | lignite / subbituminous / bituminous / anthracite |
| 乾餾 | 乾留 | carbonization |
| 焦炭／半焦 | コークス／チャー | coke / char |
| 煤焦油 | タール | coal tar |

一句速記　石炭化度：褐炭＜亜瀝青炭＜瀝青炭＜無煙炭；乾留得焦炭・煤氣（H₂＋CH₄）・煤焦油（芳香族）。（速查第114・245項；關聯 H24-Q12、H25-Q13、H27-Q13）
