# R3-Q13　石炭（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：石炭（最も不適切）　正解：③　用戶答錯（選 ⑤）

③ 為何錯　褐炭石炭化度低 → 揮發分多・含氧官能基多・孔隙多 → 著火點低（約 250〜300℃；瀝青炭約 300〜400℃、無煙炭約 400〜500℃），亦易自然發火。

⑤（正確）　中國・印度等大產國即大消費國；國際貿易量只占產量一成多（石油過半）。日本幾乎全量進口是特例。

①②④（正確）　石炭化：O・H 脫除、芳香環縮合發達（褐炭 → 亞瀝青炭 → 瀝青炭 → 無煙炭）；原料炭＝強黏結性、製焦炭；微粉炭燃燒為燃煤發電主流。

用戶失點　著火點方向判斷正確，但用日本的進口構造套用到全球貿易構造。

| 中文 | 日本語 | English |
|---|---|---|
| 褐炭 | 褐炭 | lignite |
| 揮發分 | 揮発分 | volatile matter |
| 著火點 | 着火点 | ignition point |
| 自然發火 | 自然発火 | spontaneous combustion |
| 原料炭 | 原料炭 | coking coal |

一句速記　石炭化度低 → 揮發分多 → 著火點低、易自然發火；煤炭國際貿易只占產量一成多。（速查第114・80項）
