# R5-Q21　金属の結晶構造（不適切な組合せ）

<!-- era: new; copies in source: 1 -->

主題：金属の結晶構造（不適切な組合せ）　正解：③ B、C　用戶答對（對 B 有疑：以為六方最密較密）

B 錯　立方最密＝面心立方（ABC 堆疊），不是體心立方。六方最密（ABAB）與立方最密同為充填率 74%、配位數 12，只差堆疊順序。

C 錯　面心立方單位晶格＝1/8×8＋1/2×6＝4 個（2 個是體心立方）。

A・D・E 正　大部分金屬取最密充填（BCC 金屬也不少：鹼金屬、α-Fe、Cr、W）；BCC 配位數 8；HCP 配位數 12（同層 6＋上下各 3）。

| 中文 | 日本語 | English |
|---|---|---|
| 六方最密堆積 | 六方最密充填構造 | hcp |
| 立方最密堆積 | 立方最密充填構造 | ccp |
| 面心／體心立方 | 面心／体心立方格子 | FCC / BCC |
| 單位晶胞 | 単位格子 | unit cell |
| 配位數 | 配位数 | coordination number |
| 堆積率 | 充填率 | packing fraction |

一句速記　立方最密＝FCC（ABC），六方最密＝ABAB，同為 74%・配位 12；BCC 68%・配位 8；原子數 BCC 2、FCC 4。（速查第124項；關聯 H29-Q24）
