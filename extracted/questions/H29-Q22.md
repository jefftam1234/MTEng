H29-Q22　無機物質と応用の組合せ

考點　找最不適切者。正解：⑤ チタン酸バリウム…包丁（原選②）

正答⑤為何錯　BaTiO₃ 的本業是電子材料，不是刀具。

BaTiO₃ 的核心：ペロブスカイト型（ABO₃）與強誘電性

| 溫度 | 結晶系 | 狀態 |
|---|---|---|
| >120℃（居禮點） | 立方晶 | Ti⁴⁺ 在正中央 → 無極性（順電性） |
| <120℃ | 正方晶 | Ti⁴⁺ 偏離中心 → 自發分極 → 強誘電性 |

| 性質 | 應用 |
|---|---|
| 極高誘電率（εr ≈ 1000〜10000） | 積層セラミックコンデンサ MLCC ← 最大用途 |
| 壓電性 | 超音波振動子、蜂鳴器、點火元件 |
| PTC 特性 | 正特性サーミスタ（過熱保護） |

一支智慧型手機內有 1000 個以上 MLCC，BaTiO₃ 就是其主材料。

做陶瓷刀的是部分安定化ジルコニア（PSZ）——靠應力誘導相變增韌：Y₂O₃ 把高溫的正方晶凍結到室溫（準安定），裂紋尖端應力誘發正方晶→單斜晶相變、體積膨脹約 4%，產生壓縮應力夾住裂紋 → 破壞韌性大幅提升，稱「セラミック鋼」。硬度約 1200〜1300 HV，BaTiO₃ 僅 500〜600 HV 且脆。

①　バリウムフェライト BaFe₁₂O₁₉…永久磁石——正確。マグネトプランバイト型、ハードフェライト（保磁力大）、便宜耐蝕不含稀土。 　フェライト二分類（頻出）：ソフト（Mn-Zn、Ni-Zn、スピネル型、保磁力小）→ 變壓器芯・電感；ハード（Ba、Sr、マグネトプランバイト型、保磁力大）→ 永久磁石。「軟/硬」指磁化難易，不是機械硬度。 　永久磁石性能序列：Nd-Fe-B > Sm-Co > アルニコ > フェライト（但フェライト產量最大）。

②　アルミナ Al₂O₃…LSI 基板——正確。高絕緣（>10¹⁴ Ω·cm）、熱傳導 20〜30 W/(m·K)（陶瓷中偏高 → 散熱）、彎曲強度 300〜400 MPa、化學安定、便宜。LSI 基板不是半導體本身而是承載晶片的絕緣板，正需絕緣＋散熱＋強度。更高階替代品為 AlN（150〜200 W/(m·K)）。

③　酸化チタン TiO₂…光触媒——正確。UV（<388 nm、Eg 3.2 eV）激發 → e⁻/h⁺ → •OH 與 •O₂⁻ → 有機物分解。二大機能：酸化分解（抗菌・脱臭・NOx 分解）與超親水性（接觸角≈0 → セルフクリーニング）。 　結晶型差異：アナターゼ（3.2 eV）光觸媒活性高／ルチル（3.0 eV）作白色顏料。同一 TiO₂ 因結晶型不同用途相反。

④　安定化ジルコニア…酸素センサー——正確。Zr⁴⁺ 部分被 Y³⁺ 置換 → 電荷補償生成酸素空孔 → 高溫下 O²⁻ 經空孔移動 → 酸化物イオン伝導体。感測原理是濃淡電池，E = (RT/4F)·ln(P_O₂基準/P_O₂測定)。用途：汽車 O₂ センサー（空燃比制御）、SOFC 電解質。 　④與⑤的關聯：完全安定化（立方晶）→ 氧感測器；部分安定化 PSZ → 刀具・構造材。同一 ZrO₂ 因安定化程度不同用途不同，與 TiO₂ 的結晶型差異是同一種考法。

誤判分析　把 BaTiO₃ 誤認為 ZrO₂ 系刀具材料。片假名長化合物名的辨識障礙（與 Q12 的 PAO、Q15 的 1,2/1,4 同類）。 　對策：遇到「〜酸〜」型片假名（チタン酸バリウム、ジルコン酸鉛、ニオブ酸リチウム），先認定它是複合氧化物 → 機能材料，再想具體用途。 　現場快速判定：①③④ 全是機能材料（磁性・光學・電氣），只有 ⑤ 配了一個結構用途（刀具）→ 類別不一致者最可疑。

一句話速記　BaTiO₃ 是ペロブスカイト型強誘電體，Ti⁴⁺ 偏心 → 自發分極 → 高誘電率 → MLCC，不是刀具；陶瓷刀是 PSZ 靠應力誘導相變增韌。「〜酸〜」型複合氧化物多為機能材料。
