# R7-Q16　高分子の分解とリサイクル（正しい組合せ）

<!-- era: new; copies in source: 1 -->

主題：高分子の分解とリサイクル（正しい組合せ）　正解：③ A と C　用戶選⑤（B と C）

框架　逐步聚合物（PET・PU・尼龍）→ 醇解・水解切極性鍵；乙烯系只能熱分解，PMMA 拉鍊式解聚（> 90% 單體）、PS 約一半、PE・PP 隨機斷裂；PVC 先脫 HCl。

(A)（正）　PU 醇解切胺甲酸酯鍵 → 回收多元醇。(C)（正）　PS・PMMA 真空加熱得單體，PMMA 近定量。

(B)（誤）　PVC 約 250〜300℃ 連鎖脫 HCl（烯丙位氯活化）→ 共軛多烯 → 碳化，得不到氯乙烯。

(D)（誤）　熔融再成形為纖維＝材料回收；サーマルリサイクル＝焚燒回收熱能（純背誦）。後半醇解・甲醇解後水解得 TPA 正確。

| 中文 | 日本語 | English |
|---|---|---|
| 化學回收／材料回收／熱回收 | ケミカル／マテリアル／サーマルリサイクル | chemical / material / thermal recycling |
| 解聚 | 解重合 | depolymerization |
| 脫氯化氫 | 脱塩化水素 | dehydrochlorination |
| 上限溫度 | 天井温度 | ceiling temperature |

一句速記　逐步聚合物用醇・水切鍵；PMMA 拉鍊解聚近定量；PVC 先脫 HCl；熱回收＝焚燒取熱。（速查第288項）
