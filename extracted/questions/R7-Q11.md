# R7-Q11　ASTM 認證 SAF 製造技術（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：ASTM 認證 SAF 製造技術（最も不適切）　正解：⑤「流動接触分解による SPK」　用戶推理正確

⑤（誤）　木質生質・都市垃圾（固體、成分雜）→ 氣化 → 合成氣 → 費托合成 → 氫化處理＝FT-SPK。FCC 是重質油製汽油的煉油製程，無法直接處理固體，也非 ASTM SAF 路線。

①〜④（正）　HEFA（油脂加氫）、HFS-SIP（糖發酵 → 金合歡烯 → 氫化）、FT-SPK/A（加非石油芳香族烷基化物）、ATJ（醇 → 烯 → 低聚 → 氫化）。

| 中文 | 日本語 | English |
|---|---|---|
| 永續航空燃料 | 持続可能な航空燃料 | SAF |
| 合成石蠟煤油 | 合成パラフィニックケロシン | synthesized paraffinic kerosene |
| 費托合成 | フィッシャー・トロプシュ合成 | Fischer–Tropsch synthesis |
| 合成氣 | 合成ガス | syngas |
| 醇製噴射燃料 | アルコール・トゥ・ジェット | alcohol-to-jet (ATJ) |

一句速記　固體走氣化＋FT、油脂走 HEFA、糖走發酵、醇走 ATJ；FCC 不是 SAF 路線。（速查第285項）
