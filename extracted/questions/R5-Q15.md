# R5-Q15　熱可塑性エラストマー（五空格・適切なもの）

<!-- era: new; copies in source: 1 -->

主題：熱可塑性エラストマー（五空格・適切なもの）　正解：④（ブロック／非相溶／ミクロ／弾性／エントロピー）　用戶答錯（選③：ランダム・可塑性）

用戶錯誤　D 欄違反多數決（弾性 3/5）選「可塑性」；名稱 elast-omer＝彈性體本身即答案。A：硬段・軟段需長的同種連續序列 → 只有嵌段共聚物（如 SBS）；無規・交替的序列長度短。

B・C　不相溶 → 想分離，但硬段軟段以共價鍵相連，不能宏觀分離 → 微相分離（數十 nm）；硬段聚集區＝擬似架橋點（物理交聯）。

D　軟段 Tg 低，室溫做微布朗運動，兩端被硬段固定 → 橡膠彈性。可塑性＝變形不回復，與彈性體相反。

E　ΔG_mix＝ΔH_mix − TΔS_mix；ΔH_mix＞0（凝聚能）阻止混合，T↑ 時 TΔS 項超過 → 均一相 → 物理交聯消失 → 熔融。推動混合的是熵，不是焓。

| 中文 | 日本語 | English |
|---|---|---|
| 熱塑性彈性體 | 熱可塑性エラストマー | thermoplastic elastomer (TPE) |
| 嵌段／無規／交替共聚物 | ブロック／ランダム／交互共重合体 | block / random / alternating copolymer |
| 硬段／軟段 | ハードセグメント／ソフトセグメント | hard / soft segment |
| 微相分離 | ミクロ相分離 | microphase separation |
| 物理交聯點 | 擬似架橋点 | pseudo-crosslink |
| 混合熵 | 混合エントロピー | entropy of mixing |

一句速記　TPE＝嵌段共聚物；不相溶但共價相連 → 微相分離，硬段凝聚成物理交聯、軟段給橡膠彈性；高溫 TΔS 勝過凝聚能 → 均一相熔融。（速查第247項）
