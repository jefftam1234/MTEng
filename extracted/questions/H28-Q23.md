# H28-Q23　炭素同素体に関するA〜Eのうち不適切なものの組合せ

<!-- era: new; copies in source: 1 -->

主題：炭素同素体に関するA〜Eのうち不適切なものの組合せ　正解：⑤ C、D

D ✗（不適切）

ダイヤモンドの熱伝導率は約2000 W/(m·K)で既知物質中最高(銅401の約5倍)。「きわめて熱を伝えにくく断熱材」は物性記述そのものが逆。実際の用途は放熱材(ヒートシンク) で、半導体・レーザーダイオードの放熱基板に使う。

なぜ自由電子がないのに熱を通すのか（重要な概念修正）

λ = λ電子 + λフォノン。「熱伝導には自由電子が必要」は金属でのみ成立する規則で、絶縁体・半導体にはフォノン(格子振動)という独立の経路がある。ダイヤモンドは絶縁体(バンドギャップ5.5eV)で自由電子はゼロだが、①C–C共有結合が極めて強く原子間「バネ」が硬い ②炭素原子が軽く振動数が高い ③結晶が完全で不純物がなくフォノン散乱が少ない、の三条件によりλフォノンが極大化する。音速は約18000 m/sで全固体中最速。λ∝C·v·ℓ。「電気を通さないが熱をよく通す」代表物質。

C ✗（不適切）

方向が逆。黒鉛の金属的導電性は面内(層に平行) であって面垂直ではない。各炭素はsp²混成で三つのσ結合が平面内、残り一つのp軌道が面に垂直。このp軌道が層内で側方重なりし層全体に広がる非局在化π電子を作るため面内は金属的に導電する。一方層間はファンデルワールス力のみで結合し層間距離0.335nm(C–C結合長0.142nmの2.4倍)と遠いため、面垂直方向の導電性は約1/1000。異方性は電気だけでなく熱伝導・強度も同様で、層間が滑りやすいことが潤滑性・鉛筆で書ける原理・H28-Q21のLi⁺インターカレーションが可能な理由につながる。

A ✓ と B ✓ と E ✓

A：クレッチマー・ハフマン法。ヘリウム中で黒鉛電極間にアーク放電→炭素蒸気が冷却凝集→C₆₀生成。Heを使う理由は①炭素の燃焼防止 ②緩衝ガスとして熱を奪いゆっくり冷却させ籠状構造へ自己組織化する時間を与える(急冷なら非晶質炭素)。1990年に大量合成を実現、1996年ノーベル化学賞。B：C₆₀は六員環20個+五員環12個でサッカーボール型。五員環12個はオイラーの定理による幾何学的必然(六員環だけでは閉じず平面の黒鉛になる)。どのフラーレンも五員環はちょうど12個。E：ダイヤモンド粉体の一般的製法は高温高圧法(約5–6GPa、1400–1600℃、Fe/Ni/Co溶媒触媒)。常温常圧では黒鉛が安定相でダイヤモンドは準安定相のため、密度の大きいダイヤモンド(3.51>2.26)を安定にするには高圧が必要。

推論方法の修正

「その用途は実際的でなさそう」という推論でDに辿り着いたのは結果的に正しいが方法が危険。同じ推論をAに適用すると失敗する(クレッチマー・ハフマン法も一見でっち上げのように聞こえるが事実)。検証可能な物性数値か機構に戻って判断すること——Dの正しい攻撃点は「ダイヤモンドの熱伝導率はいくつか→最高→記述が逆」。既知の弱点「聞こえが変な選択肢を選ぶ」の変形。

一句話：ダイヤモンドは熱伝導率が全物質中最高(フォノン経路)ゆえ断熱材でなく放熱材；黒鉛の金属的導電は面内(非局在化π電子)で面垂直(ファンデルワールス力のみ)ではない。
