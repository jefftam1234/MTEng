# H27-Q03　メタノール中 CH₃I 的 Sₙ2，四種求核剤相對速率（大小関係）

<!-- era: new; copies in source: 1 -->

主題：メタノール中 CH₃I 的 Sₙ2，四種求核剤相對速率（大小関係）　正解：⑤ D >** B ****>**** C ****>**** A**（HS⁻ > CH₃O⁻ > CH₃COO⁻ > NO₃⁻）

條件三要件　Sₙ2（速率 = k[Nu⁻][CH₃I]）／メタノール = protic 溶劑（靈魂）／CH₃I 無立體障礙。

兩步解法　先按共軛酸 pKa 排 → B >** D ****>**** C ****>**** A；再把硫（分極率大、溶劑化鬆）上提一格** → D >** B ****>**** C ****>**** A**。

各選項　①②把最弱的 NO₃⁻ 放第一（方向完全反）。③ B>D>C>A 是「純用 pKa 排」的結果——若溶劑改為 DMSO，③才是正解，錯在忽略「メタノール中」。④ 把 NO₃⁻ 排在 CH₃COO⁻ 之上，錯（NO₃⁻ 電荷攤 3 O、共軛酸為強酸）。

易錯點　誤以為 NO₃⁻ 弱是因為 N 上形式電荷 +1。錯：親核攻擊用的是 O 的孤對，形式電荷只是記帳工具；真正變數是負電荷分散在幾個 O 上（CH₃O⁻ 1 個 > CH₃COO⁻ 2 個 > NO₃⁻ 3 個）。

一句話：protic 溶劑先按 pKa 排，再把硫往上提一格 → HS⁻ > CH₃O⁻ > CH₃COO⁻ > NO₃⁻。
