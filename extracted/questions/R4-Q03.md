# R4-Q03　カルボニル縮合反応

<!-- era: new; copies in source: 1 -->

主題：カルボニル縮合反応　正解：④（不適切）　用戶選⑤

④為何錯　羧酸衍生物反應性正確排序（低→高）：醯胺 < 酯 < 酸酐 < 酸氯化物。題目整個倒置。

用戶疑問：「不是要把 C 的電子拉走嗎？」　方向對，但只看電負度（O > Cl > N）會推出酯比酸氯化物活潑，錯。決定性因素是共鳴供與（N 最強；Cl 3p–2p 不匹配最弱）與脫離基能力（Cl⁻ 最好，NH₂⁻ 最差）。詳見本追加檔「電子效應三框架」章。

用戶疑問：「換成 NO₂ 就對？」　不對。本排序比的是羧酸衍生物族系，R–C(=O)–NO₂ 不屬此族系，不能替換。

①（正確）　苯乙醛自身アルドール：α-C 攻擊另一分子醛羰基 → β-羥基醛。

②（正確）　乙酸乙酯 Claisen 縮合 → 乙醯乙酸乙酯；β-酮酯中央 CH₂（pKa 約 11）被去質子化拉動平衡；鹼用 NaOEt 避免エステル交換。

③（正確）　乙醛、丙醛都有 α-H → 2×2＝4 種產物。

⑤（正確）用戶選錯的理由　苯甲醛無 α-H 只能當求電子種；醛比酮親電 → 交叉產物為主；反應在 C6（立體障礙小、加成後仍有 α-H 可脫水）→ 共軛烯酮（E 體）單一產物（Claisen–Schmidt 縮合）。判斷關鍵：一方無 α-H，交叉アルドール即有選擇性。

一句速記　羧酸衍生物看共鳴供與＋脫離基：醯胺 < 酯 < 酸酐 < 酸氯化物；一方無 α-H，交叉アルドール不成混合物。（速查第107項、第225項、第226項）
