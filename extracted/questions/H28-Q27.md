# H28-Q27　伝熱に関する記述のうち不適切なもの

<!-- era: new; copies in source: 1 -->

主題：伝熱に関する記述のうち不適切なもの　正解：⑤

⑤ 為何錯——攻撃点は「だけで決まる」

放射伝熱量は Q = ε·F₁₂·A·σ(T₁⁴ − T₂⁴) で決まり、温度と距離のほかに放射率ε・伝熱面積A・形態係数Fにも依存する。特に形態係数は「距離」では代替できない：同じ距離でも平行大平板が向き合えばF≈1、小球同士なら極小、背中合わせならF=0で距離がいくら近くても放射伝熱はゼロ。形態係数は幾何形状と相対位置のみで決まり温度・材質に無関係、相互性 A₁F₁₂ = A₂F₂₁ を持つ。

題内矛盾による検出

④が一段落かけて「放射率εは表面性状で変わる(研磨アルミニウムは0に近く土は1に近い)」と説明しているのに、⑤は「温度と距離だけで決まる」と述べており直接矛盾する。同一問題内で二つの選択肢が衝突していれば一方は誤り——H28-Q11でEからAを反推したのと同じ技法。

② 為何正確（誤選者注意）

境膜理論の標準的記述。流体が固体表面を流れるとき、粘着条件により表面で流速0となり、その近傍に流速が遅く乱流混合の起きない薄い層流の膜(境膜) が形成される。膜内では巨視的な流体移動による熱輸送(対流)が起こらないため、熱は分子レベルの熱伝導でのみ膜を横切る。結果として境膜が熱抵抗の主体となり、温度降下の大半がこの薄い膜内で起こる(主流部は激しい混合で温度がほぼ一様、熱抵抗は小さい)。h = λ/δ の関係から、攪拌で伝熱が促進されるのは境膜厚さδが薄くなるためであり化学的効果ではない。同じ枠組みが物質移動にも適用でき、化学工学の共通概念。

①③④ 確認

①フーリエの法則 q = −λA(dT/dx)、伝熱量は伝熱面積と温度勾配に比例、負号は熱が高温から低温へ流れることを示す。これを積分した形が第63項の熱抵抗直列(R = L/λA、q = ΔT/ΣR)。③対流伝熱では Nu = C·Re0.8·Pr0.33 で、Re = ρuL/μ が密度と粘度を含み層流か乱流かを決め、Pr = c_pμ/λ も粘度を含む。密度・粘度は流動状態と境膜厚さを変えることで間接的に伝熱に効くため「熱伝導率だけでなく」は正しい。④黒体の射出能 E_b = σT⁴ に対し実在面は E = εσT⁴、研磨アルミニウム0.03–0.05、土0.9–0.95 で記述通り。応用は魔法瓶の銀メッキ内壁、宇宙機の多層断熱材。キルヒホッフの法則より同一温度で ε = α。

一句話：放射伝熱は温度と距離だけでは決まらず放射率ε・面積A・形態係数F(背中合わせならF=0)にも依る;境膜内は乱流混合がないため熱伝導支配で、ここが熱抵抗の主体。
