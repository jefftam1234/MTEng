# R7-Q05　環己烷的立體配座

<!-- era: new; copies in source: 1 -->

主題：環己烷的立體配座　正解：⑤（不適切）　用戶選②（誤）

注意　題目圖片未含問句；由正解⑤為錯誤敘述反推為「最も不適切」。

能量（kJ/mol）　椅形 0 < 扭船形 約23 < 船形 約29 < 半椅形 約45（最高，環反轉的過渡態）。共平面碳越多 → 鍵角應變＋扭轉應變越大。船形本身是兩個扭船形之間的過渡點。

①（正）　軸向鍵垂直於平均平面，上下各 3 個、交替。②（正）　赤道鍵向外伸、交替稍上稍下。③（正）　椅形最穩定。

④（正）　環反轉時 axial ⇄ equatorial 全部互換；但上／下方向不變，cis/trans 關係保持。

⑤（誤）　船形不是最不穩定，半椅形才是。用戶「船形不穩定」的記憶對，但漏看「最も」。
