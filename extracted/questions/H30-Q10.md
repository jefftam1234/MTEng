# H30-Q10　改質装置（リフォーマー）に関する記述（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：改質装置（リフォーマー）に関する記述（最も不適切）　正解：④

④ が誤りの理由：温度を上げるとオクタン価は上がるが収率は下がる

リフォーミングでは二種類の反応が競合する。

目的反応：ナフテン → 芳香族 + 3H₂（吸熱・モル数増）

副反応：水素化分解（C₇H₁₆ + H₂ → C₃H₈ + C₄H₁₀）→ 軽質ガス化して C5+ 液体収率を食う

温度を上げると活性化エネルギーの大きい水素化分解の方が速く増える。結果として芳香族分は増えてオクタン価は上がるが、同時に C₁〜C₄ ガスが大量に出てガソリン収率は下がる。コーク析出増・触媒寿命短縮の部分は正しい。

温度についてはオクタン価と収率がトレードオフ。実務では触媒劣化に応じて徐々に昇温してオクタン価を維持し、その代償として収率が落ちていく。

⑤ 正　圧力低下は両方を改善する（本装置の最重要事実）

オクタン価↑：C₆H₁₂ ⇌ C₆H₆ + 3H₂ は 1 mol → 4 mol。ル・シャトリエ原理で低圧が芳香族側に有利。

収率↑：低圧＝H₂ 分圧低下＝水素化分解の抑制 → 軽質ガス生成が減る。

触媒寿命↓：H₂ 分圧にはコーク前駆体を水添除去する働きもあるため、低圧ではコークが急速に堆積する。

温度は非対称（オクタン価と収率が逆）、圧力は対称（両方改善）——この違いが ④ と ⑤ を分ける。 　圧力低下が二つを同時に改善するからこそ、低圧 0.35〜0.5 MPa の CCR（連続再生式）が主流になった。コークの問題だけを「触媒を連続的に抜き出して再生する」ことで切り離す設計。旧来のセミリジェネ式は 1.5〜3 MPa で運転し、触媒寿命は半年〜1年。

③ 正（誤答した肢）　Pt–Re バイメタル触媒

| 世代 | 触媒 | 適用 |
|---|---|---|
| 初期 | Pt / Al₂O₃ | 失活が早い |
| 主流 | Pt–Re / Al₂O₃ | セミリジェネ式 |
| CCR 用 | Pt–Sn / Al₂O₃ | 低圧連続再生 |

第二金属（Re, Sn, Ir, Ge）は Pt のアンサンブル（集合サイト）を希釈して深度脱水素＝コーク生成を抑え、同時に Pt 粒子の焼結を防ぐ。記述は業界標準どおりで正しい。

二元機能触媒：金属機能（Pt-Re、脱水素・水素化）＋ 酸機能（塩素化 Al₂O₃、異性化・環化をカルボカチオン経由で進める）。酸点維持のため有機塩化物を微量注入し続ける。硫黄・窒素・ヒ素は触媒毒で、原料は事前に水素化脱硫（HDS）で硫黄 0.5 ppm 以下にする。

① 正　原料は重質ナフサ（C₇〜C₁₀、80〜180℃）。軽質ナフサ（C₅〜C₆）は環化しにくいので異性化装置へ回す。直留ナフサのオクタン価 40〜50 → リフォーメート 90〜100。

② 正　リフォーメート中の芳香族は 60〜70% に達し、スルホラン法などの溶剤抽出で BTX（ベンゼン・トルエン・キシレン）を分離する。石油化学基礎原料の主要供給源。 　付随事実：副生 H₂ は製油所内で最大の水素源となり、HDS・水素化分解へ供給される。

二次装置の方向記憶

| 装置 | 主反応 | H₂ |
|---|---|---|
| 接触改質 | 脱水素・環化 | 発生 |
| 接触分解（FCC） | 分解（カルボカチオン） | — |
| 水素化分解 | 分解＋水添 | 消費 |
| アルキレーション | イソブタン＋オレフィンの付加 | — |

一句話速記：リフォーマーは温度↑でオクタン価↑だが収率↓（水素化分解が増える）、圧力↓でオクタン価↑かつ収率↑（分解抑制）。どちらもコークは増える。④ は「温度↑で収率も↑」だけが誤り。
