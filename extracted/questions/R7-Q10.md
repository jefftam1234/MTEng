# R7-Q10　自動車ガソリン（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：自動車ガソリン（最も不適切）　正解：② 蒸餾範圍「−30〜+200℃」　用戶答對（前提錯）

用戶錯誤　以為 ② 與 ⑤ 矛盾。實際一致：T10 低＝輕質多＝蒸氣壓高 → 夏季氣阻。② 錯在數字：起點約 +30℃（常溫液體不可能 −30℃ 就沸騰）。

③④⑤（正）　T50 → 加速・暖機；T90 高 → 潤滑油稀釋、低 → 出力下降；蒸氣壓高 → 夏季氣阻，低 → 冬季難啟動。①（正）C4〜C10、抗爆震性・運轉性・氧化安定性。
