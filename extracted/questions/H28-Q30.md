# H28-Q30　幾何学的相似を保つスケールアップでn₂が最も小さくなる基準

<!-- era: new; copies in source: 1 -->

主題：幾何学的相似を保つスケールアップでn₂が最も小さくなる基準　正解：① 撹拌レイノルズ数

統一解法：各基準を n ∝ d^a に直し指數を比較する

ρ、μ、g、N_p は定数なので無視し、n と d を含む部分だけ抽出する。

| 基準 | 一定条件 | n ∝ d^a | 指數a |
|---|---|---|---|
| 撹拌レイノルズ数 ρnd²/μ | nd² = 一定 | n ∝ d⁻² | −2(最小) |
| 翼先端速度 πnd | nd = 一定 | n ∝ d⁻¹ | −1 |
| 単位容積当たり消費動力 N_pρn³d² | n³d² = 一定 | n ∝ d^(−2/3) | −0.67 |
| フルード数 n²d/g | n²d = 一定 | n ∝ d^(−1/2) | −0.5 |
| 翼回転数 n | n = 一定 | n ∝ d⁰ | 0 |

−2 < −1 < −0.67 < −0.5 < 0 ゆえRe一定が n₂ を最も小さくする。

P/V の導出（唯一の要注意点）

動力数の定義 N_p = P/(ρn³d⁵) より P = N_p ρn³d⁵。幾何相似ゆえ槽容積 V ∝ d³。よって P/V = N_p ρn³d⁵/d³ = N_p ρn³d²。d⁵ ÷ d³ = d² の除算を落とすと n³d⁵ 一定として指數−5/3を得てしまう。

数値感覚（dを10倍にした場合の n₂/n₁）

Re一定 0.01、翼先端速度一定 0.1、P/V一定 0.215、Fr一定 0.316、n一定 1.0。Re一定と翼先端速度一定で10倍の差があり、⑤を選ぶと正解との差はここに生じる。

Re一定が実務で使えない理由（工学的含意）

n ∝ d⁻² のため10倍スケールアップで転速が1/100になり攪拌がほぼ停止する。このとき P/V ∝ n³d² ∝ d⁻⁴ で単位容積動力が1/10000となり混合効果が皆無。理論上最も厳密な相似条件だが実用性がない。実務ではP/V一定が最も多用され(混合・分散・伝熱の大半)、剪断が重要な場合(乳化、細胞培養、結晶の破砕防止)は翼先端速度一定、自由表面の渦形状が重要ならフルード数一定を使う。幾何相似を保つ限り全ての無次元数を同時に一定にすることは不可能というのがスケールアップの根本的困難。

題型注意

攪拌工学の理解は不要で、量綱関係から機械的に解ける題型のため試験では優先処理してよい。逆向きの問い(「n₂が最も大きくなるのは」)なら答えは指數0の翼回転数一定——方向詞に注意。

一句話：スケールアップは各基準をn∝d^aに直し指數が最も負のものがn₂最小;Re一定(nd²)の−2が最小、翼先端速度(nd)は−1、P/V(n³d²)は−2/3。
