# R3-Q03　Stork 烯胺反應（シクロペンタノン + ピロリジン → エナミン → Michael 加成）

<!-- era: new; copies in source: 1 -->

主題：Stork 烯胺反應（シクロペンタノン + ピロリジン → エナミン → Michael 加成）　正解：⑤　用戶答錯（選 ①）

⑤（正確）　烯胺為中性、合成容易（酮 + 二級胺脫水）、取扱簡單——Stork 法相對於烯醇鹽的優點。

① 為何錯　共振 N–C1=C2 ↔ N⁺=C1–C2⁻：親核碳是 C2（離 N 兩個原子），與 N 相連的 C1 是親電的亞胺離子碳。

② 為何錯　化合物 A 為甲酯 –CO₂CH₃；用丙烯酸乙酯會得乙酯，應用丙烯酸甲酯。水解只水解亞胺離子。

③ 為何錯　N 孤對電子與 p 軌道重疊使 C2 電子密度增加（題文寫減少，自相矛盾）。

④ 為何錯　アクロレイン是典型 Michael 受體，會反應。

用戶失點　以為與 N 直接相連的碳電子最多。正確做法：畫共振式，負電荷所在原子即親核位置（共軛隔位傳遞）。籠統的 ⑤ 應在排除 ①〜④ 後確認，不要因看似簡單而跳過。

一句速記　烯胺親核碳＝離 N 兩個原子的碳（等同烯醇鹽 α 碳）；烯胺中性・易製備・易處理；酯基種類對照產物確認。（速查第208項）
