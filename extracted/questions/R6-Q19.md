# R6-Q19　分子量測定法：絕對／相對與平均分子量

<!-- era: new; copies in source: 1 -->

主題：分子量測定法：絕對／相對與平均分子量　正解：③ NMR 末端基定量／絕對法／Mn　用戶答錯（選④）

① 錯　VPO＝依數性 → 絕對法。② 錯　SEC 需 PS 標準品 → 相對法。

④ 錯　光散射＝絕對法（Mw）。⑤ 錯　固有黏度需 Mark-Houwink 常數 → 相對法（Mv）。

用戶推理錯誤　「NMR 是相對的」：訊號比是相對強度，但換算只用化學結構，不需標準品 → 絕對法。積分比需先除以質子數。

Mv 確實存在　Mn ≤ Mv ≤ Mw ≤ Mz。

| 中文 | 日本語 | English |
|---|---|---|
| 絕對法 | 絶対法 | absolute method |
| 末端基定量 | 末端基定量法 | end-group analysis |
| 光散射 | 光散乱法 | light scattering |
| 黏度平均分子量 | 粘度平均分子量 | viscosity-average MW |

一句速記　看需不需要標準品；末端基・依數性・光散射＝絕對；SEC・黏度＝相對。（速查第270項）
