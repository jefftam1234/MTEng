# R1再-Q02　p-メチル安息香酸の臭素化

<!-- era: new; copies in source: 1 -->

主題：p-メチル安息香酸の臭素化　正解：③（求電子／Lewis酸／メタ／オルト−パラ／3-ブロモ-4-メチル安息香酸）

なぜ「求電子」か——反応名は攻撃する側の性質で決まる

ベンゼン環は π 電子に富み、電子を供給する側。攻撃するのは Brᵟ⁺ で、電子を求める側。よって芳香族求電子置換（S_EAr）。芳香族求核置換（S_NAr）は環が電子不足（–NO₂ 等）かつ脱離基（–Cl 等）を持つ別の状況。

a＝求電子　芳香環は芳香族性により安定で、アルケンより求電子試薬への反応性に乏しい。ゆえに触媒が要る。

b＝Lewis酸　FeBr₃ の Fe は空軌道を持ち、Br₂ の孤立電子対を受け取って Br–Br⁺–FeBr₃⁻ を作る。Br–Br が分極し末端の Br が強い Brᵟ⁺ となる。電子対を受け取る＝Lewis 酸。Lewis 塩基（電子対供与）では Br を電子不足にできないので①②は不可。

c＝メタ（–COOH）　電子求引基。環を不活性化し、オルト・パラを特に電子不足にするのでメタ配向。

d＝オルト−パラ（–CH₃）　電子供与基（超共役）。環を活性化しオルト・パラ配向。④⑤は c と d が入れ替わっている典型的な方向トラップ。

e＝3-ブロモ-4-メチル安息香酸

| 位置 | COOH（C1）から見て | CH₃（C4）から見て | 判定 |
|---|---|---|---|
| C2 / C6 | オルト（不利） | メタ（不利） | ✗ |
| C3 / C5 | メタ（有利） | オルト（有利） | ✓ 両者一致 |
| CH₃ のパラ位 | — | COOH が占有済み | ✗ |

安息香酸を母体とし COOH を C1 とすると Br が 3 位、CH₃ が 4 位。「4-ブロモ-5-メチル」は出発物の CH₃ と COOH のパラ関係に反し、臭素化で既存置換基が動くことはないので即排除。論理推理題。

一句速記　名前は攻撃者で決まる。Br⁺ が電子を求めるから求電子、FeBr₃ が電子対を受け取るから Lewis 酸、COOH＝メタと CH₃＝オルト/パラの一致点が生成位置。
