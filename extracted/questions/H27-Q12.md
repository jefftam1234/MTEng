# H27-Q12　潤滑油の記述（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：潤滑油の記述（最も不適切）　正解：② ATフルードは無段変速機搭載車に使用される

為何②錯　ATフルード(ATF) 是有段自動変速機(AT)專用，無段変速機(CVT) 必須用專用的 CVTフルード(CVTF)，兩者不可互用。字面即矛盾：ATF 的 AT＝Automatic Transmission（步進式自排），CVT 是無段。機制理由（比字面判斷可靠）：AT 靠濕式多板離合器滑動接合 → 要摩擦係數平順可控；CVT 靠金屬皮帶夾在プーリー間、以金屬間摩擦傳扭矩 → 要高摩擦係數（否則打滑燒毀）。兩者摩擦調整劑方向相反，功能性互斥。

各選項（皆正確）　① エンジン油以高温・低温粘度分類（SAE 粘度グレード，如 5W-30；品質另用 API SL/SM/SN）。③ タービン油用於發電渦輪・高速回轉機軸受。④ 冷凍機油「機能上等同圧縮機油但冷媒相變且溶入油中故需特殊性能」——此為精確的轉折敘述，非矛盾（HFC 冷媒需エステル系合成油）。⑤ 電気絶縁油用於変圧器・コンデンサー，兼絶縁與冷却，鉱油外亦用合成油。

易錯點（第 5 類錯誤模式）　選了④，因「機能相同が特殊性能必要」讀起來像矛盾。但這是日文技術敘述標準句型（類別相同→轉折→條件不同→要求不同），是精確而非矛盾。與 H27-Q10（猜②「改質裝置＝BTX 製造裝置」）同型：在陌生工業領域傾向選「讀起來怪的選項」而非「事實錯的選項」。區分法：④宣稱的是「關係」（幾乎無法造假），②宣稱的是「配對」（ATF↔無段変速機，配對是最易造假的位置）。掃描優先級：方向詞 >** 配對句 ****>**** 不對稱 trade-off。**

一句話：ATF＝有段AT專用、CVT須用CVTF，兩者摩擦係數要求相反（AT要低而可控、CVT要高防打滑）功能性互斥——②把用途對調。
