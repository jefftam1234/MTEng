# H30-Q30　蒸留塔のリボイラで発生する蒸気量 V′

<!-- era: new; copies in source: 1 -->

主題：蒸留塔のリボイラで発生する蒸気量 V′　正解：④ V′ = RD + qF − W

最速の解法：次元チェックで三肢が落ちる

還流比 R ≡ L/D は無次元量（流量÷流量）。無次元量を流量と加減算することはできない。

| 選択肢 | 第一項 | 次元 |
|---|---|---|
| ① R+(F/q)−W | R（無次元） | ✗ |
| ② R+qF+W | R | ✗ |
| ③ R+(F/q)+W | R | ✗ |
| ④ RD+qF−W | RD（流量） | ✓ |

D が式に現れるのは、D が回収部に流れ込むからではなく、「比 R」を「実際の還流液流量 L = RD」に還元するため。 　不慣れな単元操作の問題では、まず次元チェックを行うと選択肢が大幅に絞れる。

q は分率なので「乗じる」　題意は q（液）、(1−q)（蒸気）なので、供給液 F 中の液体分は qF。

| 書き方 | q = 0.5 を代入 | 判定 |
|---|---|---|
| qF | 0.5F（半分が液体） | ✓ |
| F/q | 2F（供給量より多い） | ✗ 物理的に不可能 |

極端値の代入は最も手軽な検算手段。

塔内四流量

| 区域 | 液流量 | 蒸気流量 |
|---|---|---|
| 濃縮部 | L = RD | V = L + D = (R+1)D |
| 回収部 | L′ = L + qF = RD + qF | V′ = V − (1−q)F |

リボイラ周りの物質収支（入る液＝上がる蒸気＋抜く缶出液）：

L′=V′+W ⇒ V′=L′−W=RD+qF−W

別経路での検算：V′ = (R+1)D − (1−q)F = RD + D − F + qF、ここに全塔収支 F = D + W（→ D − F = −W）を代入すると RD + qF − W ✓。二経路が一致するので収支は自洽。

記憶法：液は下へ、蒸気は上へ。回収部の液は qF 分増え、回収部の蒸気は (1−q)F 分少ない。この一文から四式すべて再構成できる。

q 値の意味：過冷液 q>1／飽和液 q=1／気液混合 0<q<1／飽和蒸気 q=0／過熱蒸気 q<0。

極端値検算：q = 1（飽和液）なら供給はすべて液体で蒸気量は増えないはずなので V′ = V = (R+1)D になるべき。実際 RD + 1·F − W = RD + (D+W) − W = (R+1)D ✓。公式を覚えていなくても正誤判定できる最強の手段。

本題での斷點は R と L の混同——「比」と「量」の区別。定義式に「比」「率」「分率」が出てきたら、まず実際の量に換算してから代入する。

一句話速記：R は無次元の「比」なので必ず D を伴って L=RD の形で現れる——次元チェックで三肢が落ちる。進料は液 qF を下へ、蒸気 (1−q)F を上へ渡し、リボイラ収支 L′ = V′ + W から V′ = RD + qF − W。分率は乗じるのであって除さない。
