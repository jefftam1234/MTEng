# R5-Q10　石油精製装置（不適切なもの）

<!-- era: new; copies in source: 1 -->

主題：石油精製装置（不適切なもの）　正解：⑤　用戶答對

⑤ 錯　接觸改質原料為重質ナフサ（C7〜C10），在 Pt(-Re) 觸媒＋H₂ 下環烷脫氫・鏈烷脫氫環化生成甲苯・二甲苯，並副產 H₂。輕質ナフサ（C5〜C6）無法有效成苯環（C6 只得苯、受限）→ 送異構化或乙烯原料。

① 正　常壓蒸餾：LPG → ナフサ → 灯油 → 軽油 → 常圧残油。

② 正　減壓蒸餾：避免 350°C 以上熱裂解；出口為潤滑油原料、間接脫硫原料、分解原料、瀝青／減壓殘油。

③ 正　FCC：沸石觸媒於反應器・再生器間流動循環，重質油 → LPG、汽油、中間餾分，副產 C3/C4 烯烴。

④ 正　烷化：異丁烷＋丙烯／丁烯 → 高分支 C7〜C8 烷化油（無芳香族・烯烴・硫），H₂SO₄ 或 HF 觸媒。

| 中文 | 日本語 | English |
|---|---|---|
| 常壓／減壓蒸餾 | 常圧／減圧蒸留 | atmospheric / vacuum distillation |
| 流化床觸媒裂解 | 流動接触分解 | FCC |
| 烷化／烷化油 | アルキレーション／アルキレート | alkylation / alkylate |
| 觸媒重組／重組汽油 | 接触改質／リフォーメート | catalytic reforming / reformate |
| 異構化 | 異性化 | isomerization |
| 脫氫環化 | 脱水素環化 | dehydrocyclization |

一句速記　接觸改質原料＝重質ナフサ，脫氫成芳香族並副產 H₂；改質・異構化・烷化皆為提高辛烷值。（速查第243項；關聯 H27-Q10、H28-Q10、第76・111・145・201項）
