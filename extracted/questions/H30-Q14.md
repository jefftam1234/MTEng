# H30-Q14　重合による高分子合成の正しい反応式の組合せ

<!-- era: new; copies in source: 1 -->

主題：重合による高分子合成の正しい反応式の組合せ　正解：④（B）と（E）

判定法：高分子名を知らなくても解ける三手順

① 二つの単量体の官能基ペアを見る → 連結基が一意に決まる（図から名前を推測しない）

| 単量体 A | 単量体 B | 連結基 | カルボニルの両側 |
|---|---|---|---|
| ジオール／ビスフェノール | ジカルボン酸・酸クロリド | エステル –O–CO– | O と C |
| ビスフェノール | ホスゲン | カーボネート –O–CO–O– | O と O |
| ジアミン | ジ酸クロリド | アミド –NH–CO– | N と C |
| ジオール | ジイソシアネート | ウレタン –O–CO–NH– | O と N |
| ジアミン | ジイソシアネート | ウレア –NH–CO–NH– | N と N |
| ビスフェノール | 活性アリールハライド | エーテル –O– | — |

② 原子を数える（脱離するのは小分子だけ、炭素骨格は増減しない） ③ 繰り返し単位を二つ繋いでから数える（括弧をまたぐ原子を見落とさない）

(A) 誤　酸素が一つ足りない

ビスフェノール A（OH が二つ）＋ ホスゲン → ポリカーボネートなので、カルボニルの両側とも O でなければならない。図は右側の芳香環が直接カルボニルに結合しており（Ar–CO）、中間の O が欠落している。このままではエステル型であり、第二の OH が消えて C–C 結合が生じたことになる。 　検算：カーボネートの繰り返し単位には O が 3 個（エーテル酸素 2＋カルボニル酸素 1）必要。図には 2 個しかない。

(B) 正　m-フェニレンジアミン ＋ イソフタル酸クロリド → アミド結合 –NH–CO– ✓、芳香環の数・置換位置も整合。脱離は HCl。 　ポリ(m-フェニレンイソフタルアミド)＝ノーメックス（Nomex）、耐熱アラミド。対照：p-体どうしならケブラー（Kevlar）。m＝耐熱・難燃、p＝高強度。

(C) 誤（誤答した肢）　ウレアであるべきなのにウレタンが描かれている

原料はヘキサメチレンジイソシアネート ＋ ヘキサメチレンジアミン。イソシアネート＋アミンなら生成するのは ウレア –NH–CO–NH–。 　図は O–CO–N＝ウレタン結合を含むが、ウレタンにはジオールが必要。原料の (CH₂)₆ は両端 NH₂ であり、C–O 結合を作る酸素がどこにも無い。 　「生成物に原料が持たない原子がある」という型。イソシアネートの N=C=O の酸素はカルボニル酸素として残るだけで、連結用のエーテル酸素にはならない。ウレタンとウレアは最も入れ替えられやすい一組で、ウレタンには必ず OH が要る。

(D) 誤　炭素数が合わない

原料はテレフタル酸ジメチル ＋ エチレングリコール HO(CH₂)₂OH（C2）。図の繰り返し単位 –[CH₂–O–CO–Ar–CO–O–(CH₂)₂]– を二つ繋ぐと、ジオール部分が –(CH₂)₃– になる。これは 1,3-プロパンジオール（C3）を意味し、原料と一致しない。 　正しい PET は –[O–(CH₂)₂–O–CO–Ar–CO]–。 　繰り返し単位を一つだけ見ると括弧をまたぐ炭素を見落とす——出題者の狙いはここ。既知の弱点「多段の推導で前段の結果を完全に代入し忘れる」の高分子版。

(E) 正　ハイドロキノン ＋ 4,4’-ジフルオロベンゾフェノン → 芳香族求核置換（SNAr）でエーテル結合、脱離は HF（K₂CO₃ 使用時は KF）。繰り返し単位 –[O–C₆H₄–O–C₆H₄–CO–C₆H₄]– ＝ PEEK（エーテル・エーテル・ケトン）。 　隠れた出題点：SNAr のハロゲン反応性は F >** Cl ****>**** Br ****>**** I** で Sₙ1/Sₙ2 と逆。律速段階がマイゼンハイマー錯体の生成であり、F の強い電子求引性がこれを加速するため。para 位のカルボニル（電子求引基）が反応の前提。

重縮合 vs 重付加の切り口　A・B・D・E は小分子（HCl/CH₃OH/HF）が脱離する重縮合、C だけが脱離なしの重付加。設問の「脱離成分は省略してある」という但し書きは、この C を紛れ込ませるための仕掛け。

一句話速記：官能基ペアから連結基は一意に決まる——カルボニルの両側が O–O＝カーボネート、O–N＝ウレタン、N–N＝ウレア、O–C＝エステル、N–C＝アミド。あとは繰り返し単位を二つ繋いで炭素と酸素を数えるだけ。
