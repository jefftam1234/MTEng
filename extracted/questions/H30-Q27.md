# H30-Q27　Kröger-Vink 表記法による欠陥記号（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：Kröger-Vink 表記法による欠陥記号（最も不適切）　正解：③ ホールは h′ と表される

③ が誤りの理由：ホールは正電荷なので h•（+1）

「電子的な欠陥である」という前半は正しいが、記号の符号が逆。

| 欠陥 | 記号 | 有効電荷 |
|---|---|---|
| 電子 | e′ | −1 |
| ホール（正孔） | h• | +1 |

記憶の錨：electron の e に付くのが ′（マイナス）＝電子は負という当然の事実。ホールは電子が抜けた穴だからその逆。この一対だけ確実に押さえれば即断できる。

表記法の三要素　主符号（種類：原子記号、V＝空孔、e＝電子、h＝ホール）＋下付き（占める位置、i＝格子間）＋上付き（有効電荷：• は +1、′ は −1、× は 0）。設問では • の代わりに * を用いている。

有効電荷の計算法

有効電荷=今そこにある電荷−完全結晶でそこにあるべき電荷

格子間サイトの基準はゼロ（本来何もいない）。ここが通常サイトと違う。

① 正　酸素サイトには本来 O²⁻（−2）がいるので、完全電離した空孔は 0−(−2) = +2 → V_O••。電子を 1 個捕獲すれば +1 → V_O•。設問が「有効電荷 +1 の」と明示しているので記号と整合する。記述と記号が一致していれば正しい。

② 正　格子間は基準 0 なので、M²⁺ が割り込めば (+2)−0 = +2 → M_i••。

④ 正　ショットキー欠陥（MO 結晶）　陽イオンと陰イオンが対で抜けて表面へ移動し、組成比を保つ。

無 ⇌ V_M″ ＋ V_O••

V_M：0−(+2) = −2、V_O：0−(−2) = +2。総和 0 ✓ で電気的中性が保たれる。

⑤ 正　フレンケル欠陥（陽イオン型）　イオンが自分のサイトを離れて格子間に入る（結晶内で完結）。

M_M^× → M_i•• ＋ V_M″、総和 0 ✓

ショットキー vs フレンケル

|  | ショットキー | フレンケル |
|---|---|---|
| 内容 | 陽陰イオンが対で結晶外へ | イオンが格子間へ移動 |
| 密度 | 低下 | 不変 |
| 生じやすい条件 | 陽陰イオンの大きさが近い | 大きさの差が大きい |
| 例 | NaCl、KCl、MgO | AgCl、AgBr、CaF₂（陰イオン型） |

物理：格子間隙は狭いので小さいイオンでないと入れない。NaCl は Na⁺ と Cl⁻ のサイズが近く入る余地がないのでショットキー型、AgCl は Ag⁺ が小さく分極しやすいのでフレンケル型。CaF₂ が陰イオンフレンケル型なのは蛍石構造の格子間隙が大きいため（H30-Q26 の体心位置が空いている）で、これが F⁻ イオン伝導の起源。

欠陥反応の三つの保存則　質量保存・電荷保存（有効電荷の和が両辺で等しい）・サイト比保存（MO なら M:O = 1:1）。

応用（安定化ジルコニア）：Y₂O₃ →(ZrO₂中)→ 2Y′_Zr ＋ 3O_O^× ＋ V_O••。Y³⁺ が Zr⁴⁺ サイトに入って −1 × 2 = −2、中性化のため V_O•• が 1 個生成。サイト比保存の観点では Zr サイト 2 に対し O サイトが 4 必要だが O は 3 個しかなく、1 つが空孔になる。この酸素空孔が SOFC・酸素センサの伝導を担う。

一句話速記：Kröger-Vink は「何が・どこに・有効電荷いくつ」の三点表記。電子は e′（−1）、ホールは h•（+1）——電子が負だからホールは正。有効電荷＝今ある電荷 − 本来あるべき電荷で、格子間サイトの基準はゼロ。
