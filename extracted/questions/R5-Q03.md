# R5-Q03　速度論支配 vs 熱力学支配（1,3-ブタジエン＋HBr）

<!-- era: new; copies in source: 1 -->

主題：速度論支配 vs 熱力学支配（1,3-ブタジエン＋HBr）　正解：①（求電子／1,4-／反応速度／速度支配／熱力学支配）　用戶答錯（選④）

用戶錯誤　(1) C 填「反応物組成」：兩路徑共用同一中間體，組成相同，不可能造成差異；非可逆時產物比只由速度常數比決定。(2) D/E 對調（方向看反）：題文已寫「平衡の支配下、または【E】」→ E＝熱力学支配。(3) B：題目數據 0℃→40℃ 比例移向 15:85，平衡偏 1,4 → 1,4 較穩定，不需結構即可判斷。

1,4 較穩定　1,2-加成物 CH₂=CH–CHBr–CH₃ 為末端單取代烯；1,4-加成物 BrCH₂–CH=CH–CH₃ 為內部二取代烯（超共軛，同 Zaitsev 原理）。

1,2 生成較快　H⁺ 加到 C1 → 烯丙基陽離子（C2⁺↔C4⁺），C2 為二級碳、正電荷較集中，且 Br⁻ 停留在附近（離子對）→ 活化能低。

多數決驗證　逐欄多數＝求電子／1,2-／反応速度／速度支配／熱力学支配＝②（錯）。多數決只能縮到 ①②，關鍵格 B 仍須推理。

| 中文 | 日本語 | English |
|---|---|---|
| 動力學控制 | 速度論支配 | kinetic control |
| 熱力學控制 | 熱力学支配 | thermodynamic control |
| 親電加成 | 求電子付加 | electrophilic addition |
| 1,2-／1,4-加成物 | 1,2-／1,4-付加体 | 1,2-/1,4-adduct |
| 烯丙基陽離子 | アリルカチオン | allylic cation |
| 超共軛 | 超共役 | hyperconjugation |

一句速記　低溫不可逆→看速度→1,2 為主（速度支配）；高溫可逆→看穩定性→雙鍵取代多的 1,4 為主（熱力學支配）。反應名的求電子／求核描述進攻試劑，不是被攻擊的有機物。（速查第237項）
