# R1再-Q12　潤滑油の基油と用途

<!-- era: new; copies in source: 1 -->

主題：潤滑油の基油と用途　正解：①（最も不適切）

①が誤り——SN は API 品質分類であって SAE 粘度分類ではない

エンジン油には性格の異なる二つの表示が併記される。

| 分類 | 制定機関 | 表すもの | 表示形式 |
|---|---|---|---|
| API 分類 | American Petroleum Institute | 品質等級（性能） | SN、SM、SL／CF、CJ-4 |
| SAE 分類 | Society of Automotive Engineers | 粘度 | 5W-30、10W-40、0W-20 |

見分け方：数字と W が付いていれば粘度（SAE）、アルファベットの組合せだけなら品質（API）。

API の記号：先頭 S ＝ Service（ガソリンエンジン用、Spark ignition）、C ＝ Commercial（ディーゼル用、Compression ignition）。二文字目は後ろほど新しく高グレード（SA → … → SL → SM → SN → SP）。SN/RC の RC ＝ Resource Conserving（省燃費性と排気後処理装置保護の追加規格）。SAE の W ＝ Winter（低温粘度グレード）、「5W-30」は低温側 5W・高温側 30 のマルチグレード油。

②が正しい　ATF は自動変速機専用油。潤滑だけでなく動力伝達（トルクコンバーターの作動流体）・摩擦特性制御（クラッチ締結）・冷却・油圧制御を兼ねる専用調合油。手動変速機用の MTF とは互換性がない。

③が正しい　タービン油は発電用タービン、ターボブロワー等の高速回転機器の軸受に使用。連続運転が数年に及ぶため酸化安定性が最重要で、ほかに抗乳化性（水分離性）・防錆性・消泡性が要求される。

④が正しい　冷凍機油は冷媒と混ざって冷凍サイクルを循環し、凝縮・蒸発の状態変化を経る点が一般の圧縮機油と異なる。「冷媒との相溶性」「低温でワックス析出・凝固しない」「冷媒と反応しない」が要求される。HFC 冷媒は鉱油と相溶しないためエステル系や PAG 等の合成油が必須。

⑤が正しい　電気絶縁油は変圧器・コンデンサーで絶縁と冷却を担う。鉱油系のほかアルキルベンゼン、ポリブテン、シリコーン油等の合成油も使われる（毒性で禁止された PCB は過去の例）。

純暗記題。①の API／SAE の区別だけが判定点で、②〜⑤は用途記述として素直。

一句速記　W と数字（5W-30）は SAE 粘度分類、アルファベットのみ（SN、SN/RC、CF）は API 品質分類。S はガソリン用で後ろの文字ほど高グレード。
