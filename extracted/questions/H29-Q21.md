H29-Q21　ガラスの性質

考點　找最不適切者。正解：③

正答③為何錯　「石英ガラスは単一の SiO₂ 組成であり、化学的耐久性は高いが熱膨張率も高く急熱急冷には弱い」——前半正確，後半完全相反。石英玻璃的熱膨脹率是所有玻璃中最低的，抗熱震性極強。

| 玻璃種類 | 線膨脹係數（×10⁻⁶/K） | 耐熱衝擊 |
|---|---|---|
| 石英玻璃（SiO₂ 100%） | 約 0.5（最低） | 極強（1000℃ → 冷水 OK） |
| 硼矽玻璃（Pyrex） | 3.3 | 強 |
| 結晶化玻璃 | ≈0〜1 | 極強 |
| 鈉鈣玻璃（普通板玻璃） | 9 | 弱 |
| 鉛玻璃 | 9〜10 | 弱 |

機制：網絡形成體 vs 網絡修飾體　純 SiO₂ 全由 SiO₄ 四面體以橋氧連結成三維連續網絡，升溫時 Si–O–Si 鍵角可撓曲吸收振動而鍵長幾乎不變 → 巨觀膨脹極小。加入 Na₂O 等鹼金屬氧化物則：Na₂O + Si–O–Si → Si–O⁻Na⁺ + ⁻O–Si，生成非橋氧切斷網絡 → 結構鬆散 → 熱膨脹率上升。

耐熱衝擊參數 R = σ(1−ν)/(Eα)，α 在分母 → α 越小抗熱震越好。石英管、石英坩堝能承受高溫急冷正是靠這一點。 　常識檢驗：若石英玻璃怕急熱急冷，實驗室的石英管根本不會存在。且題目自己承認「化学的耐久性は高い」——網絡完整使化學耐久性高，熱學性質沒有理由反而變差，前後半自相矛盾。

①　鉛玻璃含 PbO 用於放射線遮蔽・美術工藝・裝飾——正確。PbO 的三效果：①Pb 原子序 82、電子密度高 → 光電效應吸收 γ/X 線 ②Pb²⁺ 極化率大 → 高折射率 1.6〜1.9（普通玻璃 1.52）③熔點低・黏度低 → 易切割雕刻。「クリスタルガラス」即含 PbO 24% 以上者，非水晶。

②　板玻璃加熱至軟化點附近吹冷風急冷 → 強化玻璃——正確。機制：表面先固化收縮，內部後固化時把表面往內拉 → 表面壓縮應力、內部拉伸應力。玻璃破壞始於表面微裂紋且裂紋只在拉應力下擴展，故表面預壓縮 → 強度 3〜5 倍。特徵：破壞時碎成無銳角粒狀（安全），但不可切割鑽孔（必須先加工再強化）。 　對照化學強化（KNO₃ 熔鹽中 Na⁺⇄K⁺ 交換，大離子擠壓產生壓縮應力）：壓縮層薄但薄板也適用 → 手機螢幕玻璃。

④　結晶化玻璃強度高、線膨脹率低——正確。製法：先以玻璃製程成形（加工性好）→ 加核形成劑（TiO₂、ZrO₂）→ 熱處理析出微細結晶。β-スポジュメン、β-ユークリプタイト 具負熱膨脹，與正膨脹的玻璃相複合可把整體 α 調到近乎零。用途：IH 調理器頂板、暖爐前窗、望遠鏡鏡片基板（ゼロデュア）。 　結晶化玻璃 ≠ 陶瓷：陶瓷是粉末燒結（有氣孔、難做複雜形狀），結晶化玻璃先用玻璃方式成形再結晶化（無氣孔、可精密成形）——這是它最大的工業優勢。

⑤　光纖用石英玻璃製法（SiCl₄ 的火焰水解：SiCl₄ + 2H₂ + O₂ → SiO₂ + 4HCl）——正確。主要工法 VAD 法（日本開發）、OVD 法、MCVD 法。必須用氣相法而非熔融天然石英的理由：傳輸損失需 <0.2 dB/km，要求 OH 基極低（1.38 μm 有強吸收）與過渡金屬 <ppb，只有可蒸餾精製的 SiCl₄ 氣體才能達到。折射率控制：芯摻 GeO₂ 提高、包層純 SiO₂ 或摻 F 降低。

一句話速記　石英玻璃是純 SiO₂、網絡完整無非橋氧，α = 0.5×10⁻⁶/K（普通玻璃的 1/20），抗熱震最強。網絡修飾體（Na₂O、PbO）越多 → 越易熔易加工，但熱膨脹率越高、耐熱越差。
