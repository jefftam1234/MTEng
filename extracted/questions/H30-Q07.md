# H30-Q07　アニリンに関する記述（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：アニリンに関する記述（最も不適切）　正解：② アニリンはシクロヘキシルアミンより強い塩基である

② が誤りの理由：アニリンは脂肪族アミンより 10⁶ 倍弱い塩基

| 化合物 | 共役酸 pKa |
|---|---|
| シクロヘキシルアミン | ≈10.6 |
| アンモニア | 9.3 |
| アニリン | ≈4.6 |

6 pKa 単位＝10⁶ 倍の差。

機構：塩基性の強さは「N の孤立電子対がどれだけ自由か」で決まる。シクロヘキシルアミンの孤立電子対は sp³ 軌道に完全に局在していて、いつでもプロトンを受け取れる。アニリンの孤立電子対は p 軌道に入って芳香環と共役し、オルト・パラ位へ非局在化している（共鳴式 4 つ）。プロトン化するとこの共役が完全に失われる（約 25 kJ/mol の安定化を捨てる）ため、平衡がプロトン化側に傾かない。

⑤ と相互検算できる：⑤「アミノ基はオルト–パラ配向性の活性化基」が正しいということは、孤立電子対を環に押し込んでいるということ。同じ孤立電子対を環にも与えプロトンにも与えることはできない。⑤ を正しいと判断した時点で、② は必ず誤りになる。一つの電子対の行き先を追うだけで二肢が同時に処理できる。

H30-Q5 と同じ框架：ピロール（孤立電子対が共役に参加 → 塩基性ほぼ無し）vs ピリジン（sp² で環外を向く → 塩基性あり、pKa 5.2）。アニリンは「参加する」側。さらに弱いのがアミド（pKa≈0、孤立電子対が C=O に取られる）——これがペプチド結合が加水分解されにくい理由でもある。

① 正（誤答した肢）　ベシャン還元

ニトロベンゼン + Fe / HCl → アニリニウム塩 →（NaOH）→ アニリン。アニリン工業製法の古典（現代は H₂/触媒水素化）。後処理で塩基を加えることが必須で、酸性のままでは塩として存在する。他の還元剤：Sn/HCl、Zn/HCl、H₂/Pd-C、SnCl₂。選択的還元（C=C や他の NO₂ を残す）には Na₂S、(NH₄)₂S、NaSH。

③ 正　アセチル化＝保護基

アニリン + 無水酢酸 /ピリジン → アセトアニリド。ピリジンは生成する酢酸を捕捉し、アニリンのプロトン化（失活）を防ぐ。 　真の目的は保護：NH₂ は活性化が強すぎて臭素化すれば一気に 2,4,6-トリブロモ体になる。NHAc にすると孤立電子対が一部 C=O に引かれて活性化度が下がり、単置換・パラ選択で止められる。反応後 H₃O⁺ または OH⁻ で脱保護。アニリンに直接フリーデル・クラフツができない（AlCl₃ と錯体を作り、環も失活する）ため、この保護が前提になる。

④ 正　ジアゾニウム塩からのヨウ素化

アニリン →（NaNO₂ / HCl、0〜5℃）→ ベンゼンジアゾニウム塩 →（NaI）→ ヨードベンゼン + N₂。

| 試薬 | 產物 | 名稱 |
|---|---|---|
| CuCl / CuBr / CuCN | Ar–Cl / Ar–Br / Ar–CN | ザンドマイヤー |
| NaI（Cu 不要） | Ar–I | — |
| HBF₄ 加熱 | Ar–F | シーマン |
| H₂O / 加熱 | Ar–OH | — |
| H₃PO₂ | Ar–H | 脱アミノ |
| フェノール類 | アゾ化合物 | カップリング（染料） |

必ず押さえる二点：ジアゾ化は 0〜5℃ 厳守（昇温するとフェノール＋N₂ に分解）、ヨウ素だけは Cu(I) が不要。

⑤ 正　アミノ基は最強クラスのオルト–パラ配向性活性化基（σₚ = −0.66）。理由は②で述べた孤立電子対の環への供与そのもの。

一句話速記：アニリンの N 孤立電子対は芳香環に非局在化しているので、環に対しては強い活性化基（o/p 配向）だがプロトンに対しては弱塩基（pKa 4.6、脂肪族アミンの 10⁻⁶）。同じ電子対を二度は使えない。
