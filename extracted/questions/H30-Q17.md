# H30-Q17　粘弾性流体の語句組合せ

<!-- era: new; copies in source: 1 -->

主題：粘弾性流体の語句組合せ　正解：③ ニュートン／チキソトロピー／ダイラタンシー／ワイセンベルグ／バラス

純暗記題（術語対応）だが、グラフと現象の対応は推理できる。

グラフの読み方　縦軸が応力、横軸がせん断速度なので、傾き＝見かけ粘度。

| 曲線 | 形 | 傾き（粘度） | 意味 |
|---|---|---|---|
| a | 直線 | 一定 | ニュートン流体 |
| b | 上に凸で寝ていく | 減少 | せん断速度↑で粘度↓ |
| c | 下に凸で立ち上がる | 増加 | せん断速度↑で粘度↑ |

【A】直線 → ニュートン流体　設問文が「流体の構造がせん断速度によって変化しない場合」と定義を与えている＝粘度が定数。 　④⑤ の「マックスウェル」はバネとダッシュポットの直列模型の名であって流体の分類名ではない。空欄が要求する詞類（「〜流体」の分類名）を先に確認するだけで二肢が落とせる（H30-Q15 と同じ手法）。

【B】曲線 b・粘度低下 → チキソトロピー　設問文の「高分子鎖の絡み合いの減少や流動誘起によるゾル化」がせん断による粘度低下を指す。 　厳密には擬塑性（ずり流動化、速度依存・瞬時）とチキソトロピー（時間依存・静置で回復）は別概念だが、本試験では「ゾル化を伴う粘度低下」をチキソトロピーと呼ぶ用法で出題され、選択肢に擬塑性が無い。例：ペンキ、ケチャップ、ベントナイト泥水、血液。

【C】曲線 c・海辺の濡れた砂 → ダイラタンシー　「粒子の充てん様式が変化して固くなる」がそのまま定義。 　機構：静置時は粒子が密充填し間隙水がちょうど潤滑している。急激にせん断すると粒子が疎な配列へ強制的に組み替えられ、空隙体積が増大（dilate）して水が足りなくなり乾いて固くなる。 　設問が挙げる例（濡れ砂）から方向を逆算できる——速く踏むと固い＝せん断速度↑で粘度↑＝曲線 c。片栗粉水も同じ。

【D】棒に巻きつきながら這い上がる → ワイセンベルグ効果　法線応力効果。回転せん断場で高分子鎖が流線方向に伸ばされ、第一法線応力差 N₁ が生じる。これが流れに垂直な張力としてゴムひものように軸心へ締め付け、液を棒に沿って押し上げる。 　ニュートン流体（水）では遠心力で外側へ振られ中心が凹む——方向が正反対なのが判別点。

【E】ダイ径より太くなる → バラス効果（ダイスウェル）　ダイ内のせん断・伸長で弾性変形として蓄えられたひずみが、口金を出て拘束が外れた瞬間に弾性回復（記憶効果）する。 　依存性：押出速度↑・分子量↑・分岐↑で膨張率↑、ダイの L/D を長くすると緩和時間が稼げて膨張率↓。押出成形・繊維紡糸ではダイ寸法を製品目標より小さく設計する。

D と E は同じ「粘弾性流体の弾性」が別の幾何で現れたもの——回転場では法線応力、押出後では弾性回復。

干渉語

| 語 | 実際の意味 |
|---|---|
| マックスウェル模型（直列） | 応力緩和を表す力学模型 |
| フォークト（ケルビン）模型（並列） | クリープを表す力学模型 |
| ダッシュポット | 模型中の粘性要素（部品名） |
| クリープ | 一定応力下でひずみが増大する現象 |
| ポアソン | ポアソン比（弾性力学の量） |

「直列＝応力緩和、並列＝クリープ」の対は単独でも出題される（第83項）。

非ニュートン流体の分類　ニュートン（一定）／擬塑性・チキソトロピー（低下）／ダイラタンシー（上昇）／ビンガム塑性（降伏応力あり＝グラフが原点を通らず縦軸を切る）。最後のものはグラフ問題での識別点。

一句話速記：グラフの傾き＝見かけ粘度。一定ならニュートン、下がればチキソトロピー、上がればダイラタンシー（濡れ砂）。棒に巻き上がるのがワイセンベルグ、ダイから出て太るのがバラス——後者二つは粘弾性の「弾性」の別の現れ。
