# R2-Q16　高分子の応力-ひずみ曲線

<!-- era: new; copies in source: 1 -->

主題：高分子の応力-ひずみ曲線　正解：⑤（C は B より変形に要する仕事が大きい）

用戶失誤（選③）　「B 比 A 有彈性」：日常的「有彈性・易拉長」＝低彈性率。彈性率＝曲線起始段斜率（硬度），A 最陡 → 彈性率最高。定義配對錯位。

| 選項 | 判定 | 理由 |
|---|---|---|
| ① 破斷點橫軸＝破斷應力 | ✗ | 橫軸是應變 → 破斷ひずみ |
| ② 破斷點縱軸＝破斷應變 | ✗ | 縱軸是應力 → 破斷応力（①②互換一對） |
| ③ A 彈性率比 B 低 | ✗ | A 斜率最陡 |
| ④ B 比 A 硬 | ✗ | B 斜率最平 |
| ⑤ C 變形功比 B 大 | ✓ | 功＝曲線下面積 ∫σdε（靭性）；C 全程在 B 上方且延伸更遠 |

曲線類型　A 硬脆（PS・PMMA）；B 軟弱；C 橡膠，後段上揚＝伸長結晶化（天然橡膠）。

| 中文 | 日本語 | English |
|---|---|---|
| 應力-應變曲線 | 応力-ひずみ曲線 | stress–strain curve |
| 彈性率（楊氏模量） | 弾性率（ヤング率） | elastic modulus |
| 破斷應力／破斷應變 | 破断応力／破断ひずみ | stress / strain at break |
| 韌性 | 靭性 | toughness |
| 伸長結晶化 | 伸長結晶化 | strain-induced crystallization |

一句速記　彈性率是起始斜率（越陡越硬），與日常「有彈性」方向相反；破斷點縱軸＝破斷應力、橫軸＝破斷應變；曲線下面積＝破壞所需的功。（速查第203項）
