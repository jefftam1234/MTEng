# H29-Q26　H29-Q26　レーザー

H29-Q26　レーザー

考點　找最不適切者。正解：③

正答③為何錯　「励起状態の系が入射光で刺激され、基底状態に戻る際に放出される光の波長は、入射光のエネルギーにより変化する」——誘導放出の本質は「放出光子が入射光子と完全に同一」であること。

λ = hc/ΔE——波長は媒質の準位差 ΔE だけで決まる。 　因果が逆転している：入射光のエネルギーは自由変数ではなく満たすべき条件。hν = ΔE なら誘導放出が起き、hν ≠ ΔE なら何も起きない（そもそも放出がない）。だから「入射光を変えたら波長が変わる」という因果鎖は成立しない。

誘導放出で生じる光子は、入射光子と ①波長 ②位相 ③進行方向 ④偏光 がすべて同一。1 個→2 個に増える＝LASER の** ****“****A****”****（Amplification）**。

反証となる実例

| レーザー | 媒質 | 波長 |
|---|---|---|
| He-Ne | Ne 原子 | 632.8 nm |
| Nd:YAG | Nd³⁺ in YAG | 1064 nm |
| CO₂ | CO₂ 分子（振動準位） | 10.6 μm |
| ルビー | Cr³⁺:Al₂O₃ | 694 nm（世界初、1960 Maiman） |
| InGaN | 半導体 | 405 nm（Blu-ray） |

Nd:YAG はキセノンランプ（白色光）でも半導体レーザー（808 nm）でも励起できるが、出力は常に 1064 nm——③ の直接的な反証。波長可変レーザー（色素、Ti:サファイア）が存在するのは媒質が広い準位帯をもつからで、入射光エネルギーで決まるわけではない。

①　レーザー光はコヒーレント——正確。誘導放出で全光子が同一になる結果、コヒーレンス・単色性・指向性・高輝度の四特徴がすべて導かれる。時間的コヒーレンス↔単色性、空間的コヒーレンス↔指向性。

②　白色光はインコヒーレント——正確。多数の原子が互いに無関係なタイミング・準位・方向で自然放出するため波長も位相もバラバラ。 　厳密には「波長が異なる」は非同調の十分条件の一つであって唯一の理由ではない（ナトリウムランプの 589 nm は単色だが非同調）。LED も自然放出なので準単色だが非同調——全像撮影や干渉測長に使えない理由。

④　自然放出の定義——正確。アインシュタインの三過程：吸収（1→0）、自然放出（0→1、自発的・確率的・方向と位相はランダム）、誘導放出（1→2、入射光子に誘発）。自然放出が支配的＝蛍光灯・LED（インコヒーレント）、誘導放出が支配的＝レーザー（コヒーレント）。

⑤　反転分布の定義——正確。熱平衡ではボルツマン分布 N₂/N₁ = exp(−ΔE/kT) < 1 なので必ず N₂ < N₁ となり、入射光は吸収が誘導放出を上回って減衰する。増幅には N₂ >** N₁** が必要で、これは熱平衡では不可能な状態ゆえポンピングで強制的に作る。 　二準位系では原理的に不可能（吸収と誘導放出の確率が等しく最大でも N₂ = N₁）。三準位系（ルビー）は終端が基底状態なので半数以上を励起する必要があり効率が悪い。四準位系（Nd:YAG）は下位レーザー準位が常にほぼ空なので少しの励起で反転が成立し高効率——現代のレーザーが四準位系を採る理由。

レーザー発振の三要素：①活性媒質（波長を決める）②ポンピング（反転分布を作る）③光共振器（増幅を繰り返す。L = mλ/2 の縦モードのみ存在でき単色性がさらに向上）。

ΔE ↔ λ の関係は他分野にも貫通：炎色反応（Na 589 nm）、原子吸光・発光分光、蛍光体の発光色、LED のバンドギャップ、そして H29-Q4 の β-カロテンが 450 nm を吸収して黄橙色に見えること——吸収と放出の違いだけで式は同一。

一句話速記　誘導放出で出る光子は入射光子と波長・位相・方向・偏光がすべて同一なのでレーザーはコヒーレント。波長は λ = hc/ΔE で媒質の準位差だけで決まる。反転分布 N₂>N₁ はボルツマン分布の逆転で、ポンピングで強制的に作る。
