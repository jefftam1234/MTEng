# H27-Q02　1-メチルシクロペンテン 兩種水合法與產物配對（最も適切）

<!-- era: new; copies in source: 1 -->

主題：1-メチルシクロペンテン 兩種水合法與產物配對（最も適切）　正解：④ C / A

方法1 ヒドロホウ素化–酸化 → C（trans-2-メチルシクロペンタノール）　BH₃ 的 B 接取代少的 C2（反 Markovnikov），H 接 C1；syn 加成 = B 與 H 同面 → C1 的 CH₃ 被頂到反面；H₂O₂/NaOH 氧化時 C–B → C–OH 保持組態 → OH(C2) 與 CH₃(C1) 異面 → trans。

方法2 オキシ水銀化–脱水銀 → A（1-メチルシクロペンタノール）　Hg(OAc)₂ 形成マーキュリニウムイオン，正電荷偏在取代多的 C1 → H₂O 從背面攻擊 C1（Markovnikov）→ NaBH₄ 脫汞。無カルボカチオン転位是其相對於酸触媒水和的優勢。

速判　A 是第三級醇，只可能來自 Markovnikov 路線 = 方法2 → 選項中唯一把 A 放在方法2 的是 ④ → 不必判立體化學即可鎖定。

易錯點　把「syn 加成」誤解為「OH 與 CH₃ 同面」→ 會選成 B（cis）。

一句話：ヒドロホウ素化 = 反 M + syn → trans-2-醇(C)；オキシ水銀化 = M 無重排 → 第三級醇(A)。
