# R5-Q14　SAF の製造技術（ASTM 認証）（不適切なもの）

<!-- era: new; copies in source: 1 -->

主題：SAF の製造技術（ASTM 認証）（不適切なもの）　正解：①　用戶答對但理由錯

用戶錯誤　以為「垃圾太雜、不能做航空燃料」。實際上木質生物質・都市垃圾可先氣化成合成氣（CO＋H₂），原料雜亂無妨；① 錯在製程名：應為フィッシャー・トロプシュ（FT-SPK），不是流動接觸分解（FCC 是石油重質油分解）。

② 正　HEFA-SPK：廢食用油・動植物油脂加氫脫氧 → 異構化／裂解；商業化最廣。

③ 正　HFS-SIP：糖發酵 → 金合歡烯（C15）→ 加氫 → 金合歡烷（異鏈烷烴）。

④ 正　FT-SPK/A：非石油輕質芳香族烷基化；噴射燃料需芳香族使密封材膨潤。

⑤ 正　ATJ-SPK：乙醇／異丁醇脫水成烯烴 → 寡聚合 → 加氫。

| 中文 | 日本語 | English |
|---|---|---|
| 永續航空燃料 | 持続可能な航空燃料 | SAF |
| 費托合成 | フィッシャー・トロプシュ合成 | Fischer–Tropsch synthesis |
| 氣化／合成氣 | ガス化／合成ガス | gasification / syngas |
| 金合歡烯 | ファルネセン | farnesene |
| 寡聚合 | オリゴマー化 | oligomerization |
| 密封材膨潤 | シール材の膨潤 | seal swelling |

一句速記　雜亂原料（木質・垃圾）→ 氣化 → FT 合成；油脂 → HEFA；糖 → 發酵加氫；醇 → ATJ。FCC 不是 SAF 製程。（速查第246項；關聯第40項）
