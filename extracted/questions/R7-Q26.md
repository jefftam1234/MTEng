# R7-Q26　非酸化物セラミックス（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：非酸化物セラミックス（最も不適切）　正解：④ ホウ化ジルコニウム　用戶選①（誤）

用戶錯誤　「含 C 就會燃燒」不成立：化合物中的 C 以強共價鍵結合；SiC 高溫表面形成 SiO₂ 保護膜（被動氧化）→ 空氣中可用到約 1600℃。MoSi₂ 同理（約 1700℃）。

④（誤）　熱電子放射材料是功函數小的 LaB₆（約 2.7 eV）・CeB₆；ZrB₂ 是超高溫陶瓷（熔點約 3250℃）（純背誦）。

②③（正）　hBN 層狀易切削、cBN 超高壓合成作切削工具（適合鐵系）；β-賽隆置換固溶、α-賽隆再加侵入型固溶。

|---|---|---|
| 碳化矽 | 炭化ケイ素 | silicon carbide |
| 六硼化鑭 | 六ホウ化ランタン | lanthanum hexaboride |
| 熱電子放射 | 熱電子放射 | thermionic emission |
| 功函數 | 仕事関数 | work function |
| 賽隆 | サイアロン | SiAlON |

一句速記　含 Si 陶瓷靠 SiO₂ 膜耐氧化；熱電子放射＝LaB₆。（速查第155項）
