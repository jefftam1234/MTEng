# R2-Q05　芳香族胺（對位取代苯胺）的鹼性

<!-- era: new; copies in source: 1 -->

主題：芳香族胺（對位取代苯胺）的鹼性　正解：③（p-アニシジン，鹼性最強）

核心框架：鹼性＝N 孤對電子的電子密度；推電子基穩定 –NH₃⁺

| 選項 | 對位取代基 | 電子效應 | pKaH | 鹼性 |
|---|---|---|---|---|
| ③ | –OCH₃ | –I 弱、+R 強 | 5.3 | 最強 |
| ② | –CH₃ | +I・超共軛 | 5.1 | 第二 |
| ① | –H | 基準 | 4.6 | 中 |
| ④ | –Cl | –I 強 ＞ +R 弱 | 4.0 | 弱 |
| ⑤ | –NO₂ | –I・–R 皆強 | 1.0 | 最弱 |

用戶失誤（選④）　「Cl 使 –NH₃⁺ 更穩定」方向顛倒。–NH₃⁺ 帶正電，能穩定它的是推電子基；Cl 拉電子使正電荷更集中、N 孤對電子更少 → 鹼性下降。混淆來源：Cl 使氯乙酸・氯苯酚酸性增強，是因為它穩定陰離子（共軛鹼）。

| 要穩定的物種 | 需要的取代基 | 結果 |
|---|---|---|
| 陰離子（RCOO⁻、ArO⁻） | 拉電子基 | 酸性增強 |
| 陽離子（R–NH₃⁺） | 推電子基 | 鹼性增強 |

OCH₃ 與 Cl 相反的原因　O 的 2p 與 C 的 2p 大小相近、重疊良好 → +R 占優；Cl 的 3p 重疊差 → –I 占優。間位 OCH₃ 只剩 –I（pKaH≈4.2，弱於苯胺）。

pKaH 的方向　共軛酸 pKa 越大 → R–NH₃⁺ 越不放 H⁺ → 胺鹼性越強。

| 中文 | 日本語 | English |
|---|---|---|
| 苯胺 | アニリン | aniline |
| 對甲苯胺 | p-トルイジン | p-toluidine |
| 對甲氧基苯胺 | p-アニシジン | p-anisidine |
| 對氯苯胺／對硝基苯胺 | p-クロロアニリン／p-ニトロアニリン | p-chloroaniline / p-nitroaniline |
| 推電子基／拉電子基 | 電子供与基／電子求引基 | electron-donating / -withdrawing group |
| 誘導效應 | 誘起効果 | inductive effect |
| 共振效應 | 共鳴効果（メソメリー効果） | resonance (mesomeric) effect |
| 超共軛 | 超共役 | hyperconjugation |
| 孤對電子 | 非共有電子対 | lone pair |
| 共軛酸 | 共役酸 | conjugate acid |

一句速記　胺的鹼性看 N 上電子密度；推電子基穩定 NH₃⁺ 使鹼性增強（OCH₃ ＞ CH₃ ＞ H ＞ Cl ＞ NO₂）；拉電子基穩定的是陰離子，只讓酸性增強。（速查第142項）
