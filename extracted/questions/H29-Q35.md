H29-Q35　剛性・断熱の閉じた系での気体の移動

考點　観念題（計算不要）。正解：③ 25℃（原選⑤）

系の取り方が全て

両タンク全体を一つの閉じた系とすると：

| 条件 | 題目の根拠 | 帰結 |
|---|---|---|
| 剛性容器（体積固定） | 密閉タンク | 外部に仕事をしない W = 0 |
| 断熱 | 外部からの入熱は無視 | Q = 0 |
| 閉じた系 | 気体は外へ出ない | n_total 一定 |

ΔU=Q−W=0 ⇒ Ufinal=Uinitial

理想気体は U = nC_vT なので

ntotalCvTfinal=ntotalCvTinitial ⇒ Tfinal=Tinitial=25℃

題目が問うのは「圧力が均一で平衡となったとき」＝最終状態であり、そのとき両タンクとも 25℃。

検算　n_A = 10⁶×10/(8.314×298) = 4036 mol、n_B = 404 mol 　P_f = (4036+404)×8.314×298/20 = 0.55 MPa（圧力は上がるが温度は変わらない）

これはジュール膨張（自由膨張）

理想気体が剛性・断熱の閉じた系内で膨張しても温度は変わらない

理由：理想気体は分子間力ゼロ → 分子が離れても位置エネルギーの変化がない → 運動エネルギー（＝温度）も変わらない。実在気体なら分子間引力に逆らう分だけわずかに降温する。

H29-Q27 のジュール・トムソン効果との区別

|  | ジュール膨張（本問） | ジュール・トムソン効果（Q27） |
|---|---|---|
| 系 | 閉じた系（気体が系外へ出ない） | 開いた系（定常流動） |
| 保存量 | 内部エネルギー U 一定 | エンタルピー H 一定 |
| 理想気体 | ΔT = 0 | ΔT = 0（μ_JT = 0） |
| 実在気体 | わずかに降温 | 逆転温度による |

どちらも理想気体では温度不変。題目が「窒素ガスは理想気体とし」と明記しているのが答えの鍵。

誤答分析：γ = 1.4 は撹乱条件

⑤ 47℃ は「γ が与えられたから PVᵞ を使おう」とした者が落ちる選択肢。閉じた系の充填・移動問題で γ を使ってはならない。

なぜ可逆断熱式が使えないか：①バルブを通る流れは絞り（throttling）で本質的に不可逆であり、系全体のエントロピーは増大する（等エントロピーの前提が成立しない）②仮にバルブを開けた瞬間に B 側が局所的に圧縮されて昇温したとしても、それは過渡状態にすぎず、「時間をかけて」開ければ内部で熱が移動して最終的に全体が均一化する。題目が問うのは平衡状態。 　「時間をかけて」の真の意味は「最終状態が均一になることを保証する」ことであって、「準静的だから可逆断熱式が使える」ではない。内部エネルギーは状態量なので、バルブを速く開けようと遅く開けようと平衡後の温度は同じ 25℃。

γ を使う場面と使わない場面の判別

| 過程 | 使う式 |
|---|---|
| 剛性・断熱・閉じた系（タンク間の移動） | ΔU = 0 → 理想気体なら ΔT = 0 |
| 定常流動・断熱・絞り | ΔH = 0 → 理想気体なら ΔT = 0 |
| 可逆断熱（圧縮機・膨張機・タービン） | PVᵞ = 一定、T₂/T₁ = (P₂/P₁)^((γ−1)/γ) ← γ はここだけ |
| 外部から容器へ充填 | ΔU = 流入分のエンタルピー |

γ を使うのは「機械が仕事をする」可逆断熱過程のときだけ

バルブ・絞り・自発的な流れがあれば不可逆であり、PVᵞ は適用できない。

変形問題への対応

| 変形 | 答 |
|---|---|
| B タンクが最初真空なら | 同じく 25℃（古典的ジュール膨張） |
| 実在気体なら | わずかに降温 |
| バルブを急に開けたら | 平衡後はやはり 25℃（内部エネルギーは状態量） |
| コンプレッサーで 0.1→0.55 MPa に圧縮したら | 約 210℃（これが γ を使う場面） |

撹乱条件としての物性定数　既載の「与えられた数値を全部使おうとすると誤答に誘導される」の上位版。γ は無関係な数字ではなく、誤った公式へ誘導するために置かれている。H29 では撹乱条件が三度出た：Q28（0℃・100 kPa → 体積換算を誘う）、Q34（相互溶解度 0.1%・0.5% → 計算に入れたくなる）、Q35（γ=1.4 → PVᵞ を誘う）。 　判断順序を修正する：「物性定数は必ず使う」は誤り。まず過程の熱力学的性質を確定し、それから使う式を決め、最後に与えられたデータが必要かを見る。

一句話速記　剛性＋断熱＋閉じた系 → ΔU = 0 → 理想気体なら温度不変（ジュール自由膨張）。バルブは絞りで不可逆なので PVᵞ は使えない。γ は可逆断熱（圧縮機・膨張機）専用で、本問では誤答へ誘導する撹乱条件。答は元の 25℃。

主題：有機溶媒に関する A〜E の正誤組合せ　正解：④ 誤／正／正／正／誤

(A) 誤　共沸を見落とすと引っかかる

「20%の水を含むトルエンを常圧で単蒸留すると、まず水が留出する」——誤り。水とトルエンは互いに溶けないため、両相共存下では全蒸気圧 P = P°(水) + P°(トルエン) となり、84.1℃で 1 atm に達する。したがって最初に出るのは水とトルエンの共沸混合物（水約20% : トルエン約80%）。題目の「20%の水」はほぼ共沸組成そのもの（実測19.6%）なので、大部分が 84.1℃ で同時に留出する。水が尽きた後、残ったトルエンが 110.6℃ で留出する。これが水蒸気蒸留の原理で、混じり合わない二液の共沸点は必ず両成分の沸点より低い。

(B) 正　「〜95℃」は波ダッシュではなく負号（−95℃）

読み取り注意点：全角のマイナス「−」が波ダッシュ「〜」に見える。トルエンの融点は −94.9℃。記述内容は「ベンゼンはトルエンより分子量は小さいが（78 < 92）、トルエンの融点が −95℃ なのに対しベンゼンの融点は 5.5℃ と高い」で、すべて正しい。

框架：融点は対称性、沸点は分子量。ベンゼンは D6h の高対称平面分子で結晶格子に緊密に充填できるため融点が高い。トルエンはメチル基が対称性を壊し充填効率が落ちるため融点が 100℃ も下がる。一方沸点は分子量・ファンデルワールス力が支配するので、ベンゼン 80.1℃ < トルエン 110.6℃ と逆転する。

異常な数値を見たらまず符号を疑う。「トルエンの融点が +95℃」と読むと文全体が無意味になる。

(C) 正　クロロホルム d = 1.49 > 水 1.00 → 下層。ハロゲン化アルカンは一般に水より重い。

(D) 正　ジエチルエーテル d = 0.71 < 水 → 上層。

(E) 誤　アセトンは水と任意の割合で混和するため二層に分離しない。上層・下層を論じる前提が成立しない。

密度・混和性の速査（分層題の必修）

| 水より重い（下層） | 水より軽い（上層） | 水と混和（分層しない） |
|---|---|---|
| クロロホルム 1.49、ジクロロメタン 1.33、四塩化炭素 1.59、二硫化炭素 1.26 | ジエチルエーテル 0.71、トルエン 0.87、ヘキサン 0.66、酢酸エチル 0.90 | アセトン、エタノール、メタノール、THF、DMSO、DMF、アセトニトリル |

一句話速記：融点は対称性（ベンゼン > トルエン）、沸点は分子量（ベンゼン < トルエン）；水と混じらない有機物はまず共沸で一緒に出る、アセトンはそもそも分層しない。

H29-Q2 ＝ H28-Q1（逐字重複題）

主題：pKa 表による酸塩基反応の可否判定　正解：②（(A)と(D)）

H28-Q1 と題幹・反応式(A)〜(D)・pKa 表がすべて同一。相違は選択肢の番号のみ（H28 では ③、H29 では ②）で、答の内容は同じ (A)と(D)。詳細な機構解説は H28-Q1 の項を参照。

要点のみ再掲：反応はより弱い酸を生成する方向にのみ進む。K = 10^(pKa右酸 − pKa左酸)。(A) 5 → 16 で ΔpKa = +11 可行、(B) 9 → 5 で −4 不可、(C) 16 → 9 で −7 不可（逆反応が自発）、(D) 19 → 36 で +17 可行（アセトンからエノラートを定量生成する標準法）。

重複題への対応：気づいた時点で旧題の選択肢番号の記憶は捨て、設問文を読み直す（第141項）。
