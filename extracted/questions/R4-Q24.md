# R4-Q24　半導体

<!-- era: new; copies in source: 1 -->

主題：半導体　正解：⑤（C、E）　用戶選④（B、E）

用戶錯誤　以為半導體導電率隨溫度降低（那是金屬）。σ＝n·e·μ：半導體 n ∝ exp(−Eg/2kT) 指數增加，主導 → σ 上升；金屬 n 固定，μ 下降 → σ 下降。

E為何錯　P（15 族、5 價電子）→ ドナー → n 型；B（13 族）→ アクセプター → p 型。

A・B・D（正確）　Si、Ge 鑽石型；GaAs III–V 族閃亜鉛鉱型；真性半導體熱激發電子與正孔數相等。

一句速記　金屬升溫 σ 降，半導體升溫 σ 升；多一個價電子 → n 型。（速查第232項）
