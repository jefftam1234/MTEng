# R7-Q03　由苯合成對胺基苯磺酸（スルファニル酸）的步驟順序

<!-- era: new; copies in source: 1 -->

主題：由苯合成對胺基苯磺酸（スルファニル酸）的步驟順序　正解：① 硝化 → Béchamp 還原 → 磺化　用戶選④（誤）

框架　目標為 1,4-取代 → 第二步親電取代時環上須已有鄰／對位定位基。–NH₂ 為鄰／對位，–NO₂、–SO₃H 為間位 → NH₂ 必須先裝；苯無法直接胺化 → 先硝化再還原（NO₂ 還原後定位性質由間位反轉為鄰／對位）。

①（正）　混酸硝化 → Fe/HCl（Béchamp）還原為苯胺 → 濃 H₂SO₄ 磺化。苯胺在濃硫酸中先成 –NH₃⁺（間位定位），但苯胺硫酸鹽加熱約 180–200℃（baking）得熱力學穩定的對位產物——純背誦。

②（誤）　先磺化 → SO₃H 間位定位 → 得 3-硝基 → metanilic acid，非 4-位。

③（誤）　苯 + 丙醯氯 → 苯基乙基酮 → Wolff-Kishner → 正丙苯；全程無 N、S。

④（誤）　(1) 溴苯 + NH₃ 不反應：未活化鹵化芳基不發生 SNAr（同 R7-Q2）；需 Cu 觸媒高溫高壓或 NaNH₂ 苯炔。(2) 苯胺 + 磺醯氯 → N 親核攻擊 S → 磺醯胺（N–S），不是環上 C-磺化。

⑤（誤）　スルファニル酸是磺胺藥・偶氮染料的工業原料。
