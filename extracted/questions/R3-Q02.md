# R3-Q02　1-メチルシクロペンテン 的酸觸媒水合 vs 硼氫化-氧化

<!-- era: new; copies in source: 1 -->

主題：1-メチルシクロペンテン 的酸觸媒水合 vs 硼氫化-氧化　正解：③ C / B　用戶答錯（選 ② A / C）

重複題　與 H27-Q2 同一受質・同一產物組（A cis、B trans、C 三級醇），完整解說見 H27-Q2 條目。本次差異：方法 I＝酸觸媒水合 → C（Markovnikov，經三級碳陽離子）；方法 II＝硼氫化-氧化 → B（反 Markovnikov + syn → CH₃ 與 OH trans）。

用戶失點　① 方法順序對應顛倒（硼氫化不經碳陽離子，不可能得三級醇 C）；② 未用 syn 加成區分 A（cis，對應 anti 加成）與 B。此題為第二次出現仍失分。

| 中文 | 日本語 | English |
|---|---|---|
| 酸催化水合 | 酸触媒水和 | acid-catalyzed hydration |
| 硼氫化 | ヒドロホウ素化 | hydroboration |
| 同面加成 | シン付加 | syn addition |
| 馬可尼可夫規則 | マルコフニコフ則 | Markovnikov's rule |

一句速記　酸水合經碳陽離子 → 三級醇；硼氫化是反 Markovnikov + syn → CH₃ 與 OH 互為 trans。（速查第69項）
