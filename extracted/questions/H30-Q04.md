# H30-Q04　アルキンに関する記述（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：アルキンに関する記述（最も不適切）　正解：③

③ が誤りの理由：アセチリドが攻撃するのはブロモエタンの「炭素」

第一段（正しい）：1-ブチン + NaNH₂ → アセチリド。末端アルキン pKa 25 vs NH₃ pKa 36、ΔpKa = +11 で定量的（H29-Q2(D) と同一框架）。

第二段（題目の誤り）：アセチリドは炭素求核剤であり、ブロモエタンの δ+ 炭素を Sₙ2 攻撃し、Br⁻ が脱離基として抜ける。生成するのは C–C 結合：

CH₃CH₂–C≡C⁻ + CH₃CH₂–Br → CH₃CH₂–C≡C–CH₂CH₃（3-ヘキシン）

題目の「1-ブロモ-1-ブチン」は Br が炔炭素に付いた構造で、これには Br₂ や NBS のような Br⁺ 源が必要。ハロゲン化アルキルの Br は脱離基であって求電子中心ではない。

最速の検算：炭素数を数える。エチル基が1個付加するのだから産物は C₆ でなければならず、C₄（ブチン）のままという時点で誤り。

② 正（誤答した肢）

1-ブチンの骨格は H–C¹≡C²–C³H₂–C⁴H₃。2当量の Br₂（＝Br 原子4個）はすべて C1 と C2 に集中して入る（三重結合の付加は同じ2炭素上で完結し、位置は移動しない）。

HC≡C–CH₂CH₃ →(Br₂)→ BrCH=CBr–CH₂CH₃ →(Br₂)→ Br₂CH–CBr₂–CH₂CH₃ ＝ 1,1,2,2-テトラブロモブタン ✓

C3・C4 に Br が回ると考えるのは、付加をラジカル置換と混同したもの。

① 正　3当量の意味

CH₂=CHCH₂CH₃ →(Br₂)→ 1,2-ジブロモブタン →(NaNH₂ 3当量)→ 後処理後 1-ブチン。

| 当量 | 用途 |
|---|---|
| 1 | 1回目の脱 HBr（E2）→ ブロモアルケン |
| 2 | 2回目の脱 HBr（E2）→ 1-ブチン |
| 3 | 末端炔水素（pKa 25）の引き抜き → アセチリド |

3当量目は無駄ではなく、平衡を完全に引き切ると同時に末端位置を「固定」して強塩基下での内部アルキン（2-ブチン）への異性化を防ぐ。最後の後処理（水系）でプロトンを戻して 1-ブチンを得る。内部アルキンを作る場合は酸性水素がないので2当量で足りる——対照点。

④ 正　1-ヘキシン + H₂O / HgSO₄・H₂SO₄ はマルコフニコフ水和。OH が置換の多い C2 に付きエノールを経て、ケト-エノール互変異性で 2-ヘキサノン。対照：ヒドロホウ素化-酸化（BH₃ → H₂O₂/NaOH）は反マルコフニコフで同じ原料からヘキサナール（アルデヒド）を与える。

⑤ 正　4-オクチン + H₂ / Lindlar 触媒（Pd/CaCO₃ を Pb またはキノリンで被毒）→ 表面 syn 付加で cis-4-オクテンで停止する。対照：Na / 液体 NH₃ なら trans（ラジカルアニオン経由、trans ビニルアニオンが安定）。無処理の Pd-C なら止まらずオクタンまで還元される。

一句話速記：アセチリド + ハロゲン化アルキルは Sₙ2 で C–C 結合を作る（炭素数を数えれば誤りが分かる）；Br を炔炭素に付けるには Br₂ が要る。Lindlar = cis、Na/NH₃ = trans。

H30-Q5 ＝ H26-Q1（設問方向が反転した重複題）

主題：5つの化学種のうち芳香族性を示すものの数　正解：④ 4個

H26-Q1 と化学種（シクロブタジエン、シクロペンタジエニルアニオン、ピロール、ピリジン、トロピリウムカチオン）は完全に同一。相違は設問の向きのみ。

|  | H26-Q1 | H30-Q5 |
|---|---|---|
| 設問 | 芳香族性を示さないものはどれか | 芳香族性を示すものの数 |
| 答 | ① シクロブタジエン | ④ 4個（5 − 1 = 4） |

誤答の機構（記憶が旧題の方向を帯びる）

「芳香性を持たないのは1つだけ」という記憶自体は正しいが、それを本題の「1個」に直結させると誤る。本題が問うのはその補集合。従来の弱点（設問の方向詞の見落とし）の上位版で、方向詞を読んでも旧題の答をそのまま書いてしまう点が厄介。対策は第141項——「解いたことがある」と気づいた瞬間に、答ではなく設問文（「どれか」か「いくつか」か）に戻る。

検算（4n+2 則）

| 化学種 | π 電子の内訳 | π 電子数 | 判定 |
|---|---|---|---|
| シクロブタジエン | C=C × 2 | 4 ＝ 4n | 反芳香性 ✗ |
| シクロペンタジエニルアニオン | C=C × 2 (4π) ＋ 負電荷の孤立電子対 (2π) | 6 | 芳香性 ✓ |
| ピロール | C=C × 2 (4π) ＋ N 孤立電子対が共役に参加 (2π) | 6 | 芳香性 ✓ |
| ピリジン | C=N / C=C × 3 | 6 | 芳香性 ✓ |
| トロピリウムカチオン | C=C × 3 (6π)、正電荷は空の p 軌道（電子を出さないが共役路に参加） | 6 | 芳香性 ✓ |

ピロール N と ピリジン N の対比（本題の実質的な知識点）

|  | ピロール | ピリジン |
|---|---|---|
| 孤立電子対の軌道 | p 軌道（環面に垂直） | sp² 軌道（環外を向く） |
| 共役への参加 | する（2π を供給） | しない |
| 塩基性 | 極めて弱い（プロトン化は芳香性を壊す） | あり（pKa(BH⁺) ≈ 5.2） |
| 環の電子密度 | 高い（求電子置換が容易） | 低い（求電子置換が困難） |

判別線索：N に H が付いているか。ピロールの N–H が sp² の1方向を占めるため孤立電子対は p 軌道へ押し出され共役に参加する。ピリジンの N は環結合2本のみで sp² が1方向空くのでそこに孤立電子対が座り、共役に参加しない。

電荷と共役の関係：シクロペンタジエニルアニオンの負電荷は 2電子を供給、トロピリウムの正電荷は 0電子だが共役路には参加する（空 p 軌道）。この非対称が出題される。稠合体がアズレン（H28-Q2）。

一句話速記：4n+2 が芳香、4n は反芳香。5つ中シクロブタジエン（4π）のみ脱落 → 4個。解いた記憶がある問題ほど、答ではなく設問文（「どれか」か「いくつか」か）を読み直す。
