# H27-Q08　我が国の1次エネルギー供給構造（2013年度，正しい組合せ）

<!-- era: new; copies in source: 1 -->

主題：我が国の1次エネルギー供給構造（2013年度，正しい組合せ）　正解：⑤ C、E

正確數值　石油 約44%（(A)說60%台→錯）／石炭 約25%（(C)20%台 ✓）／天然ガス 約24%（(B)說40%台→錯）／再エネ含水力 約5%（(D)說20%台→錯）／原子力 約0.4%（(E)10%以下 ✓）。

三個推理錨點　①2013＝福島後第2年，核電幾乎全停 → (E) 幾乎送分，可先砍到只剩②④⑤。②核電缺口由 LNG＋石炭補上 → 化石依存度約94%（石油危機後最高）→ 三大化石不可能有任一項達60%，(A)(B) 同時排除。③FIT 制度 2012年7月才啟動 → 再エネ僅約5%，(D) 排除。

最大陷阱（(B)）　「LNG 40%台」是発電電力量的數字（LNG 約43%、石炭約30%、石油約15%），不是一次能源供給。差異原因：石油大量用於運輸燃料與石化原料（非發電），LNG 幾乎全部投入發電。審題第一步必須確認分母。

易錯點　「石油第一位」的定性判斷正確，但級距誤判（記成60%台）。60%台是1980年代的數字（1973約75% → 1980年代中約60% → 2010約40% → 2013約44%），屬時代錯置。與 H27-Q4（認出 Cl 是 EWG 但未排強度）同為「定性對、定量檔位錯」。

記憶法　只記級距與排序：石油40%台 ＞ 石炭20%台 ≈ LNG 20%台 ≫ 再エネ約5% ＞ 原子力ほぼゼロ。

一句話：2013年度石油約44%（非60%）居首，化石合計約94%，原子力約0.4%；LNG的40%台是發電構成，別與一次能源供給混用。
