# H30-Q23　無機材料の機能・効果と応用例の組合せ（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：無機材料の機能・効果と応用例の組合せ（最も不適切）　正解：① マイスナー効果：超音波探傷器

判定法：効果が扱う物理量と、応用が必要とする物理量を突き合わせる

マイスナー効果は超伝導体が内部の磁束を完全に排除する現象（完全反磁性、B_内部 = 0）で、磁気の現象。応用は磁気浮上（リニアモーターカー）、SQUID（脳磁図・心磁図）、MRI・NMR の超伝導マグネット——すべて磁気。

一方超音波探傷器は超音波を出して反射を見る装置で、その振動子は PZT などの圧電素子。必要なのは電気 ⇄ 機械振動の変換であり、エネルギー変換の種類が全く違う。

③ に「圧電効果」がすでに出ていることに気づけば、超音波探傷器はそちらの仲間だと分かる。同じ選択肢群の中に、その応用にふさわしい効果が別の肢として存在している——これが本題の構造。

⑤ 正（誤答した肢）　本多・藤嶋効果

本多健一・藤嶋昭（1972年）が発見した、TiO₂ 電極に紫外光を当てると水が分解される現象。日本発の代表的発見で技術士試験では頻出。

TiO₂ →(hν < 387 nm)→ e⁻ + h⁺。正孔 h⁺ が H₂O を酸化して ·OH ラジカル、電子 e⁻ が O₂ を還元して ·O₂⁻ スーパーオキシドを生じ、生成したラジカルが有機物を CO₂ と H₂O まで完全分解する。

| 用途 | 原理 |
|---|---|
| 有機物分解・抗菌・消臭 | ラジカル酸化 |
| セルフクリーニング建材 | 分解＋超親水性で雨水が洗い流す |
| 防曇ミラー | 超親水性（水滴にならず膜状に広がる） |
| 水素製造 | 本来の発見内容（水の光分解） |

「分解」と「超親水性」の二本柱で覚える（超親水性は表面の OH 基増加による別機構）。バンドギャップ 3.2 eV（アナターゼ）なので紫外光しか使えないのが弱点で、可視光応答化が課題。アナターゼ型がルチル型より高活性。

② 正　熱電効果（ゼーベック効果）　V = S·ΔT。温度差から直接発電し可動部がない。低温排熱発電・地熱発電、宇宙用 RTG（原子力電池）、熱電対。 　逆効果＝ペルティエ効果（電流を流すと吸熱・発熱）→ ペルティエ素子（電子冷却）。ゼーベック（熱→電気）とペルティエ（電気→熱）は表裏一体で対で出題される。材料は Bi₂Te₃（室温域）、PbTe（中温）、SiGe（高温）。性能指数 ZT = S²σT/κ。

③ 正　圧電効果　正効果（応力→電圧）：ライター着火、圧力・加速度センサ、マイク。逆効果（電圧→変形）：圧電モーター（超音波モーター）、一眼レフの AF 駆動、インクジェットヘッド、超音波振動子、精密ステージ。 　カメラの AF に超音波モーターが使われるのは、静音・高トルク・高速応答・電源を切っても位置を保持するため。材料は PZT（水晶は時計の振動子）。

④ 正　焦電性（パイロ電気）　温度変化 → 自発分極の変化 → 表面に電荷。dT/dt ≠ 0 のときだけ信号が出て、温度が一定だと信号がゼロ。だから「動くもの」しか検出しない——人感センサーでじっとしていると反応しなくなる理由そのもの。

包含関係（重要）：圧電性 ⊃ 焦電性 ⊃ 強誘電性。圧電性＝対称中心がない結晶（20 点群）、焦電性＝そのうち自発分極を持つもの（10 点群）、強誘電性＝そのうち外部電界で分極を反転できるもの（BaTiO₃、PZT）。強誘電体はすべて焦電体かつ圧電体（PZT が両方に使える理由）。逆は成立しない（水晶は圧電だが焦電ではない）。

一句話速記：マイスナー効果は超伝導体の完全反磁性＝磁気の現象で、磁気浮上や SQUID に使う。超音波探傷器は電気⇄機械振動なので圧電効果の領分。効果が扱う物理量と応用が要求する物理量を突き合わせれば、材料名を知らなくても判定できる。
