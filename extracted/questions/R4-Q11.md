# R4-Q11　石炭

<!-- era: new; copies in source: 1 -->

主題：石炭　正解：③（最も不適切）　用戶答對

用戶推理（成立）　（1）①②綁定（燃料比用到固定炭素），只有一個答案 → 兩者同時排除；（2）煤炭以產地國內消費為主（國際貿易僅一成多，見 R3-Q13），各國依本國煤質制定規格（JIS M 1002、ASTM D388）→「世界規格で統一」錯。

①②（正確）　工業分析：固定炭素＝100−水分−揮發分−灰分；燃料比＝固定炭素÷揮發分。

④⑤（正確）　泥炭 < 褐炭 < 亜瀝青炭 < 瀝青炭 < 無煙炭。

技巧　絕對化用語（統一、違いはない、必ず、すべて）優先懷疑。

| 中文 | 日本語 | English |
|---|---|---|
| 工業分析／元素分析 | 工業分析／元素分析 | proximate / ultimate analysis |
| 固定碳 | 固定炭素 | fixed carbon |
| 燃料比 | 燃料比 | fuel ratio |
| 煤化度 | 石炭化度 | coal rank |

一句速記　固定炭素＝100−水分−揮發分−灰分；燃料比＝固定炭素÷揮發分；煤分類各國不同。（速查第114項、第147項）
