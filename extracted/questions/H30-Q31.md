# H30-Q31　ベルヌーイの定理による噴水の噴出量

<!-- era: new; copies in source: 1 -->

主題：ベルヌーイの定理による噴水の噴出量　正解：② 8.4 L/min

前半（ベルヌーイ）の推導は正しい

噴嘴出口（点1：z₁=0、u₁=未知）と最高点（点2：z₂=20 m、u₂=0）で立てる。両点とも大気開放なので圧力項は相殺。

u22g=z ⇒ u22×10=20 ⇒ u2=400 ⇒ u=20 m/s

これはトリチェリの定理 u = √(2gz) そのもので、自由落体の v² = 2gh と同一の式。位置水頭がすべて速度水頭に変わる。

後半（流量計算）が斷點

① 口径 3.0 mm は直径 → 半径 r = 1.5 mm = 1.5×10⁻³ m ② 断面積 A = πr² = 3.14 × (1.5×10⁻³)² = 3.14 × 2.25×10⁻⁶ = 7.07×10⁻⁶ m² ③ Q = Au = 7.07×10⁻⁶ × 20 = 1.414×10⁻⁴ m³/s ④ 単位換算 ×1000（m³→L）×60（s→min）＝ ×60000 → 8.48 L/min

最も落としやすいのは (1.5×10⁻³)² = 2.25×10⁻⁶。指数も平方する（−3×2 = −6）。ここを 10⁻³ のままにすると量級が 1000 倍ずれる。

推奨する書き方（式を全部つないでから代入）

Q L/min=πr22gz×60000=3.14×1.5×10−32×20×60000

=3.14×2.25×10−6×1.2×106=3.14×2.25×1.2=8.48

10⁻⁶ と 10⁶ が相殺して、最後は三つの数の掛け算だけになる。 小数点の位置を間違えようがない。

量級推定　π≈3、r²≈2×10⁻⁶、u=20、×6×10⁴ → 3×2×20×6×10⁻² ≈ 7。選択肢 1.5 / 8.4 / 21 / 84 / 840 は数倍ずつ離れているので、量級が合えば勝てる。計算題の固定動作：先に量級推定 → 選択肢を絞る → 精算。

実際の噴水との差　本題は無損失（理想流体）の仮定。実際は u = C_v√(2gz)（流速係数 C_v ≈ 0.95〜0.99）、Q = C_d A√(2gz)（流量係数 C_d ≈ 0.6〜0.65）。C_d が小さいのは噴流が出口直後に縮む「縮流（vena contracta）」のためで、実効断面積が孔口より小さい。設問に「実際の流量」「流量係数」とあれば係数を掛ける。

一句話速記：最高点では u=0 なので位置水頭がすべて速度水頭に変わり u = √(2gz) = 20 m/s。あとは Q = πr²u で、半径（直径の半分）・10⁻⁶・×60000 の三点のみ。式を全部つないでから数値を入れれば指数が相殺して一行で終わる。
