# H30-Q24　セラミックス製造法の説明（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：セラミックス製造法の説明（最も不適切）　正解：⑤ 射出成形法

⑤ が誤りの理由：記述内容は鋳込成形（スリップキャスティング）

「泥しょうを吸溶媒性の多孔質型に向けて噴出しながら、溶媒を吸収させることで成形する」——これは鋳込成形の定義。吸水性石膏型の毛管力で水を吸い取るのがスリップキャスティングの本質で、洗面器・便器・るつぼなど大型・複雑形状の陶磁器製造に使われる。

射出成形（CIM/MIM）の実際：原料粉末に熱可塑性バインダー（樹脂・ワックス、体積で 50% 近く）を加えて加熱混練し、流動性のあるコンパウンドを高圧で金型に射出、冷却固化させてから脱脂（脱バインダー）し焼結する。

| 項目 | 射出成形 | 鋳込成形 |
|---|---|---|
| 媒体 | 熱可塑性バインダー（溶融樹脂） | 溶媒（水） |
| 駆動力 | 高圧射出 | 型の毛管力（吸水） |
| 型 | 金属製の金型（非吸収性） | 多孔質石膏型（吸水性） |
| 固化 | 冷却 | 溶媒の除去 |
| 特徴 | 複雑形状の量産、寸法精度高、脱脂が律速 | 大型・複雑形状、設備安価、時間がかかる |

判別線索は「型」の性質：吸わせる型なら鋳込成形、冷やして固める金型なら射出成形。「射出」「噴出しながら」という語は入っているが、その後の「溶媒を吸収させることで成形」は射出成形の機構ではない。前半を正しく書いて後半で別手法にすり替える型（H30-Q11 主語、H30-Q21 サーミスタと同型）。

② 正（誤答した肢）　チョクラルスキー法（CZ 法）　半導体シリコン単結晶の標準製法で、記述に誤りはない。

| 操作 | 目的 |
|---|---|
| 融点より僅かに高温に保つ | 高すぎれば種結晶が溶け、低すぎれば全体が凝固する。この狭い温度窓が要点 |
| 回転させる | 温度・濃度分布を均一化し対称な円柱形にする |
| ゆっくり引き上げる | 固液界面の結晶成長速度に合わせる（速いと多結晶化） |

付随知識：直径 300 mm（12 インチ）が主流。偏析により不純物が液相に残りやすく、インゴットの頭と尻で抵抗率が変わる。対照手法 FZ 法（浮遊帯溶融）はるつぼを使わないので高純度（石英るつぼからの酸素混入がない）だが大口径化が困難。CZ＝大口径・低コスト、FZ＝高純度。

① 正　フロート法　溶融ガラス（比重 2.5）を溶融スズ（比重 6.5）の上に浮かべ、両面が平滑な板ガラスを得る。 　スズを使う理由：①ガラスより比重が大きい ②ガラスの成形温度域（約 1000℃）で液体 ③ガラスと反応しない ④蒸気圧が低い。還元雰囲気（N₂+H₂）でスズの酸化を防ぐ。研磨なしで鏡面が得られるため旧来の磨き板ガラスを駆逐した。

③ 正　ドクターブレード法　泥しょうを剥離性フィルム上に流し、ブレード（刃）で厚さを規制して均一なグリーンシートを得る。厚さ数 μm〜数百 μm。積層セラミックコンデンサ（MLCC）・セラミック基板・SOFC 電解質の製造に不可欠。H30-Q21 の MLCC と直結し、BaTiO₃ のグリーンシートに電極を印刷して積層一括焼成する。

④ 正　CVD 法

|  | CVD | PVD |
|---|---|---|
| 原理 | 気体原料の化学反応・熱分解 | 固体ターゲットの物理的蒸発・スパッタ |
| 温度 | 高温（数百〜1000℃） | 比較的低温 |
| 段差被覆性 | 良好（回り込む） | 劣る（直進性） |
| 例 | SiH₄ → Si、TiCl₄+CH₄ → TiC | 真空蒸着、スパッタ、イオンプレーティング |

キャリアーガスで原料蒸気を反応室に運ぶという記述も正しい。

一句話速記：⑤ の記述は鋳込成形（吸水性石膏型が毛管力で溶媒を吸う）であって射出成形（熱可塑性バインダーを加えて高圧で金型に射出し冷却固化）ではない。判別は「型が吸うのか、冷やすのか」。
