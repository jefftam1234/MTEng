# R7-Q23　酸性酸化物（どれか）

<!-- era: new; copies in source: 1 -->

主題：酸性酸化物（どれか）　正解：① B₂O₃　用戶答對

框架　非金屬氧化物酸性（B₂O₃・SiO₂・P₂O₅）、交界元素兩性（Al₂O₃・ZnO）、金屬鹼性（CaO・FeO）；同元素氧化數越高越酸（CrO → Cr₂O₃ → CrO₃）。玻璃：網狀形成體＝酸性、修飾體＝鹼性；爐渣鹼度＝CaO/SiO₂。

| 中文 | 日本語 | English |
|---|---|---|
| 酸性／鹼性／兩性氧化物 | 酸性／塩基性／両性酸化物 | acidic / basic / amphoteric oxide |
| 網狀形成體 | 網目形成酸化物 | network former |
| 爐渣鹼度 | スラグ塩基度 | slag basicity |

一句速記　非金屬氧化物酸性、交界兩性、金屬鹼性；氧化數高偏酸。（速查第180項）
