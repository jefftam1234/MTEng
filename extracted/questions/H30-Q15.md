# H30-Q15　ポリエチレンの語句組合せ

<!-- era: new; copies in source: 1 -->

主題：ポリエチレンの語句組合せ　正解：② 低密度／高密度／結晶性／直鎖状低密度／超高分子量

一つの物理ですべて解ける：分岐が結晶化を妨げ、結晶化度が密度を決める

分岐 ↑ → 鎖が揃わない → 結晶化度 ↓ → 密度・融点・剛性・耐熱性・耐薬品性 ↓、柔軟性・透明性 ↑。「密度」は結晶化度の別名なので、名称中の「低密度／高密度」はそのまま「分岐が多い／少ない」を意味する。

【A】高圧ラジカル重合 → 低密度　ラジカルが自分の鎖を噛み戻す（バックバイティング＝連鎖移動）ことで長鎖分岐が生じ、結晶化しにくくなる → LDPE。

【B】チーグラー触媒・常温常圧 → 高密度　配位重合は金属中心で単量体を逐次挿入する機構で、原理的に分岐を生じない → 直鎖 → 高結晶 → HDPE。

③④⑤ は A・B に「高圧法」「低圧法」「中圧法」を入れているが、これらは製法名であって材料名ではない。設問文は「長鎖分岐構造を有する【A】ポリエチレン」なので、空欄はポリエチレンを修飾する形容詞でなければならない。空欄の文法的役割を先に見るだけで三肢が落とせる。

【C】直鎖状だから → 結晶性　設問文自身が「分岐構造をほとんど含まない直鎖状の構造を持っているため【C】が高く、耐熱性や耐薬品性、絶縁性が高い」と因果を与えている。①「非晶性」は直鎖という前提と矛盾。⑤「融点」は意味は通るが結果であって原因ではない——後続の耐熱性・耐薬品性・絶縁性をまとめて統べるのは結晶性。

【D】α-オレフィンとの共重合 → 直鎖状低密度　1-ブテン・1-ヘキセンの共重合は、Ziegler の直鎖骨格に意図的に短鎖分岐を入れる操作。「直鎖状（主鎖に長鎖分岐がない）」＋「低密度（短鎖分岐で結晶化度が下がる）」の二つの特徴を重ねた名称が LLDPE。

【E】粘度平均分子量 100万〜600万 → 超高分子量　通常の HDPE は 5〜30 万。百万級は UHMWPE。「超粘性」「大分子量」は術語ではない。

四種の対照

|  | LDPE | HDPE | LLDPE | UHMWPE |
|---|---|---|---|---|
| 製法 | 高圧ラジカル（100〜300 MPa） | チーグラー・ナッタ | Ziegler＋α-オレフィン | Ziegler |
| 分岐 | 長鎖（偶発的） | ほぼ無し | 短鎖（意図的・制御） | ほぼ無し |
| 密度 | 0.91〜0.93 | 0.94〜0.97 | 0.91〜0.94 | 0.93〜0.94 |
| 結晶化度 | 40〜50% | 70〜80% | 45〜55% | 中 |
| 融点 | 105〜115℃ | 130〜135℃ | 120〜125℃ | 135℃ |
| 用途 | 包装シート、ゴミ袋 | 容器、パイプ、灯油缶 | フィルム、チューブ、ホース | ロープ、防弾材、人工関節 |

LDPE と LLDPE の分岐は別物：前者は偶発的な長鎖分岐で強度が出にくい、後者は分布が均一な短鎖分岐なので柔軟性と強靭性を両立する。設問文の「柔軟性と強靭性を合わせ持つ」はこれを指す。

UHMWPE の逆説：分子量が大きすぎて溶融流動せず射出成形できない（圧縮成形・ラム押出による）。密度も特別高くない（結晶化が阻害される）。それでも絡み合いが多いため強度・耐摩耗性は最高。「分子量は大きいほど良い」わけではない点で H30-Q12 の VII と同型のトレードオフ。

語句組合せ問題の手順　①空欄の文法的役割を確認 → ②設問文中の因果接続詞を利用 → ③2〜3 箇所の確定で選択肢は一意になる（本題は A と C の二箇所で決まる）。全欄を検証しない。

一句話速記：分岐が結晶化を妨げ結晶化度が密度を決める。高圧ラジカル＝連鎖移動で長鎖分岐＝LDPE、チーグラー＝直鎖＝HDPE、α-オレフィン共重合で短鎖分岐を入れたのが LLDPE、分子量 100 万超が UHMWPE。
