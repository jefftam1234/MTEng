# H30-Q08　一次エネルギーとして分類されるもの

<!-- era: new; copies in source: 1 -->

主題：一次エネルギーとして分類されるもの　正解：② 天然ガス

純暗記題だが、一問で判別できる：「自然界から採り出したそのままの形か、工場を通ったか」。

| 選択肢 | 判定 | 理由 |
|---|---|---|
| ① 水素 | 二次 | 自然界に遊離 H₂ はほぼ存在しない。天然ガスの水蒸気改質、水の電解、石炭ガス化で製造 |
| ② 天然ガス | 一次 ✓ | ガス田から採出した CH₄ をそのまま利用 |
| ③ 都市ガス | 二次 | LNG を気化し熱量調整・付臭して供給 |
| ④ LPガス | 二次 | 天然ガスからの分離、または原油の石油精製 |
| ⑤ コークス | 二次 | 石炭を空気遮断下 1000℃ で乾留して製造 |

誤答の機構（⑤ を選んだ場合）：コークスは外観が石炭に似ているため天然物と誤認しやすい。石炭は一次、コークスは二次——両者の間にコークス炉がある。本題は五肢中四肢が「天然物に見える」ように作られており、本当に採出そのままなのは天然ガスだけ。

分類の全体像

| 一次 | 二次 |
|---|---|
| 原油、石炭、天然ガス、ウラン | 電力（最も典型的） |
| 太陽光・太陽熱、風力、水力、地熱、潮力 | ガソリン、灯油、軽油、重油、ナフサ |
| バイオマス | バイオエタノール（発酵・蒸留） |
| — | LPガス、都市ガス、コークス、コールタール、石炭ガス、水素 |

高頻度の対：石炭／コークス、原油／石油製品、天然ガス／都市ガス・LPガス、バイオマス／バイオエタノール。いずれも原料 vs 製品の境界。 　水素は「エネルギーキャリア」（運搬・貯蔵の媒体）であり、次世代エネルギーとして語られても定義上は二次エネルギー——近年の出題増加点。

コークスの製程（単独出題あり）：石炭（原料炭・粘結炭）→ 乾留 → コークス ＋ 副産物（石炭ガス、コールタール、アンモニア水）。コークスは高炉で還元剤兼熱源。コールタールはベンゼン・ナフタレン・アントラセン・フェノールの伝統的供給源で、有機化学分野と接続する。

一句話速記：一次＝自然界からそのまま（原油・石炭・天然ガス・ウラン・再生可能・バイオマス）、二次＝工場を通った（電力・石油製品・都市ガス・LPガス・コークス・水素）。石炭は一次、コークスは二次。
