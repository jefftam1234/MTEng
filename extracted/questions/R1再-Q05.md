# R1再-Q05　Cahn-Ingold-Prelog 則の優先順位

<!-- era: new; copies in source: 1 -->

主題：Cahn-Ingold-Prelog 則の優先順位　正解：②

CIP 実行手順

直結する第一原子の原子番号で比較、大きいほうが優先。

同点なら、その原子が持つ 3 原子を大きい順に並べ、最大のものから一つずつ比較。最初に差が出たところで決着。

なお同点なら、最優先の枝を一段外へ辿って続行。

多重結合は相手原子を複製する（C=O は C が (O,O) を持つ、C≡C は C が (C,C,C) を持つ）。

合計しない。遠くの重原子も見ない。決着したら即停止。

②が正しい　-C₆H₅ ＞ -C≡CH ＞ -C(CH₃)₃ ＞ -CH=CH₂

| 置換基 | 第一層 | 第二層（各枝） |
|---|---|---|
| -C₆H₅ | (C, C, C) | {(C,C,H), (C,C,H), (0,0,0)} |
| -C≡CH | (C, C, C) | {(C,C,H), (0,0,0), (0,0,0)} |
| -C(CH₃)₃ | (C, C, C) | {(H,H,H), (H,H,H), (H,H,H)} |
| -CH=CH₂ | (C, C, H) | — 第一層で最下位 |

第一層で -CH=CH₂ が脱落。残り三つは第二層へ。最大枝を比べるとフェニル (C,C,H)・エチニル (C,C,H) ＞ tert-ブチル (H,H,H) で tert-ブチルが三位。フェニルとエチニルは第二枝 (C,C,H) 対 (0,0,0) でフェニルの勝ち。

①が誤り（方向トラップ）　原子番号 I(53) ＞ Br(35) ＞ Cl(17) ＞ F(9)。設問は「左ほど高い」なので -I、-Br、-Cl、-F の順でなければならない。完全に逆順。

③が誤り　-CO₂CH₃ (O,O,O) ＞ -COCH₃ (O,O,C) ＞ -CH₂OCH₃ (O,H,H) ＞ -CH₂CH₃ (C,H,H)。-COCH₃ と -CH₂OCH₃ は第一原子 O で同点、第二原子が O 対 H で -COCH₃ が上。設問は二番目と三番目が逆。「どちらも O を含む」で止めず、原子組を一つずつ比べるのが要点。

④が誤り　-SO₃H の S は (O,O,O,O,O)、-SO₂CH₃ の S は (O,O,O,O,C) なので -SO₃H ＞ -SO₂CH₃。また -SCH₃ (C) ＞ -SH (H)。正しくは -SO₃H ＞ -SO₂CH₃ ＞ -SCH₃ ＞ -SH。二組とも逆。

⑤が誤り　第一原子が Br の -Br が必ず一位。-CH₂Br の C は (Br,H,H)、-CN の C は (N,N,N)。最大原子どうしで Br ＞ N なので -CH₂Br ＞ -CN（N 三つを足しても無意味）。-CH₂CH₂Br は (C,H,H) で最下位（Br は第二層にあり、第一層で決着済みなので見えない）。正しくは -Br ＞ -CH₂Br ＞ -CN ＞ -CH₂CH₂Br。

試験戦略　②は第二層＋複製原子まで要するが、①③④⑤は第一層〜第二層の原子組だけで誤りと分かる。②を完走せず消去法で残すのが速い。

一句速記　原子番号 → 同点なら原子組を大きい順に一つずつ比較 → 合計禁止・多重結合は複製。
