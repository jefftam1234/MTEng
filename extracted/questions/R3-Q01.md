# R3-Q01　苯環化合物反應式（A〜E）產物正誤

<!-- era: new; copies in source: 1 -->

主題：苯環化合物反應式（A〜E）產物正誤　正解：① A、E　用戶答錯（選 ② B、E）

A（正確）　Birch 還原（Li／液態 NH₃／EtOH）：電子加成 → 自由基陰離子 → EtOH 質子化 → 再加電子 → 碳陰離子在對位質子化 → 1,4-環己二烯（非共軛）。產物型態屬純背誦。

B 為何錯　p-甲苯甲酸：CH₃（活化、o/p）導向 C3・C5，COOH（鈍化、m）也導向 C3・C5 → 正確產物為 3-溴-4-甲基苯甲酸（Br 在 CH₃ 旁）。題圖 Br 在 COOH 鄰位（C2），兩基皆不導向。

C 為何錯　氯苯為芳基鹵化物：sp² C–Cl 有部分雙鍵性、芳基陽離子極不穩定 → 不進行 Friedel–Crafts，不生成聯苯。

D 為何錯　tert-丁基苯苄位為四級碳、無 H → KMnO₄ 不氧化。

E（正確）　H₂/Pd 溫和條件只氫化共軛 C=C；酮 C=O 與苯環保留 → 4-苯基-2-丁酮。

用戶失點　A・B 二選一時用猜的。B 可用定位框架直接排除：先標兩基導向位置，再比對圖中 Br 位置。

| 中文 | 日本語 | English |
|---|---|---|
| 伯奇還原 | バーチ還元 | Birch reduction |
| 1,4-環己二烯 | 1,4-シクロヘキサジエン | 1,4-cyclohexadiene |
| 定位效應 | 配向性 | directing effect |
| 芳基鹵化物 | ハロゲン化アリール | aryl halide |
| 苄位 | ベンジル位 | benzylic position |
| 催化氫化 | 接触水素化 | catalytic hydrogenation |

一句速記　Birch 還原產物是 1,4-二烯；二取代苯看兩基導向重疊處；芳基鹵化物不做傅-克；沒有苄位 H 就不被 KMnO₄ 氧化；H₂/Pd 先還原 C=C。（速查第207項）
