# H27-Q31　硫酸銅飽和水溶液の冷却で析出する CuSO₄·5H₂O（計算）

<!-- era: new; copies in source: 1 -->

主題：硫酸銅飽和水溶液の冷却で析出する CuSO₄·5H₂O（計算）　正解：③ 14 g

核心：析出的是水合鹽，結晶帶走「無水鹽＋結晶水」，後者使溶劑減少。只比無水鹽溶解度差＝錯。

步驟　分子量：M(CuSO₄)=64+32+64=160、M(5H₂O)=90、M(水合)=250 → 無水/水合=0.64、結晶水/水合=0.36。60°C飽和100g（溶解度30）：無水鹽=100×30/130=23.08、水=76.92。設析出W克，冷卻20°C（溶解度20）剩餘仍飽和：(23.08−0.64W)/(76.92−0.36W)=20/100 → 23.08−0.64W=15.384−0.072W → 7.696=0.568W → W=13.55≈14g。驗算：剩餘無水鹽14.41/剩餘水72.04=0.200 ✓。

用戶錯誤　用 100/30=(100−x)/x 得 x=23.08（此步對，溶液無水鹽量）；但第二式 100/20=(100−y)/y 假設冷卻後溶液仍100g（錯，結晶已離開溶液變輕），且完全沒扣結晶水（核心陷阱），最後 0.104×250=26 邏輯不成立。

陷阱選項　④10g＝只算無水鹽溶解度差、不扣結晶水的典型錯值。

一句話：水合鹽結晶題設析出W，列(原無水鹽−0.64W)/(原水−0.36W)=低溫溶解度比；結晶水從溶劑扣，只比無水鹽差(得④10g)是錯的 → W=13.55≈14g。
