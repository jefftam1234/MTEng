# R1再-Q04　Diels-Alder 付加環化

<!-- era: new; copies in source: 1 -->

主題：Diels-Alder 付加環化　正解：⑤（最も正しい）

フレーム五本柱

| 柱 | 内容 |
|---|---|
| 協奏 | 一段階、中間体なし、遷移状態は一つ |
| 立体特異性 | ジエノフィルの cis/trans がそのまま生成物に保存される |
| 電子要求 | ジエンに供与基、ジエノフィルに求引基で最速 |
| 4n+2 則 | [4+2]＝6π は熱で許容、[2+2]＝4π は熱禁制・光許容 |
| エンド則 | 主生成物はエンド体 |

②が誤り（前半正・後半誤の罠）　「環状遷移状態を経由」は正しいが、「すべての結合変化が多段階に起こり中間体を生成する」は誤り。Diels-Alder は協奏反応で二本の σ 結合と π 再配置が同時に起こる。長い選択肢は最後まで読んでから判定する。

①が誤り　立体特異的なのは正しいが方向が逆。マレイン酸ジエチルは cis アルケンであり、協奏で二本同時に結合するため置換基が回転する余地がなく cis-二置換シクロヘキセンを与える。trans を得るにはフマル酸エステルを使う。条件も室温でなく加熱（設問図に Heat）。

③が誤り　Woodward-Hoffmann 則により [2+2]（4π、4n）は熱禁制で光照射が必要。[4+2]（6π、4n+2）は熱許容。

④が誤り　方向が逆。通常電子要求型ではジエンの HOMO とジエノフィルの LUMO が相互作用する。ジエノフィルに電子求引基（–CO₂Et、–CHO、–CN）が付くと LUMO が下がり HOMO–LUMO 差が縮まって加速する。本題のマレイン酸ジエチルは –CO₂Et を二つ持つ典型的な良ジエノフィル。供与基が付くべきはジエン側。

⑤が正しい（エンド則）　ジエノフィルの電子求引基（C=O）がジエンの π 系の側を向いて配列する。二次軌道相互作用が遷移状態を安定化するためエンド体が速度論支配の主生成物（エキソ体のほうが熱力学的には安定）。暗記寄り。なお本題のジエンは鎖状ブタジエンなのでエンド/エキソは同一生成物になる。⑤は一般論として正しい。

一句速記　一段階協奏・中間体なし／cis で入れば cis で出る／ジエノフィルに求引基で最速／[4+2] は熱・[2+2] は光／主生成物はエンド。
