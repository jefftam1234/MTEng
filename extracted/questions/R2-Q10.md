# R2-Q10　原油常壓蒸餾得不到的餾分

<!-- era: new; copies in source: 1 -->

主題：原油常壓蒸餾得不到的餾分　正解：④ 潤滑油　用戶答對

④ 為何　潤滑油 C20〜C40 以上、沸點約 350〜550℃；常壓下加熱超過 350℃ 先熱分解 → 常壓塔底只有常壓殘油。潤滑油須減圧蒸留 → 溶剤精製 → 溶剤脱ろう → 水素化仕上げ → 添加剤配合。

ナフサ（用戶不認識的選項）　常壓蒸餾 C5〜C10、30〜180℃ 的粗汽油，中間原料。輕質→石化原料（熱分解製乙烯・丙烯）；重質→接觸改質（高辛烷值汽油＋BTX＋H₂）。

①　LPG 的「液化」只是儲運形態，它是塔頂最先蒸出的直留餾分。

重複論點　速查第17項 D（H24）同一論點。

| 中文 | 日本語 | English |
|---|---|---|
| 常壓蒸餾／減壓蒸餾 | 常圧蒸留／減圧蒸留 | atmospheric / vacuum distillation |
| 常壓殘油 | 常圧残油 | atmospheric residue |
| 粗汽油 | ナフサ | naphtha |
| 脫蠟 | 脱ろう | dewaxing |
| 接觸重組 | 接触改質 | catalytic reforming |
| 基礎油 | 基油 | base oil |

一句速記　常壓蒸餾只得 LPG・ナフサ・灯油・軽油・常壓殘油；潤滑油常壓下會先熱分解，須減壓蒸餾再精製。（速查第201項）
