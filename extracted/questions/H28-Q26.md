# H28-Q26　半導体に関するA〜Eのうち不適切なものの組合せ

<!-- era: new; copies in source: 1 -->

主題：半導体に関するA〜Eのうち不適切なものの組合せ　正解：② A、D

C と D は対で検査すべき（本題の核心）

出題者は「正しい半分」と「逆に書いた半分」を並置している。判定は周期表の族だけで足りる：添加元素の価電子数 − 4 が −1 なら正孔→p型、+1 なら余分な電子→n型。

C：ケイ素にホウ素(13族、価電子3、Si比で−1)→アクセプター準位が価電子帯のすぐ上に形成→正孔が多数キャリア→p型。記述は正しい。

D：ケイ素にリン(15族、価電子5、Si比で+1)→ドナー準位が伝導帯のすぐ下に形成→電子が多数キャリア→n型。題目は「p型」と書いており誤り。

覚え方

「Siより左の13族(B、Al、Ga、In)= 電子不足 = アクセプター = p型」「右の15族(P、As、Sb)= 電子過剰 = ドナー = n型」。周期表の位置がそのまま対応するので元素名を覚える必要はない。名称自体が説明でもある：ドナー=donor(電子を与える)、アクセプター=acceptor(電子を受け取る=正孔を生む)。リン(Phosphorus)は頭文字がPだがn型という紛らわしさが出題の狙い。

A ✗（不適切）

「電気伝導性は湿度が増すと低下する」——依存する変数は温度であり、しかも方向も逆で温度上昇とともに増大する(σ ∝ exp(−Eg/2k_BT)、熱エネルギーで価電子帯から伝導帯へ励起されキャリア数が指数関数的に増加)。金属とは正反対で、金属は温度上昇で格子振動が増え散乱により移動度が下がるため伝導率が低下する。湿度は純Si・Geのバルク導電率に本質的影響を与えず、表面吸着水膜によるリーク電流(素子実装・信頼性の問題)にすぎない。なおAの前半「純粋なケイ素やゲルマニウム等は半導体であり」は正しく、前半が正しくても全文が正しいとは限らないため拆句検査が必要。

B ✓ と E ✓

B：不純物半導体=p型とn型の2種、最も基本的な分類で陥穽なし。E：真性半導体=不純物を含まない純物質半導体で n = p = nᵢ(電子と正孔が完全に同数)、伝導率は低く温度依存性が強い。「純物質がそのまま半導体となったもの」は正確な定義であり、Aの言う「純粋なケイ素やゲルマニウム」と同じものを指す。

一句話：周期表でSiの左(13族ホウ素)がアクセプター→p型、右(15族リン)がドナー→n型;半導体の伝導率が依存するのは温度であり温度上昇で増大する(金属と逆)、湿度ではない。
