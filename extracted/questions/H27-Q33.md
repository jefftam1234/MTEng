# H27-Q33　撹拌動力を変えた時の回転数上限（計算）

<!-- era: new; copies in source: 1 -->

主題：撹拌動力を変えた時の回転数上限（計算）　正解：① 95 rpm

核心：同一攪拌機 Np・ρ・D 全不變 → P∝n³，相除時常數全消，不用算絕對值也不用換單位。

步驟　P=Np·ρ·n³·D⁵ → 同機 P∝n³ → (n₂/n₁)³=P₂/P₁=0.75/1.5=1/2 → n₂/n₁=(1/2)(1/3)=1/2(1/3)=1/1.26=0.794 → n₂=120×0.794=95rpm。

用戶錯誤　試圖先從1.5kW解出 Np·ρ·D⁵ 常數（super small 算不動）——多做了不必要的一步。直接用比例 P∝n³ 相除，常數根本不出現。

識別信號　給 2^(1/3)=1.26 → 明示開三次方（同 Q30 給 ln、Q34 給 e）。相似則：泵風機 P∝n³、Q∝n、H∝n²。

一句話：同攪拌機 Np·ρ·D⁵ 全消 → P∝n³，n₂/n₁=(0.75/1.5)^(1/3)=1/1.26=0.794 → 120×0.794=95rpm；不用算常數也不用換單位。
