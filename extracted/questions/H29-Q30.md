H29-Q30　食塩水の沸点（気液平衡計算）

考點　計算題。正解：③ 103℃

沸騰の条件　液面上の蒸気分圧 = 全圧。塩を加えると水の蒸気圧が下がる（ラウール則）ので、p* をより高温まで上げて全圧に追いつかせる必要がある。

計算（基準：食塩水 100 g ＝ NaCl 15 g + H₂O 85 g）

① n_NaCl = 15/58.5 = 0.2564 mol、n_H₂O = 85/18.0 = 4.7222 mol 　② 解離を考慮：NaCl → Na⁺ + Cl⁻ なので溶質粒子は 0.2564 × 2 = 0.5128 mol ← 最大の罠 　③ x_H₂O = 4.7222 / (4.7222 + 0.5128) = 4.7222/5.2350 = 0.9020 　④ 気相は非揮発性の Na⁺・Cl⁻ を含まないので y_H₂O = 1 　　K = y/x = 1/0.9020 = 1.1086、K = p*/P より p* = 1.1086 × 0.1 = 0.1109 MPa 　⑤ 蒸気圧表で 0.1109 に最も近いのは 103℃（0.1112） → ③

102℃ は 0.1074、104℃ は 0.1152 なので 0.1109 は 103℃ が最近接。

解離を忘れた場合　x = 4.7222/(4.7222+0.2564) = 0.9485 → p* = 0.1/0.9485 = 0.1054 MPa → 101℃(0.1036) と 102℃(0.1074) の間。選択肢が 1℃ 刻みなので、2 倍を忘れると確実に 1〜2 段ずれる。

「2 倍」に気づくための手がかり　題目がわざわざ解離式 NaCl → Na⁺ + Cl⁻ を単独で書き出し、「100% 解離する」と明記している。試験問題で単独の式が提示されるときは、それが計算に直接入る。 　同じ趣旨の表現：「イオン化された Na 及び Cl は非揮発性」——これも「イオンとして 2 種類存在している」ことを重ねて示唆している。 　一般則：束一的性質（沸点上昇・凝固点降下・浸透圧）はすべて溶質粒子の個数で決まるので、電解質ではファントホッフ係数 i を掛ける。NaCl は i = 2、CaCl₂ は i = 3、非電解質（ショ糖・尿素）は i = 1。

粗い検算　ΔT_b = K_b·m·i、K_b(水) = 0.515 K·kg/mol、m = 0.2564/0.085 = 3.02 mol/kg、i = 2 　→ ΔT_b ≈ 0.515 × 3.02 × 2 = 3.1 K → 約 103℃ ✔ 　15 wt% は海水（約 3.5 wt%）の 4 倍以上の濃厚溶液なので稀薄溶液近似は厳密には使えないが、方向確認には十分。1℃ や 6℃ が出たらどこかで間違えている。

気液平衡係数 K の扱い　K = y/x が標準定義。本題では非揮発性溶質のため y_H₂O = 1 となり、K = 1/x へ簡略化される。題目が K = p*/P と与えているので、両者を等置して p* = P/x と一気に書ける。

一句話速記　沸騰条件は p* = P。塩の解離で溶質粒子は 2 倍（NaCl → Na⁺ + Cl⁻、i = 2）。x_H₂O = 4.7222/(4.7222+0.5128) = 0.902 → p* = 0.1/0.902 = 0.1109 MPa → 表より 103℃。解離を忘れると 101〜102℃ に落ちる。

無機分野（Q21〜Q26）の失点は知識型、化学プロセス分野（Q27〜Q30）の失点は手順型とはっきり分かれている。前者の対策は物質↔用途の対応表の暗記、後者の対策は計算前に表を書くという作業手順の固定化。

計算題三題（Q28・Q29・Q30）の失点原因はすべて「計算力ではなく組み立て」：Q28 は成分の列挙漏れ、Q29 は定義式への代入誤り、Q30 は係数（解離の 2 倍）の漏れ。既存の弱点「多段推導で前段の結果を完全に代入し忘れる」が三題連続で現れた。 　共通対策：計算に入る前に必ず表を書いて全項目を可視化する。物質収支なら入出表、分子量なら四欄表、束一的性質なら粒子数の欄を作る。頭の中で分母分子を組み立てない。

日常経験・語感による判断が二度失敗した（Q25 の「毒だから使わない」、Q27 の「スプレー缶は冷たい」）。工業プロセスと物性の問題では、日常直感ではなく機構と定義に戻る。答えが合っていても理由が違えば、変形題で必ず失点する。

片假名由来の失点が継続（Q22 の チタン酸バリウム、Q25 の ソーダ）。H29 全体では Q12（ポリ-α-オレフィン）、Q15（1,2/1,4）と合わせて四題。字根の分解と多義語の識別を独立した対策項目とすべき。
