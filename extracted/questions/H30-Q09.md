# H30-Q09　石油の物理的性質（最も不適切）

<!-- era: new; copies in source: 1 -->

主題：石油の物理的性質（最も不適切）　正解：③ ノルマルパラフィンの粘度はイソパラフィンより低い

最短の解法：① と ③ は同一の物理量に支配されるので方向が一致しなければならない

沸点も粘度も分子間の接触面積（ファンデルワールス力）で決まる。直鎖は棒状で互いに広く貼り合うため分子間力が強く、沸点も粘度も高い。分枝は球に近づき接触面積が減るのでどちらも低い。

①「n の沸点は iso より高い」

③「n の粘度は iso より低い」

同じ原因から出る二つの物性が逆向きに書かれている以上、どちらかが誤り。① は周知の事実なので ③ が誤答肢。データを一切参照せず判定できる。

正しくは「ノルマルパラフィンの粘度は、同じ炭素数のイソパラフィンより高い」。実務的裏づけ：直鎖ワックスは結晶化して流動性を悪化させるため、潤滑油・軽油は脱ろう（dewaxing）・異性化で分枝化する（＝粘度と流動点を下げる）。

出題の型として記憶する：「最も不適切」題では、同じ物理原因を扱う肢どうしを先に並べて相互検算する。個別に知識を思い出すより速く確実。

④ 正（誤答した肢）　石油の比熱

c ≈ (1/√d)(0.403 + 0.00081 t) [kcal/(kg·℃)]。

組成依存性が小さい：石油製品の比熱は 1.8〜2.1 kJ/(kg·K) という狭い範囲に収まる。粘度や発熱量が数倍変動するのに比べれば「あまり変わらず」と言える。

温度依存性は明確：式の +0.00081 t 項のとおり温度上昇で増大する。

厳密には 1/√d の項で密度によりわずかに変わるが、設問の表現は「全く変わらない」ではなく「あまり変わらず」なので成立する。

② 正　融点　直鎖は結晶格子に整然と充填できるため融点が高い。 　注意すべき例外：融点の真の支配因子は対称性（H30-Q1 のベンゼン vs トルエンと同じ）。短鎖の高対称分枝は逆転する——ネオペンタン −16.6℃ ≫ n-ペンタン −129.7℃（球形で自由回転しながら充填できる）。ただし石油留分は C₁₅ 以上の長鎖なので分枝は必ず充填を乱し、n > iso が成立する。

⑤ 正　総発熱量は密度が大きいほど小さい

発熱量 ∝ H/C 比（水素 約142 MJ/kg ≫ 炭素 約33 MJ/kg）。

|  | H/C 比 | 密度 | 質量基準発熱量 |
|---|---|---|---|
| パラフィン | 高（≈2.1） | 小 | 大 |
| ナフテン | 中（2.0） | 中 | 中 |
| 芳香族 | 低（1.0〜1.3） | 大 | 小 |

方向反転に注意：以上は質量基準（MJ/kg）。体積基準（MJ/L）では密度が大きいほど発熱量が大きい（1 L により多くの質量が入る）。航空燃料が体積発熱量を重視するのはこのため。発熱量の設問はまず基準が kg か L かを確認する。

n / iso の方向一覧

| 物性 | 同炭素数での大小 |
|---|---|
| 沸点・粘度・融点 | n >** iso**（すべて分子間接触面積） |
| オクタン価 | n ≪ iso |
| セタン価 | n ≫ iso |

オクタン価・セタン価だけが逆向きなのは、支配因子が分子間力ではなくラジカル連鎖による自己着火の起こりやすさだから。ガソリンは iso、軽油は n が有利。

一句話速記：沸点と粘度は同じ分子間接触面積が支配するので方向は必ず一致（直鎖が高い）。①③ を並べれば即断できる。発熱量は H/C 比で決まり、密度大＝芳香族多＝質量基準では小（体積基準では逆）。
