主題：ゴムの名称と化学構造式の組合せ　正解：③（B と C）

|  | 名称 | 図の構造が示すもの | 判定 |
|---|---|---|---|
| A | スチレン−ブタジエンゴム | イソブチレン ＋ イソプレン | ✗ ブチルゴムの構造 |
| B | アクリロニトリル−ブタジエンゴム | アクリロニトリル ＋ ブタジエン | ✓ |
| C | アクリルゴム | アクリル酸エチル ＋ 2-クロロエチルビニルエーテル | ✓ |
| D | ブチルゴム | エチレン ＋ プロピレン | ✗ EPR の構造 |
| E | エチレン−プロピレンゴム | エチレン ＋ ビニルアルコール | ✗ EVOH（ゴムですらない） |

A・D・E は名称と構造が玉突き式にずれている。

側鎖から単量体を読む判定表

| 側鎖 | 単量体 |
|---|---|
| –C₆H₅ | スチレン |
| –CN | アクリロニトリル |
| –CH₃（主鎖上） | プロピレン |
| –C(CH₃)₂– | イソブチレン |
| 主鎖に –CH=CH– | ブタジエン／イソプレン（ジエン系） |
| –COOCH₂CH₃ | アクリル酸エチル |
| –OH | ビニルアルコール |

A の誤りが最も見つけやすい：SBR には必ずベンゼン環（–C₆H₅）があるが図にはない。

C の確認：アクリルゴムの主成分はアクリル酸エチル。アクリル酸エステル自体は二重結合を持たず硫黄加硫できないため、架橋点モノマー（cure site monomer）として少量の含塩素単量体（2-クロロエチルビニルエーテル）を共重合させる。構造と一致。

E の判定：ビニルアルコール単位の –OH は水素結合を作り硬く親水性になる。ゴムに必要な柔軟性と正反対で、EVOH はガスバリア性フィルム材料。

消去法の使い方　B が正しいと確定すれば答えは B を含む①（A と B）か③（B と C）。A の構造にベンゼン環がないことを確認すれば③に決まる。

一句速記　ゴムの構造題は側鎖で単量体を読む。ベンゼン環→SBR、CN→NBR、C(CH₃)₂→ブチル、COOEt→アクリルゴム、OH→EVOH（ゴムではない）。

主題：生分解性が最も乏しい高分子　正解：②　ポリメタクリル酸メチル（PMMA）

判定フレーム：主鎖が何でできているかだけを見る

生分解とは微生物の酵素が主鎖を切ることである。酵素が加水分解できるのはエステル結合・アミド結合・グリコシド結合に限られる。

| 主鎖の結合 | 加水分解 | 生分解性 |
|---|---|---|
| –C–O–CO–（エステル） | ✓ | あり |
| –CO–NH–（アミド） | ✓ | あり（天然蛋白質系） |
| –C–C–（炭素–炭素単結合） | ✗ | なし |

PMMA が分解しない理由：エステル基が側鎖にあって主鎖にない。主鎖は –[CH₂–C(CH₃)(COOCH₃)]ₙ– で全て C–C。側鎖の –COOCH₃ が加水分解されてもポリメタクリル酸になるだけで主鎖は切れず、分子量は下がらない。

他の四つはすべて主鎖にエステル結合を持つポリエステル

| 肢 | 単量体 | 備考 |
|---|---|---|
| ① ポリヒドロキシ酪酸（PHB） | 3-ヒドロキシ酪酸 | 微生物産生ポリエステル |
| ③ ポリ（L-乳酸）（PLA） | L-乳酸 | トウモロコシ澱粉由来 |
| ④ ポリカプロラクトン（PCL） | ε-カプロラクトンの開環 |  |
| ⑤ ポリブチレンスクシネート（PBS） | 1,4-ブタンジオール ＋ コハク酸 |  |

名称からの速判：単量体名に「〜酸」「〜ラクトン」が入っていれば主鎖はポリエステル → 生分解性あり。②だけが「メタクリル酸メチル」＝ C=C を持つビニル単量体で、付加重合により主鎖が C–C になる。

「メチル基があるから分解しない」は誤り。③のポリ（L-乳酸）も乳酸 CH₃–CH(OH)–COOH 由来で主鎖にメチル基が付いている（名称に現れないだけ）。側鎖の種類ではなく主鎖の結合で判定する。

一般化　PE、PP、PS、PVC、PMMA、PAN、PTFE はすべてビニル単量体の付加重合で主鎖が C–C なので生分解しない。これがプラスチック廃棄物問題の化学的な根源。

一句速記　主鎖がエステルなら分解、主鎖が C–C なら分解しない。PMMA のエステルは側鎖なので切っても主鎖は残る。
