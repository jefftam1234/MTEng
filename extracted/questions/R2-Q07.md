# R2-Q07　經苯炔中間體的胺化（o-クロロアニソール ＋ NaNH₂／液氨）

<!-- era: new; copies in source: 1 -->

主題：經苯炔中間體的胺化（o-クロロアニソール ＋ NaNH₂／液氨）　正解：③（m-アニシジン）　用戶答對

三步推理

苯炔生成位置：C1＝OCH₃、C2＝Cl。NaNH₂ 拔掉 Cl 相鄰的 H 再脫 Cl⁻；C1 無 H，只能拔 C3–H → 苯炔只在 C2≡C3。

NH₂⁻ 加成方向：加到 C3 → 碳負離子在 C2（緊鄰 OCH₃，–I 穩定）✓ → m 體；加到 C2 → 碳負離子在 C3（遠離 OCH₃）且 C2 立體擁擠 ✗ → o 體（少量）。

質子化：C2 碳負離子從 NH₃ 取 H⁺ → 3-甲氧基苯胺。NH₂ 接在離去基的相鄰碳＝cine 取代。

與 R2-Q5 的對比（重點）　Q5 的 OCH₃ 以 +R 推電子；苯炔的碳負離子在環平面內的 sp² 軌域，與 π 系統垂直，共振不能作用，只剩 –I → OCH₃ 在此是拉電子、穩定負電荷。

錯誤選項　①：碳負離子落在遠端不穩定。②④⑤：含 p 體，但苯炔只在 C2/C3，NH₂ 不可能到 C4，結構上不可能。

一句速記　苯炔只在離去基與其相鄰 C–H 之間生成；親核劑加成後碳負離子落在靠近拉電子基的一端；苯炔碳負離子在 sp² 平面內，只看誘導效應。（速查第198項）
