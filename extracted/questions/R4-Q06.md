# R4-Q06　求核置換・脫離反應機構的判定

<!-- era: new; copies in source: 1 -->

主題：求核置換・脫離反應機構的判定　正解：①（E2／SN1／SN2／SN1／E1cB）　用戶答對（以各欄出現頻率選答）

過去題　R2-Q1（同類題，框架表見該條目）；(E) β-羥基酮 → E1cB 與 R2-Q1 (d) 相同。

出現頻率法　① 在每一欄都是多數（各 3 次）。出題者以正解為基礎改一兩格製造干擾選項時有效，但不可靠，只作最後手段或驗算。

| 式 | 條件 | 判定 | 理由 |
|---|---|---|---|
| A | KOH／EtOH，Newman 投影 | E2 | 強鹼；前碳 H 與後碳 Br anti-periplanar，產物幾何由構象決定（立體特異） |
| B | 2° 苄基 Cl，AcONa／AcOH・H₂O | SN1 | 苄基陽離子共鳴穩定；弱求核種；質子性溶劑（加溶媒分解） |
| C | 1° 烯丙基 Br，CH₃SNa／CH₃CN | SN2 | 1° 立體障礙小；RS⁻ 強求核弱鹼；非質子性極性溶劑 |
| D | AcONa／AcOH 水溶液，反應性序列 | SN1 | 乙烯基 ≪ 1° < 2° < 2°烯丙基＝碳陽離子穩定性順序；SN2 應為 1° > 2° |
| E | β-羥基酮，NaOH／EtOH | E1cB | 先奪 α-H 成エノラート，再推出 OH⁻ → 共軛烯酮 |

| 中文 | 日本語 | English |
|---|---|---|
| 反式共平面 | アンチペリプラナー | anti-periplanar |
| 紐曼投影式 | ニューマン投影式 | Newman projection |
| 苄基位／烯丙基位 | ベンジル位／アリル位 | benzylic / allylic |
| 溶劑解 | 加溶媒分解 | solvolysis |
| 乙腈 | アセトニトリル | acetonitrile |

一句速記　弱求核＋質子性溶劑＋穩定碳陽離子＝SN1；強求核＋非質子性＋1°＝SN2；強鹼＋anti＝E2；α-H 先奪、OH⁻ 被推出＝E1cB。（速查第195項）
