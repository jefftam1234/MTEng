# R7-Q13　潤滑油添加剤の機能（最も適切）

<!-- era: new; copies in source: 1 -->

主題：潤滑油添加剤の機能（最も適切）　正解：② 酸化防止剤　用戶誤讀為「不適切」

②（正）　捕捉自由基；螯合 Cu・Fe 離子，阻止其催化過氧化物分解。

①（誤）　分散的是油泥・積碳前驅物並中和酸，非「磷酸」。③（誤）　VI 改進劑使黏度變化「變小」。

④（誤）　流動點降低劑對付蠟結晶網狀化，與水無關。⑤（誤）　極壓劑生成剪切強度「小」的金屬鹽膜，防燒結。

| 中文 | 日本語 | English |
|---|---|---|
| 清淨分散劑 | 清浄分散剤 | detergent-dispersant |
| 抗氧化劑 | 酸化防止剤 | antioxidant |
| 黏度指數改進劑 | 粘度指数向上剤 | viscosity index improver |
| 流動點降低劑 | 流動点降下剤 | pour point depressant |
| 極壓添加劑 | 極圧添加剤 | extreme pressure additive |

一句速記　抗氧化劑捕自由基＋螯合金屬；VI 改進使變化變小；PPD 對蠟；EP 生成易剪切膜。（速查第287項）
