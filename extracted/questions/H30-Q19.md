# H30-Q19　プラスチックや繊維と比較したゴムの特性（最も適切）

<!-- era: new; copies in source: 1 -->

主題：プラスチックや繊維と比較したゴムの特性（最も適切）　正解：⑤ 弾性率が小さい

判準：ゴムとは「使用温度が Tg より上にある非晶性の架橋高分子」。①〜④ はその条件を全部裏返した記述＝プラスチック・繊維の特徴。

⑤ 正　弾性率の差は桁違い：ゴム（加硫 NR）1〜10 MPa、プラスチック（PE・PP）1,000〜2,000 MPa、繊維（PET・ナイロン）3,000〜10,000 MPa、アラミド 130,000 MPa。1000 倍以上の差があり、最も直接的な識別量。

④ 誤（誤答した肢）　結晶化しにくいことがゴムの条件

結晶化すると鎖が格子に固定されて動けなくなり、ゴム弾性を失う。ゴムの分子設計は「結晶化させない」ことそのもの——シス型二重結合で鎖を曲げる（天然ゴム）、共重合でランダム配列にする（SBR、EPDM）、側鎖をアタクチックにする。

決定的な対比：シス-1,4-ポリイソプレン＝天然ゴム（弾性体） vs トランス-1,4-ポリイソプレン＝グタペルカ（硬い樹脂）。化学組成は完全に同一で、二重結合の幾何だけが違う。トランス体は鎖が直線的で規則正しく揃うため結晶化して硬くなる。結晶化するかどうかがゴムか樹脂かを分けるという最も明快な実例で、これ一つで ④ を誤りと断定できる。

例外として押さえる点：天然ゴムは延伸すると結晶化する（延伸誘起結晶化）＝自己補強機構で引張強度が上がる。ただしこれは変形時に一時的に起こることで、無変形時に結晶化しやすいわけではない。SBR など延伸結晶化しない合成ゴムはカーボンブラック補強が必須。

① 誤　ゴムは Tg が低い

| 材料 | Tg |
|---|---|
| シリコーンゴム | −125℃ |
| 天然ゴム | −70℃ |
| SBR | −50℃ |
| PET | +70〜80℃ |
| ポリスチレン | +100℃ |
| ポリカーボネート | +150℃ |

室温（25℃）が Tg のどちら側にあるかで、その材料がゴムかプラスチックかが決まる。 ゴム製品の耐寒性は Tg で決まり、冬季にタイヤやシール材が硬化するのは Tg に近づくため。極低温用にはシリコーンゴムを使う。

② 誤　エントロピーはむしろ大きい

| 状態 | 鎖の形 | エントロピー |
|---|---|---|
| 無変形時 | ランダムコイル（配座数が膨大） | 大 |
| 延伸時 | 引き伸ばされて整列 | 小 |

ゴム弾性＝エントロピー弾性：F = (∂U/∂L)_T − T(∂S/∂L)_T ≈ −T(∂S/∂L)_T。内部エネルギー項はほぼゼロ（結合を伸ばしているのではなく配座を変えているだけ）で、復元力は乱雑な状態に戻ろうとする力。

金属バネ（エネルギー弾性）との決定的な違い：金属は加熱すると膨張して緩むが、荷重をかけたゴムは加熱すると収縮する（グー・ジュール効果）。F ∝ T から直接導ける。方向が直感と逆なので頻出。

③ 誤　凝集エネルギーは小さい

| 材料 | 凝集エネルギー密度 | 分子間力 |
|---|---|---|
| ゴム（NR、SBR） | 小（250〜300 MJ/m³） | ファンデルワールス力のみ |
| PET | 中 | 双極子＋π相互作用 |
| ナイロン（繊維） | 大（700〜800 MJ/m³） | 水素結合 |

分子間力が弱いからこそ鎖が互いに滑って大変形（破断伸び 500〜1000%）できる。繊維の要件は正反対で、強い水素結合＋高結晶性＋高配向が高強度を生む。

架橋（加硫）の役割　架橋がないと鎖が滑り抜けて永久変形（塑性流動）する。架橋点があるから「元に戻る」。未加硫ゴムはベタついて実用にならず、グッドイヤーの加硫発見が天然ゴムを工業材料にした。ただし架橋が多すぎると動ける範囲が狭まり硬くなる（硫黄 30〜40% のエボナイトは硬質樹脂）。

一句話速記：ゴムの条件は「Tg が室温より低い・結晶化しない・分子間力が弱い・架橋されている」の四点で、①〜④ はその全否定。シス体＝天然ゴム、トランス体＝グタペルカという同組成の対比が、結晶化の可否がすべてを決めることを示す。
