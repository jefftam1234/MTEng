# S240　有機鹵化物：NBS 烯丙位溴化・過氧化物效應・IUPAC 編號

| 條件 | 機制 | 產物（以異丁烯＋HBr 為例） |
|---|---|---|
| HBr（無過氧化物） | 離子型：H⁺ 先加 → 三級碳陽離子 | 2-溴-2-甲基丙烷（M 型） |
| HBr＋過氧化物 (PhCO₂)₂ | 自由基鏈：Br• 先加 → 三級自由基 | 1-溴-2-甲基丙烷（反 M 型） |
| NBS＋hν（CCl₄） | 烯丙位 H 引抜 → 烯丙基自由基 | 兩端碳皆可接 Br → 混合物 |

- 烯丙基自由基 ψ₂ 中央碳為節點 → 自旋密度在兩端碳。二級烯丙位 H 比一級易拔。

- 過氧化物效應只對 HBr 成立。

- IUPAC：鹵素與烷基同為前綴。順序：主官能基 → 位置組最小（第一個不同的數字）→ 打平才依字母順序（bromo＜methyl）。例：2-bromo-5-methylhexane、4-bromo-2-methylhexane。

- C^δ+–X^δ−：鹵烷碳為求電子剤 → 被求核剤攻擊（求核置換）。
