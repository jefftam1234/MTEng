# F21　H24 陶瓷電子材料・氧感測器（能斯特方程式）

A　陶瓷絕緣材料選用：看用途需要哪個物理量

| 用途 | 關鍵特性 | 代表材料 |
|---|---|---|
| 高功率電路基板(散熱) | 熱傳導率高 | AlN(氮化鋁)遠高於Al₂O₃！ |
| 高頻IC基板(訊號完整性) | 誘電率小、誘電損失小 | 低損耗陶瓷 |
| 電容器(儲能) | 誘電率大且可調控溫度特性 | BaTiO₃(鈦酸鋇) |
| 壓電致動器(機電轉換) | 壓電歪み定數大、誘電率大 | PZT等壓電陶瓷(如PICO Pµlse用材料) |

重點** **陷阱：AlN熱傳導率(~150-200 W/m·K)遠高於Al₂O₃(~20-30)，別把兩者優勢寫反。判準：先問『這個用途最在乎的物理量』(散熱→熱傳導率、高頻→誘電損失、電容→誘電率、致動器→壓電係數)。

B　氧感測器原理：能斯特方程式（濃度電池）

汽車O₂感測器＝氧濃度電池：排氣側(低O₂) | 固態電解質(O²⁻導通) | 大氣側(高O₂,參考)

| 元件 | 材料/公式 | 作用 |
|---|---|---|
| 電解質 | YSZ(イットリア安定化ジルコニア) | Y₂O₃摻雜製造氧空位→O²⁻固態導體 |
| 電極 | Pt(白金) | 催化O₂氧化還原+高溫穩定 |
| 控制方程式 | ネルンストの式** E=(RT/4F)ln(****比****)** | 電位∝ln(氧分壓比)，非差值！ |
| 輸出訊號 | 起電力(EMF) | ECU讀取電壓反推氧濃度→調整噴油量 |

重點** **易混淆：ネルンストの式(濃度↔電位)≠アレニウスの式(溫度↔反應速率k=Ae^(-Ea/RT))，兩者描述完全不同現象。D是『比』不是『差』——ln裡套的是分壓比值。Nafion是質子(H⁺)導電膜(用於燃料電池PEMFC)，不是O²⁻導體，別混淆。能斯特方程式是pH電極/離子選擇電極的理論基礎，與分析化學直接相關。
