# S093　半導体:周期表の族で p 型/n 型を判定する

添加元素の価電子数** − 4 ****が判定基準。****Si****より左の****13****族****(****価電子****3****、電子不足****)→****正孔****→****アクセプター準位****→p****型****;****右の****15****族****(****価電子****5****、電子過剰****)→****ドナー準位****→n****型。「左が****p****、右が****n****」で元素名を覚える必要はない。**

|  | 添加元素 | 族 | 価電子 | Si比 | 形成準位 | 多数キャリア | 型 |
|---|---|---|---|---|---|---|---|
|  | ホウ素** B****、****Al****、****Ga****、****In** | 13族 | 3 | −1 | アクセプター準位(価電子帯のすぐ上) | 正孔(ホール) | p型 |
|  | リン** P****、****As****、****Sb** | 15族 | 5 | +1 | ドナー準位(伝導帯のすぐ下) | 電子 | n型 |

名称そのものが説明:ドナー=donor(電子を与える)、アクセプター=acceptor(電子を受け取る=正孔を生む)。

高頻陥穽:リン(Phosphorus)は頭文字がPだがn型。この紛らわしさが出題の狙い。族の位置で判断すること。

電気伝導率が依存するのは「温度」であって「湿度」ではない。σ∝exp(−Eg/2k_BT)で、温度上昇とともに増大する。湿度は純Si・Geのバルク導電率に本質的影響を与えず、表面吸着水膜によるリーク電流(素子の実装・信頼性の問題)にすぎない。

|  | 温度上昇時 | 機構 |
|---|---|---|
| 金属 | 電気伝導率低下 | キャリア数一定、格子振動増→散乱増→移動度低下 |
| 半導体 | 電気伝導率上昇 | キャリア数が指数関数的に増加し移動度低下を圧倒 |

真性半導体=不純物を含まない純物質半導体(純Si、純Ge)で n = p = nᵢ(電子と正孔が完全に同数)、伝導率は低く温度依存性が強い。不純物半導体=ドープしたもので p型とn型の2種。

バンドギャップによる分類:Ge 0.67 < Si 1.12 < GaAs 1.42 < GaN 3.4(青色LED、ワイドギャップ) < ダイヤモンド** 5.5(****絶縁体****)。Si****とダイヤモンドはどちらも****sP³****立体網目の****14****族**で、C–C結合が短く強いためEgが大きく絶縁体になる(第90項と接続)。

化合物半導体:GaAs、GaN、InP(13-15族)、CdS(12-16族)。

*出處：**H28-Q26*
