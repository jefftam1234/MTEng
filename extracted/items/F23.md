# F23　H24 計算：LiAlH₄計量比・燃燒配平・Mn vs Mw

A　LiAlH₄還原醛/酮：計量比** 1:4****（不是****1:1****）**

完整反應：4CH₃CHO + LiAlH₄ → LiAl(OCH₂CH₃)₄ →(酸性水解+4H₂O)→ 4CH₃CH₂OH + LiOH + Al(OH)₃

LiAlH₄的4個H⁻依序轉移給4個醛分子(一次一個)，故 n(LiAlH₄) = n(醛)/4，不是1:1！驗算：算出LiAlH₄莫耳數後×4應等於醛的莫耳數。

重點** **常見誤判：誤設LiAlH₄:醛=1:1(算出76g,量級對但比例錯)。正確關係是1個LiAlH₄配4個醛分子，LiAlH₄用量遠少於醛。

B　完全燃燒配平：C→CO₂，H→H₂O，分開算不要混

CₓHᵧ + (x+y/4)O₂ → xCO₂ + (y/2)H₂O　陷阱：把H的量也折算進CO₂會使排放量計算膨脹。驗算：配平後用C、H、O三種原子數逐一核對兩邊是否守恆。

重點** **運輸CO₂減排計算鏈：算燃料完全燃燒的CO₂排放係數(g CO₂/g燃料)→乘燃料消費原単位→得CO₂排出原単位(g/(t·km))→乘貨物量×距離得總排放→比較轉換前後算削減率。

C　Mn vs Mw：加權方式不同（延伸問17框架）

| 平均值 | 公式 | 加權 |
|---|---|---|
| Mn 數平均 | ΣNᵢMᵢ / ΣNᵢ | 個數加權 |
| Mw 重量平均 | ΣNᵢMᵢ² / ΣNᵢMᵢ | 質量加權，分子多乘一次Mᵢ |

重點** **鐵則：Mn分子只有一個Mᵢ(個數×分子量)；Mw分子多一次Mᵢ(個數×分子量²)——這個『多一次平方』是Mw的正字標記。恆等式：Mn<Mw(除非所有分子量相同)，因Mw對大分子加權更重。呼應問17：Mn<Mv<Mw<Mz。易混淆：算成Mn的公式(個數加權)會算出偏小的值，題目問Mw時務必用質量加權公式。
