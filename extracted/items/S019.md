# S019　氧化鈦(TiO2)：光觸媒 + 白色顏料應用

TiO2是全球最重要的白色顏料(鈦白，titanium white)，取代鉛白/鋅白，因高折射率(銳鈦礦2.49、金紅石2.7)帶來強遮蔽力。

| 應用/性質 | 機制 | 備註 |
|---|---|---|
| 光觸媒(分解污染/殺菌) | 本多-藤嶋效應：UV激發電子電洞對→生成OH自由基 | 空氣清淨、抗菌塗層 |
| 白色顏料(鈦白) | 高折射率→強光散射→遮蔽力強 | 塗料、防曬乳、造紙 |
| 超親水防霧塗層 | UV照射後表面超親水，水滴鋪展成膜 | 鏡子、玻璃防霧 |
| 製造法 | 硫酸法(水解沉澱) 或 氯化法(TiCl4氧化，現代主流) | — |
| 天然多晶型 | 金紅石(rutile,最穩定)、銳鈦礦(anatase,光觸媒活性高)、板鈦礦(brookite) | — |

陷阱：TiO2絕非黑色顏料，是白色顏料的代表——日文材料學術語常是「顏色+材料名」固定複合詞(如チタン白)，需整體記憶。
