# S230　アニオン重合：開始剤の強さと単量体の適合

| 化學種 | 共軛酸 pKa（約） | 可起始的單體 |
|---|---|---|
| n-BuLi（烷基鋰） | 50 | 苯乙烯、丁二烯、異戊二烯（及以下全部） |
| 苄基碳陰離子（苯乙烯成長末端） | 41 | — |
| PhMgCl（格氏試劑） | 43（C–Mg 共價、實際更弱） | MMA、丙烯腈 |
| t-BuOK、NaNH₂ | 18、35 | MMA、丙烯腈等帶吸電子基單體 |
| H₂O、胺 | — | 氰基丙烯酸酯（CN＋COOR 同碳） |

- 原則：起始劑陰離子必須比成長末端更不穩定（鹼性更強）；單體吸電子基越強，起始劑可越弱。

- 強弱：碳陰離子 > 氧陰離子；同為碳陰離子時 M–C 離子性高者強（Li、Na、K > Mg）。

- 苯乙烯＋n-BuLi（無水無氧）＝リビング重合 → Mw/Mn≈1、ブロック共重合体（SBS）。

出處：R4-Q18（關聯：第150項）
