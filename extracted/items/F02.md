# F02　易混淆日文試劑名（高頻陷阱）

| 日文名 | 化學式/英文 | 意義 | 備註 |
|---|---|---|---|
| 水酸化アルミニウム | Al(OH)₃ | 氫氧化鋁（兩性）— 無還原力 | 差一「素」字 |
| 水素化アルミニウムリチウム | LiAlH₄ | 氫化鋁鋰 — 強還原劑 | 給 H⁻ |
| 酸化アルミニウム | Al₂O₃ | 氧化鋁（載體/研磨），非還原劑 | — |
| 過酸化ベンゾイル（BPO） | (PhCOO)₂ | 過氧化物（O–O）— 加熱均裂 → 自由基開始劑 | 重合開始剤 |
| 過酢酸 / 過安息香酸（過酸） | RCO₃H | peroxyacid — 環氧化劑（給 O） | 非自由基源 |
| 過酸化水素 | H₂O₂ | 氧化後處理（如 O₃ 分解、環氧開環） | 氧化劑 |
| ホモリシス | homolysis（均裂） | 電子一邊一個 → 生 自由基（ラジカル） | 光/熱引發 |
| ヘテロリシス | heterolysis（異裂） | 電子都給一邊 → 生 離子（イオン） | 極性溶劑助 |

重點** **一字記法：ラジカル＝ホモ（均裂）；イオン＝ヘテロ（異裂）。看到「ヘテロリシス」配「ラジカル生成」直接判錯。
