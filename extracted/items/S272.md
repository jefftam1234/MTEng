# S272　Kröger-Vink 表記法補遺：有效電荷計算

格式 Aᵇᶜ：A＝什麼（元素・V・e・h）；b＝在哪（原本的位置，i＝格子間）；c＝有效電荷（•＝+1、′＝−1、×＝0）。

有效電荷＝實際電荷 − 該位置原本應有的電荷（格子間基準＝0）。

| 缺陷（MO 結晶） | 計算 | 符號 |
|---|---|---|
| 電洞 | +1 | h•（h′ 錯） |
| 電子 | −1 | e′ |
| 格子間 M²⁺ | (+2) − 0 | Mᵢ•• |
| M 空孔 | 0 − (+2) | V_M″ |
| O 空孔（全空） | 0 − (−2) | V_O•• |
| O 空孔（捕捉 1 電子） | (−1) − (−2) | V_O• |
| 陽離子 Frenkel | 格子間＋空孔 | Mᵢ•• ＋ V_M″ |
| Schottky | 陽空孔＋陰空孔 | V_M″ ＋ V_O•• |
