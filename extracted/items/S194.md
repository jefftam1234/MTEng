# S194　R1（再試験）全35問の出題傾向と失点パターン

A　方向トラップ（本年度最大の失点源。35 問中 7 問）

| 題 | 逆にされた方向 | 正しい向き |
|---|---|---|
| Q2 | 配向性 c と d | COOH＝メタ、CH₃＝オルト/パラ |
| Q5 | ハロゲンの優先順位、S 系二組 | -I ＞ -Br ＞ -Cl ＞ -F |
| Q9 | 沸点の不等号 | ヘプタン ＞ 2-メチルヘキサン |
| Q11 | 煙点「25 以下」 | 25 mm 以上（下限規定） |
| Q13 | 石炭化で燃料比が減少 | 増大 |
| Q18 | 不均化が再結合の 2 倍 | 再結合が不均化の 2 倍 |
| Q29 | CSTR の方が容積が小さい | CSTR の方が大きい |

方向を含む語：以上／以下、大きい順／小さい順、最も適切／最も不適切、高磁場／低磁場、増加／減少、左ほど優先、〜倍。読んだ瞬間に向きを確認する固定動作を入れる。
