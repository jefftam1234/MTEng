# S246　SAF（ASTM D7566）認證製程：原料 ↔ 製程配對

| 略稱 | 原料 | 轉換路線 |
|---|---|---|
| FT-SPK | 木質生物質・都市垃圾（雜亂原料） | 氣化 → CO＋H₂ → フィッシャー・トロプシュ合成 → 水素化 |
| HEFA-SPK | 廢食用油・動植物油脂 | 加氫脫氧 → 異構化／裂解（商業化最廣） |
| HFS-SIP | 甘蔗等糖 | 發酵 → 金合歡烯（C15）→ 加氫 → 金合歡烷 |
| FT-SPK/A | 非石油輕質芳香族 | 烷基化 → 含芳香族合成煤油（密封材膨潤用） |
| ATJ-SPK | 生物乙醇・異丁醇 | 脫水成烯烴 → 寡聚合 → 加氫 |

- 陷阱：製程名張冠李戴（如 FT 寫成 FCC）。FCC 是石油重質油分解，不是 SAF 製程。

- 氣化把任何有機物分解成 CO＋H₂ → 原料成分雜亂也可用。

出處：R5-Q14（關聯：第40項）
