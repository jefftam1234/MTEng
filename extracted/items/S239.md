# S239　酸鹼強弱排序框架

| 比較對象 | 判斷軸 | 例（左強） |
|---|---|---|
| 取代苯酚 | 共軛鹼穩定性（共振・誘導） | 苦味酸 0.4 ＞ p-NO₂ 7.2 ＞ 苯酚 10.0 ＞ p-CH₃ 10.3 |
| 氟取代乙酸 | F 誘導效應（個數） | CF₃ 0.2 ＞ F₂CH 1.2 ＞ FCH₂ 2.6 ＞ CH₃ 4.8 |
| 含 N 鹼 | 孤對是否參與芳香性 → 混成 → 共軛酸共振 | 胍 13.6 ＞ iPr₂NH 11.1 ＞ 吡啶 5.2 ＞ 吡咯 約−4 |
| 陰離子鹼 | 同週期電負度（小者強） | CH₃⁻ ＞ NH₂⁻ ＞ OH⁻ ＞ NH₃ |
| 氫化物酸 | 同族往下鍵弱；同週期電負度 | HF 3.2 ＞ H₂S 7.0 ＞ H₂O 15.7 ＞ NH₃ 38 |

- 排序題先圈方向詞（左ほど強い／弱い順）。HF vs H₂S 跨週期跨族須背 pKa。
