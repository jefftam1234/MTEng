# T097　熱交換器：Q＝ṁcΔT ＆ 対数平均温度差(LMTD)

出處：H27-Q30、H29-Q33（第133項）　計算題

識別信號：題目出現 ln 的數值(ln2, ln3…) → 幾乎必用 LMTD。

步驟 1. Q＝ṁ·c·ΔT（任一側能量平衡；蒸汽側用凝縮潜熱 Q=ṁ·L，兩側 Q 相等可互驗） 2. 畫兩端溫差 Δt₁, Δt₂（蒸汽凝縮＝恆溫，溫度分布為水平線） 3. LMTD：

Δtlm=Δt1-Δt2lnΔt1/Δt2

U＝Q/(A·LMTD)

例：水 2.8kg/s 30→80°C，蒸汽 130°C 恆溫，A=10m²。 - Q=2.8×4180×50=5.85×10⁵ W（＝蒸汽側 0.28×2.09×10⁶ ✓） - Δt₁=130−30=100、Δt₂=130−80=50 → LMTD=(100−50)/ln2=50/0.69=72.5 K - U=5.85×10⁵/(10×72.5)=8.1×10² W/(m²·K)

為何非算術平均：溫差沿管指數衰減 → LMTD ≤ 算術平均(72.5<75)。 蒸汽側用凝縮潜熱非比熱：130°C 恆溫靠相變放熱（顯熱僅過熱段才算）。
