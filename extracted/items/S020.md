# S020　光致發光：螢光 vs 燐光的躍遷機制對照

|  | 螢光(fluorescence) | 燐光(phosphorescence) |
|---|---|---|
| 躍遷類型 | S1→S0，自旋允許 | T1→S0，自旋禁阻(需經系間跨越) |
| 發光壽命 | 極短(奈秒級10-9~10-8秒) | 長(毫秒~數小時) |
| 激發停止後 | 幾乎立即熄滅 | 持續發光(餘輝) |
| 常見例子 | 螢光筆、螢光增白劑 | 夜光錶盤、暗夜貼紙 |

易混淆：市售「螢光棒」其實靠化學發光(chemiluminescence)，兩種液體混合氧化反應直接激發染料發光，不是光激發後緩慢釋放(那是燐光的定義)——命名本身不夠精確。

熱猝滅(thermal quenching)：溫度升高提供更多非輻射弛豫路徑，發光強度下降。

濃度猝滅(concentration quenching)：活化劑(付活劑)濃度過高，離子間距縮短產生非輻射能量轉移，發光強度反而下降。
