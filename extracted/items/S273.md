# S273　無機材料 ↔ 用途（高頻配對）

| 物質 | 用途 | 依據性質 |
|---|---|---|
| Al₂O₃ | IC 封裝・基板 | 絕緣・耐熱・強度 |
| TiO₂（銳鈦礦） | 光觸媒 | UV 激發電子-電洞對 |
| 完全安定化 ZrO₂（立方晶） | 氧感測器・SOFC 電解質 | 氧離子傳導（Y₂O₃/CaO 固溶 → 氧空孔） |
| 部分安定化 ZrO₂（PSZ） | 陶瓷剪刀・刀具 | 相變韌化（正方 → 單斜，體積 +4%） |
| BaTiO₃ | MLCC・壓電・PTC | 強介電體（鈣鈦礦） |
| BaFe₁₂O₁₉ | 永久磁鐵 | 六方晶硬磁性鐵氧體 |
