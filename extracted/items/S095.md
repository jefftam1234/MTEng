# S095　流体力学の式の分類地図:保存則・構成方程式・圧力損失式

「速度勾配によって生じる運動量の輸送速度が速度勾配に比例する」はニュートンの粘性法則(τ = μ du/dy)であってBernoulliの式ではない。Bernoulliはエネルギー保存。

| 類別 | 式 | 内容 |
|---|---|---|
| 保存則 | 連続の式 | 質量保存 ρ₁A₁u₁ = ρ₂A₂u₂(非圧縮なら A₁u₁ = A₂u₂) |
|  | Bernoulliの式 | エネルギー保存 P/ρ + u²/2 + gz = 一定 |
| 構成方程式 | ニュートンの粘性法則 | τ** = ****μ****(du/dy)**、満たす流体をニュートン流体という |
| 圧力損失 | Fanning | 管内流、層流・乱流とも(fで吸収) ΔP = 4f(L/D)(ρu²/2) |
|  | Hagen-Poiseuille | 円管・層流のみ ΔP = 32μLu/D² |
|  | Kozeny-Carman | 固体充填層 ΔP ∝ μLu(1−ε)²/(Dp²ε³) |
|  | Ergun | 充填層で高流速時(Kozeny-Carmanの粘性項+慣性項) |
| その他 | ストークスの法則 | 球の沈降速度 |
|  | トリチェリの定理 | Bernoulliの特例(第62項) |

FanningとHagen-Poiseuilleの関係:層流ではファニング摩擦係数 f = 16/Re。これをFanning式に代入するとHagen-Poiseuille式が得られる——後者は前者の層流特例。

流動状態の判別:ΔP ∝** u ****の****1****乗なら層流(Hagen-Poiseuille、Kozeny-Carmanの粘性項);ΔP ****∝**** u ****の約****2****乗なら乱流**(Fanning+乱流域のf)。

Kozeny-Carman式の含意:空隙率εが分母で3乗→εが少し下がるだけで圧損が激増(充填が密になりすぎる問題);粒子径Dpが分母で2乗→細粒ほど圧損大。用途は充填塔、触媒層、ケーク濾過。

連続の式とBernoulliの式は対で使う:連続の式で断面積変化から流速変化を求め、Bernoulliで流速変化から圧力変化を求める(ベンチュリー管流量計の原理)。

ニュートンの粘性法則はH28-Q16のσ** = ****ηγ****̇****と同一の式**——粘弾性の文脈では「粘性体」、流体力学の文脈では「粘性法則」と呼ばれるだけ。

掃描技巧:複数の選択肢が同一カテゴリ(圧力損失式)で、残りが各々独立概念を代表する構成のとき、誤りは後者に置かれることが多い(前者は互いに照合できるが後者は単独知識でしか判定できないため)。
