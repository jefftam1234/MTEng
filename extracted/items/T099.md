# T099　等温理想気体の混合（PV 総量保存）

出處：H27-Q32　計算題

核心：等溫、同種理想氣體、連通 → 莫耳數守恆 → PV 總量守恆（RT 相同時 PV∝n）。

P混合=P1V1+P2V2V1+V2

例：100m³@1MPa ＋ 5m³@100MPa → (1×100+100×5)/105=600/105=5.7MPa。 - 常數與單位全消：不用算 n，P 用 MPa、V 用 m³ 直接比即可 - 分壓法（等價）：各氣體膨脹到總體積的分壓相加 P₁V₁/V總+P₂V₂/V總 - 直覺：小體積高壓槽 PV=500 主導、大體積低壓槽 PV=100 → 偏高壓側但被稀釋 易錯：除法後檢查數量級（100/105≈0.95 不可能是0.01）。
