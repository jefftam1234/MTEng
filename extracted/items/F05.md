# F05　片假名構詞速讀（把名字拆成結構）

長化合物名多是「詞根拼接」，認得片段就能拆解，不必死記整串。

| 片假名 | 英文詞根 | 結構/意義 | 例 |
|---|---|---|---|
| シクロ | cyclo | 環（環狀） | シクロヘキサン＝環己烷 |
| メチル | methyl | –CH₃ | メチルシクロヘキサン |
| メチレン | methylene | =CH₂ / –CH₂– | メチレンシクロヘキサン（=CH₂） |
| エチル | ethyl | –C₂H₅ | 臭化エチルMg＝EtMgBr |
| フェニル | phenyl | C₆H₅– | フェニルマグネシウム＝PhMgX |
| ベンゾイル | benzoyl | C₆H₅CO– | 過酸化ベンゾイル＝BPO |
| アセト / アセチル | aceto / acetyl | CH₃CO– | アセトフェノン＝苯乙酮 |
| オキシ | oxy | –O–（含氧） | ベンゾイルオキシラジカル |
| ヒドロキシ | hydroxy | –OH | ヒドロキシ基 |
| カルボニル | carbonyl | C=O | — |
| ジ / トリ | di / tri | 2個／3個 | ジシクロヘキシル＝兩個環己基 |
| ケトン / アルデヒド | ketone / aldehyde | 酮／醛 | — |
| エポキシド | epoxide | 環氧（三元含氧環） | 過酸化で生成 |
| ジオール | diol | 二醇（兩個–OH） | シクロヘキサンジオール |
