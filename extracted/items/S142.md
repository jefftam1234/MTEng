# S142　アミンの塩基性と アニリン の反応系統

判準はただ一つ——N の非共有電子対が「自由に使えるか、共役に取られているか」。

| 化合物 | 孤立電子対の状態 | 共役酸 pKa | 塩基性 |
|---|---|---|---|
| (CH₃)₂NH 二級脂肪族アミン | sp³ に局在、＋I 効果で電子密度↑ | ≈10.7 | 最強 |
| シクロヘキシルアミン | sp³ に完全局在 | ≈10.6 | 強 |
| NH₃ | sp³ に局在 | 9.3 | 中 |
| アニリン | p 軌道に入り芳香環と共役（4 つの共鳴式） | ≈4.6 | 極めて弱い（脂肪族の 10⁻⁶） |
| アミド（CH₃CONH₂） | C=O と共役 | ≈0 | ほぼ中性 |

アニリン が弱塩基である理由＝アミノ基が強い活性化基である理由は同一。孤立電子対を環に貸しているので、環は電子豊富（オルト–パラ配向性の活性化基）だが、N 上にはもう電子がない。プロトン化すると共役（約 25 kJ/mol の非局在化安定化）が失われるため平衡が不利。この二つの記述は互いに検算に使える——片方を正しいと認めたら、もう片方の「アニリンは強塩基」は必ず誤り。

第33項・H30-Q5 と同じ框架：ピロール（孤立電子対が共役に参加 → 塩基性ほぼ無し）vs ピリジン（sp² で環外を向く → 塩基性あり）。共役に参加＝塩基性を失う。

アニリン の入口と出口

| 段階 | 反応 | 要點 |
|---|---|---|
| 製法（入口） | ニトロベンゼン + Fe / HCl（または Sn/HCl、H₂/Pd-C） → ベシャン還元 | 後処理で NaOH 必須（酸性下ではアニリニウム塩）。選択的還元は Na₂S・(NH₄)₂S |
| 保護 | + 無水酢酸 / ピリジン → アセトアニリド | NH₂ は活性化が強すぎて多置換になるので、NHAc に落として単置換・パラ選択に。反応後は加水分解で脱保護。フリーデル・クラフツはアニリンに直接適用できない（AlCl₃ と錯体形成＋環が失活）のでこの保護が必須 |
| ジアゾ化 | + NaNO₂ / HCl、0〜5℃ → ジアゾニウム塩 | 温度厳守（昇温すればフェノール＋N₂ に分解） |

ジアゾニウム塩からの変換（芳香環に官能基を載せる中継点）

| 試薬 | 產物 | 名稱 |
|---|---|---|
| CuCl / CuBr / CuCN | Ar–Cl / Ar–Br / Ar–CN | ザンドマイヤー反応 |
| NaI（KI）— Cu 不要 | Ar–I | — |
| HBF₄ 加熱 | Ar–F | シーマン反応 |
| H₂O / 加熱 | Ar–OH | — |
| H₃PO₂ | Ar–H（アミノ基の除去） | — |
| フェノール・アニリン類 | アゾ化合物 | カップリング（染料） |

ヨウ素だけは Cu(I) 触媒が要らない——ザンドマイヤーとの相違点として出題される。

出處：H30-Q7（關聯：第33項＝ピロール/ピリジンの孤立電子対、H28-Q4＝ザンドマイヤー/ホフマン/クルチウス）
