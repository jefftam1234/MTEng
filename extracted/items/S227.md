# S227　構造解析的判斷點：MS・UV・IR

| 手法 | 判斷點 | 常見陷阱 |
|---|---|---|
| MS：McLafferty 轉位 | γ-H 經 6 員環轉移至 C=O → 烯烴＋烯醇自由基陽離子 | 需 γ 位（隔 3 原子）有 H |
| MS：MALDI-TOF | 軟游離、少碎片、[M+H]⁺；TOF 無質量上限 | 用於蛋白質、高分子分子量 |
| UV：共軛長度 | 共軛長 → ΔE 小 → λmax 長（紅移） | 寫成短波長側即錯 |
| UV：丙二烯 | 兩 π 鍵垂直 → 集積二重結合不共軛 | 「雙鍵相鄰＝共軛」為陷阱 |
| IR：N–H 伸縮 | 一級胺 2 條、二級胺 1 條；非對稱（約 3450）> 對稱（約 3350） | 對稱／非對稱歸屬互換 |
