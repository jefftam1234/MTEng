# S290　回分吸着：物質収支＋吸着等温式

- 物料平衡：V(C₀ − C) ＝ W·q*（左 m³×kg/m³、右 kg×kg/kg，單位皆 kg）。

- Freundlich q＝kC^(1/n)；n＝2 時設 y＝√C → 二次方程式 → 取正根 → C＝y²。

- 直接兩邊平方會產生假根（例：1.19 > C₀），必須以 0 < C < C₀ 及代回原式檢查。

| 例（R7-Q31） | 值 |
|---|---|
| 方程式 | 1 − 10C ＝ 10√C → 10y² ＋ 10y − 1 ＝ 0 |
| y | (−10 ＋ √140)/20 ＝ 0.0916 |
| C | 0.0916² ＝ 0.0084 kg/m³ |
