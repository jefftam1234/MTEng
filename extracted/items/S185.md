# S185　X 線分析：透過・蛍光・回折の三系統

A　透過力を決める二因子

| 因子 | 向き | 理由 |
|---|---|---|
| 波長 | 短いほど透過する（硬X線） | 光子エネルギーが高く光電吸収されにくい |
| 原子番号 Z | 大きいほど透過しない | 質量吸収係数が概ね Z³〜Z⁴ に比例 |
| 厚さ | 薄いほど透過する | Lambert-Beer |

| 元素 | Z | 用途 |
|---|---|---|
| H、C、O（軟組織） | 1、6、8 | ほぼ透過（X 線写真で黒） |
| Ca（骨） | 20 | 白く写る |
| Ba（造影剤） | 56 | 強吸収 |
| Pb（遮蔽） | 82 | ほぼ全吸収 |

「波長が長いほどよく透る」は可視光・赤外の散乱主導の経験則で、X 線には当てはまらない。「原子番号が大きいほど透過する」型の肢は、鉛が遮蔽材であることが直接の反証。

B　特性X線の発生

入射 X 線が内殻（K 殻）電子を叩き出す → 外殻（L、M 殻）電子が落ちて空孔を埋める → エネルギー差を X 線として放出＝特性X線（蛍光X線、二次X線）、波長は元素固有。X 線管球のスペクトルは連続X線（制動放射、白色X線）と特性X線の重ね合わせ。波長と原子番号の関係はモーズリーの法則 √ν ∝ (Z − σ)。

C　三つの元素分析法の命名論理（取り違えを狙う作問が頻出）

| 方法 | 入射 | 測定対象 | 論理 |
|---|---|---|---|
| 蛍光X線分析（XRF） | X 線 | 特性X線（発光） | X 線 → X 線。だから名前に X 線が残る |
| 発光分光分析（AES／OES） | 熱（火炎、ICP、アーク、スパーク） | 紫外・可視光（発光） | 熱 → 光 |
| 原子吸光分析（AAS） | その元素固有波長の光 | 光の減衰 | 光 → 吸収 |

AAS の光源は中空陰極（ホロカソード）ランプで陰極が目的元素そのもの。一元素一ランプが特徴であり制約（同時多元素定量ができない）。「全波長を掃引して吸収ピークを探す」のは分子吸光光度法（UV-Vis）であって AAS ではない。

D　X 線を使う二つの構造解析法の区別

| 方法 | 見るもの |
|---|---|
| X 線透過法 | 内部構造（透過力の差） |
| X 線回折法（XRD） | 結晶構造・単位格子の大きさ |
| 蛍光X線分析（XRF） | 構成元素 |

XRF と XRD はどちらも X 線を使うが、XRF は「何の元素か」、XRD は「原子がどう並んでいるか」。

回折条件はブラッグの条件 2d sinθ ＝ nλ（d＝面間隔、θ＝入射角、n＝整数）。各原子が散乱した X 線の位相がそろって強めあうときに回折線が現れ、回折角 θ から d を逆算して単位格子の大きさが求まる。

（解答技術）一つの下線部に複数の主張が含まれることがある。「原子番号が大きいほど、物体が薄いほどよく透過する」は二つの主張の合成で、後者は正しく前者が誤り。一つでも誤れば下線部全体が不適切。
