# S219　三角圖與槓桿法則（液液萃取）

刻度是質量分率 → 槓桿法則得到質量比。m_E / m_R ＝ MR / ME：離混合點 M 越近的相越多。

| 性質 | 內容 |
|---|---|
| 讀點 | 直角三角圖：橫軸＝C 質量分率、縱軸＝A 質量分率、B＝1−A−C |
| 槓桿法則推導 | C 收支：m_E·x_E ＋ m_R·x_R ＝ (m_E＋m_R)·x_M → m_E/m_R ＝ (x_M−x_R)/(x_E−x_M) |
| 混合點在連線上 | 兩組成混合 → 混合點落在兩點連線；只加入 C → 組成沿 F→C 直線移動，A：B 比恆定 |
| 邊上的點 | AB 邊上 ⇒ C＝0（只有 A、B 兩成分） |
| 萃取用語 | E＝抽出相、R＝抽殘相、E–R 連線＝タイライン，M 必在其上 |

例（R3-Q29）：x_R＝0.1、x_M＝0.3、x_E＝0.4 → m_E/m_R＝0.2/0.1＝2 → E：R＝2：1（題目寫 1：2 為錯）。
