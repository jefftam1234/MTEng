# T100　相似則・比例法（同一設備で1パラメータ変更）

出處：H27-Q33　計算題

核心：同一設備 → 幾何・物性常數不變 → 列比例式，絕對值常數與單位全消，不用算。

Y2Y1=X2X1k k＝冪次

識別信號：題目給特殊開方值（2^(1/3)=1.26 等）→ 明示要開該次方。

例（撹拌動力 P=Np·ρ·n³·D⁵）：同機同液 Np,ρ,D 不變 → P∝n³。功率 1.5→0.75kW（減半）：n₂/n₁=(0.75/1.5)(1/3)=(1/2)(1/3)=1/1.26=0.794 → n₂=120×0.794=95rpm。 關鍵：Np·ρ·D⁵ 相除時全消，不必算其絕對值（也不用換 rpm↔s⁻¹）。 同類（相似則/affinity laws）：泵風機 P∝n³、流量 Q∝n、揚程 H∝n²。
