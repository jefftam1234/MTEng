# S049　高分子結構術語：二烯單體定義 + 共聚物排列分類

「ジエン(diene)」= di(2)+ene(烯) = 含2個雙鍵，不是1個——字首定義本身就是判斷依據，不需外部背誦。

| 共聚物類型 | 日文 | 排列方式 |
|---|---|---|
| 均聚物(單一單體) | ホモポリマー | — |
| 無規共聚物 | ランダム共重合体 | 隨機排列(…ABBABAABB…) |
| 交替共聚物 | 交互共重合体 | 規則交替(ABABAB…) |
| 嵌段共聚物 | ブロック共重合体 | 成段區塊(AAA…BBB…AAA…) |
| 接枝共聚物 | グラフト共重合体 | 主鏈A、支鏈B(側鏈接枝) |

環氧乙烷(ethylene oxide)是環狀單體(cyclic monomer)，可開環聚合，與己內醯胺(H26-Q15學過)同屬開環聚合機制家族。
