# T092　ハロゲン族の遞変規律（F→I 一條主線）

出處：H27-Q25（與第 1 章「電気陰性度」、H26-Q24「ソーダ工業」互參）

主線：F 在最上→半径最小→電気陰性度最大・酸化力最強；往下所有「搶電子」相關性質遞減。

| 性質 | F→I 方向 | 備註 |
|---|---|---|
| 電気陰性度 | 減小（F=4.0 全元素最大！） | F>Cl>Br>I；F 是天花板不是最小 |
| 酸化力 | 減小（F₂最強） | 上位が下位を置換（Cl₂追出 Br⁻/I⁻） |
| 単質の状態(常温) | F₂気・Cl₂気・Br₂液・I₂固 | Br₂ 是少數常溫液態非金屬；分子量↑→分散力↑ |
| 色 | 淡黃→黃綠→赤褐→紫黒 | I₂ 有昇華性 |
| HX 酸性 | 増強（HF弱酸→HI強酸） | — |

製法（可推理）：氧化力 F₂>Cl₂>Br₂>I₂ → - F₂・Cl₂＝電解（自身太強，無更強化學氧化劑能製造；F₂ 用 KF·HF 熔融電解 Moissan 法、Cl₂ 用食鹽水電解） - Br₂・I₂＝Cl₂ 酸化（Cl₂+2Br⁻→Br₂+2Cl⁻；Cl₂+2I⁻→I₂+2Cl⁻）

生産量：Cl₂≫F₂>Br₂>I₂（Cl₂ 與 NaOH 共生於ソーダ工業，用途廣）。 HF（フッ酸）：溶玻璃（SiO₂+6HF→H₂SiF₆+2H₂O，故用塑膠容器）＋劇毒（與體內 Ca²⁺/Mg²⁺ 結合，少量致命）。

記憶錨：電負度「右上最大」＝F；F 是搶電子冠軍＝電負度最大（勿與「原子小」誤連成「電負度小」）。
