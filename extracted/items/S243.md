# S243　煉油流程總覽：各裝置的原料與產物

| 裝置 | 原料 | 產物／目的 |
|---|---|---|
| 常圧蒸留 | 原油 | LPG・ナフサ・灯油・軽油・常圧残油 |
| 減圧蒸留 | 常圧残油 | 潤滑油原料・間接脱硫原料・分解原料（VGO）・アスファルト／減圧残油（避免熱裂解） |
| 流動接触分解（FCC） | 減圧軽油等重質油 | LPG・汽油・中間餾分＋C3/C4 烯烴（沸石觸媒循環） |
| アルキレーション | 異丁烷＋丙烯／丁烯 | 烷化油（高分支、高辛烷值、無芳香族・硫） |
| 接触改質 | 重質ナフサ（C7〜C10） | リフォーメート（芳香族多）＋副產 H₂ |
| 異性化 | 軽質ナフサ（C5〜C6） | 分支烷烴（提高辛烷值） |

- 辛烷值：分支越多・越接近芳香族越高 → 改質・異構化・烷化三者目的相同。

出處：R5-Q10（關聯：H27-Q10、H28-Q10、第76・111・145・201項）
