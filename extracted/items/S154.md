# S154　平均分子量の階梯と測定法の対応

測定量が M の何乗に比例するかで、得られる平均が一段ずつ上がる。

Mn=∑NiMi∑Ni, Mw=∑NiMi2∑NiMi, Mz=∑NiMi3∑NiMi2

分子の冪が 1 → 2 → 3 と上がり、高分子量成分の重みが一段ずつ増す。

| 測定法 | 得られる平均 | なぜそうなるか |
|---|---|---|
| 浸透圧法・凝固点降下・沸点上昇 | M_n | 束一的性質＝粒子の個数だけで決まる（大小を区別しない） |
| 末端基定量法 | M_n | 末端の数＝分子の数 |
| 光散乱法 | M_w | 散乱強度 ∝ M×c＝信号自体が質量で重み付けされる |
| 超遠心法（沈降平衡） | M_z | 遠心力 ∝ 質量、かつ濃度分布が指数関数に M を含む → さらに一段高い重み |
| 粘度法 | M_v（M_n < M_v < M_w） | [η] = K M_v^a、a ≈ 0.5〜0.8 <** 1** なので M_w にも届かない |
| GPC/SEC、MALDI-TOF | 分布全体 | 分離して全モーメントを算出 |

大小関係 M_n ≤ M_v ≤ M_w ≤ M_z（等号は単分散のみ）。多分散度 Đ = M_w/M_n ≥ 1：リビングアニオン重合 1.0〜1.1、ラジカル重合 1.5〜2、逐次重合は理論値 2.0（Flory 分布）。

超遠心＝M_z の一点だけ確実に押さえれば、残りは上の階梯から導ける。粘度法は高分子量に敏感そうに見えるが a <** 1 なので M_z ではない**——最も引っかかりやすい誤答肢。

出處：H30-Q20、R1再-Q20（關聯：第129項＝Mn/Mw の計算手順、第117項＝カロザース式と分散度）
