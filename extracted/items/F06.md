看到日文反應名 ↔ 立刻對應英文概念與框架。按反應類型分組。

|---|---|---|---|

E　官能基變換・工業・脫離

| 日文 | English | 中文 | 重點（框架/產物） |
|---|---|---|---|
| エステル化 | Esterification | 酯化 | 羧酸 + 醇（酸触媒，可逆）→ エステル + 水 |
| けん化（鹸化） | Saponification | 皂化 | エステル + NaOH → 羧酸鹽 + 醇（不可逆） |
| ハロホルム反応 | Haloform reaction | 鹵仿反應 | メチルケトン + X₂/OH⁻ → CHX₃（ヨードホルム陽性） |
| クメン法 | Cumene process | 異丙苯法 | 苯 → クメン → 工業製 フェノール + アセトン |
| 求核置換** SN1****／****SN2** | Nucleophilic substitution | 親核取代 | SN2=背面反轉；SN1=carbocation，外消旋化 |
| 脱離** E1****／****E2** | Elimination | 脫離 | → アルケン生成 |
| ザイツェフ則 | Zaitsev’s rule | 札依采夫規則 | 脫離主產物 = 取代基多（穩定）的烯 |
| ホフマン則 | Hofmann’s rule | 霍夫曼規則 | 大體積鹼 → 取代基少的烯為主 |

重點** **易混淆：クライゼン「縮合」(エステル→β-ケトエステル) ≠ クライゼン「転位」([3,3]重排)。ホフマン「転位」(アミド→アミン) ≠ ホフマン「則」(脫離取向)。同名不同反應，考試常設陷阱。
