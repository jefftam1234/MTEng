# T079　潤滑油の分類と用途

出處：H27-Q12

| 潤滑油 | 用途 | 特殊要求 |
|---|---|---|
| エンジン油 | 內燃機 | SAE 粘度グレード（5W-30：W=低溫流動性、30=100°C 粘度）；品質分類另用 API（SL/SM/SN） |
| ATフルード(ATF) | 有段自動変速機(AT)專用 | 濕式離合器摩擦係數平順可控 |
| CVTフルード(CVTF) | 無段変速機(CVT)專用 | 金屬皮帶間高摩擦係數維持（防打滑） |
| タービン油 | 發電渦輪・高速回轉機軸受 | 酸化安定性・抗乳化性・防錆 |
| 冷凍機油 | 圧縮機潤滑 | 冷媒相溶性・低流動点・化學安定性（HFC 用エステル系合成油） |
| 電気絶縁油 | 変圧器・コンデンサー | 絶縁＋冷却；鉱油／合成油（シリコーン・エステル） |

ATF ≠ CVTF（功能性互斥）：AT 用濕式離合器滑動接合 → 要摩擦低減／可控；CVT 靠金屬皮帶夾在プーリー間傳扭矩 → 要高摩擦係數（否則打滑燒毀）。兩者摩擦調整劑方向相反，不可互用。字面亦矛盾：ATF 的 AT＝有段自排，CVT 是無段。

冷凍機油的「機能相同但要求特殊」不是矛盾：功能上確等同圧縮機油，但冷媒會相變且溶入油中，故需一般壓縮機油沒有的相溶性・低流動点。此為日文技術敘述的標準轉折句型，非造假。
