# S247　熱可塑性エラストマー（TPE）：微相分離與物理交聯

| 要素 | 內容 |
|---|---|
| 分子構造 | ブロック共重合体（例 SBS：PS 硬段－PB 軟段－PS 硬段）；無規・交替不行（連續序列短） |
| 相構造 | 非相溶＋共價相連 → ミクロ相分離（數十 nm） |
| 硬段 | 凝集・結晶化 → 擬似架橋点（物理交聯） |
| 軟段 | Tg 低、室溫微布朗運動 → ゴム弾性 |
| 高溫 | ΔG_mix＝ΔH − TΔS：TΔS 勝過凝聚能（ΔH＞0）→ 均一相 → 熔融、可再成形 |

- TPE vs 加硫ゴム：物理交聯（可逆、可回收）vs 化學交聯（不熔、難回收）。

- 選項組合題：エラストマー＝elastic polymer → D 欄必為「弾性」。

出處：R5-Q15（關聯：第84項、R5-Q17 熵彈性）
