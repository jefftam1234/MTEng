# S288　高分子の分解とリサイクル

| 類型 | 主鏈的鍵 | 回收方式 | 例 |
|---|---|---|---|
| 逐步聚合物 | 酯・胺甲酸酯・醯胺 | 醇解・水解・胺解切回單體 | PET（BHET・DMT → TPA）、PU（多元醇） |
| 乙烯系 | C–C | 只能熱分解 | PMMA > 90% 單體（拉鍊式）、PS 約一半、PE・PP 蠟・油 |
| 側基先脫離 | C–C＋易脫基 | 得不到單體 | PVC 約 250〜300℃ 連鎖脫 HCl → 多烯 → 碳化 |

| 分類 | 內容 |
|---|---|
| マテリアル（材料） | 熔融再成形（PET 瓶 → 纖維） |
| ケミカル（化學） | 單體化・氣化・油化・高爐還原劑・焦爐原料 |
| サーマル（熱） | 焚燒回收熱能（發電・RPF） |

- PMMA 易解聚：主鏈四級碳、無 α-H、聚合熱小 → 上限溫度低。
