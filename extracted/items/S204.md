# S204　付加縮合系の熱硬化性樹脂：甲醛的「搭檔」決定樹脂名

付加縮合：甲醛先加成到苯環或胺基上形成羥甲基（メチロール基 –CH₂OH），再與另一分子縮合脫水形成 –CH₂– 橋（メチレン架橋）。

| 原料 | 樹脂 | 備註 |
|---|---|---|
| フェノール ＋ ホルムアルデヒド | フェノール樹脂（ベークライト） | 最早的合成樹脂 |
| 尿素（ユリア・ウレア）＋ ホルムアルデヒド | ユリア樹脂 | 白色、便宜；接著劑 |
| メラミン ＋ ホルムアルデヒド | メラミン樹脂 | 耐熱・耐水・表面硬；餐具・化妝板 |
| ビスフェノールA ＋ エピクロロヒドリン | エポキシ樹脂（≠ フェノール樹脂） | 脫 HCl 生成縮水甘油醚（環氧端基），再以胺類硬化劑開環交聯 |
| ポリオール ＋ イソシアネート | ポリウレタン | 重付加（無副產物）；需 –N=C=O |

判斷陷阱：雙酚 A 雖含酚性 –OH，但搭檔是環氧氯丙烷（看到三員環 C–C–O＝環氧）→ エポキシ樹脂。

フェノール樹脂的兩種預聚物

|  | ノボラック | レゾール |
|---|---|---|
| 觸媒 | 酸 | 鹼 |
| 原料比 | 苯酚過量 | 甲醛過量 |
| 結構 | 只有 CH₂ 橋、無羥甲基 → 熱可塑性 | 帶 –CH₂OH |
| 硬化 | 需加ヘキサメチレンテトラミン（加熱分解出甲醛＋NH₃，補 CH₂ 橋） | 單獨加熱即硬化 |

出處：R2-Q17
