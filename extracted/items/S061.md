# S061　燃燒計算：完全燃燒仍需計入過量O2與惰性N2

乾燃燒氣量(不含水蒸氣) = CO2生成量** + O2****剩餘量****(****供給****O2-****理論消耗****O2) + N2****總量****(****完全不參與反應但體積照計****)****。**

解題步驟：①按體積比例分別算各燃料的理論需氧量②理論空氣量=理論O2/0.21③實際供給空氣=理論空氣×供應倍率④CO2生成量按係數比計算⑤O2剩餘=供給O2-理論O2⑥N2=供給空氣×0.79⑦加總CO2+O2剩餘+N2。

常見漏項：忘記把「過量供應的O2剩餘部分」算入最終氣體量；忘記把「不參與反應的N2」算入總氣體量(N2通常占比最大)。
