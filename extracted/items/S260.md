# S260　多取代苯的親電取代定位（例：m-溴氯苯的硝化）

- 鹵素＝鈍化・o,p-定位（−I 鈍化，+R 定位）。

- 步驟：①列出每個空位相對各取代基是 o/m/p ②兩者都指向的位置優先 ③夾在兩基之間（立體障礙）少 ④兩者皆 meta 幾乎不生成。

- 同等指向時比 para 給電：Cl（3p–2p）> Br（4p–2p）；ortho 誘導吸電 Cl > Br → Cl 的 para・Br 的 ortho 位置為主。

- 一般硝化條件主產物＝單硝化物（NO₂ 強鈍化），多硝基選項直接排除。

| 位置（Cl=C1, Br=C3） | 相對 Cl／Br | 產物 |
|---|---|---|
| C4 | p／o | 2-ブロモ-4-クロロ-1-ニトロベンゼン（主） |
| C6 | o／p | 4-ブロモ-2-クロロ-1-ニトロベンゼン（次） |
| C2 | o／o | 1-ブロモ-3-クロロ-2-ニトロベンゼン（立體障礙・少） |
| C5 | m／m | 幾乎不生成 |
