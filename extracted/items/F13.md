# F13　無機：鹵素趨勢／薄膜 PVD vs CVD

A　鹵素（ハロゲン）周期性趨勢（F → I）

| 性質 | F → I 趨勢 | 極端 |
|---|---|---|
| 電気陰性度(電負度) | 變小 | F 最大(全元素之最,≈4.0) |
| 酸化力 | 變弱 | F₂ 最強 → 強者置換弱者 |
| 原子/離子半徑 | 變大 | I 最大 |
| 還元性(X⁻失電子) | 變強 | I⁻ 最強 |
| 常溫狀態 | 氣→液→固 | F₂/Cl₂ 氣、Br₂ 液、I₂ 固(昇華) |
| 製法 | — | F₂/Cl₂ 電解；Br₂/I₂ 用 Cl₂ 氧化置換 |

重點** **高頻混淆：電負度＝原子搶電子能力(無正負號)→F 最大；別跟 X⁻ 的還原性/半徑(I 方向)搞混，兩條趨勢相反。HF(フッ酸)：弱酸但劇毒、腐蝕玻璃(SiO₂)，塑膠容器保存。工業生產量 Cl₂ 最大。

B　薄膜形成：PVD vs CVD（一條線判準）

| 家族 | 判準 | 成員 |
|---|---|---|
| PVD 物理堆積 | 純物理，無化學反應 | 真空蒸着(電阻加熱)／電子ビーム蒸着(EB加熱)／スパッタリング(動量交換打出原子)／イオンプレーティング(電漿離子化)／MBE 分子線エピタキシー(超高真空分子束磊晶) |
| CVD 化学堆積 | 氣體原料＋化學反應 | 原料氣體在氣相或基板表面反應成膜 |

重點** **鐵則：見「反応を利用」＝CVD。MBE 是 PVD(無反應)，若敘述給 MBE 套上「氣體輸送＋反應」＝CVD 定義＝錯。EB 蒸着只是真空蒸着換加熱方式(電子束)，本質相同。

C　コンクリート耐久性** ****四本柱**

| 項目（日／英） | 機制 | 備註 |
|---|---|---|
| 凍害 Freeze-thaw | 孔隙水結冰膨脹約9%，凍融循環→龜裂/表面剝落 | 寒地頭號問題 |
| 塩害 Chloride attack | Cl⁻破壞鋼筋鈍態皮膜→鏽蝕膨脹→開裂 | 海砂/海風/除冰鹽 |
| 炭酸化(中性化) Carbonation | CO₂+Ca(OH)₂→CaCO₃，pH 12-13→<10→鋼筋鏽 | 化學反應型 |
| アルカリ骨材反応 ASR | 水泥鹼+骨材反應性SiO₂→吸水膨脹膠→地圖狀裂 | 「混凝土癌」 |

重點** **外來詞排除：耐スポーリング性(spalling resistance)＝耐火物(耐火磚)的熱衝擊剝落抵抗，不在混凝土耐久性清單。凍害的表面剝落叫スケーリング；見「スポーリング」先想耐火物。

D　ホットプレス焼結（熱壓燒結）特徵

| 面向 | 內容 |
|---|---|
| 優點(因果鏈) | 加壓→低溫緻密化→高密度＋粒成長抑制(細晶)；燒結性高→助劑低減/無添加→高純度 |
| 副產物 | 單軸加壓→粒子配向→結晶異方性(可利用提升特定方向性能) |
| 代價/限制 | 型不可欠→形狀受限・量產性差；大型化→型強度確保＋油壓プレス大型化問題 |

重點** **熱壓三大賣點＝低溫緻密化・粒成長抑制・高純度。「粒成長は抑制できない」＝把賣點反寫＝錯(半真半假陷阱：低溫緻密化對、抑制不了錯)。名詞：焼結 sintering／ホットプレス hot press／粒成長 grain growth／焼結助剤 sintering aid。

E　ソーダ工業（氯鹼＋ソルベー法）

| 工業 | 反應與產物 |
|---|---|
| 電解ソーダ(氯鹼)　可推理！ | 電解食鹽水：陰極 2H₂O+2e⁻→H₂+2OH⁻(Na⁺不析出,水搶先)→NaOH；陽極 2Cl⁻→Cl₂+2e⁻。三產物＝NaOH・Cl₂・H₂(無** HCl****！****HCl ****是下游**** H₂+Cl₂ ****合成****)** |
| ソーダ灰(ソルベー法) | NaCl+NH₃+CO₂+H₂O→NaHCO₃↓+NH₄Cl；2NaHCO₃→(加熱)→Na₂CO₃+H₂O+CO₂。原料含 CO₂ 與 NH₃ |

重點** **電解半題純推理(=問19「Na 不從水溶液析出」的應用)；ソルベー半題記一條流程。NaOH 與 Cl₂ 固定比率同時產出→需平衡供需→『バランス産業』。名詞：か性ソーダ caustic soda／ソーダ灰 soda ash(Na₂CO₃)／クロールアルカリ chlor-alkali／ソルベー法 Solvay process。

F　機能材料：效應** → ****應用**** ****配對**

| 效應（日／英） | 物理 | 應用 |
|---|---|---|
| 熱電/ゼーベック Seebeck | 溫差→電壓 | 溫差發電、體溫手錶 |
| 圧電 Piezoelectric | 電⇄力(伸縮) | 致動器、超音波探傷、噴墨頭 |
| 焦電 Pyroelectric | 溫度變化→電荷 | 紅外線/人體感測器 |
| PTC | 溫度↑→電阻↑ | 自控溫加熱器、過流保護 |
| マイスナー** Meissner** | 超導→排磁(完全反磁性) | 磁浮、超導磁鐵、MRI（≠超音波！） |

重點** **陷阱：マイスナー効果＝超導磁浮，與超音波無關；超音波探傷靠圧電効果。「マイスナー配超音波探傷」＝錯。這類效應↔應用配對題，一個名字對不上就是答案。

G　CO₂ 吸收分離：化學** vs ****物理**

|  | 化學吸收法 | 物理吸收法 |
|---|---|---|
| 原理 | 化學反應(酸鹼中和) | 物理溶解(亨利定律) |
| 吸收液 | 鹼性：MEA(モノエタノールアミン)、K₂CO₃(熱鉀鹼/Benfield) | 甲醇(Rectisol)、ポリエチレングリコール(Selexol) |
| 液性/條件 | アルカリ性 | 高圧(分壓高才溶得多) |
| 再生方式 | 加熱(放熱可逆反應逆轉) | 減圧(降壓逸出) |

重點** **兩條鐵則：①吸酸性 CO₂→用鹼性液(B=アルカリ性)；②化學吸收靠『加熱』再生、物理吸收靠『加壓吸/減壓放』(C=加熱、D=高圧)。物理吸收液是甲醇/聚乙二醇(不是乙醇！)。注意：熱炭酸カリウム(K₂CO₃/Benfield)其實『能』做化學吸收，別記成不能。名詞：MEA Monoethanolamine／Rectisol 低溫甲醇洗／ヘンリーの法則 Henry’s law。
