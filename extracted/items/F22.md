# F22　H24 化工分離操作：蒸餾・三成分相圖

A　McCabe-Thiele蒸餾圖解法

| 概念 | 定義 | 關鍵點 |
|---|---|---|
| x-y線圖 | 液相/氣相莫耳分率關係曲線 | 用低沸點成分(易揮發者)當基準，非高沸點！ |
| 濃縮部/回收部 | 以原料供給段分界 | 上方濃縮、下方回收(汽提) |
| 操作線 | 連接理論板間物料關係 | 斜率=R/(R+1)，隨還流比R變化 |
| 最小還流比 | 理論段數→∞時的還流比下限 | 還流比↑⇒所需理論段數↓，互相取捨 |
| 相對揮發度 α | α=P_A/P_B(純液體飽和蒸氣壓比) | Raoult定律下純物質蒸氣壓只是溫度函數→α只跟溫度有關 |

重點** **陷阱：x-y線圖用低沸點成分(易揮發者)當座標基準，別記反成高沸點成分。此節與問34拉午耳定律直接相連(純物質蒸氣壓只是溫度函數，故α只跟溫度有關可自行推導)。

B　三成分相圖(Gibbs三角形)＋槓桿法則

三頂點=純成分；邊上點=相鄰兩成分的二成分混合物；從邊上一點加入第三成分C，組成沿『該點與C頂點連線』移動(A:B比例不變)。

槓桿法則(てこの原理)：質量_E : 質量_R = MR距離** : ME****距離（反比！）**

重點** **蹺蹺板記憶法：離支點(M)近的一側質量反而要重(才能平衡)，離支點遠的一側質量輕——與直覺『近的東西量少』相反！這是槓桿法則(二元/三元相圖通用)最容易犯錯的方向陷阱，每次都要重新讀圖上距離，代入反比關係，不能死記固定比值。
