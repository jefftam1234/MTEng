# S207　芳香族反應式正誤判定：五個成立條件

看反應式先問「這個試劑在這個受質上能不能動」，再問「動在哪個位置」。

| 反應 | 成立條件／產物 | 常見陷阱 |
|---|---|---|
| Birch 還原（Li 或 Na / 液態 NH₃ / EtOH） | 苯 → 1,4-環己二烯（非共軛） | 畫成 1,3-二烯或環己烷 → 錯 |
| 二取代苯的 SEAr | 兩基導向位置重疊處；衝突時活化基優先 | p-甲苯甲酸 + Br₂/FeBr₃ → 3-溴-4-甲基苯甲酸（Br 在 CH₃ 旁），畫在 COOH 鄰位 → 錯 |
| Friedel–Crafts 烷基化 | 需 sp³ 鹵烷 R–X | 芳基鹵化物・乙烯基鹵化物不反應（sp² C–Cl 有部分雙鍵性、芳基陽離子極不穩定）→ 苯 + 氯苯不生成聯苯 |
| KMnO₄ 側鏈氧化 | 苄位碳上至少 1 個 H → 任何長度側鏈 → –COOH | tert-丁基苯不氧化（苄位為四級碳） |
| H₂/Pd 溫和氫化 | C=C 優先；酮 C=O 與苯環保留 | 苯亞甲基丙酮 → 4-苯基-2-丁酮 ✓ |

出處：R3-Q1（關聯：既有 Friedel–Crafts 試劑列）
