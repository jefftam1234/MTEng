# S087　溶融塩電解とファラデーの電気分解の法則(計算手順)

溶融塩電解は水溶液から電析できない卑金属(Na、Mg、Al、Li、Ca、K)の製錬に用いる。製錬の本質は還元であり、「還元しにくい金属」を電気の力で強制還元する。

| 金属 | 電解浴 | 温度 | 製法名 |
|---|---|---|---|
| Al | Al₂O₃+氷晶石(Na₃AlF₆) | 約960℃ | ホール・エルー法 |
| Mg | MgCl₂ | 約700℃ | — |
| Na | NaCl+CaCl₂ | 約600℃ | ダウン法 |
| 反応 | E°(V vs SHE) | 水溶液電析 |  |
| Cu²⁺/Cu | +0.34 | 可能 |  |
| 2H⁺/H₂ | 0.00 | (基準) |  |
| Ni²⁺/Ni | −0.25 | 可能 |  |
| Zn²⁺/Zn | −0.76 | 可能(亜鉛上の水素過電圧が大きいため) |  |
| Al³⁺/Al | −1.66 | 不可能 |  |
| Mg²⁺/Mg | −2.37 | 不可能 |  |
| Na⁺/Na | −2.71 | 不可能 |  |

亜鉛が境界例:E°は水素より卑だが水素過電圧が大きいため実際にはZnが先に析出→亜鉛電解採取が工業的に成立。選択肢に「亜鉛」が出たら溶融塩電解の対象ではない。

A(水溶液電析不可)とB(還元しにくい)は同じ物性の裏表:還元しにくい⟺酸化物が安定⟺イオン化傾向が大きい⟺水溶液電析できない。片方が決まれば他方も自動的に決まる。

同名別法則の陥穽:ファラデーの法則は二つある——電気分解の法則(電極で変化する物質量∝電気量,電気化学)と電磁誘導の法則(誘導起電力∝磁束の時間変化率,電磁気学)。電解計算では前者。同類:クライゼン縮合vs転位、ホフマン転位vs則(第80項の対策がそのまま適用)。

計算手順(固定五段階,途中の行を省略しないこと)

| 段階 | 式 | 例(1000A、1時間、電流効率80%、MgCl₂) |
|---|---|---|
| ① 総電気量 | Q=I×t(秒に換算) | 1000×3600=3.6×10⁶ C |
| ② 有効電気量 | Q×電流効率 | 3.6×10⁶×0.80=2.88×10⁶ C |
| ③ 電子のmol | Q/F | 2.88×10⁶/9.65×10⁴=29.84 mol |
| ④ 物質のmol | 電子mol ÷ 価数 | 29.84/2=14.92 mol |
| ⑤ 質量 | ×原子量/分子量 | Mg:14.92×24.3≈360g;Cl₂:14.92×71≈1060g |

④が最頻出の脱落点。③から⑤へ飛ぶと価数分の倍率を落とす。電子のmolと物質のmolは必ず別行に書き分けること(既知の弱点「代入遺漏・漏乗因子」に直結)。

Cl₂は分子(2原子) ゆえ分子量71を使う(原子量35.5ではない)——独立した第二の脱落点。陽極反応は2Cl⁻→Cl₂+2e⁻。

誤答の設計:Mgを1価として計算→720g;MgもCl₂も1電子として計算→720g/2120g。出題者はDとEそれぞれに独立の罠を用意している。

検算法:電荷収支からMg 1molに対しCl₂ 1mol。質量比24.3:71=1:2.92。360×2.92≈1050≒1060 ✓

題型注意:前半の空欄が知識問題、最後の空欄が計算という構成では、知識だけでは選択肢が二つまでしか絞れないよう設計されている場合がある。必ず計算を完遂すること。

出處：H28-Q20、H29-Q20（第120項）
