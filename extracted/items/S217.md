# S217　陶瓷感測器的原理對照

「圧電」＝圧→電：加壓（含超音波）生電＝正壓電效應；施加電場生變形・超音波＝逆壓電效應。

| 感測器 | 材料 | 原理 |
|---|---|---|
| 氣體感測器 | SnO₂ 燒結體（n 型） | 空氣中吸附 O⁻ 奪走電子 → 晶界空乏層 → 高電阻；可燃性氣體消耗吸附氧 → 電子歸還 → 電阻下降 |
| 溫度計（熱敏電阻） | PTC：半導體化 BaTiO₃；NTC：Mn-Co-Ni 氧化物 | 電阻隨溫度變化（第155項） |
| 氧感測器 | 安定化 ZrO₂（氧離子導體） | 氧濃淡電池：E＝(RT/4F) ln(P₁/P₂)；參考側為已知氧分壓 |
| 非接觸溫度（紅外線） | 焦電體 LiTaO₃、PZT | 溫度變化 → 自發極化改變 → 表面電荷；只對變化反應（需截波器） |
| 障礙物（超音波） | 壓電體 LiNbO₃、PZT | 發射＝逆壓電（電→振動）；接收回波＝正壓電（振動→電） |

出處：R3-Q22（關聯：第21項＝介電/壓電/焦電/鐵電包含關係、第155項）
