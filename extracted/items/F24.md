# F24　H24 化工計算：攪拌放大・反應器・氣液平衡・熱收支

A　攪拌功率放大：比值法(先消去不變量)

P=Npρn³d⁵，Np/ρ不變時 → PB/PA=(nB/nA)³×(dB/dA)⁵。轉速3次方、翼徑5次方，尺寸放大比轉速更劇烈影響功率。

重點** **流程：①標記題目說『一定』的量(會在比值消掉)②相除消去不變量③代入改變量比值④乘已知P得答案。工業放大常降轉速抵銷尺寸放大帶來的功率暴增。

B　批次反應器週期時間：一級反應+裝卸料時間

ln(C₀/C)=kt，先用已知條件(如反應50%需30分)求k，再用k反推目標反應率(如99%)所需時間。

1サイクルの時間** = ****純反應時間**** + ****仕込み・取出し****(****裝卸料****)****時間**——非生產時間每週期都要重複計入。與問32(碘131半衰期)同一套一級動力學數學。

C　亨利定律：質量ppm↔莫耳分率(液相濃度→氣相組成)

四步：①質量ppm→莫耳濃度C_A(mol/m³)②亨利定律 P_A=H×C_A 求平衡分壓③y=P_A/P_總(道爾頓分壓)。與問28(氣液平衡殘留水蒸氣)同一類『濃度↔分壓』互換，方向相反(這次液相推氣相)。

D　緩衝槽容量：流量差→莫耳數→反推槽體積

三步橋樑：①算供給/使用流量差的淨氣體損失量(標準狀態Nm³)②換算成莫耳數(用標準狀態T,P代入PV=nRT)③同一莫耳數變化，套用槽內實際T和壓力變化(P₁−P₂)反推V。核心：用同一個n把『標準狀態描述』與『槽內實際狀態』串起來。

E　蒸汽夾套加熱：熱收支(潛熱驅動，非顯熱)

關鍵概念：蒸汽加熱靠潛熱(相變熱)而非溫度下降——飽和蒸汽冷凝過程溫度不變，釋熱靠氣→液相變。

| 步驟 | 公式 |
|---|---|
| ①蒸汽側總釋熱 | Q = m_蒸汽** × (H_g−H_L)****　****(****查飽和蒸汽表****)** |
| ②水側反推溫升 | ΔT = Q / (m_水** × c)** |
| ③橋樑 | 無熱損失時，蒸汽放熱=水吸熱(Q相等) |

重點** **與DSC/問13的Tm=ΔHm/ΔSm同源：都是『用焓差算熱量』，只是焓差來源從DSC儀器量測換成查飽和蒸汽表。相變潛熱通常遠大於顯熱，這是工業愛用蒸汽加熱(高效傳熱)的原因。
