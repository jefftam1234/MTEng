# S281　芳香族多取代合成：定位效應決定步驟順序

| 取代基 | 定位 |
|---|---|
| –NH₂、–OH、–OR、烷基、鹵素 | 鄰／對位 |
| –NO₂、–SO₃H、–COOH、–CHO、–CN、–NH₃⁺ | 間位 |

- 目標為對位 → 第二步時環上須已有鄰／對位定位基 → 該基先裝。

- NH₂ 不能直接引入：硝化 → Béchamp 還原（Fe/HCl）；NO₂（間位）還原後成 NH₂（鄰／對位），定位反轉。

- スルファニル酸：苯 → 硝基苯 → 苯胺 → 濃 H₂SO₄ 加熱（約 180〜200℃）→ 對位（純背誦）。先磺化得間位。

- 胺＋磺醯氯 → 磺醯胺（N–S），不是環上 C-磺化。

出處：R7-Q3（關聯：第142項＝取代基效應、第198項＝SNAr）
