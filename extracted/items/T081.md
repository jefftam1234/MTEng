# T081　平均分子量：数平均 Mₙ vs 重量平均 M_w

出處：H27-Q14（與問63/H24-Q30 計算題互參）

|  | Mₙ** 数平均** | M_w 重量平均 |
|---|---|---|
| 定義 | Mₙ = Σxᵢ Mᵢ（xᵢ＝モル分率／個數權重） | M_w = Σwᵢ Mᵢ（wᵢ＝重量分率／質量權重） |
| 展開式 | Σnᵢ Mᵢ / Σnᵢ | Σnᵢ Mᵢ² / Σnᵢ Mᵢ |
| 敏感於 | 小分子（數量多者主導） | 大分子（重者主導，出現 Mᵢ²） |
| 測定 | 滲透壓・末端基・依數性 | 光散射・超離心 |

下標對應名稱（不必背）：x→数（number/個數）、w→weight（重量）。 恆成立：Mₙ** ****≤**** M_w；多分散度** Đ = M_w/Mₙ** ****≥**** 1**（=1 完全単分散，リビング重合可達 ≈1.0–1.1，一般自由基 2–10）。

術語：モノマー（基本單位）──重合──→ ポリマー；合成高分子＝構造単位同、鏈長不一的同族体混合物＝多分散（非単分散）。
