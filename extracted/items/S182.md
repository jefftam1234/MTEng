# S182　無機工業プロセス：製品と製法の対応

誤り作問の定番は「製品名と製法名の付け替え」。反応式に炭素源・窒素源があるかで検算する。

| 製品 | 製法 | 要点 |
|---|---|---|
| NaOH（苛性ソーダ） | 食塩電解（隔膜法／水銀法／イオン交換膜法） | 2NaCl ＋ 2H₂O → 2NaOH ＋ Cl₂ ＋ H₂ |
| Na₂CO₃（ソーダ灰） | アンモニアソーダ法（ソルベー法） | 2NaCl ＋ CaCO₃ → Na₂CO₃ ＋ CaCl₂ |
| 高純度シリコン | 帯域融解法（提純）、CZ 法／FZ 法（単結晶） | 偏析を利用 |
| アンモニア | ハーバー・ボッシュ法 | 高圧・中温・鉄系触媒 |
| アルミナセラミックス | 焼結法 | 融点以下で拡散により緻密化 |

電解槽には炭素源がないので炭酸塩は生じない。「水銀法で炭酸ソーダ」型の肢はこれだけで切れる。なお水銀法は実在の工業法（日本では水俣病を受け 1980 年代に全廃）であり、「有毒だから使わない」という推論では判定できない。

食塩電解三法

| 方法 | 原理 | 問題 |
|---|---|---|
| 隔膜法 | 石綿隔膜で陽極室・陰極室を仕切る | NaOH 純度が低い（NaCl 混入） |
| 水銀法 | 陰極に水銀、Na アマルガム経由 | 高純度だが水銀汚染 |
| イオン交換膜法 | 陽イオン交換膜が Na⁺ のみ通す | 現行主流。高純度・無公害 |

アンモニアソーダ法の設計精髄　原料は NaCl と CaCO₃ のみ。NH₃ は①で消費され⑤で回収される閉ループなので原料に数えない。副生物は CaCl₂ のみ。

① NaCl ＋ NH₃ ＋ CO₂ ＋ H₂O → NaHCO₃↓ ＋ NH₄Cl　② 2NaHCO₃ → Na₂CO₃ ＋ H₂O ＋ CO₂　③ CaCO₃ → CaO ＋ CO₂（①へ）　④ CaO ＋ H₂O → Ca(OH)₂　⑤ 2NH₄Cl ＋ Ca(OH)₂ → CaCl₂ ＋ 2NH₃ ＋ 2H₂O

①で NaHCO₃ が析出するのは、Na⁺・NH₄⁺・Cl⁻・HCO₃⁻ の組合せのうち NaHCO₃ の溶解度が最小だから。

高純度シリコンの三法の区別

| 方法 | 目的 | 特徴 |
|---|---|---|
| 帯域融解法 | 提純 | 偏析（k＜1）で不純物を末端へ掃き寄せ、末端を切除 |
| FZ 法（浮遊帯溶融） | 提純＋単結晶 | るつぼ不使用 → 酸素混入なしで高純度、大口径化が困難 |
| CZ 法（チョクラルスキー） | 単結晶 | るつぼ中の融液から引き上げ。大口径・低コストだが酸素を含む |
