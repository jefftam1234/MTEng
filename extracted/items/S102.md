# S102　化学工学の計算題に共通する構造:公式は単純、失点は読題に集中

H28-Q32〜Q35 の四題はいずれも「公式そのものは三十秒で片づくが、幾何または定義の陥穽が一つ埋め込まれている」構成。計算力ではなく読題精度を問う設計。

| 題號 | 主題 | 核心公式 | 唯一の考点 | 答 |
|---|---|---|---|---|
| Q32 | 融解エントロピー | S = R ln W | Wを数える(結晶1、液体3) | ③ 9.14 |
| Q33 | ジャケット伝熱 | Q = U A ΔT | 面積は液深0.4、側面のみ | ③ 72,000 |
| Q34 | 蒸留の還流比 | R = L/D | 分母はDでありVではない | ② 0.5 |
| Q35 | トリチェリ | H = u²/(2g) | Hは液面〜ノズル、+0.1が必要 | ⑤ 0.97 |
| 題號 | 与えられたが使わない条件 |  |  |  |
| Q32 | 融点とΔSの反比例関係 |  |  |  |
| Q33 | 壁厚10 mm、槽深0.7 m |  |  |  |
| Q34 | (なし、本題は条件が clean) |  |  |  |
| Q35 | 槽4 m×4 m、密度1,000 kg/m³ |  |  |  |

干擾条件の存在自体が手がかり:与えられた数値を全部使おうとすると誤答に誘導される。「この数値は式のどこに入るか」を確認し、入らないなら使わないと決める。

読題時に丸で囲むべき語の一覧:①高さの基準(底面から/液面から/ノズル位置から) ②寸法(内径/外径、槽深/液深) ③範囲(側面のみ/全面) ④方向詞(最も大きい/小さい、適切/不適切)。

第①〜③は幾何判断で、最初の一歩を誤ると以降が全て崩れるが、逆に正しく判断できれば残りは単純な代数。図を描いてから式を立てることが最も確実な対策。
