# S209　酸性・鹼性強弱序列總表（取代基效應與鹼性）

EWG 穩定共軛鹼 → 酸性↑；EDG 使共軛鹼不穩定 → 酸性↓。NO₂ 是拉電子基（−I、−M），CH₃ 是推電子基（+I、超共軛）。

| 系列 | 正確順序（強 → 弱） | pKa / pKaH | 判斷軸 |
|---|---|---|---|
| 苯酚類（酸性） | 苦味酸 > p-硝基苯酚 > 苯酚 > p-甲酚 | 0.4 / 7.2 / 10.0 / 10.3 | NO₂ 越多越酸；CH₃ 使酸性略降（常考翻轉點） |
| 含 N 鹼（鹼性） | 胍 > 二異丙胺 > 吡啶 > 吡咯 | 13.6 / 約11 / 5.2 / 約−4 | 胍鎓離子三 N 共振；吡啶 sp² 孤對；吡咯孤對參與芳香 6π → 幾乎無鹼性 |
| 陰離子（鹼性） | CH₃⁻ > NH₂⁻ > OH⁻ > NH₃ | 共軛酸 約50 / 36 / 15.7 / 9.2 | 同週期電負度 C < N < O |
| 氫化物（酸性） | HF > H₂S > H₂O > NH₃ | 3.2 / 7.0 / 15.7 / 36 | 同週期比電負度、同族比原子大小 |
| 氟代乙酸（酸性） | CF₃COOH > F₂CHCOOH > FCH₂COOH > CH₃COOH | 0.2 / 1.3 / 2.6 / 4.8 | F 數越多 −I 越強 |

- 鹼的強弱不能憑「看起來強」判斷：CH₃O⁻（共軛酸 pKa 16）與 OH⁻（15.7）同級；反應能否進行仍以兩側 pKa 比較（第68項）。
