# S114　石炭：石炭化度と諸性質、統計の分母

石炭化度：泥炭 → 褐炭 → 亜瀝青炭 → 瀝青炭 → 無煙炭

| 性質 | 石炭化度 低（褐炭） | 石炭化度 高（無煙炭） |
|---|---|---|
| 固定炭素・発熱量・密度 | 低 | 高 |
| 揮発分・水分・酸素・H/C比 | 高 | 低 |
| 着火点 | 低（着火しやすい） | 高 |
| 自然発火性 | 高（危険） | 低 |
| 粘結性 | 無 | 無（瀝青炭で最大） |

着火点を支配するのは揮発分：褐炭は揮発分40〜50%で低温から熱分解して可燃性ガスを大量放出し、そのガスが低温で引火する。無煙炭はほぼ固定炭素で、固体炭素自体を高温まで加熱しないと燃えない。概略値は褐炭250〜300℃、瀝青炭300〜400℃、無煙炭400〜500℃。 　現場推理：褐炭は自然発火しやすいことで有名（貯炭場で締固め・堆高制限・温度監視が必須）。勝手に燃え出す＝着火しやすい＝着火点が低い。数値を覚えていなくても判定できる。 　単調変化しないのは粘結性だけ（中間の瀝青炭で最大）——ここが最も出題されやすい。褐炭は溶融性がなく、無煙炭は揮発分が少なすぎて軟化しない。瀝青炭だけが加熱時に軟化溶融段階を経て冷却後に強度ある多孔質塊になる。コークスは高炉内で上方数十mの鉱石荷重に耐えねばならず、粉化すれば炉内が閉塞するため粘結性は代替不可能。 　高炉でのコークスの三役割：①還元剤(C+O₂→CO、Fe₂O₃+3CO→2Fe+3CO₂) ②熱源 ③通気性の確保。製法は瀝青炭をコークス炉で約1,100℃・空気遮断で乾留。

統計（2014年度＝原子力ゼロの特殊年度）

| 統計 | 石炭 | その他 |
|---|---|---|
| 一次エネルギー国内供給 | 約25% | 石油41%、LNG25%、原子力0%、水力・再エネ9% |
| 発受電電力量 | 約31% | LNG46%、石油9%、水力9%、原子力0% |
| 石炭需要の内訳 | — | 電力約50%＋製鉄約31%＝約81%、残19%が窯業・化学等 |

同一物質に二つの異なる百分率が出たら分母を確認する：石炭は運輸にほぼ使われないため発電分野での比率が高い。逆に石油は一次エネルギー41%（最大）だが発電では9%——運輸燃料と石化原料が主用途だから。（速查表の「LNG 40%台は発電電力量であって一次エネルギー供給ではない」と同一の陥穽。） 　震災後2013年9月〜2015年8月は原子力全機停止。その空白を化石燃料が埋めたため石炭・LNGがともに25%程度に押し上げられている。年度限定は必ず丸で囲む。 　一般炭 vs 原料炭：一般炭＝燃やして熱を取る（発電・セメント）、原料炭（粘結炭）＝コークスにして製鉄。日本はほぼ100%輸入で最大供給国はオーストラリア（6〜7割）、次いでインドネシア・ロシア。
