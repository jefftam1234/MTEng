# S161　蒸留塔の四流量と q 値

還流比 R は無次元の「比」。流量と加減算する式には必ず D を伴って L = RD の形で現れる。

| 区域 | 液流量 | 蒸気流量 |
|---|---|---|
| 濃縮部 | L = RD | V = (R+1)D |
| 回収部 | L′ = L + qF = RD + qF | V′ = V − (1−q)F = RD + qF − W |

q 値（供給液の熱状態）

| 状態 | q |
|---|---|
| 過冷液 | q > 1 |
| 飽和液 | q = 1 |
| 気液混合 | 0 <** q ****<**** 1** |
| 飽和蒸気 | q = 0 |
| 過熱蒸気 | q < 0 |

q は分率なので必ず「乗じる」。qF が液体分、(1−q)F が蒸気分。F/q は誤り——q = 0.5 を代入すると 2F となり供給量より多くなる時点で不合理と分かる。

液は下へ、蒸気は上へ：回収部の液は qF 分増え、回収部の蒸気は (1−q)F 分少ない。この一文から四式すべて再構成できる。

V′ はリボイラ周りの収支 L′ = V′ + W から出る（入る液＝上がる蒸気＋抜く缶出液）。

この型の検算三点

① 次元チェック：R は無次元なので、R 単独が流量と加減算されている選択肢は即座に誤り。これだけで選択肢の大半が落ちることが多い。 ② 分率は乗じる（除さない）。 ③ 極端値代入：q = 1（飽和液）なら蒸気量は増えないはずなので V′ = V = (R+1)D になるべき。実際 RD + F − W = RD + (D+W) − W = (R+1)D ✓。公式を覚えていなくても正誤判定できる最強の手段。 ④ 全塔収支 F = D + W が常に成立。
