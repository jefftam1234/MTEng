# S287　潤滑油添加剤の機能

| 添加劑 | 機構 | 代表物質 |
|---|---|---|
| 清浄分散剤 | 分散油泥前驅物、中和酸 | Ca・Mg 磺酸鹽／酚鹽、琥珀醯亞胺 |
| 酸化防止剤 | 捕自由基、分解過氧化物、螯合金屬離子 | 受阻酚、芳香胺、ZnDTP |
| 粘度指数向上剤 | 使黏度隨溫度的變化變小 | PMA、OCP |
| 流動点降下剤 | 吸附蠟結晶，阻止網狀化（與水無關） | PMA |
| 極圧添加剤 | 生成剪切強度小的金屬鹽膜，防燒結 | S・P・Cl 系 |

出處：R7-Q13（關聯：第113項、第173項＝潤滑油）

補充至第205項

- 判斷芳綸非尼龍：全對位苯環＝剛直棒狀液晶原；尼龍為脂肪族柔軟鏈，無液晶性。

出處追加：R7-Q15

補充至第153項

- 蒲松比 ν＝−橫向應變／縱向應變；ΔV/V＝ε(1−2ν) → ν＝0.5 體積不變。橡膠約 0.49〜0.5、塑膠 0.35〜0.4、金屬約 0.3、軟木約 0。

- 陷阱：「彈性」好（能大伸長並回復）≠「彈性率」大（彈性率＝變形難度，橡膠最小）。

出處追加：R7-Q17

補充至第152項

- R7-Q18 為 H30-Q18 原題；選項欄位標題印錯（A・D・B・C），以題幹文法（B 須為溫度名詞）判定欄位。

出處追加：R7-Q18

補充至第150項

- 起始劑強度須 ≥ 成長末端：苯乙烯（苄基碳負離子，甲苯 pKa 約 41）→ 只有烷基鋰・鹼金屬可引發；格任亞（C–Mg 共價性高）・t-BuOK（pKa 約 18）只能引發 MMA 以上的活化單體。

- 過硫酸鉀雖以陰離子形式存在，活性種是 SO₄•⁻ 自由基 → 自由基起始劑。n-BuLi／苯乙烯＝活性聚合 → 嵌段共聚物（SBS）。

出處追加：R7-Q20
