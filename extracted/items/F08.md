# F08　石油製品・物性（近本職，投報率高）

粘度雙胞胎：絶対粘度** ****μ**** vs ****動粘度**** ****ν**

|  | 絶対粘度** μ** | 動粘度** ν** |
|---|---|---|
| 英／日 | dynamic/absolute viscosity 粘性係數 | kinematic viscosity 動粘性係數 |
| 定義 | 流體內摩擦本身 | μ ÷ ρ（絶対粘度／密度） |
| 單位 | Pa·s（cP） | m²/s（cSt） |
| 用途 | 本質黏性 | 油品分級(ISO VG、重油A/B/C)靠它；毛細管黏度計靠重力量出的就是 ν |

關係：ν** = ****μ**** / ****ρ****　****⟺****　****μ**** = ****ν**** × ****ρ****。****單位反推驗證：****Pa·s ÷ kg/m³ = m²/s ****✓****（乘則兜不出）。**

三大油品** ****評價指標對照**

| 油品 | 指標（日／英） | 要什麼特性 | 有利烴 |
|---|---|---|---|
| ガソリン | オクタン価 Octane number（抗爆震） | 難自燃 | 芳香族（高オクタン価） |
| 灯油 | 煙点 Smoke point（燃燒乾淨） | 少煤煙 | パラフィン（煙点高） |
| 軽油 | セタン価 Cetane number（自燃性） | 易自燃 | パラフィン（高セタン価） |

重點** **一線貫穿：芳香族→汽油好(高オクタン価)，但灯油煙点低、軽油セタン価低(都差)；パラフィン系相反。根源都是 H/C 比。

物性通則

| 性質 | 規則 |
|---|---|
| 沸點 | 同碳數：分枝越多 → 越低（表面積↓、分子間力↓）。n-丁烷 > イソ丁烷 |
| 融點 | 碳數越多 → 越高（有奇偶鋸齒，但大趨勢上升） |
| 單位重量發熱量 | H/C 比越大(越飽和) → 越高；烷 > 烯 > 芳香族 |
| 比熱 | 溫度上升 → 增大 |
| 重油分級 | 依動粘度：A重油(1種) < B重油(2種) < C重油(3種) |
