# S252　XRD でできること

| 測定對象 | 依據 | 備註 |
|---|---|---|
| 同定・多形區分 | 峰位置（d 值） | ICDD/PDF 比對 |
| 固溶濃度 | 晶格常數 | Vegard 定律 |
| 晶粒尺寸 | 峰寬（半高寬） | Scherrer D＝Kλ/(β cos θ)，約 100 nm 以下 |
| 混合物定量 | 峰強度比 | 內標準・RIR・Rietveld |
| 結晶化度 | 結晶峰／非晶暈面積比 | 高分子 |
| 配向性 | 強度的方位依存 | 極圖 |

- 陷阱：晶粒「大」時峰寬接近儀器寬度 → 測不出（方向相反）；「混合物難定量」為錯。

出處：R5-Q24（關聯：第185項、R2-Q26）
