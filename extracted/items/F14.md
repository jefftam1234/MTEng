# F14　物理化学計算：氣體濃度 ppm（錨定得分區）

純計算、不吃日文/記憶，靠** PV=nRT + ****單位反推即秒殺。**

| 步驟 | 內容 |
|---|---|
| ① 目標氣體莫耳數 | 由反應式定量(如 S+O₂→SO₂ 為 1:1，96g S÷32=3mol→3mol SO₂) |
| ② 總氣體莫耳數 | n = PV/RT；看 R 單位定其他量：R=0.083 L·bar·K⁻¹·mol⁻¹→V 用 L(m³×1000)、P 用 bar、T 用 K |
| ③ vol ppm | = (n目標/n總)×10⁶；理想氣體 vol ppm = mol ppm(體積比=莫耳比) |

重點** **例：100m³(=10⁵L)、1bar、300K → n總=10⁵/(0.083×300)≈4016mol；3mol SO₂ → 3/4016×10⁶≈747ppm。技巧：R 的單位就是說明書(反推 P/V/T 單位)。陷阱干擾項：22,400(莫耳體積 22.4L/mol) 與本題無關，別被帶偏。名詞：理想気体の状態方程式 PV=nRT／気体定数 R／体積ppm vol ppm。

B　反應物料衡算** + ****冷卻氣液平衡（化學工學）**

兩步：①反應率+化學計量算各成分出口量；②冷卻凝縮分離水，殘留水由飽和蒸氣壓決定。

| 步驟 | 內容 |
|---|---|
| ① 反應物料衡算 | 反應掉量=進料×反應率；依化學計量增減各成分。注意反應前後總莫耳數會變(如 4mol→2mol) |
| ② 冷卻氣液平衡 | 殘留水莫耳分率** y****水**** = P****飽和蒸氣壓****/P****總壓；乾氣不凝結****→N****出口**** = N****乾氣****/(1−y****水****)** |

重點** **關鍵觀念：冷卻不會把水除盡！氣相殘留『飽和蒸氣壓對應的那部分水』。例：乾氣112、60°C 水蒸氣壓0.02/總壓0.1→y水=0.2→N=112/0.8=140。陷阱：反應器出口總量(冷卻前,如168)是誘餌，別停在第一部分。名詞：物質収支 mass balance／反応率 conversion／飽和蒸気圧 vapor pressure／気液平衡 VLE／ドルトンの分圧 Dalton’s law。

驗算提醒：莫耳分率 y = 分壓/總壓，分子=部分、分母=全體，結果必** ****<****1**。若算出 >1(如誤用 0.1/0.02=5) 立刻知道倒反了。

C　熱傳導(伝熱)＝電路串聯類比

| 概念 | 公式/直覺 |
|---|---|
| 熱阻(單位面積) | R = b/k（厚度/熱傳導率；b 用公尺，mm→m） |
| 串聯總熱阻 | R_total = R₁ + R₂（多層牆＝電阻串聯） |
| 熱流(處處相同) | Q = (T₁−T₃)/R_total（＝歐姆定律 I=ΔV/R） |
| 某層溫度降 | ΔT = Q × R_該層 |
| 快速直覺 | 溫度降** ****∝**** ****熱阻；熱阻大的層掉溫多，接觸面溫度貼近熱阻小的那側** |

重點** **例：R₁=0.01/0.90≈0.0111、R₂=0.02/0.12≈0.1667(R₂≈15×R₁)→溫降主要在外層→T₂ 貼近 T₁。T₁−T₂=(T₁−T₃)×R₁/(R₁+R₂)=850×0.0111/0.1778≈53→T₂≈1147≈1150K。熱傳導=電路(Q↔I、ΔT↔ΔV、R↔R)，不用背傅立葉定律。單位驗算：R=b/k→m²·K/W、Q=ΔT/R→W/m²。名詞：熱伝導率 thermal conductivity(k)／熱抵抗 thermal resistance／熱流束 heat flux。
