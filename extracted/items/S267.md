# S267　高分子：結構式 ↔ 名稱 ↔ 性質・用途（結構與名稱對調陷阱）

解法：先從結構式讀出名稱，再對照敘述；苯環間連接基依序讀出即名稱（–O–・–O–・–C(=O)– ＝ PEEK）。

| 高分子 | 結構特徵 | 性質・用途 | 常見陷阱 |
|---|---|---|---|
| PVC | –CH₂–CHCl– | 耐候・絕緣・自熄性（鹵素）・電線被覆 | 與 PVA（–OH，水溶性）對調 |
| PVA | –CH₂–CH(OH)– | 水溶性；維尼綸・偏光膜・黏著劑 | — |
| PHEMA | 甲基丙烯酸酯 + –CH₂CH₂OH | 水凝膠・軟式隱形眼鏡 | — |
| PLA | –O–CH(CH₃)–C(=O)– | 酯鍵水解 → 生物分解性 | — |
| 聚 4-羥基苯乙烯 | 乙烯基加成聚合物掛苯酚 | 熱塑性；KrF 光阻 | 冒充酚醛樹脂（苯酚環＋–CH₂– 網狀） |
| 聚丙烯酸鈉 | –CH₂–CH(COONa)– | 交聯 → 高吸水性（解離・靜電排斥・滲透壓） | 不是「遇水分解」 |
| HDPE | 直鏈・高結晶 | 硬・強度高；Ziegler-Natta 低壓 | 與 LDPE 性質對調 |
| LDPE | 多分支・低結晶 | 軟・透明；高壓自由基 | — |
| PVDC 共聚物 | 塩化ビニリデン＋塩化ビニル | 食品保鮮膜（阻隔性高） | 毒性在單體不在聚合物 |
| 碳纖維 | PAN（–C≡N 環化 → 梯形）或瀝青 | 耐炎化 200〜300℃ → 碳化 1000〜1500℃ | PP 不行 |
| 三聚氰胺樹脂 | 三聚氰胺＋甲醛 | 熱硬化 | 乙醛 → 錯 |
| PMMA | 甲基丙烯酸甲酯（α-CH₃，Tg ≈105℃） | 透明・硬・玻璃替代 | アクリル酸メチル（Tg ≈10℃，軟） |
| POM（聚縮醛） | –(O–CH₂)–：碳上 2 個 O＝縮醛 | 高結晶・耐磨耗・齒輪 | 以為是醚 |
| PPS | –Ph–S– | 耐熱・耐藥品・難燃 | — |
| PPE（改性 PPO） | –[C₆H₂(CH₃)₂–O]– | — | 與 PEEK 對調 |
| PEEK | –O–Ph–O–Ph–C(=O)–Ph– | 超耐熱 | — |
| PC | –O–C(=O)–O– ＋ C(CH₃)₂（雙酚 A） | 透明・耐衝擊 | — |
| 聚醯亞胺 | 醯亞胺環 –C(=O)–N–C(=O)– | Kapton | 與 PBO（苯并噁唑環 N=C–O）對調 |

出處：R6-Q15、R6-Q16、R6-Q20（關聯：第202項、第204項）
