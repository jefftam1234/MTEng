# S289　高分子反応：イオン交換樹脂・ビニロン・感光性樹脂・セルロース溶解

| 項目 | 要點 | 陷阱 |
|---|---|---|
| イオン交換樹脂 | –SO₃⁻＝陽離子交換；氯甲基化 PS＋胺 → –N⁺R₃＝陰離子交換 | 固定基電荷與被交換離子相反 |
| ビニロン | 乙酸乙烯酯聚合 → 皂化成 PVA → HCHO 縮醛化 | 乙烯醇單體不存在（互變異構為乙醛） |

| セルロース | 氫鍵強難溶；NaOH＋CS₂（黏膠）、[Cu(NH₃)₄]²⁺（銅氨）可溶 | 純背誦 |
