# S250　機能性セラミックス：用途 → 必要性質 → 材料

| 用途 | 材料 | 關鍵性質 |
|---|---|---|
| 積層電容器 | BaTiO₃ | 強介電・高介電常數 |
| PTC サーミスタ | BaTiO₃（半導化） | 居禮點附近電阻急升 |
| 壓電元件 | PZT | 壓電效應 |
| 光快門 | PLZT（PZT＋La） | 透明＋電氣光學效應 |
| 壓敏電阻 | ZnO（＋Bi₂O₃） | 晶界能障・非線性 V-I |
| 高溫超導 | YBa₂Cu₃O₇、Bi 系 | 銅氧化物（必含 Cu） |
| 發熱體 | SiC、MoSi₂、LaCrO₃ | 導電＋耐高溫氧化（SiO₂ 絕緣，不行） |
| 人工骨 | 水酸アパタイト | 生物相容性 |

- 解法：先問用途需要什麼性質，再檢查材料是否具備。BaTiO₃ 配電容器・PTC 以外 → 錯。

出處：R5-Q22（關聯：第155項、H26-Q25、H29-Q22、H30-Q21、R2-Q22）
