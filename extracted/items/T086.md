# T086　逐次重合の分子量分布（Flory 最確分布）

出處：H27-Q19

反應程度 p ＝已反應官能基分率。設初始分子數 N₀：

| 量 | 式 | 推導 |
|---|---|---|
| 殘存分子數 N | N₀(1−p) | 每成一鍵少一分子 |
| 数平均重合度 Pn | 1/(1−p) | Carothers 式，p→1 才有高聚合度 |
| n 量體の個數分率 Nₙ | N₀ pⁿ⁻¹(1−p)² | ＝N·pⁿ⁻¹(1−p)，代入 N=N₀(1−p) 故 (1−p)² |
| n 量體の重量分率 wₙ | n pⁿ⁻¹(1−p)² | wₙ＝nNₙ/N₀ |

分布名：最も確からしい分布（Flory 分布），非正規分布。PDI＝M_w/Mₙ＝1+p → p→1 時趨 2（常考數字）。

消去骨架：ア要(1−p)砍不合者；ウ・エ要 (1−p)² 砍只有一次方者；オ「非正規分布」砍寫正規分布者。
