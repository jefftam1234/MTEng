# S098　ボルツマンの式による融解エントロピー:W を数えるだけの問題

S = R ln W。融解エントロピーは** ΔS_m = R ln(W_****液体**** / W_****結晶****)****。結晶中は全結合がトランスに固定され****W=1****、液体中はトランス・ゴーシュ・逆ゴーシュの****3****配座が等確率で****W=3****。**

| 状態 | 配座数** W** | S = R ln W |
|---|---|---|
| 結晶中 | 全てトランス → W = 1 | R ln 1 = 0 |
| 液体中 | T、G、Ḡ が等確率 → W = 3 | R ln 3 |

計算:ΔS_m = R ln 3 − 0 = 8.31 × 1.10 = 9.14 J K⁻¹ mol⁻¹。

「メチレン基1molあたり」=「回転可能なC–C結合1molあたり」。各メチレン基(−CH₂−)が鎖上の1つのC–C結合に対応するためW=3。

開頭の「融点は融解エントロピーに反比例する」は背景説明であって計算条件ではない。T_m = ΔH_m/ΔS_m に由来し「ΔSを求めれば融点の高低が推定できる」と述べているだけで、本問はΔSのみを問うためΔHは与えられず不要。

誤答の設計:①1.10=log3のみでRを掛け忘れ、②1.61=log5のみで二重の誤り、④13.4=R×log5(Wを5と誤数)、⑤19.1=R×log10(Wを10と誤数)。題目が与えたlog値を片端から代入すると必ず引っかかる構成。

立体配座(コンフォメーション、conformation、単結合の回転で相互変換可能) と 立体配置(コンフィギュレーション、configuration、結合を切らないと変換できない) は別概念で、出題で混同を誘われる。

SOP(この** pattern ****の固定手順****)**:①初状態のWを数える ②終状態のWを数える ③ΔS = R ln(W_終/W_初)。延伸変形として混合エントロピー、同位体置換、欠陥濃度も全て同一の枠組みで、違いはWの数え方だけ。
