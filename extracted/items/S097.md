# S097　撹拌槽のスケールアップ:n ∝ d^a の指數比較で機械的に解く

幾何学的相似を保つスケールアップでは、各基準量を「n と** d ****だけの関係」に整理し**** n ****∝**** d^a ****の形にする。指數****a****が最も負の基準が**** n₂ ****を最も小さくする。攪拌工学の理解は不要で機械的に解ける。**

| 基準 | 式 | 一定条件 | n ∝** d^a** | 指數a |
|---|---|---|---|---|
| 撹拌レイノルズ数 | ρnd²/μ | nd² = 一定 | n ∝ d⁻² | −2(最小) |
| 翼先端速度 | πnd | nd = 一定 | n ∝ d⁻¹ | −1 |
| 単位容積当たり消費動力 | N_p ρn³d² | n³d² = 一定 | n ∝ d^(−2/3) | −0.67 |
| フルード数 | n²d/g | n²d = 一定 | n ∝ d^(−1/2) | −0.5 |
| 翼回転数 | n | n = 一定 | n ∝ d⁰ | 0(最大) |

ρ、μ、g、N_p は定数なので無視し、n と d を含む部分だけ抽出するのが手順の要。

P/V の導出(唯一の要注意点):動力数の定義 N_p = P/(ρn³d⁵) より P = N_p ρn³d⁵。幾何相似ゆえ槽容積 V ∝** d****³。よって P/V = N_p ρn³d⁵/d³ =** N_p ρn³d²。d⁵ ÷ d³ = d² の除算を忘れるとn³d⁵一定として指數−5/3を得てしまう。

数値感覚(dを10倍にした場合のn₂/n₁):Re一定 0.01、翼先端速度一定 0.1、P/V一定 0.215、Fr一定 0.316、n一定 1.0。Re一定と翼先端速度一定で10倍の差。

Re一定が実務で使えない理由:n ∝ d⁻² のため10倍スケールアップで転速が1/100になり攪拌がほぼ停止する。このときP/V ∝ n³d² ∝ d⁻⁴ で単位容積動力が1/10000——混合効果が皆無。理論上最も厳密な相似条件だが実用性がない。

| 実務で使う基準 | 適用場面 |
|---|---|
| P/V 一定 | 最も多用。混合、分散、伝熱の大半 |
| 翼先端速度一定 | 剪断が重要な場合(乳化、細胞培養、結晶の破砕防止) |
| フルード数一定 | 自由表面の渦(ボルテックス)形状が重要な場合 |

幾何相似を保つ限り全ての無次元数を同時に一定にすることは不可能——これがスケールアップの根本的困難。どの現象が最も重要かを選び、それだけを相似にする。

逆向きの問い(「n₂が最も大きくなるのは」)なら答えは指數0の「翼回転数一定」。方向詞に注意。
