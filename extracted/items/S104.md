# S104　テルペノイドの分類階梯とカロテノイド → 視覚

イソプレン則（ワラッハ則）：テルペンは C₅ のイソプレン（2-メチル-1,3-ブタジエン C₅H₈）単位が頭尾結合して生成。イソペンタン（飽和 C₅H₁₂）ではない——二重結合がなければ連結機構（IPP/DMAPP のカルボカチオン機構）が成立しない。

語尾規則（片假名化合物名の即断法）：-タン = 飽和(-ane)／-テン, -レン = 二重結合(-ene)／-チン, -イン = 三重結合(-yne)。

| 名称 | イソプレン単位数 | 炭素数 | 代表例 |
|---|---|---|---|
| モノテルペン | 2 | C₁₀ | ミルセン、リモネン、ピネン、メントール、樟脳 |
| セスキテルペン | 3 | C₁₅ | ファルネセン、ファルネソール |
| ジテルペン | 4 | C₂₀ | フィトール、レチノール、タキソール |
| トリテルペン | 6 | C₃₀ | スクアレン → ステロール |
| テトラテルペン | 8 | C₄₀ | β-カロテン、リコペン |
| ポリテルペン | 多数 | (C₅)ₙ | 天然ゴム（ポリイソプレン） |

命名の要注意：接頭辞は「イソプレン単位数」ではなく C₁₀ を1単位とする倍数。モノ=C₁₀、ジ=C₂₀、テトラ=C₄₀。「モノ＝イソプレン1個＝C₅」と読むのが最頻の誤り。

精油の主成分がモノテルペン(C₁₀)である理由：揮発性（沸点150〜180℃）。C₂₀ 以上は不揮発で精油成分になり得ない。なお「ミルセン」等は個別化合物名であり、「一群の化合物の名称」を問われたら分類名（総称）で答えること。

β-カロテンの発色：共役二重結合11個 → HOMO–LUMOギャップ小 → 約450 nm（青）を吸収 → 補色の黄橙色。全直鎖のリコペンが赤なのに β-カロテンが橙止まりなのは、両端の環上の二重結合が主鎖と同一平面に乗れず実効共役長が短いため。「緑黄色」は緑黄色野菜からの誘導肢（緑はクロロフィル）。

視覚サイクル：β-カロテン →(小腸で中央開裂)→ レチナール ⇄ レチノール(ビタミンA) → 11-cis-レチナール →(オプシンとシッフ塩基)→ ロドプシン →(光)→ all-trans-レチナール → 神経信号。C11=C12 の cis→trans 光異性化が視覚の分子的基盤。問題文に「11-cis-」が出た時点で答えは視覚。 欠乏症＝夜盲症。
