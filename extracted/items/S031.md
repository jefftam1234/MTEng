# S031　攪拌動力比例定律：P∝n³ + 徒手開立方根技巧

同槽同葉輪只換馬達功率時，Np、ρ、D皆不變，可從Np=P/(ρn³D⁵)直接導出P∝n³的比例關係，不需代入Np數值(比較兩狀態時會自動消掉)。

| 立方數錨點(徒手估算用) | 數值 |
|---|---|
| 1.0³ | 1.000 |
| 1.1³ | 1.331 |
| 1.15³ | 1.521 |
| 1.2³ | 1.728 |

解法：n2/n1=(P2/P1)(1/3)=(2.2/1.5)(1/3)=(1.4667)^(1/3)。目標值1.4667落在1.1³=1.331與1.15³=1.521之間，線性插值：(1.4667-1.331)/(1.521-1.331)≈0.714，x≈1.1+0.05×0.714≈1.136，n2≈200×1.136≈227 rpm。

通用技巧：任何「開n次方根」但無計算機時，找兩個鄰近的整數次方當錨點，用線性插值估算，誤差通常在0.1-0.5%等級，足以分辨選擇題的相鄰選項。
