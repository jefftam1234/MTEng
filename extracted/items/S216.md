# S216　電氣絕緣性陶瓷的熱傳導：一切看「聲子平均自由徑」

絕緣體沒有自由電子 → 熱由聲子（晶格振動）傳遞。κ ≈ (1/3)·C·v·l：任何縮短平均自由徑 l 的因素都使熱傳導率下降。

| 因素 | 熱傳導率 | 理由 |
|---|---|---|
| 高溫 | 下降（約 ∝ 1/T） | 聲子-聲子散射（Umklapp）增加 |
| 多孔質 | 下降 | 氣孔內空氣熱傳導率極低＋氣孔界面散射（→ 斷熱磚） |
| 不純物・固溶 | 下降 | 點缺陷（質量差・應變）散射聲子（例：AlN 含氧） |
| 玻璃（非晶） | 下降 | 無長程秩序，l 約等於原子間距（石英晶體約 10、石英玻璃約 1.4 W/(m·K)） |
| 結晶性高・純度高・緻密・輕原子強鍵結 | 高 | 例：金剛石、BeO、AlN、SiC |

出處：R3-Q21
