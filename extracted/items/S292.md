# S292　反応機構と速度式：律速段階・定常状態近似

- 總反應式的係數 ≠ 反應次數；只有基本反應可由係數寫速率式。

- 定常態近似：中間體 d[I]/dt ＝ 0（中間體快速消耗、濃度小且一定）。

- 慢步驟（律速）後接快步驟且無逆反應 → 整體速率＝慢步驟速率×化學計量係數；快步驟的濃度項全部消去。

- 慢步驟之前有快速可逆平衡 → 用前平衡近似，可能出現高次項。

| 例（R7-Q35） | 式 |
|---|---|
| 機構 | A＋B → C'（k₂、慢）；2B＋C' → 2C（k₃、快） |
| [C'] | k₂[A]/(k₃[B]) |
| 速率 | d[C]/dt ＝ 2k₂[A][B] → B 的 1 次方 |
