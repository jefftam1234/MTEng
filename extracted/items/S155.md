# S155　ファインセラミックスの機能別整理とサーミスタの符号

| 機能 | 材料 | 製品 |
|---|---|---|
| 構造（強度・耐摩耗） | Si₃N₄、SiC、Al₂O₃、ZrO₂（応力誘起相変態で高じん性） | ボールベアリング、切削工具、人工関節 |
| 高誘電 | BaTiO₃ | 積層セラミックコンデンサ（MLCC） |
| PTC | 半導体化 BaTiO₃ | 自己制御ヒーター |
| 圧電 | PZT、水晶 | 超音波探傷器、超音波モーター（カメラの AF）、着火装置、インクジェット |
| 焦電 | PZT、LiTaO₃ | 赤外線センサー、人感センサー |
| フェリ磁性 | BaFe₁₂O₁₉、SrFe₁₂O₁₉（ハードフェライト） | 永久磁石（モーター、スピーカー） |
| ソフトフェライト | MnZn、NiZn | トランスコア、インダクタ |
| 透光性 | 透光性アルミナ（多結晶 Al₂O₃） | 高圧ナトリウムランプ発光管 |
| イオン伝導 | 安定化ジルコニア（YSZ）、β-アルミナ | 酸素センサ、SOFC、NAS 電池 |
| 光触媒 | TiO₂（アナターゼ） | 有機物分解、抗菌、セルフクリーニング |

サーミスタの符号（最頻出の方向陥穽）

| 型 | 温度↑のとき抵抗 | 材料 | 用途 |
|---|---|---|---|
| NTC（Negative） | 低下 | Mn・Co・Ni・Fe の複合酸化物 | 温度センサ、突入電流抑制 |
| PTC（Positive） | 上昇（急峻） | 半導体化 BaTiO₃ | 自己制御ヒーター、過電流保護 |
| CTR | ある温度で急低下 | VO₂、V₂O₃ | 温度警報 |

自己温度制御ヒーターは PTC でなければならない：温度↑→抵抗↑→電流↓→発熱↓の負のフィードバックで自然に温度が止まる。抵抗が下がる材料では温度↑→電流↑→発熱↑の正のフィードバックで熱暴走し、ヒーターにならない。材料名を知らなくてもフィードバックの符号だけで判定できる。

PTC の機構：キュリー点（約 120℃）を超えて強誘電性が失われると粒界のポテンシャル障壁が急増し、抵抗が数桁跳ね上がる。サーモスタット不要・自己消火。

BaTiO₃ が二つの機能で登場する点に注意：強誘電性そのものを使えばコンデンサ、キュリー点で消える性質を使えば PTC ヒーター。

効果と応用の突き合わせ

| 効果 | 扱う物理量／変換 | 正しい応用 |
|---|---|---|
| マイスナー効果 | 磁気（完全反磁性 B=0） | 磁気浮上（リニア）、SQUID、MRI マグネット |
| 圧電効果 | 応力 ⇄ 電気 | 超音波探傷器、超音波モーター、着火 |
| 焦電性 | 温度変化 → 電気（dT/dt ≠ 0 のときだけ信号） | 人感センサー（静止すると反応しない理由） |
| ゼーベック効果 | 熱 → 電気 | 排熱発電、地熱発電、熱電対、宇宙用 RTG |
| ペルティエ効果 | 電気 → 熱 | 電子冷却 |
| 本多・藤嶋効果（光触媒） | 光 → 化学反応 | 有機物分解、抗菌、超親水セルフクリーニング |

効果が扱う物理量と、応用が必要とする物理量を突き合わせるのが判定法。「超音波探傷器」は電気⇄機械振動なので圧電の領分であり、磁気現象であるマイスナー効果とは結びつかない。

包含関係：圧電性 ⊃ 焦電性 ⊃ 強誘電性。強誘電体はすべて焦電体かつ圧電体（PZT が両方に使える理由）。逆は成立しない（水晶は圧電だが焦電ではない）。

本多・藤嶋効果は TiO₂ に紫外光（<387 nm）を当てると正孔が ·OH、電子が ·O₂⁻ を生じ、有機物を CO₂ と H₂O まで分解する。分解と超親水性の二本柱。アナターゼ型がルチル型より高活性。

出處：H30-Q21、H30-Q23、R1再-Q22
