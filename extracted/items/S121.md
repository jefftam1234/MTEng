# S121　ガラス：網目形成体と網目修飾体が物性を決める（第 H28-Q24 章の補遺）

判斷原則：網絡形成體（SiO₂、B₂O₃、P₂O₅）多 → α 小・耐熱強・難熔難加工／網絡修飾體（Na₂O、K₂O、CaO、PbO）多 → α 大・耐熱弱・易熔易加工。

| 玻璃種類 | 主成分 | 線膨脹係數 ×10⁻⁶/K | 特徵・用途 |
|---|---|---|---|
| 石英玻璃 | SiO₂ 100% | 0.5（最低） | 耐熱・耐藥品最強、紫外透過、光纖、半導體爐管 |
| 硼矽玻璃 | SiO₂＋B₂O₃ | 3.3 | 耐熱理化學器材（Pyrex） |
| 鈉鈣玻璃 | SiO₂＋Na₂O＋CaO | 9 | 最汎用（板玻璃・瓶）、便宜、耐熱差 |
| 鉛玻璃 | SiO₂＋PbO | 9〜10 | 高折射率、放射線遮蔽、工藝品 |
| 鋁矽酸玻璃 | SiO₂＋Al₂O₃ | 4〜5 | 高強度、手機面板（化學強化用） |
| 結晶化玻璃 | Li₂O-Al₂O₃-SiO₂ | ≈0 | 微結晶析出、IH 頂板、望遠鏡鏡基板 |

機制：純 SiO₂ 全由 SiO₄ 四面體以橋氧連結，升溫時 Si–O–Si 鍵角撓曲吸收振動而鍵長不變 → 膨脹極小。Na₂O 加入生成非橋氧切斷網絡 → 結構鬆散 → α 上升。 　耐熱衝擊參數 R = σ(1−ν)/(Eα)，α 在分母 → α 越小抗熱震越好。石英玻璃可從 1000℃ 直接投入冷水。 　陷阱：「純 SiO₂ 組成」與「熱膨脹率高」是自相矛盾的敘述——網絡完整既帶來化學耐久性也帶來低膨脹。

強化玻璃の二法

|  | 物理強化（風冷） | 化學強化（離子交換） |
|---|---|---|
| 方法 | 軟化點附近加熱 → 急冷 | KNO₃ 熔鹽中 Na⁺⇄K⁺ |
| 原理 | 表面先固化、內部後收縮拉扯 | K⁺ 較大 → 擠壓產生壓縮應力 |
| 壓縮層 | 厚（數百 μm） | 薄（數十 μm）、薄板也可 |
| 破壞形態 | 無銳角粒狀（安全） | 普通碎片 |

原理：玻璃破壞始於表面微裂紋，裂紋只在拉應力下擴展。表面預壓縮 → 外力須先抵銷 → 強度 3〜5 倍。強化後不可切割鑽孔（必須先加工再強化）。

結晶化玻璃：先以玻璃製程成形 → 加核形成劑（TiO₂、ZrO₂）→ 熱處理析出微細結晶。β-スポジュメン・β-ユークリプタイト 具負熱膨脹，與正膨脹玻璃相複合可使 α ≈ 0。與陶瓷的差異：陶瓷是粉末燒結（有氣孔、難成形），結晶化玻璃可精密成形且無氣孔。 　光纖：SiCl₄ + 2H₂ + O₂ → SiO₂ + 4HCl（火焰水解、VAD 法は日本開發）。必用氣相法的理由是傳輸損失 <0.2 dB/km 要求 OH 基極低（1.38 μm 吸收）與過渡金屬 <ppb。芯摻 GeO₂ 提高折射率、包層摻 F 降低。 　鉛玻璃的 PbO 三效果：Pb 原子序 82 → 放射線遮蔽／極化率大 → 折射率 1.6〜1.9／熔點低 → 易切割。「クリスタルガラス」＝PbO 24% 以上，非水晶。
