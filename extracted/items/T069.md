# T069　水合三法對照：Markovnikov / 反 Markovnikov / 重排

出處：H27-Q2

|  | ヒドロホウ素化–酸化 | オキシ水銀化–脱水銀 | 酸触媒水和 |
|---|---|---|---|
| 試劑 | BH₃·THF → H₂O₂/NaOH | Hg(OAc)₂/H₂O → NaBH₄ | H₂O/H₂SO₄ |
| 位置選択性 | 反 Markovnikov | Markovnikov | Markovnikov |
| 立体選択性 | syn 加成 | 無（NaBH₄ 步驟消旋） | 無 |
| 中間體 | 四中心遷移狀態 | マーキュリニウムイオン（三員環） | カルボカチオン |
| 転位 | 無 | 無 | 有（缺點） |

syn 加成的正確理解：syn 是指「新加入的 B 與新加入的 H 同面」，不是「OH 與原有取代基同面」。 → 1-メチルシクロペンテン + BH₃/H₂O₂：B 上 C2、H 上 C1（把 C1 的 CH₃ 頂到反面）→ 氧化保持組態 → trans-2-メチルシクロペンタノール。 → 同一受質走オキシ水銀化 → 1-メチルシクロペンタノール（第三級醇）。

速判：選項中出現第三級醇 → 必是オキシ水銀化（M）；出現 trans-第二級醇 → 必是ヒドロホウ素化（反 M + syn）。
