# S139　アルキンの反応系統：末端アルキンの酸性が起点

pKa: HC≡CH (25) ≪ H₂C=CH₂ (44) <** CH₃CH₃ (50)。sp 炭素は s 性 50% で負電荷を安定化できる。NaNH₂（共役酸 NH₃ の pKa 36）で定量的にアセチリドが生成する。**

| 反應 | 試薬 | 產物 | 要點 |
|---|---|---|---|
| アルキル化 | NaNH₂ → R–X（1級のみ） | 内部アルキン（C–C 結合生成） | Sₙ2。炭素数が増える——ここで検算できる |
| ハロゲン付加 | Br₂ 2当量 | テトラハロアルカン | 4個のハロゲンは元の三重結合炭素2つに集中 |
| 水和（マルコフニコフ） | H₂O / HgSO₄・H₂SO₄ | エノール →互変異性→ ケトン | 末端アルキン → メチルケトン |
| 水和（反マルコフニコフ） | BH₃ → H₂O₂/NaOH | エノール → アルデヒド | 末端アルキンのみ意味を持つ |
| 部分水素化（cis） | Lindlar 触媒（Pd/CaCO₃＋Pb または キノリンで被毒） | cis（Z）-アルケン | 表面 syn 付加（第138項と同一原理） |
| 部分水素化（trans） | Na / 液体 NH₃ | trans（E）-アルケン | ラジカルアニオン経由、trans ビニルアニオンが安定 |
| 完全水素化 | H₂ 過剰 / Pd-C | アルカン | 止まらない |
| ジハロゲン化物からの合成 | NaNH₂ 3当量 | 末端アルキン（後処理後） | 3当量目はアセチリド生成用（第3の当量を忘れない） |

当量数の論理：脱 HBr × 2 ＋ 末端 H の引き抜き × 1 ＝ 3当量。内部アルキンを作る場合は酸性水素がないので 2当量で足りる。3当量目はアセチリドとして「鎖の末端に固定」し、強塩基下での内部アルキンへの異性化を防ぐ役目もある。

アセチリド ＋ ハロゲン化アルキルの設問は、まず炭素数を数えるのが最速の検算。付加した R の炭素が増えていなければ誤り。ハロゲン化アルキルの Br は脱離基であって求電子中心ではないので、Br が炔炭素に付く産物は生成しない（それには Br₂ や NBS が要る）。

Lindlar = cis、Na/NH₃ = trans の対は毎年級の頻出。

出處：H30-Q4（關聯：第34項＝アセチレンの pKa 方向、第68項＝pKa による反応方向判定）
