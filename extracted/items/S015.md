# S015　橡膠 vs 塑膠/纖維：熵彈性 vs 結構支撐

橡膠彈性的本質是熵彈性(entropy elasticity)：未拉伸時鏈段捲曲熵高，拉伸後熵下降，鏈段自發回捲提供回彈力。

| 性質 | 橡膠 | 塑膠/纖維 |
|---|---|---|
| 彈性率 | 小(軟) | 大(硬) |
| 結晶傾向 | 難結晶(非晶為主) | 易結晶(規則排列) |
| 彈性機制 | 熵彈性(構型熵驅動) | 能量彈性/結構支撐 |
| 玻璃轉移溫度Tg | 遠低於室溫(室溫時在橡膠態) | 接近或高於室溫(維持剛性) |
| 凝聚能(分子間作用力) | 小(鏈段需自由旋轉) | 大(需要強度/剛性) |

*出處：**H25-Q18*
