# T083　高分子溶液：浸透圧法による分子量測定

出處：H27-Q16

半透膜（只通溶劑、不通高分子）隔開純溶媒與溶液 → 溶劑滲入溶液側，需在溶液側加壓 π（浸透圧）達平衡。

ファントホッフの式（不是ファンデルワールス！）

π=RTCM=cRT 與理想氣體 P=cRT 同形

ファントホッフ＝把浸透壓當氣體壓力的類比（式中無 a、b 修正項）

ファンデルワールス＝實氣體狀態方程 (P+a/V²)(V−b)=RT，與浸透壓無關

兩者都是荷蘭人、名字皆「ファン」開頭 → 陷阱。用式形判：有 a/b 修正→van der Waals；純理想式→van ’t Hoff。

測得 Mₙ（数平均）：浸透壓是依数性（只數粒子個數）→ 必為個數加權的数平均分子量（同第 81 章 x↔数）。

ビリアル展開（有限濃度修正）

πRTC=1M+A2C+A3C2+⋯

| 項 | 名稱 | 意義 |
|---|---|---|
| 1/M（常數項） | 第1（慣例） | 無限稀釋極限 → 分子量 |
| A₂ C（一次項） | 第2ビリアル係数 A₂ | 高分子–溶劑相互作用 |
| A₃ C² | 第3ビリアル係数 | 高階修正 |

「π/RTC 近似的に C に比例」＝取到一次項 → 比例定数＝第2ビリアル係数（第1是常數項，故含 C 的一次項為第2）。 A₂ 判溶劑：A₂>0 良溶劑；A₂=0 θ溶劑；A₂<0 貧溶劑。

測定法整合：π/C 對 C 作圖，外插 C→0：截距＝RT/Mₙ（求 Mₙ）、斜率∝A₂（判溶劑良否）。一圖兩收穫。

分子量測定法 → 平均種類對照

| 測定法 | 得到 |
|---|---|
| 浸透圧・依数性・末端基定量 | Mₙ（数平均） |
| 光散乱・超遠心 | M_w（重量平均） |
