# S276　陶瓷機械性質的定義

| 用語 | 定義 | 陷阱 |
|---|---|---|
| 彈性率 | 應力／應變（E＝σ/ε） | 應變／應力＝柔度 |
| 曲げ強さ | 破壞起於拉應力側的最大拉應力 | — |
| モース硬さ | 刮痕法相對序列 1〜10 | 冒用維氏定義 |
| ビッカース硬さ | 正四角錐鑽石壓頭 136°；荷重／壓痕表面積 | — |
| ヌープ硬さ | 菱形鑽石壓頭；荷重／投影面積 | — |
| 破壊靭性 K_IC | 裂縫不穩定擴展開始時的應力強度因子 | — |
| ワイブル係数 m | 最弱環節理論；m 大 → 分散小・可靠性高 | — |

- 審題：定義題只檢查定義本身（含比值方向），不拿沒寫的性質（如溫度依存）判錯。
