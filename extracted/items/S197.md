# S197　紅外光譜（IR）：波數區域・吸收強度・氫鍵

波數由虎克定律決定：ν̃ = (1/2πc)√(k/μ)。鍵越強（k 大）、原子越輕（μ 小）→ 波數越高。

| 區域（cm⁻¹） | 歸屬 | 推理 |
|---|---|---|
| 4000〜2500 | X–H 伸縮（O–H、N–H、C–H） | H 最輕，μ 最小 |
| 2500〜2000 | 三鍵（C≡N、C≡C） | k 最大 |
| 2000〜1500 | 雙鍵（C=O 約 1700、C=C 約 1650） | k 次之 |
| 1500〜400 | 指紋區（指紋領域） | 分子固有圖形，用於比對鑑定 |

吸收強度 ∝ (dμ/dx)²：振動時偶極矩變化越大吸收越強。C=O 通常是最強峰。偶極矩不變的振動（N₂、O₂、對稱炔 C≡C、CO₂ 對稱伸縮）IR 不活性，改用拉曼光譜（互補）。出題陷阱：「偶極矩大 → 吸收弱」＝反向。

氫鍵：H 被拉向對方 → O–H 鍵變弱 → 低波數移動＋寬峰（各分子氫鍵強度不一，吸收疊加）。游離 O–H 約 3600 尖銳；醇 3200〜3400 寬；羧酸二聚體 2500〜3300 非常寬。

出處：R2-Q6
