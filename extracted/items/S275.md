# S275　玻璃種類與用途

| 玻璃 | 特徵 | 用途 |
|---|---|---|
| ソーダ石灰ガラス | 便宜・易熔；日本生產大半 | 窗・瓶 |
| ホウケイ酸塩ガラス | 低熱膨脹（3.3×10⁻⁶/K）→ 耐熱衝擊 | 理化學器具・耐熱食器・安瓿 |
| 鉛ガラス | Pb 易極化 → 高折射率 | クリスタルガラス |
| E ガラス（無鹼） | 強度・絕緣・耐水 | 強化用長纖維（GFRP・電路板） |
| 短纖維（グラスウール） | 夾帶空氣 | 建築隔熱・吸音 |

- 玻璃定義：過冷液體冷卻至 Tg 以下固化。

- 審題：檢查「性質 → 用途」因果是否成立（低熱膨脹推不出強化纖維）。

出處：R6-Q25
