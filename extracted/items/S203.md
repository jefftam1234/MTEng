# S203　応力-ひずみ曲線の読み方：弾性率・破断点・靭性

| 讀取位置 | 名稱 | 意義 |
|---|---|---|
| 起始段的斜率 | 弾性率（ヤング率） E = σ/ε | 剛性・硬度。越陡越硬 |
| 破斷點的縱軸值 | 破断応力（引張強さ） | 強度 |
| 破斷點的橫軸值 | 破断ひずみ（破断伸び） | 伸長能力 |
| 曲線下面積 ∫σdε | 破壞所需的功＝靭性 | 吸收能量的能力 |

「彈性率」≠ 日常的「有彈性」：日常說「有彈性、容易拉長」＝低彈性率。方向相反，最易誤判（定義配對錯位）。

縱軸／橫軸互換是固定的作問手法（破断応力 ↔ 破断ひずみ）。

| 曲線形狀 | 材料類型 | 例 |
|---|---|---|
| 斜率陡、應變小即破斷 | 硬而脆 | PS、PMMA（玻璃態） |
| 斜率平、低應力下伸長 | 軟而弱 | 未補強軟質材料 |
| 初段平緩、高應變時急升 | 橡膠（伸長結晶化） | 天然橡膠（第176項） |
| 降伏後頸縮、長距離伸長 | 硬而韌 | PE、PP 等結晶性塑膠 |

出處：R2-Q16（關聯：第11項＝橡膠彈性、第176項＝伸長結晶化）
