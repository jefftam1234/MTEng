# S280　計算題公式集（R6-Q30〜Q35）

通則：每一步寫單位；分子分母來自同一系統；解二次方程式後把根代回驗算。

| 主題 | 公式 | 易錯點 | 出處 |
|---|---|---|---|
| Raoult 定律 | P/P₀＝X溶媒＝n水 ÷ (n水 + Σn粒子) | 電解質乘解離粒子數（NaCl ×2）；分子用同一溶液的水量（不是另取純水） | R6-Q30 |
| 室內熱平衡 | Q冷卻＝m換氣·cp·(T外 − T室)；m＝V̇·ρ | 只計穿過邊界的流；內部循環風量不計 | R6-Q31 |
| 液液分配 | x/(n有機 + x)＝K·(n總 − x)/(n水 + n總 − x) | K 是濃度比不是 mol 比；展開常數項別漏 | R6-Q32 |
| Bernoulli（噴水） | u＝√(2gh) | 出口與頂點皆大氣壓，壓力項相消 | R6-Q33 |
| 圓截面積 | A＝πr²＝πd²/4 | πd 是圓周長（m），不是面積（m²） | R6-Q33 |
| 體積流量 | Q＝A·u（m³/s）→ ×60 → ×1000 ＝ L/分 | 1 m³＝1000 L | R6-Q33 |
| 總括傳熱 | Q＝U·A·ΔT | ΔT＝兩側溫度差（110−30）；U·A 單位 W/K | R6-Q34 |
| 圓筒側面積 | A＝πDH | 只加熱側面就不加上下底 2×πD²/4 | R6-Q34 |
| 一級反應・半衰期 | A＝A₀(1/2)ⁿ，n＝t/t½；log(A/A₀)＝n·log0.5 | 2¹⁰ ≈ 1000；10ˣ＝1 後接 x 個 0 | R6-Q35（同 H23-Q32） |

數值例

- Q30：15 wt% NaCl → 100 g 基準：NaCl 0.256 mol ×2＝0.513；水 85/18＝4.722；X水＝4.722/5.235＝0.90（漏乘 2 → 0.95）。

- Q31：Q＝20 kWh×3.6×10⁶＝7.2×10⁷ J/h；m·cp＝12,000×1.1×1,010＝1.333×10⁷；ΔT＝5.40 → 24.6℃（冷氣機出口約 16.5℃）。

- Q32：K＝2.6/7.8＝5.0/15.0＝1/3；3x(120−x)＝(20−x)(100+x) → x²−220x+1000＝0 → x＝4.64 mol。

- Q33：u＝√(2×9.8×20)＝19.80 m/s；A＝π(0.0015)²＝7.07×10⁻⁶ m²；Q＝1.400×10⁻⁴ m³/s → 8.4 L/分。

- Q34：A＝π×0.4×0.4＝0.5027 m²；Q＝500×0.5027×80＝20,106 W → 72,400 kJ/h。

- Q35：n＝80/8＝10；A₀＝10⁴×1,024 ≈ 10⁷ Bq。

SNAr（付加−脱離）：有拉電子基時

|  | SNAr | ベンザイン |
|---|---|---|
| 條件 | 鄰／對位 NO₂ 等拉電子基；NaHCO₃ 程度的弱鹼即可 | NaNH₂／液 NH₃，或 NaOH 約 350℃ 高壓（Dow 法） |
| 中間體 | 碳負離子（Meisenheimer 錯合物） | 苯炔（中性） |
