出處：R1再-Q1〜Q15 175. 生分解性の判定：主鎖が何でできているか

生分解＝微生物の酵素が主鎖を切ること。酵素が加水分解できるのはエステル結合・アミド結合・グリコシド結合だけ。

| 主鎖の結合 | 加水分解 | 生分解性 | 例 |
|---|---|---|---|
| エステル –C–O–CO– | ✓ | あり | PLA、PHB、PCL、PBS、PGA |
| アミド –CO–NH– | ✓ | あり | 天然蛋白質、一部のポリアミド |
| グリコシド | ✓ | あり | セルロース、澱粉、キチン |
| 炭素–炭素 –C–C– | ✗ | なし | PE、PP、PS、PVC、PMMA、PAN、PTFE |

側鎖にエステルがあっても無意味。PMMA の主鎖は –[CH₂–C(CH₃)(COOCH₃)]ₙ– で全て C–C。側鎖の –COOCH₃ が加水分解されてもポリメタクリル酸になるだけで主鎖は切れず分子量は下がらない。

名称からの速判

単量体名に「〜酸」「〜ラクトン」「〜ジオール＋〜酸」 → 重縮合または開環重合 → 主鎖がエステル → 生分解性あり

単量体名がビニル単量体（〜エチレン、〜スチレン、アクリル酸〜、メタクリル酸〜、塩化ビニル） → 付加重合 → 主鎖が C–C → 生分解しない

「メチル基があるから分解しない」は誤り。ポリ（L-乳酸）も乳酸 CH₃–CH(OH)–COOH 由来で主鎖にメチル基を持つ（名称に現れないだけ）。判定するのは側鎖の種類ではなく主鎖の結合。
