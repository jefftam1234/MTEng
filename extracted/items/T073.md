# T073　フェノール類：氧化還原・臭素化・ジアゾニウム塩・クメン法

出處：H27-Q6、H29-Q3（クメン法の生成物を直截に問う形）

A　ヒドロキノン ⇄ p-ベンゾキノン（2 電子氧化還原對）

| 物種 | 結構 | 態 | 角色 |
|---|---|---|---|
| ヒドロキノン（1,4-ジヒドロキシベンゼン）C₆H₆O₂ | 兩個 OH | 還原態 | 電子供給體＝抗氧化劑、照相顯影液 |
| p-ベンゾキノン C₆H₄O₂ | 兩個 C=O ＋兩個 C=C | 氧化態 | 電子接受體＝輔酶 Q、維生素 K |

方向判定不必背，數 H 即可：C₆H₆O₂ → C₆H₄O₂ 少 2 個 H ＝ 脱水素＝酸化。 → ヒドロキノン ──酸化(Ag₂O, FeCl₃, Na₂Cr₂O₇)──→ p-ベンゾキノン（反向為還元）。 中間態 キンヒドロン（1:1 電荷移動錯合物，暗綠色）曾用於 pH 電極。

B　フェノールの臭素化：無需 Lewis 酸、必得三取代

C₆H₅OH + 3Br₂ →(水中) 2,4,6-トリブロモフェノール↓（白色沉澱） + 3HBr OH 的 +M 極強 → 環高度活化 → 不需 FeBr₃、且無法停在單溴化。 判準：需不需要催化劑 ＝ 環活化程度的指標（苯需 Br₂/FeBr₃ 且只得單溴化物）。

C　ジアゾニウム塩置換總表（N₂ 是最佳離去基）

ArNH₂ →(NaNO₂／稀酸, 0–5°C)→ ArN₂⁺ → 各種取代

| 試劑 | 產物 | 名稱 |
|---|---|---|
| CuCl / CuBr | Ar–Cl / Ar–Br | Sandmeyer |
| CuCN | Ar–CN | Sandmeyer |
| H₂O, Δ 或 Cu₂O／Cu(NO₃)₂ 水溶液（溫和改良法） | Ar–OH | — |
| KI（無需 Cu） | Ar–I | — |
| HBF₄, Δ | Ar–F | Schiemann |
| H₃PO₂ | Ar–H | 脫胺基 |
| フェノール／ArNMe₂ | Ar–N=N–Ar′ | ジアゾカップリング（アゾ染料） |

意義：苯環上直接引入 OH 極困難，必須繞道 ニトロ化 → 還元 → ジアゾ化 → 水解。

D　クメン法（ホック法）：フェノール工業製法

ベンゼン + プロペン →(酸, Friedel–Crafts アルキル化)→ クメン →(空氣 O₂ 氧化，3° C–H)→ クメンヒドロペルオキシド →(H₂SO₄, ホック転位)→ フェノール + アセトン

全球 約 95% 的フェノール由此法製造

アセトン為 1:1 聯產品→ 兩者價格連動（工業經濟學常考點）

E　ビタミンE（α-トコフェロール） 結構 ＝ クロマン環 ＋ 酚性 OH ＋ C16 植基側鏈。抗氧化機制：酚性 OH 交出 H• 給 ROO•，自身成為共振穩定的トコフェロキシラジカル → 終止鏈鎖反應。BHT／BHA（ヒンダードフェノール）同機制。「有酚性 OH」正是抗氧化能力的結構理由，可由功能反推結構。
