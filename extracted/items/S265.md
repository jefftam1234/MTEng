# S265　潤滑油：SAE 黏度分類・油底殼方式・用途

- 黏度必然隨溫度變化（VI 只代表變化程度）→ 引擎油在高溫・低溫兩端分級（SAE J300）。

| 標示（例 5W-30） | 意義 |
|---|---|
| 5W | 低溫等級：低溫啟動性・泵送性（數字小 → 低溫易流動） |
| 30 | 高溫等級：100℃ 動黏度・150℃ 高溫高剪切黏度 |
| 多級油 | 兩端皆合格，需黏度指數向上劑 |

| 油底殼方式 | 構造 | 採用 |
|---|---|---|
| ウェットサンプ | 油存於曲軸箱底部 | 小・中型引擎 |
| ドライサンプ | 獨立油箱強制給油 | 大型船用低速二行程柴油機、賽車 |

- 用途：ATF＝有段 AT（CVT 用 CVTF）；絕緣油＝變壓器・電容器的絕緣＋冷卻（鑛油・合成油）；タービン油＝發電渦輪・高速旋轉機軸承。

出處：R6-Q13（關聯：H27-Q12、H25-Q12＝黏度指數向上劑）
