# T102　非理想溶液の気液平衡（活量係数つきラウール則）

出處：H27-Q35、H29-Q30（第130項）　計算題（與第 95 章 T-x-y 相図互參）

核心：非理想溶液 → 拉午耳定律加活量係數 γ** 修正。**

Pi=γi xi Pisat  yi=PiPtotal=Pi∑P

xᵢ 液相莫耳分率、Pᵢ^sat 純物質蒸氣壓、γᵢ 活量係數（理想時=1）

求氣相 yᵢ＝該分壓/總壓（道爾頓）

識別信號：給「活量係数」→ 明示非理想，公式前面要乘 γ。給了不用＝漏算。

例：液相甲醇 x=0.10（水 x=0.90）。P^sat：甲醇236.7、水64.24；γ：甲醇1.786、水1.009。 - P甲醇=1.786×0.10×236.7=42.3；P水=1.009×0.90×64.24=58.3 - P總=100.6 → y甲醇=42.3/100.6=42% 陷阱：忘乘活量係數（只用理想拉午耳）→ 偏小（約24%，③）。 呼應第 95 章：易揮発成分（甲醇蒸氣壓高×γ大）在氣相富集 → y(42%)>x(10%)，落對角線上方。

【計算題通用心法（H27-Q29~Q35 七題共通）】 1. 給的特殊常數是路標：ln→LMTD/對數；e→exp次方；2^(1/3)→開三次方；活量係数→非理想修正。 2. 比值題把不變量消掉：同設備/同反應→常數與單位全消，不算絕對值（Q32/Q33/Q34）。 3. 守恆優先：PV守恆（Q32）、質量/莫耳守恆（Q29/Q31）。 4. 單位雙查：°C→K（+273）、kJ→J、確認分母是溶劑還是溶液。 5. 數量級檢查：除法後看商是否合理（Q32 的 0.01 vs 0.95）。
