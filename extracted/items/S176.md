# S176　ポリイソプレンの四つの付加様式とゴム弾性

イソプレンの重合には 1,4（cis/trans）・1,2・3,4 の四通りがあり、ゴムになるのは cis-1,4 だけ。

| 付加様式 | 主鎖 | 物性 |
|---|---|---|
| cis-1,4 | 二重結合が主鎖、二つの主鎖 CH₂ が同じ側 | 天然ゴム。Tg 約 −70 ℃、非晶、良好なゴム弾性 |
| trans-1,4 | 二重結合が主鎖、CH₂ が反対側 | グタペルカ。結晶化度 50〜60 %、融点約 60 ℃、硬い樹脂 |
| 1,2-付加 | 主鎖 C–C、側鎖に –C(H)=CH₂ | 嵩高い側基で Tg 上昇、ゴムにならない |
| 3,4-付加 | 主鎖 C–C、側鎖に –C(CH₃)=CH₂ | 同上 |

判定手順　① 二重結合が主鎖にあるか側鎖にあるかで 1,4 か否かを分ける。② 1,4 なら主鎖が繋がる二つの CH₂ の位置で cis/trans を判定する（CH₃ と H を見ない——ここが見誤りやすい）。

因果の鎖（暗記不要）

cis → 各二重結合で主鎖が約 120° 折れ曲がる → 鎖の形が不規則 → 鎖どうしが揃わず結晶化しない → 非晶で Tg が室温よりはるかに低い → 鎖が動ける → エントロピー弾性

trans は二重結合部でも主鎖がまっすぐ伸びるため形が規則的で、ファスナーのように平行積層して結晶化する。同一化学式の幾何異性体でありながら物性が正反対になる。

ゴム弾性の三条件

| 条件 | 内容 | 破れると |
|---|---|---|
| 長鎖で柔軟 | Tg ≪ 使用温度 | 硬いプラスチック |
| 非晶 | 結晶は鎖の運動を凍結する | グタペルカ、高結晶 PE |
| 適度な架橋 | 加硫 | 無架橋＝塑性流動（永久変形）、過度＝エボナイト |

天然ゴムは 400 % 以上の伸長で伸長結晶化を起こし、これは逆に強度を高める天然ゴム固有の利点。工業的には Ziegler-Natta 系・リチウム系触媒で cis 含有率 98 % 以上の IR（合成天然ゴム）を作る。
