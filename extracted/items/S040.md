# S040　新燃料常見配對陷阱：原料/技術名稱張冠李戴

| 燃料/技術 | 正確原料/機制 | 易混淆處 |
|---|---|---|
| 生質ETBE | 生質乙醇+異丁烯(酸催化加成，靠C=C雙鍵) | 不是正丁烷(飽和烷烴無雙鍵，反應性低無法加成) |
| 沼氣(biogas) | 厭氧消化：廚餘等經嫌氣性微生物甲烷發酵 | — |
| 生質柴油(BDF) | 植物油(甘油三酸酯)+甲醇，鹼觸媒酯轉化反應(transesterification) | 產物為脂肪酸甲酯(FAME)+副產物甘油 |
| 頁岩氣(shale gas) | 天然氣一種，靠水力壓裂(強力水壓破碎岩層)抽取 | — |
| DME(二甲醚) | 可由天然氣、煤炭、生質能等多元資源經合成氣(syngas)製造 | 原料多樣性是其優勢 |

推理框架：MTBE(甲醇+異丁烯)、ETBE(乙醇+異丁烯)都需要異丁烯提供雙鍵進行酸催化加成，飽和烷烴(丁烷各異構物)因惰性無法直接參與此類加成反應。
