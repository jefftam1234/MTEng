# S235　碳負離子的 C–C 鍵生成：Grignard 增碳數 ＋ 炔化物烷基化的限制

| 試劑組合 | 產物 | 碳數變化 |
|---|---|---|
| RMgX ＋ CO₂（乾燥）→ H₃O⁺ | RCOOH | +1C |
| RMgX ＋ HCHO | RCH₂OH（一級醇） | +1C |
| RMgX ＋ 環氧乙烷 | RCH₂CH₂OH（一級醇） | +2C |
| RMgX ×2 ＋ 酯 R'COOR'' | 三級醇（兩取代基來自 RMgX） | — |
| RC≡C⁻ ＋ CH₃X／1° RX | 內炔（Sₙ2） | +R |
| RC≡C⁻ ＋ 2°／3° RX | 烯（E2 消除），不是烷基化 | — |

- 炔化物＝強鹼（共軛酸 pKa≈25）：受質立體障礙大時拔 β-H。看到 2°/3° 鹵烷＋強鹼型親核劑 → 先想 E2。

- 交叉醛醇：一方無 α-H，或一方為活性亞甲基（乙醯乙酸乙酯 pKa≈11）被選擇性去質子化。

出處：R5-Q1（關聯：H30-Q4、第34項）
