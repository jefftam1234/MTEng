# T091　共有結合結晶：ダイヤモンド vs グラファイト（混成と積層）

出處：H27-Q24

|  | ダイヤモンド | グラファイト |
|---|---|---|
| 混成 | sp³（立體四面體，4配位） | sp²（平面六員環，3配位＋離域π） |
| 結構 | 3D 共價網 | 2D 層狀 |
| 層間/鍵 | 全共價 | 層內共價強、層間ファンデルワールス力 |
| 導電 | 絕緣（電子全用於σ鍵） | 層內導電（離域π）、層間不導→異方性 |
| 硬度 | 最硬 | 軟（層易滑→潤滑・鉛筆） |

Si・Ge・C(金剛石) 同為 IV 族 → ダイヤモンド型構造・sp³（ウルツ鉱型是 AB 化合物如 ZnS）。 積層の相対位置：上下層六員環若一致→π電子雲正面排斥（不穩）→ 實際錯開半格（一致しない, AB 堆疊），上層一半碳落在下層六員環中心正上方。

混成速判：sp³＝立體(四面體/金剛石)、sp²＝平面(三角/石墨)、sp＝直線(乙炔)。混成軌域數＝σ鍵數＝(4−π鍵數)。

炭素同素体：ダイヤ(sp³)／グラファイト・グラフェン・CNT・C₆₀(sp²)。
