# S168　Diels-Alder 反応の五本柱

| 柱 | 内容 | よくある誤り作問 |
|---|---|---|
| 協奏 | 一段階、中間体なし、環状遷移状態は一つ | 「多段階で中間体を生成する」 |
| 立体特異性 | ジエノフィルの cis/trans が生成物に保存 | cis のマレイン酸エステルから trans 体が出来るとする |
| 電子要求 | ジエンに供与基、ジエノフィルに求引基で最速（ジエンの HOMO とジエノフィルの LUMO） | 「ジエノフィルに電子供与基があると最速」 |
| 4n+2 則 | [4+2]＝6π は熱許容、[2+2]＝4π は熱禁制・光許容 | 「[2+2] も熱で進行する」 |
| エンド則 | 二次軌道相互作用でエンド体が速度論支配の主生成物（エキソ体のほうが熱力学的に安定） | エキソ体を主生成物とする |

ジエンは s-cis 配座をとれることが必須。環状ジエン（シクロペンタジエン）が特に速いのはこのため。

鎖状ジエン（ブタジエン）ではエンドとエキソが同一生成物になるので、立体の差は環状ジエンでのみ現れる。

良いジエノフィル：無水マレイン酸、マレイン酸／フマル酸エステル、アクロレイン、アクリロニトリル、ベンゾキノン。

出處：R1再-Q4（關聯：第74項＝協奏機構 vs 段階機構）
