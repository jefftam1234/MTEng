# T089　ファインセラミックスの機能-応用対応表

出處：H27-Q22

| 機能 | 代表材料 | 應用 |
|---|---|---|
| 半導・PTC（正温度係数） | BaTiO₃ 系 | PTC ヒーター、サーミスタ（溫度↑→電阻↑→自動控溫） |
| 誘電（強誘電） | BaTiO₃ | セラミックコンデンサ（MLCC） |
| 圧電 | PZT | 壓電振盪子、點火器、超音波 |
| 絶縁 | Al₂O₃ | IC 基板 |
| イオン伝導 | ジルコニア ZrO₂(YSZ) | 酸素センサ、SOFC 電解質 |
| 機械的 | 窒化ケイ素 Si₃N₄、SiC | ボールベアリング、刃物、引擎零件 |
| 光透過 | 透光性アルミナ | ナトリウム発光管（耐高溫高腐蝕鈉蒸氣，玻璃撐不住） |
| 磁気 | フェライト | 硬質→永久磁石（冰箱磁鐵）；軟質→變壓器鐵芯 |
| 生体 | ハイドロキシアパタイト | 人工骨・歯 |

PTC 陷阱：PTC 的 T＝Temperature（溫度），非湿度；靠「電阻隨溫度大幅變化」工作，非「變化極小」。縮寫自帶答案，展開對照即可判錯。 BaTiO₃ 一材多用：PTC（半導）＋誘電（電容），靠不同摻雜/加工實現。 フェライト永久磁石＝最普及的陶瓷磁性應用（勿因陌生而懷疑其正確性）。
