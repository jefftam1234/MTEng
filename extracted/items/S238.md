# S238　環己烷構象：ax/eq 交替法與二取代穩定性

| 位置 | cis | trans |
|---|---|---|
| 1,2- | a,e（兩構象等價） | e,e（穩）／a,a |
| 1,3- | e,e（穩）／a,a | a,e（等價） |
| 1,4- | a,e（等價） | e,e（穩）／a,a |

- 推法：C1 up＝axial → C2 up＝equatorial → C3 up＝axial…（相鄰交替）。

- axial CH₃：1,3-二アキシアル相互作用約 7.6 kJ/mol；相鄰兩 CH₃ gauche 約 3.8 kJ/mol。trans-1,2：a,a≈15.2 vs e,e≈3.8 → e,e 穩。

- 椅形：鍵角約 111°、全交錯 → 無應變。舟形：無角應變但重疊＋旗杆 H → 約 +29 kJ/mol。
