# S231　金属精錬法：活潑度で決まる

| 活潑度 | 金屬 | 方法 | 例 |
|---|---|---|---|
| 最活潑 | K、Ca、Na、Mg、Al | 熔融鹽電解 | MgCO₃ → MgCl₂ → 電解；Al₂O₃／冰晶石 |
| 中等 | Zn、Fe、Sn、Pb | （硫化物先焙燒成氧化物）碳・CO 還原 | 2ZnS＋3O₂ → 2ZnO＋2SO₂；ZnO＋C → Zn＋CO |
| 氧化物極穩定 | V、Cr、Mn、Ti | 更活潑金屬還原 | 3V₂O₅＋10Al → 6V＋5Al₂O₃（テルミット）；TiCl₄＋Mg（Kroll） |
| 較不活潑 | Cu、Hg、Ag | 硫化物空氣中加熱直接得金屬 | Ag₂S＋O₂ → 2Ag＋SO₂；HgS 同理；Cu₂S 轉爐 |
| 貴金屬 | Pt、Au | 物理分選（比重選鉱） | 自然金屬 |

- 判斷：方法太弱 → 錯；方法多餘（貴金屬還用碳）→ 也錯。C 不能從硫化物搶 S。
