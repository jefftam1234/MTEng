# S285　SAF（持続可能な航空燃料）：ASTM D7566 路線

| 路線 | 原料 | 製程 |
|---|---|---|
| FT-SPK | 木質生質・都市垃圾（固體） | 氣化 → 合成氣 → FT 合成 → 氫化 |
| HEFA-SPK | 廢食用油・動植物油脂 | 加氫脫氧 → 異構化 |
| HFS-SIP | 糖 | 發酵 → 金合歡烯 → 氫化 |
| FT-SPK/A | ＋非石油輕質芳香族 | 芳香族烷基化 |
| ATJ-SPK | 乙醇・異丁醇 | 脫水成烯 → 低聚 → 氫化 |

- 原料物態決定路線。FCC（重質油 → 汽油）不是 SAF 路線。

出處：R7-Q11（關聯：第111項＝FCC）
