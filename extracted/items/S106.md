# S106　SN2 補遺：可逆性の実例と枝分かれ速度序列（第16項D・第3項の補遺）

「協奏一段階」と「不可逆」は独立した軸。SN2 は機構的に可逆であり、右へ振り切れるかは熱力学の問題。

微視的可逆性：逆反応では脱離基 LG⁻ 自身が求核剤として Nu–R の背面を攻撃する。正反応と全く同型の機構。

反証の実例（フィンケルシュタイン反応）：R–Cl + NaI ⇌(アセトン) R–I + NaCl↓。I⁻ は強い求核剤かつ良い脱離基なので両方向に進む。右へ寄る理由は NaCl がアセトンに不溶で沈殿する（ルシャトリエ）であって、不可逆だからではない。逆に LG が N₂・OTs⁻ など極端に弱い求核剤の場合のみ事実上不可逆——これは個別の熱力学的帰結であり SN2 の定義的性質ではない。

SN2 相対速度（立体障害）

| 基質 | 相対速度 |
|---|---|
| CH₃–X（メチル） | ≈30 |
| 1° (CH₃CH₂–X) | 1 |
| 2° ((CH₃)₂CH–X) | ≈0.03 |
| 3° ((CH₃)₃C–X) | ≈0（進行しない） |
| ネオペンチル（β炭素に分枝） | ≈10⁻⁵ |

ネオペンチルの罠：1級炭素でありながら β位の三メチルが背面通路を塞ぐため極端に遅い。「1級だから SN2 が速い」と機械的に判断させる定番の誘導。

方向の対照：SN2 は CH₃ >** 1° ****>**** 2° ≫ 3°／SN1 は** 3° >** 2° ****>**** 1° ≫ CH₃（完全に逆順**）。

その他の性質（一括確認用）：命名 S=Substitution / N=Nucleophilic / 2=bimolecular、速度式 v = k[R–LG][Nu⁻]（二次）、遷移状態は五配位・sp²平面＋二本の軸方向結合（中間体なし・山は一つ）、立体特異的（背面攻撃180°→ワルデン反転、一つの立体異性体→一つの立体異性生成物）。対照：SN1 は平面カルボカチオン経由でラセミ化、律速段階が単分子で v = k[R–LG]。
