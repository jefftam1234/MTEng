# F10　高分子：共聚合・結晶性・熱分析（DSC）

A　共聚合組成・反應性比** r₁ / r₂**

r₁ = k₁₁/k₁₂、r₂ = k₂₂/k₂₁。r ＝「自由基接『自己』vs『對方』的偏好比」：大＝愛接自己，小＝愛接對方。

| 組成曲線位置（相對對角線） | r₁、r₂ | 傾向 |
|---|---|---|
| 上方（M₁ 優先進共聚物） | r₁ >** 1****、****r₂ ****<**** 1** | 兩自由基都偏好 M₁（曲線 A 型） |
| 對角線（理想/無規） | r₁·r₂ = 1 | 共聚物組成 = 投料組成 |
| 下方（M₂ 優先） | r₁ < 1、r₂ > 1 | 兩自由基都偏好 M₂（曲線 B 型） |
| S 型穿越、交點居中 | r₁ <** 1****、****r₂ ****<**** 1** | 都愛接對方 → 交替傾向 |
| 自聚/嵌段傾向 | r₁ > 1、r₂ > 1 | 都愛接自己 |

重點** **縱軸＝共聚物中 M₁ 莫耳分率，橫軸＝投料 M₁ 莫耳分率。看曲線在對角線哪一側，就知道哪個單體被優先納入。名詞：ラジカル共重合 Radical copolymerization／モノマー反応性比 reactivity ratio／交互 alternating・ランダム random・ブロック block。

B　聚乙烯** HDPE vs LDPE****（製法****-****結構****-****物性因果）**

|  | 製法 | 分枝 | 結晶度/密度 | 物性 |
|---|---|---|---|---|
| HDPE 高密度 | 低壓觸媒(配位) | 少(線性) | 高 / 高 | 硬・耐熱・剛性・強度大、T_m 高 |
| LDPE 低密度 | 高壓自由基(O₂/過氧化物) | 多 | 低 / 低 | 軟・韌・低溫不脆・絕緣佳・耐藥品 |

重點** **因果鏈：製法→分枝多寡→結晶度→密度→物性。陷阱：高密度用『低壓』、低密度用『高壓』（方向相反！）；密度差來自結晶度/分枝，不是壓力本身。觸媒：チーグラー・ナッタ Ziegler–Natta／酸化クロム系 Phillips → 配位重合 coordination polymerization → HDPE。

C　DSC 升溫三事件（近本職，必秒殺）

非晶高分子(結晶度0%)升溫，依序：ガラス(玻璃態) →[T_g]→ 過冷却液体** →[****結晶化****]→[****融解****]****。**

| 事件 | 日／英 | DSC 表現 | 吸/放熱 |
|---|---|---|---|
| 玻璃轉移 | ガラス転移点 T_g / Glass transition | 台階** step** | 比熱變化(擬二次轉移,非峰;本質は非平衡) |
| (冷)結晶化 | 結晶化 T_c / Crystallization | 放熱峰(向上) | 放熱 |
| 熔融 | 融解 T_m / Melting | 吸熱峰(向下) | 吸熱 |

重點** **鐵則：①先看題目起始狀態(0%結晶=玻璃態起步，不是結晶！)；②放熱峰(向上)=結晶化、吸熱峰(向下)=熔融、台階=T_g。分解(分解)溫度更高(PET 約300°C+)，別把250°C的熔融吸熱峰誤判成分解。「エンタルピー急増」對應熔融吸熱。
