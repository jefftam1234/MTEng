# S279　流體・傳熱公式對照

| 公式 | 內容 |
|---|---|
| 連続の式 | 質量守恆：ρ₁A₁u₁＝ρ₂A₂u₂ |
| Navier-Stokes | 動量守恆（黏性流體運動方程式） |
| Bernoulli | 流線上能量守恆 |
| Fanning | 管內摩擦壓損 ΔP＝4f(L/D)(ρu²/2) |
| Hagen-Poiseuille | 圓管層流的壓損・流量：ΔP＝32μuL/D²；Q＝πR⁴ΔP/(8μL)；→ f＝16/Re |
| Fourier | 傳導：q＝−k(dT/dx)（溫度梯度在此） |
| Newton 冷卻 | 對流：q＝hΔT |
| Stefan-Boltzmann | 黑體輻射：E＝σT⁴ |

- 判斷：流體公式配上熱的物理量 → 類別不一致即錯。
