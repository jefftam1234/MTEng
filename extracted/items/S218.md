# S218　常壓燒結的前處理與物質移動路徑

緻密化需要物質從晶界移走（顆粒中心靠近）；表面擴散・蒸發-凝結只讓頸部長大、顆粒粗大化，不收縮。

| 項目 | 正確敘述 | 常見錯誤選項 |
|---|---|---|
| 分散媒 | 氧化物表面極性（–OH）→ 易分散於高介電常數極性溶劑（水）；低介電常數溶劑中電雙層不形成 → 易凝集 | — |
| 防止凝集 | 靜電排斥（zeta 電位遠離等電點）＋立體障礙（高分子分散劑） | — |
| 乾式壓製 | 仍需黏結劑（PVA 等）；漿料噴霧乾燥成造粒粉再壓製，提供生坯強度 | 「乾式不用分散劑・黏結劑」✕ |
| 脫脂 | 低溫緩慢脫脂後再燒結；殘留有機物 → 氣體被封在閉氣孔＋殘碳 → 無法緻密 | 「脫脂不足也可靠高溫緻密化」✕ |
| 高蒸氣壓粉體 | 蒸發-凝結為主 → 只粗大化 → 難緻密化（例：SnO₂ 需加燒結助劑） | — |

出處：R3-Q23（關聯：第156項＝燒結法・成形法、HIP 需先閉氣孔）
