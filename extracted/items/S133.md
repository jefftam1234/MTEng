# S133　熱交換器：四段階の計算手順（第97項 LMTD の補遺）

① Q = ṁ c_p ΔT ← データの揃っている側で計算 ② 熱収支 Q_高温側 = Q_低温側 → 他方の出口温度 ③ 向流／並流の配置図を描き、両端の ΔT₁・ΔT₂ を読む ④ A = Q/(U ΔT_m) → L = A/(πd)

伝熱面積は側面 A = πdL（管を展開した長方形）。断面 πd²/4 は流速計算用で伝熱には使わない。 　「外径基準」「内径基準」の指定を必ず探す。総括伝熱係数は面積と対で定義され U_o A_o = U_i A_i すなわち U_o d_o = U_i d_i。直径が二つ与えられていたら必ずどちらを使うか指定されている。内径と外径で 10% 前後の差が出て、選択肢がちょうど一つずれる。

向流の温度配置（間違えやすい）

<!--SourceCode--> ← 高温流体 入口              高温流体 出口 →

┌────────────────────────────────────────┐ └────────────────────────────────────────┘ 低温流体 出口 → ← 低温流体 入口 ΔT₁ ＝ 高温入口 − 低温出口 ΔT₂ ＝ 高温出口 − 低温入口

向流は「高温側の入口が低温側の出口と向かい合う」。並流の配対と混同しない。

|  | 向流 | 並流 |
|---|---|---|
| ΔT_m | 大 | 小 |
| 必要伝熱面積 | 小 | 大 |
| 低温流体の到達温度 | 高温流体の出口温度を超えられる | 超えられない |
| 管壁温度 | 比較的均一 | 入口側で温度差が極大 |

工業的には向流が原則。並流の利点は管壁温度が上がりすぎないこと（熱に弱い流体の保護）。

ΔT_m の選択

| 条件 | 使う平均 |
|---|---|
| 厳密 | LMTD ＝ (ΔT₁−ΔT₂)/ln(ΔT₁/ΔT₂) |
| ΔT₁/ΔT₂ <** 2** | 相加平均で誤差 4% 未満 |
| ṁc_p が両側で等しい | ΔT₁ = ΔT₂ となり LMTD は 0/0 の不定形。極限値は ΔT₁ そのもの（相加平均が厳密に正しい） |

熱容量流量 ṁc_p が両側で等しいと、向流では温度差が全長にわたって一定（T-L 線図で二直線が平行）。題目が「相加平均でよい」と書いたらこの状況を疑う。

U の分解　1/U_o = d_o/(d_i h_i) + d_o ln(d_o/d_i)/(2λ) + 1/h_o 　三項は内側境膜・管壁・外側境膜の熱抵抗で、最大の熱抵抗が全体を支配する——伝熱強化をどちら側から行うかの判断根拠。

問題を読んだら最初に丸で囲む五項：①流向 ②基準（外径／内径）③ΔT_m の算出法 ④求めるもの ⑤どちらの流体のデータが揃っているか。
