# S057　無機材料應用配對：功能材料勿與機械/切削用途混淆

| 材料 | 正確應用 | 應用機制 |
|---|---|---|
| 氧化鈦(TiO2) | 光觸媒 | 本多-藤嶋效應(H26-Q22學過) |
| 鋇鐵氧體 | 永久磁鐵 | 鐵氧體磁性(H25-Q24學過) |
| 氧化鋁(alumina) | LSI基板 | 高絕緣性+高導熱性 |
| 安定化氧化鋯(ZrO2) | 氧氣感測器 | 氧離子傳導特性(如汽車λ感測器) |
| 鈦酸鋇(BaTiO3) | 電容器、壓電元件、熱敏電阻(非菜刀) | 高介電常數/鐵電體特性(H26-Q21批次已學過)，非機械硬度 |

*出處：**H26-Q25*
