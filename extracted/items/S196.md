# S196　Wittig 反應的反應性：ylide 碳上的取代數最優先

機構：PPh₃ 對 RX 做 S_N2 → 鏻鹽（ホスホニウム塩）→ 強鹼拔 α-H → ylide（イリド）→ 攻擊羰基 → オキサホスフェタン → 烯烴＋Ph₃P=O。

| 因素 | 反應性順序 | 理由 |
|---|---|---|
| ylide 碳上取代數 | =CH₂ ＞ =CHR ＞ =CR₂ | PPh₃ 巨大，再加兩個取代基立體擁擠；且 CR₂ ylide 需從二級鹵化物 S_N2 製備（慢） |
| ylide 穩定性 | 非穩定化（烷基）＞ 半穩定化（芳基）＞ 穩定化（C=O、CN、COOR） | 碳負離子越穩定親核力越弱；穩定化 ylide 常不與酮反應 |
| 羰基 | 醛 ＞ 酮 | 立體障礙・烷基推電子 |

難易由較差的一側決定：醛的高反應性救不了 CR₂ ylide。

Ph₃P=CH₂ 最活潑：連立體障礙大的酮（樟腦）都能亞甲基化。

α,β-不飽和酮＋磷 ylide → 1,2-加成為主（不走共軛加成），Wittig 照常進行。

實戰：先數 ylide 碳上的取代基，只有一個 CR₂ 的選項即為答案。

出處：R2-Q2（關聯：第1項表中 Wittig 試劑、第195項＝二級鹵化物 S_N2 慢）
