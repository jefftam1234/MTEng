# S202　乙烯基類高分子的重複單元與命名

解法：寫出單體 CH₂=CXY，把雙鍵打開 → –CH₂–CXY–。

| 名稱成分 | 意思 | 結構 |
|---|---|---|
| ビニル | 一個取代基 | CH₂=CH–X → –CH₂–CHX– |
| ビニリデン | 同一個碳上兩個取代基 | CH₂=CX₂ → –CH₂–CX₂– |
| アクリル酸 | 丙烯酸 | CH₂=CH–COOH |
| メタクリル酸 | α 位帶 CH₃ | CH₂=C(CH₃)–COOH |
| 〜酸メチル | 甲酯 | –COOCH₃ |

| 高分子 | 重複單元 |
|---|---|
| PE ポリエチレン | –CH₂–CH₂– |
| PVC ポリ塩化ビニル | –CH₂–CHCl– |
| PVF ポリフッ化ビニル | –CH₂–CHF– |
| PVDF ポリフッ化ビニリデン | –CH₂–CF₂– |
| PVDC ポリ塩化ビニリデン | –CH₂–CCl₂– |
| PTFE ポリテトラフルオロエチレン | –CF₂–CF₂– |
| PS ポリスチレン | –CH₂–CH(C₆H₅)– |
| PMA ポリアクリル酸メチル | –CH₂–CH(COOCH₃)– |
| PMMA ポリメタクリル酸メチル | –CH₂–C(CH₃)(COOCH₃)–（兩個甲基） |

出題陷阱：PMMA 畫成缺 α-CH₃ 的結構＝其實是 PMA。

α-CH₃ 限制主鏈旋轉：PMA 的 Tg 約 10℃（軟，黏著劑・塗料）、PMMA 約 105℃（硬，壓克力板・光學材料）。

出處：R2-Q14（關聯：第118項＝玻璃轉移）
