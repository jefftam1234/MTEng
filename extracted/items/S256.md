# S256　光化學・分光的人名法則對照（純背誦）

| 法則 | 內容 | 題目關鍵字 |
|---|---|---|
| ボルン-オッペンハイマー近似 | 電子與核運動分離求解（求解近似） | 核の運動と電子の運動を分離 |
| フランク-コンドンの原理 | 電子遷移瞬間核不動 → 垂直遷移（10⁻¹⁵ s vs 振動 10⁻¹³ s） | 遷移の間、原子の位置は変化しない |
| カッシャの規則 | 發光只從 S₁／T₁ 發出（高激發態內部轉換極快） | 最低励起状態から発光 |
| デクスター機構 | 電子交換型能量轉移，短距離（約 1 nm） | 電子交換 |
| フェルスター機構 | 偶極-偶極能量轉移，長距離（1–10 nm） | 双極子相互作用 |
| ランベルト-ベールの法則 | A＝εcl | 吸光度・濃度 |

易混：Born-Oppenheimer 講分子「狀態」的求解；Franck-Condon 講遷移「過程」。

出處：R6-Q2
