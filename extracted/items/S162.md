# S162　リサイクル・パージプロセスの物質収支

アンモニア合成のように 1 回通過反応率が低い（0.10〜0.30）プロセスでは未反応原料を循環させる。イナートガスは反応も分離もされないため蓄積し、パージで抜くしかない。

解法の三本柱

| ①イナートの収支 | 定常状態では「入った量＝パージから出る量」。イナートは反応も分離もされないので逃げ道がパージしかない |
|---|---|
| ②分流の性質 | 分離器出口の混合ガスを一股として R:P に分けるので、成分ごとの比もすべて R:P と同じ。x₁/x₃ = x₂/1 = R/P |
| ③反応器の収支 | (原料 + リサイクル未反応分) × (1 − 反応率) = 分離器出口の未反応原料 |

計算例（H30-Q33）：原料 100、イナート 1、1 回通過反応率 0.30、R:P = 40:1

イナート収支よりパージ中のイナート = 1 → 分流比 40:1 より x₂ = 40

同じ比より x₃ = x₁/40

(100 + x₁)(0.70) = x₁ + x₁/40 → 両辺 ×40：2800 + 28x₁ = 41x₁ → 13x₁ = 2800 → x₁ = 215.4

R = x₁ + x₂ = 255.4 ≈ 260

検算：左辺 (100+215.4)×0.7 = 220.8、右辺 215.4 + 5.4 = 220.8 ✓。答えを元式に戻して 10 秒で確認する。

パージ比のトレードオフ：パージを増やすとイナートの蓄積は減るが原料の損失が増える（本例では x₃ = 5.4 kmol/s の原料を捨てている）。最適化がプロセス設計の要点。

1 回通過反応率 0.30 でも全体収率は約 95% に達する。代償はリサイクル量が原料の 2.5 倍＝圧縮機動力と設備サイズ。

出處：H30-Q33、R1再-Q29
