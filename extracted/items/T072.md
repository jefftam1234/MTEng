# T072　反應分類：受質電子密度 → 進攻者身分

出處：H27-Q5

核心一句：電子豐富的受質 → 求電子剤攻擊；電子貧乏的受質 → 求核剤攻擊。

| 受質 | 電子狀態 | 進攻者 | 反應類型 | 例 |
|---|---|---|---|---|
| C=C、C≡C | 富 | 求電子剤 | 求電子付加 | 烯 + HBr；アセチレン + H₂O/HgSO₄ |
| 芳香環 | 富 | 求電子剤 | 求電子芳香族置換 (SEAr) | ニトロ化、ハロゲン化、Friedel–Crafts |
| C=O | 貧（C δ+） | 求核剤 | 求核付加 | シアノヒドリン合成、Grignard |
| C–X（1°） | 貧 | 求核剤 | Sₙ2 | CH₃I + Nu⁻ |
| C–X（3°）、C–OH₂⁺ | 貧 | 求核剤 | Sₙ1 | (CH₃)₃COH + HBr |
| C–X ＋ 強鹼／アルコール溶媒 | — | 鹽基 | E2 | ブロモシクロヘキサン + KOH/EtOH |
| 芳香環 ＋ 強 EWG | 貧 | 求核剤 | SₙAr | 2,4-ジニトロクロロベンゼン + OH⁻ |

ニトロ化的活性種：HNO₃ + 2H₂SO₄ → NO₂⁺（ニトロニウムイオン） + H₃O⁺ + 2HSO₄⁻。 苯環 π 電子攻擊 NO₂⁺ → アレニウムイオン（σ 錯体） → 脫 H⁺ → 芳香性回復（驅動力）。 NO₂⁺（正、求電子）與 NO₃⁻（負、弱求核）是電荷相反的兩個物種，切勿混用。

溶劑決定 E2 vs Sₙ2（高頻）：KOH／エタノール溶液中 → 脱離（E2）；KOH／水溶液中 → 置換（Sₙ2）。

アセチレン水和（Kucherov／京都法）：HC≡CH + H₂O/HgSO₄/H₂SO₄ → ビニルアルコール（エノール）→ ケト–エノール互変異性 → アセトアルデヒド（付加反応）。現已被 Wacker 法取代。
