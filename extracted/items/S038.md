# S038　命名反應辨識：試劑指紋(reagent signature)速查法

解題策略：先掃過選項刪除明顯試劑對不上的錯配，再記住每個命名反應最具辨識度的試劑組合，不需死背整個機制細節。

| 試劑指紋 | 反應名稱 | 產物/用途 |
|---|---|---|
| POCl3 + DMF(HCON(CH3)2) | Vilsmeier(-Haack)反應 | 富電子芳環→芳香醛(甲醯化) |
| CHCl3 + NaOH + 酚類 | Reimer-Tiemann反應 | 酚鄰位生成水楊醛(經二氯卡賓中間體) |
| 路易士酸(AlCl3/BF3)+醯化試劑+芳環 | Friedel-Crafts醯化反應 | 芳環直接接醯基/甲醯基 |
| 磷ylide(Ph3P=CHR)+醛/酮 | Wittig反應 | 生成烯烴(C=C)，非醛 |
| ジアゾニウム塩 + CuX(CuBr/CuCl/CuCN) | Sandmeyer反應 | Ar–X／Ar–CN(芳香族專屬,碳數不變) |
| 1級アミド R–CONH₂ + Br₂/NaOH | Hofmann転位 | 減一碳的1級アミン + CO₂ |
| 酸塩化物 R–COCl + NaN₃ | Curtius転位 | 減一碳的1級アミン + CO₂ + N₂ |

*出處：H26-Q6、**H28-Q4*
