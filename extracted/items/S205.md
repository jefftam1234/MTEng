# S205　液晶ポリマー（LCP）：二條獨立的分類軸

液晶＝能流動但方向排列整齊的狀態，前提是剛直棒狀單元（メソゲン：對位苯環・萘環＋酯／醯胺鍵）。

| 分類軸 | 類型 | 判斷 | 例 |
|---|---|---|---|
| メソゲン的位置 | 主鎖型 | メソゲン在主鏈中 | 全芳香族ポリエステル、アラミド |
|  | 側鎖型 | 經柔性間隔基（スペーサー）掛在側鏈 | 聚甲基丙烯酸酯主鏈＋苯甲酸苯酯型側鏈 |
| 液晶相的出現方式 | サーモトロピック（熱致） | 加熱熔融時呈現 → 射出成形 | 全芳香族ポリエステル（Vectra：HBA/HNA 共聚） |
|  | リオトロピック（溶致） | 溶於溶劑達一定濃度時呈現 → 溶液紡絲 | アラミド（Kevlar）／濃硫酸 |

判斷芳綸為溶致型的邏輯：全對位剛直＋醯胺氫鍵 → 熔點 ＞ 分解溫度（約 500℃ 以上） → 不能熔融 → 不可能是熱致型。濃硫酸液晶溶液紡絲 → 高配向 → 高強度・高彈性率纖維。

共聚降低熔點：對羥基苯甲酸均聚物熔點 ＞ 500℃ 無法加工；共聚 2,6-萘單元（兩端鍵平行錯開＝曲柄軸型，「非直線性」）→ 打亂規則性 → 熔點約 280℃ → 可熔融加工。規則性↓ → 結晶性↓ → 熔點↓（同第87項立體規則性的邏輯）。

側鏈型的間隔基讓メソゲン不受主鏈運動牽制而能自由排列。

出處：R2-Q20（關聯：第11項 B＝熱致 vs 溶致、第202項＝PMMA 主鏈）
