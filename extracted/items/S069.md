# S069　碳氫化合物的顏色判定與各類質子化學位移範圍

只由C、H組成又在可視領域有極大吸收(=有顏色)的化合物極罕見，考試唯一常考答案是アズレン(薁，深藍色)。一般芳香烴(苯、萘、菲、蒽)全為無色，λmax落在紫外區。

| 化合物 | 結構 | π電子/顏色 |
|---|---|---|
| アズレン(薁) | 五員環+七員環稠合，C₁₀H₈(萘的異構物) | 10π芳香、深藍色，λmax約580–700nm |
| ナフタレン(萘) | 兩個六員環線性稠合 | 無色，λmax≈275nm |
| フェナントレン(菲) | 三個六員環角形稠合 | 無色，紫外區 |

薁的芳香性來自電荷分離共振：五員環給出π電子→帶負電成シクロペンタジエニルアニオン(6π)；七員環接受π電子→帶正電成トロピリウムカチオン(6π)。此非交互(non-alternant)結構使HOMO-LUMO能隙異常小，只需10π電子即進入可見區。

副產特徵：因電荷分離，薁具異常大的偶極矩(約1.0 D)——純烴類幾乎不可能有偶極矩。

名稱記憶線索：azulene 源自西班牙語 azul(藍色)。

| 氫的種類 | 典型δ(ppm) | 原因 |
|---|---|---|
| 芳香族H | 6.5–8.5 | 環電流去遮蔽 |
| 烯H(sp², =C–H) | 4.5–6.5 | 去遮蔽但弱於芳香環 |
| 炔H(sp, ≡C–H) | 1.8–3.1 | 圓柱形π電子雲的環電流使軸向H被遮蔽，反常出現在高磁場 |
| sp³ 甲基H | ~0.9–2.5 | 遮蔽較強 |

高頻陷阱：フェニルアセチレン(苯乙炔)雖含苯環，但末端炔氫δ≈3.1不在芳香區；スチレン(苯乙烯)的乙烯基氫δ5.2–6.8亦在區外。題目寫「すべての水素核」時，只要一個氫出界即出局。

解題順序：多條件同時滿足題，應先找最嚴苛的條件下手(本題為「可視領域吸收」)，一步鎖定答案，勿依序逐條檢查。

碳氫化合物λmax與共軛程度：單環200–280nm；2–3環稠合270–320nm；4環以上線性稠合350–380nm；大型稠環或非交互芳香烴才進入400nm以上有色區。
