# S127　気体の物性：粘度・熱伝導率・蒸発潜熱・ジュールトムソン効果

A　気体と液体で逆になるもの

|  | 気体 | 液体 |
|---|---|---|
| 粘性の起源 | 分子の運動量輸送 | 分子間引力（凝集力） |
| 温度上昇時の粘度 | 増大（μ ∝ √T） | 減少（μ ∝ exp(E/RT)） |
| 温度上昇時の熱伝導率 | 増大（λ ∝ √T） | 減少（水は約130℃まで例外） |
| 圧力依存 | ほぼ無関係 | わずかに増大 |

気体分子運動論　μ = (1/3)ρ v̄ λ、λ_th = (1/3)ρ c_v v̄ ℓ。粘度・熱伝導率・拡散係数は三つとも同一の分子運動由来で同方向に動く。 　気体の粘度が圧力に依存しない理由：圧力上昇で密度 ρ は増えるが平均自由行程 λ が減り相殺する。 　日常経験（機油・蜂蜜を温めると薄くなる）は液体の話。気体は逆。空気の粘度は 0℃ 1.71×10⁻⁵ → 100℃ 2.17×10⁻⁵ Pa·s（約27%増）。 　状態別の熱伝導機構：気体＝分子運動／液体＝分子間相互作用／金属＝自由電子（温度↑で散乱増→減少）／絶縁体・セラミックス＝フォノン（同じく減少）。

B　蒸発潜熱は圧力上昇とともに減少する

| 圧力 | 0.1 MPa | 1 MPa | 10 MPa | 22.06 MPa（臨界点） |
|---|---|---|---|---|
| 飽和温度 | 100℃ | 180℃ | 311℃ | 374℃ |
| 蒸発潜熱 | 2257 kJ/kg | 2015 | 1317 | 0 |

圧力上昇 → 沸点上昇 → 液相と気相の密度差が縮小 → 相変化に要するエネルギーが減少 → 臨界点でゼロ。Watson 式 ΔHv/ΔHv,0 = ((1−Tr)/(1−Tr,0))^0.38。高圧蒸気は単位質量あたりの熱輸送能力が低い。

C　エンタルピー　理想気体では H = H(T) のみ（(∂H/∂P)_T = 0）。実在気体では (∂H/∂P)_T = −C_P·μ_JT で、常温の大部分の気体は μ_JT>0 ゆえ圧力上昇でわずかに減少。

D　ジュール・トムソン効果（逆転温度）

μ_JT = (∂T/∂P)_H。減圧（dP****<****0）のとき**** μ_JT>0 → 降温／μ_JT<0 → 昇温。

| 気体 | 最高逆転温度 | 25℃(298K) での挙動 |
|---|---|---|
| H₂ | 約 202 K（−71℃） | 昇温 |
| He | 約 45 K | 昇温 |
| Ne | 約 250 K | 昇温 |
| N₂ / 空気 | 621 K / 603 K | 降温 |
| CH₄ / CO₂ | 968 K / 1500 K | 降温 |

T >** T逆転 → 膨張で昇温。常温で昇温するのは H₂・He・Ne の三つだけ。** 　機構：分子間引力（膨張時に引力に逆らう仕事→降温）と分子自身の体積による斥力（斥力エネルギー解放→昇温）の競合。水素・ヘリウムは分子間引力が異常に小さい（沸点 20 K、4 K）ため斥力が勝つ。 　実務：70 MPa 高圧水素の漏洩は冷えずむしろ昇温して発火リスク——水素ステーション設計の要点。LNG（CH₄）は逆に急冷して白霧。液体水素は JT 液化の前に液体窒素で 202 K 以下へ予冷が必要（空気のリンデ法が直接 JT で可能なのは逆転温度 603 K だから）。

「膨張・減圧 → 温度」の設問の判定手順：①相変化はあるか（あれば蒸発潜熱で必ず降温——スプレー缶・冷房・汗）②外部に仕事をするか（すれば断熱膨張で必ず降温）③どちらもなければ JT → 逆転温度を確認。 　陷阱：スプレー缶が冷たくなるのは中身が液化ガスで蒸発潜熱を奪うからであり、JT 効果ではない。日常経験からの類推は機構を取り違える。
