# S263　石油系芳香族（BTX）製造流程

| 步驟 | 內容 | 要點 |
|---|---|---|
| 分解系原料 | ナフサ熱分解（750〜850℃）→ 烯烴；副產分解ガソリン | 重油不用（結焦・雜質） |
| 改質系原料 | 接觸改質（Pt／Pt-Re）提高オクタン価 → リフォーメート | 環烷・烷烴脱水素（C₆H₁₂ → C₆H₆ + 3H₂）；副產 H₂ |
| 萃取 | スルホラン（高極性）向流接觸，選擇性溶解芳香族 | CCl₄ 非極性無選擇性；另有 NMP、ジエチレングリコール |
| 分離 | 蒸留（苯 80℃、甲苯 111℃、二甲苯約 140℃） | 沸點差大 → 蒸餾；量產 |

- 脫氫判斷：芳香族 H/C 最低 → 由 H 多的分子轉成芳香族必為脫氫。

- 層析法：分析（GC・HPLC）為主；工業分離用分取層析・擬似移動床（SMB）——例：p-キシレン（Parex 法，間/對二甲苯沸點差約 1℃ 無法蒸餾）。

出處：R6-Q9（關聯：第111項、第145項、第262項）
