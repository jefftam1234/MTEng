# F16　H24 有機化學：命名詞根・機制易混點

A　片假名尾音速讀

| 片假名尾 | 英文字尾 | 意義 | 例 |
|---|---|---|---|
| -エン/テン | -ene | 烯(C=C) | オクテン(辛烯) |
| -オン/ケトン | -one/ketone | 酮(C=O) | アセトン |
| -オール | -ol | 醇(-OH) | エタノール |
| -アン | -ane | 烷(飽和) | オクタン |
| -イン | -yne | 炔(C≡C) | エチン |

重點** **テン是エン(烯)的連音變化，不是酮！オクト+エン→オクテン。記法：アルデヒド(醛)→アルドース(醛糖)、ケトン(酮)→ケトース(酮糖)，字首一致好記。

B　KMnO₄酸性氧化裂解（逆推烯烴結構）

| 雙鍵碳原本連接 | 氧化後產物 |
|---|---|
| =CH₂(末端,2個H) | → CO₂+H₂O(完全氧化) |
| =CH–(1個H,鏈中) | → –COOH(羧酸) |
| =CR₂(0個H,全取代) | → 酮 |

重點** **逆推流程：①產物碳數相加=原分子碳數(裂解不增不減碳)②CO₂代表末端=CH₂→雙鍵在末端③羧酸代表=CH–。與O₃分解(得醛/酮)機制類似但KMnO₄氧化力更強(末端直接到CO₂/羧酸，不停在醛)。

C　芳香族取代位置不變** + ****重氮化正確試劑**

鐵則：氧化/還原/取代反應通常不改變取代基在環上的位置(p-キシレン氧化→テレフタル酸(對位)，不是イソフタル酸(間位))。

重氮化(ジアゾ化)正確試劑：ArNH₂ + NaNO₂ + 稀酸(H₂SO₄/HCl皆可,提供H⁺) → 低溫 → ArN₂⁺。酸的作用是把NaNO₂轉成HNO₂/NO⁺，不需要HX(鹵酸)——HX是重氮鹽生成『之後』做Sandmeyer反應(換成Ar-X)才用到，是下一步。

D　SN2：機制(協奏) ≠ 可逆性（獨立兩軸）

| 概念 | 在講什麼 | 與SN2的關係 |
|---|---|---|
| 協奏(concerted) | 怎麼發生：斷鍵成鍵同時、一個過渡態、無中間體 | SN2是協奏一步 ✓ |
| 可逆/不可逆 | 能不能反向：取決熱力學/逆反應活化能 | SN2原則上可逆！ |

重點** **陷阱：『一步反應』不等於『不可逆』，兩者是獨立的軸！例：I⁻+CH₃Br⇌CH₃I+Br⁻ 可雙向走SN2。其餘SN2性質：二分子(bimolecular,rate=k[Nu][substrate])、立體特異(背面進攻→構型反轉Walden inversion)、離去能力I⁻>Br⁻>Cl⁻>F⁻(C-X鍵弱、陰離子穩定)。

E　糖類（醣類）核心術語配對

| 術語 | 意義 | 別搞混 |
|---|---|---|
| アルドース | 含醛基(–CHO)的糖 | vs ケトース |
| ケトース | 含酮基(C=O在鏈中)的糖 | vs アルドース |
| ヘミアセタール | 半縮醛，可逆開環→有還原性 | vs アセタール |
| アセタール | 全縮醛，醛基鎖死→無還原性 | vs ヘミアセタール |
| アノマー | 環化生成的α/β端基異構物，會平衡互變(變旋) | vs エナンチオマー |
| エナンチオマー | 整分子鏡像對映異構物，不會自發平衡互變 | vs アノマー |

重點** **碳水化合物根本定義：ポリヒドロキシカルボニル化合物(多羥基+一個羰基)。ミュータロテーション(變旋)＝アノマー平衡，不是エナンチオマー平衡、也不是エノール平衡。トレンス試薬(銀鏡)氧化的是游離醛基，アセタール鎖死醛基故不還原。這五組陷阱都是『定義配對錯誤』型，抓住哪兩個概念被調換即可判。
