# S220　Levenspiel 圖：CSTR／PFR 的選擇與組合

PFR 容積＝1/(−r_A) 曲線下面積；CSTR 容積＝Δx × 出口的 1/(−r_A)（長方形）。1/(−r) 下降段用 CSTR，上升段用 PFR。

| 速率對 x 的變化 | 1/(−r) 曲線 | 容積最小 |
|---|---|---|
| 一路下降（正級數，一般反應） | 一路上升 | PFR |
| 不變（零級） | 水平 | PFR＝CSTR |
| 一路上升（負級數） | 一路下降 | CSTR |
| 先升後降（自觸媒） | U 字形 | CSTR 停在最低點 → 接 PFR |

- 自觸媒例：乙酸甲酯水解，生成的乙酸為酸觸媒，−r_A＝k·C_A·C_乙酸 → 初期慢、x≈0.45 最快、後期原料不足再變慢。

- R3-Q30 估算（V/F_A0）：①CSTR 16.0、②PFR 13.2、③PFR→CSTR 15.2、④CSTR→PFR 5.4＋5.0＝10.4（最小）、⑤CSTR→CSTR 12.4。

- 一次反應 x＝0.9：PFR kτ＝ln10＝2.30、CSTR kτ＝0.9/0.1＝9.0 → CSTR 約 3.9 倍；CSTR 串聯台數 N→∞ 趨近 PFR。
