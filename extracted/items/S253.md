# S253　蛍石型 vs ペロブスカイト型

|  | 蛍石型 CaF₂ | ペロブスカイト型 ABO₃ |
|---|---|---|
| 骨架 | Ca²⁺ 面心立方 | A²⁺＋O²⁻ 立方最密充填 |
| 空隙 | F⁻ 佔全部四面體空隙 | B⁴⁺ 佔八面體空隙（體心） |
| 配位數 | Ca 8、F 4 | A 12（頂點）、B 6（體心） |
| 晶胞離子數 | 12 | 5 |
| 代表 | CaF₂、ZrO₂、UO₂、CeO₂ | BaTiO₃、PZT、SrTiO₃ |

- 配位數判位置：體心到 6 個面心＝6 配位；頂點到 12 個面心＝12 配位 → 小離子體心、大離子頂點。

- 安定化 ZrO₂：Ca²⁺/Y³⁺ 取代 → 氧空位 → O²⁻ 擴散（Zr⁴⁺ 不動）→ 氧感測器・SOFC。

- 容許因子 t＝(r_A＋r_O)/[√2(r_B＋r_O)]；t≠1 → 正方・斜方・菱面體（BaTiO₃ 室溫正方晶＝自發極化）。
