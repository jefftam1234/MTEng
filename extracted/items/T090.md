# T090　結晶欠陥の分類：フレンケル vs ショットキー

出處：H27-Q23

維度分類（骨架）：

| 維度 | 名稱 | 例 |
|---|---|---|
| 0 点欠陥 | 点欠陥 | 空孔、格子間原子、置換原子 |
| 1 線欠陥 | 線欠陥 | 転位（唯一） |
| 2 面欠陥 | 面欠陥 | 結晶粒界、積層欠陥 |
| 3 体欠陥 | 体欠陥 | 空隙、析出物 |

点欠陥の二子類（本題核心）：

|  | フレンケル欠陥 | ショットキー欠陥 |
|---|---|---|
| 機制 | イオンが格子点→格子間へ移動（搬家） | 陽・陰イオンが対で結晶外へ（離職） |
| 生成物 | 空孔＋格子間イオン | 陽空孔＋陰空孔＝空孔対 |
| 原子總數 | 不變 | 減少（密度略降） |
| 易發生 | 陰陽半径差大（AgBr, AgCl） | 陰陽半径近い（NaCl, KCl） |

陷阱：フレンケル的正確配對是「空孔＋格子間イオン」，不是「格子間イオン対」（④把「格子間」與「対」錯拼——「対」是ショットキー才有的特徵）。 偵測法：並列的兩個分類，檢查特徵詞有無交叉污染。
