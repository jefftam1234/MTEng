# S076　石油物性:受組成影響大小的分野與低溫流動性用語

比熱容量幾乎不受組成影響(約1.9–2.1 kJ/(kg·K),主要隨溫度變),是石油物性中的特例;密度、粘度則受組成影響極大。

| 性質 | 日本語 | 受組成影響 | 要點 |
|---|---|---|---|
| 比熱 | 比熱容量 | 小 | 各餾分皆約2.0 kJ/(kg·K);熱平衡計算可直接取此值 |
| 密度 | 密度 | 大 | パラフィン<ナフテン<芳香族;溫度↑→膨脹→密度↓ |
| 黏度 | 粘度 | 大 | 用動粘度ν=μ/ρ表示 |
| 電導度 | 電気伝導度 | 小 | 極低→トランス・ケーブルの絶縁油 |
| 用語 | 日本語 | 定義 |  |
| 濁點 | 曇り点 | 冷卻時蠟開始析出、油變白濁的溫度(仍可流動) |  |
| 冷濾點 | 目詰まり点(CFPP) | 燃料通過標準濾網開始堵塞的溫度(介於兩者間) |  |
| 流動點 | 流動点 | 規定條件下試料仍能流動的最低溫度 |  |

溫度關係固定:曇り点** ****>**** ****目詰まり点**** ****>**** ****流動点**。字面線索:「曇る=變濁」只講外觀,與能否流動無關;把「流動する最低の温度」稱為曇り点即為定義張冠李戴。

密度判準:同碳數下H/C比越低→密度越大(芳香族最低H/C故最重)。同一判準亦適用於質量發熱量(H/C高則高)與煤煙生成傾向(芳香族多則易生煤煙)。

三語錯亂警告:日文「絶対粘度」=中文動力黏度=English dynamic/absolute viscosity(Pa·s);日文「動粘度」=運動黏度=kinematic viscosity(m²/s)。日文的「動」對應kinematic而非dynamic。石油業慣用動粘度,因細管黏度計直接測得ν。

錯誤類型辨識:本題屬「定義配對錯位」——敘述內容本身正確但掛在錯誤術語名下。讀到「〜をAと呼ぶ」「Aとは〜である」句型時,須分開檢查「定義內容對不對」與「這定義是否屬於這個名字」。與第32項碳水化合物定義配對陷阱同型。

出處：H28-Q9、H30-Q9（第144項＝n/iso の方向一覧）
