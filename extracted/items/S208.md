# S208　エナミン（烯胺）與 Stork 反應

烯胺 N–C1=C2 的親核碳是 C2（離 N 兩個原子＝原酮的 α 碳），與烯醇鹽 O⁻–C=C 同一模式。

共振式：N–C1=C2 ↔ N⁺=C1–C2⁻　→ C1 是亞胺離子碳（親電），C2 帶負電（親核）。

流程：酮 + 二級胺（ピロリジン等）→ 烯胺 → α,β-不飽和羰基化合物的 β 碳 Michael 加成 → 亞胺離子 → 水解 → 2-取代酮。

|  | エノラート（烯醇鹽） | エナミン（烯胺） |
|---|---|---|
| 電荷 | 陰離子 | 中性 |
| 製備 | LDA 等強鹼、低溫、無水 | 酮 + 二級胺，酸催化脫水 |
| 處理 | 對水・空氣敏感 | 穩定、易處理 |
| 烷基化 | 易多重烷基化 | 單烷基化選擇性高 |

- 陷阱 1：「與 N 相連的 sp² 碳是親核中心」→ 錯（C1 是親電端）。

- 陷阱 2：「N 孤對電子與 p 軌道重疊使 C2 電子密度減少」→ 錯（應為增加）。

- 陷阱 3：產物酯基種類必須對照（產物 –CO₂CH₃ ⇒ 用丙烯酸甲酯，不是乙酯）。

- アクロレイン・丙烯酸酯・MVK 都是 Michael 受體，皆會反應。

出處：R3-Q3
