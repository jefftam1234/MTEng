# S119　工程塑膠（エンプラ）的判準：苯環或強分子間力→耐熱

判準：有苯環（剛直）或強分子間力（氫鍵）→ 耐熱 → 工程塑膠。

| 高分子 | 耐熱來源 | 分類 |
|---|---|---|
| PBT | テレフタレート 苯環 | 工程塑膠 |
| ナイロン66 | 醯胺鍵氫鍵（熔點約265℃） | 工程塑膠 |
| PC | 雙酚A 苯環（剛直、T_g約150℃） | 工程塑膠 |
| PPS | フェニレン 苯環＋S | 超級工程塑膠（連續使用150℃以上） |
| POM | 高結晶度（熔點約175℃） | 工程塑膠（例外：脂肪族聚醚） |
| PEG | 無（柔軟、熔點約60℃、水溶） | 非工程塑膠 |

五大汎用工程塑膠：PA（尼龍）、POM、PC、m-PPE、PBT。超級工程塑膠：PPS、PEEK、PI 等。 　PEG 的辨識線索：名稱中「グリコール（二醇）」即暗示水溶性小分子系列。主鏈無苯環、無強分子間力，低分子量者為液體，用途為化妝品・醫藥添加劑・界面活性劑，非結構材料。 　陷阱：不可簡化為「聚醚＝非工程塑膠」，POM 是反例（同為脂肪族聚醚卻因結晶度極高而列入五大）。

出處：H29-Q19（關聯：H24-Q16、H26-Q19＝第51項 PBT/PET 結晶速度、Kevlar/Nomex）
