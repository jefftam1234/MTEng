# S270　分子量測定：絕對法／相對法與各平均分子量

判據：需不需要已知分子量的標準品（不需要＝絕對法）。

| 方法 | 分類 | 平均分子量 |
|---|---|---|
| 依數性（滲透壓・VPO・沸點上升・凝固點下降） | 絕對 | Mn |
| NMR 末端基定量 | 絕對 | Mn（積分比先除以質子數） |
| 光散射（Zimm 圖） | 絕對 | Mw（另得 Rg、A₂） |
| 沉降平衡（超離心） | 絕對 | Mz |
| SEC／GPC | 相對（PS 標準品） | Mn・Mw・分布 |
| 固有黏度（Mark-Houwink [η]＝KMᵃ） | 相對（K、a 需絕對法求） | Mv |

- Mv＝[ΣNᵢMᵢ^(1+a)／ΣNᵢMᵢ]^(1/a)，a 約 0.5〜0.8；Mn ≤ Mv ≤ Mw ≤ Mz。

- 易錯：NMR 訊號是相對強度 ≠ 相對法。
