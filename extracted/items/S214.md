# S214　共聚組成曲線與 r₁・r₂

r₁＝k₁₁/k₁₂＝M₁ 末端「接自己 ÷ 接對方」。F₁（縱軸，共聚物中 M₁）vs f₁（橫軸，投料中 M₁）。

| 曲線 | r₁・r₂ | 特徵 |
|---|---|---|
| 對角線 | r₁＝r₂＝1 | 理想（無規），F₁＝f₁ |
| F₁＝0.5 水平線 | r₁＝r₂＝0 | 完全交互（例：苯乙烯／馬來酸酐） |
| F₁ 上限 0.5 | r₁＝0、r₂ < 1 | M₁ 不會連續 |
| S 形、與對角線交叉 | r₁ < 1、r₂ < 1 | 交互傾向；只在共沸點 F₁＝f₁ |
| 整條在對角線上方 | r₁ > 1、r₂ < 1 | 富含 M₁ |
| 整條在對角線下方 | r₁ < 1、r₂ > 1 | 富含 M₂ |

驗算（f₁＝0.5）：r₁＝5、r₂＝0.2 → d[M₁]/d[M₂]＝(1+5)/(1+0.2)＝5 → F₁＝5/6＝0.83（上方）。

- 日文陷阱：「必ずしも一致しない」＝「不一定一致」，不是「一定不一致」。
