# T088　元素存在量：宇宙 vs 地殻 vs 人体（語境不可錯置）

出處：H27-Q21

| 排名 | 宇宙（原子比） | 地殻（質量比） | 人体（質量比） |
|---|---|---|---|
| 1 | H（約90%） | O（約46%） | O |
| 2 | He（約9%） | Si（約28%） | C |
| 3 | O | Al | H |
| 4 | C | Fe | N |

三語境第一名各異：宇宙＝H、地殼＝O、人体＝O。看到「〇〇に次いで存在量が多い」先確認語境。 陷阱：把地殼「O>Si」的排序錯置到宇宙（宇宙是 H>He，H 自己就是第一多，Si 排很後）。

水素の基本（純背誦，配合推理）： - 同位体 3 種：¹H(プロチウム,99.98%)／²H=D(ジュウテリウム,重水素)／³H=T(トリチウム,放射性,半減期約12.3年) - 重水 D₂O：沸點101.4°C、原子炉の減速材（D 中子吸收截面小） - パラジウム(Pd) 吸蔵水素：1 體積 Pd 吸約900倍體積 H₂（水素吸蔵合金、氫純化膜） - オルソ/パラ水素：兩質子核スピン 平行(ortho,常溫75%)/反平行(para,低溫穩定)；液化氫貯存需先觸媒轉 para 防蒸發
