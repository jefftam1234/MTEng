# S143　一次エネルギー と 二次エネルギー の分類

判準：自然界から採り出したそのままの形か（一次）、人為的な転換・加工を経たか（二次）。

| 一次エネルギー | 二次エネルギー |
|---|---|
| 原油（石油）、石炭、天然ガス | 電力（最も典型的） |
| ウラン（核燃料） | ガソリン、灯油、軽油、重油、ナフサ（原油の精製） |
| 太陽光・太陽熱、風力、水力、地熱、潮力 | LPガス（天然ガス分離または原油精製） |
| バイオマス（自然界の有機物そのもの） | 都市ガス（LNG の熱量調整＋付臭） |
| — | コークス、コールタール、石炭ガス（石炭の乾留） |
| — | 水素（水蒸気改質・電解）、バイオエタノール（発酵・蒸留） |

頻出の対（原料 vs 製品）

石炭は一次、コークスは二次——コークスは石炭を空気遮断下 1000℃ で乾留して作る。副産物のコールタール（ベンゼン・ナフタレン・アントラセン・フェノールの伝統的原料）、石炭ガス、アンモニア水もすべて二次。高炉では還元剤兼熱源。

原油は一次、ガソリン・灯油・重油・ナフサはすべて二次。統計上の「石油」は原油を指す。

天然ガスは一次、都市ガス・LPガスは二次。

バイオマスは一次、バイオエタノールは二次。

水素は「二次エネルギー」であり「エネルギーキャリア」——次世代エネルギーとして宣伝されるが、定義上は電力と同類の運搬・貯蔵媒体。近年出題頻度が上昇。
