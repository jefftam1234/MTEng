# F01　試劑 → 反應類型（核心框架）

| 試劑（日／英） | 反應類型 | 受質** → ****產物** | 備註 |
|---|---|---|---|
| グリニャール試薬　RMgX（Grignard） | 求核加成 | 醛→二級醇；酮→三級醇；HCHO→一級醇；CO₂→羧酸；エステル→三級醇 | 無水必須；酸處理後得醇 |
| 有機リチウム　RLi | 求核加成 | 同 Grignard，反應性更強；可加成受阻羰基 | 強鹼性 |
| Wittig 試薬　Ph₃P=CHR（ウィッティッヒ） | 烯化（オレフィン化） | 羰基 C=O → C=C（醛/酮 變烯烴） | 把「酮→烯」的標準法 |
| LiAlH₄　水素化アルミニウムリチウム | 強還元 | 醛/酮→醇；羧酸/エステル/アミド→醇或胺 | 強力；連羧酸都還原 |
| NaBH₄　水素化ホウ素ナトリウム | 溫和還元 | 醛/酮 → 醇（不還原羧酸/エステル） | 選擇性；質子溶劑可用 |
| OsO₄　四酸化オスミウム | syn 二羥基化 | 烯 → cis-1,2-二醇 | 亜硫酸水素Na後處理 |
| KMnO₄　過マンガン酸カリウム | 冷稀=syn diol／熱濃=開裂 | 冷稀鹼性→cis-diol；熱濃→C=C 切斷成羧酸/酮 | 條件決定產物 |
| 過酸** mCPBA / ****過酢酸**　過安息香酸類 | 環氧化（syn） | 烯 → エポキシド；再水解得 trans-diol | 開環為背面(anti) |
| O₃　オゾン（オゾン分解） | C=C 切斷 | 還元後処理(Zn/Me₂S)→醛/酮；酸化後処理(H₂O₂)→羧酸/酮 | 環內雙鍵→開環 |
| Br₂ / Cl₂　臭素/塩素 | anti 加成 | 烯 → trans-1,2-二鹵化物 | ハロニウムイオン中間體 |
| Br₂ / 醋酸（對酮） | α-鹵化 | 酮的 α位 H → Br（等莫耳控制單溴化） | 酸催化エノール化 |
| H₂ / 觸媒　Pd, Pt, Ni | syn 加成 | 烯/炔 → 烷（同側加 H） | 接觸還元 |

重點** **這場對話出現的④題陷阱：想還原酮成醇卻用「水酸化アルミニウム Al(OH)₃」——那是氫氧化物，無還原力。正解須用 LiAlH₄ 或 NaBH₄。
