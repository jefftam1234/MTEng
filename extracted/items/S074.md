# S074　協同機制 vs 分步機制自檢表(SN1／SN2／E1／E2)

機制題最高頻陷阱是「把分步機制的特徵安給協同機制」。看到SN2/E2,立刻掃描敘述中有無「段階的」「中間体」「カルボカチオン」「自発的開裂」「先に〜してから」等分步用語;出現即錯。反之SN1/E1敘述若寫「協奏的」「一段階」亦錯。

| 檢查軸 | SN1 / E1 | SN2 / E2 |
|---|---|---|
| 步驟 | 分步,有カルボカチオン中間體 | 協奏的,一個過渡態無中間體 |
| 速率式 | 一級(只依基質) | 二級(依基質+親核種/鹼) |
| 基質偏好 | 三級 > 二級 > 一級 | 甲基 > 一級 > 二級 ≫ 三級 |
| 立體化學 | ラセミ体(平面碳陽離子兩面等機率) | SN2反転(Walden);E2需アンチペリプラナー |
| 試劑條件 | 弱親核種/弱鹼、質子性溶劑 | 強親核種/強鹼、非質子性極性溶劑 |

高頻誤述範例①:「E2反応は炭素–臭素結合の自発的開裂から始まる」→錯,那是E1。E2為鹼奪β-H與C–X斷裂同時發生。佐證:一級基質(如PhCH₂CH₂Br)的碳陽離子極不穩定,E1物理上也不可能。

高頻誤述範例②:「SN2反応はラセミ体の生成物を与える」→錯,外消旋化是SN1的標誌;SN2給單一反轉產物,光學活性保留但構型翻轉。

アルドール反応酸触媒でも進行する→正確,不可直覺判錯。鹼催化生成エノラート(提升親核種活性);酸催化生成中性エノール並質子化羰基氧(提升親電種活性)。酸性條件下常直接脫水得エノン。

通則:凡經エノール/エノラート中間體的反應(アルドール、α-鹵化、Michael付加),酸鹼兩種催化通常皆可行。

Diels-Alder=協奏的[4+2]環化付加(ペリ環状反応)的典型例;α,β-不飽和カルボニル化合物是標準的マイケルアクセプター(β碳因共軛帶部分正電,親核種行1,4-共役付加)。

與第39項SN2「機制(協奏)≠可逆性」併讀。
