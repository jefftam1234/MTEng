# S046　高分子命名速算法：尼龍XY數碳原子、脫小分子判斷反應類型

尼龍XY命名不需死背：X=二胺中間碳鏈碳數，Y=二酸兩端COOH碳+中間碳鏈碳數之和。單體制內醯胺開環聚合只給一個數字(如尼龍6，環上碳數)，命名邏輯與雙體制尼龍(二胺+二酸)不同。

| 反應類型判準(延續H25-Q14) | 本題對應實例 |
|---|---|
| 重縮合(脫小分子：水/HCl) | 己二胺+己二酸→尼龍66(脫水)；雙酚A+光氣→聚碳酸酯(脫HCl) |
| 重付加(無小分子脫離) | 二異氰酸酯+二醇→聚胺酯 |
| 開環聚合(環張力驅動) | 己內醯胺+NaH，陰離子開環聚合→尼龍6 |
| 自由基連鎖聚合(乙烯基單體) | MMA+AIBN→PMMA |

*出處：**H26-Q15*
