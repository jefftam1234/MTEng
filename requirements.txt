# Python requirements for this repository.
#
# All scripts in .codex/skills/gijutsushi-study-guide/scripts/ use only the Python standard library
# (Python >= 3.9; developed on 3.12). `pip install -r requirements.txt` is therefore a no-op.
# Run scripts with `python -X utf8 ...` on Windows (console is cp1252).
#
# Optional, for skill validation only (global skill-creator quick_validate.py):
#   pyyaml>=6.0
#
# Non-Python system requirements (not installable with pip):
#   - XeLaTeX via MiKTeX or TeX Live, with packages: extarticle (extsizes), xeCJK, fontspec, mhchem,
#     chemfig, pgfplots/tikz, tcolorbox, adjustbox, colortbl, tabularx, booktabs, enumitem, fancyhdr,
#     newunicodechar, needspace, hyperref, amssymb
#   - Fonts: PMingLiU, Microsoft JhengHei, MS Mincho, Yu Gothic, Times New Roman, Arial, Consolas
#     (Windows system fonts; elsewhere substitute Noto Serif/Sans TC and JP in latex/preamble.tex)
#   - pdftoppm (Poppler; bundled with MiKTeX) for `build.py --png` previews
#   - Optional: git and GitHub CLI (gh) for publishing
